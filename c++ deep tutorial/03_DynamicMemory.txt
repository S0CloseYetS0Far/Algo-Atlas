## Chapter Overview

Memory management is one of the most important skills in C++ programming. Unlike
garbage-collected (GC) languages such as Java and Python, C++ hands full control
of memory management to the programmer. This means you can precisely control object
lifetimes and memory layout, but you are also responsible for freeing memory that
is no longer in use at the right time.

This chapter starts from the operating system's low-level memory model and digs into
the physical differences between the stack and the heap, the internal implementation
of malloc/free, how new/delete work, the smart pointer family introduced in C++11,
and advanced topics such as memory pools. Through five carefully designed practical
examples, ranging from a simple dynamic array to a complex RAII matrix class, you
will progressively master every skill of dynamic memory management in C++.

This chapter incorporates material from Chapter 1 (namespaces) and Chapter 2
(preprocessor/macros), showing how all three chapters work together.

3.1 new / delete Basic Syntax
----------------------------

C++ provides the `new` and `delete` operators for dynamically allocating and freeing memory on the heap:

```cpp
#include <iostream>

struct Point {
    int x, y;
    Point(int a, int b) : x(a), y(b) {
        std::cout << "Point(" << x << ", " << y << ") constructed" << std::endl;
    }
    ~Point() {
        std::cout << "Point(" << x << ", " << y << ") destroyed" << std::endl;
    }
};

int main() {
    // 1. Allocate a single object
    int* pInt = new int(42);
    std::cout << "*pInt = " << *pInt << std::endl;
    delete pInt;

    // 2. Allocate an array
    int* arr = new int[10];
    for (int i = 0; i < 10; ++i) arr[i] = i * 10;
    std::cout << "arr[5] = " << arr[5] << std::endl;
    delete[] arr;  // use delete[] for arrays

    // 3. Allocate an object with a constructor
    Point* pt = new Point(10, 20);
    pt->x += 5;
    std::cout << "pt->x = " << pt->x << std::endl;
    delete pt;

    // 4. Allocate an array of objects (requires a default constructor)
    Point* pts = new Point[3]{{1, 2}, {3, 4}, {5, 6}};
    delete[] pts;

    return 0;
}
```

Key rules:
- The `new` operator does two things: (1) calls operator new to allocate raw memory (2) calls the constructor on the allocated memory
- The `delete` operator does two things: (1) calls the destructor (2) calls operator delete to free the raw memory
- Use `new` / `delete` for single objects and `new[]` / `delete[]` for arrays; **never mix them**
- Memory allocated with `new` must be freed with `delete`, otherwise you get a memory leak

3.2 Differences Between malloc / free and new / delete
-------------------------------------------------------

C uses `malloc` / `free` for memory management, while C++ provides `new` / `delete`. The two
are fundamentally different:

```cpp
#include <iostream>
#include <cstdlib>  // malloc, free
#include <cstring>  // memset

class MyClass {
public:
    MyClass(const char* s) {
        std::cout << "MyClass constructed: " << s << std::endl;
    }
    ~MyClass() {
        std::cout << "MyClass destroyed" << std::endl;
    }
};

int main() {
    // 1. Allocate a fundamental type
    int* pMalloc = (int*)std::malloc(sizeof(int));  // size must be computed manually
    *pMalloc = 100;
    std::cout << "*pMalloc = " << *pMalloc << std::endl;
    std::free(pMalloc);

    int* pNew = new int(200);  // size computed automatically, can be initialized directly
    std::cout << "*pNew = " << *pNew << std::endl;
    delete pNew;

    // 2. Allocate an array
    int* arrMalloc = (int*)std::malloc(10 * sizeof(int));
    std::memset(arrMalloc, 0, 10 * sizeof(int));  // zero it manually
    std::free(arrMalloc);

    int* arrNew = new int[10]{};  // value-initialized, all elements are 0
    delete[] arrNew;

    // 3. Key difference: constructor invocation
    std::cout << "\n--- malloc does not call the constructor ---" << std::endl;
    MyClass* objMalloc = (MyClass*)std::malloc(sizeof(MyClass));
    // MyClass's constructor was NOT called! The object is uninitialized!
    // You must construct it manually with placement new:
    new (objMalloc) MyClass("from malloc");
    objMalloc->~MyClass();  // call the destructor manually
    std::free(objMalloc);

    std::cout << "\n--- new calls the constructor automatically ---" << std::endl;
    MyClass* objNew = new MyClass("from new");
    delete objNew;  // calls the destructor automatically

    return 0;
}
```

| Feature | malloc / free | new / delete |
|------|--------------|-------------|
| Origin | C standard library | C++ operator |
| Type safety | Returns void*, needs a cast | Returns a correctly typed pointer |
| Constructor | Not called | Called |
| Destructor | Not called | Called |
| Size calculation | Manual sizeof | Automatic |
| Initialization | None (indeterminate values) | Can value-initialize |
| On failure | Returns NULL | Throws std::bad_alloc |
| Overloading | Not possible | Possible (global/class level) |
| Array allocation | malloc(n * sizeof(T)) | new T[n] |

3.3 The Stack and Heap Memory Model
----------------------------------------

Understanding the difference between the stack and the heap is the key to mastering memory management:

```
High addresses
┌─────────────────────────┐
│  Cmd-line args / env vars│ ← set up by the OS at process start
├─────────────────────────┤
│         Stack           │ ← Stack: grows downward (toward low addresses)
│    ┌───────────────┐    │
│    │ Func params    │    │    Each function call creates a stack frame:
│    │ Return address │    │
│    │ Local variables│    │    - saves the return address
│    ├───────────────┤    │    - saves register values
│    │ Next frame     │    │    - stores local variables
│    │    ...        │    │    - automatic allocation/release
│    ▼               ▼    │
│                         │
│    ▲               ▲    │
│    │ Unused address space│ ← heap and stack grow toward each other
│    │               │    │
├─────────────────────────┤
│         Heap            │ ← Heap: grows upward (toward high addresses)
│  (dynamically allocated)│    - malloc/new allocate from here
│    - linked-list nodes  │    - programmer controls lifetime
│    - object instances   │    - fragmentation can occur
│    - large arrays       │
├─────────────────────────┤
│       BSS segment       │ ← uninitialized global variables
│   (static vars, etc.)   │    initial value is 0
├─────────────────────────┤
│       Data segment      │ ← initialized global variables
│ (initialized global/static)│ occupy space in the executable
├─────────────────────────┤
│       Text segment      │ ← executable code (read-only)
│ (program instructions)  │    compiled machine code of function bodies
└─────────────────────────┘
Low addresses
```

**Characteristics of the stack:**
- Last-in, first-out (LIFO) structure
- Automatic allocation and release: pushed on function call, popped on return
- Limited size (about 8MB by default on Linux, adjustable via ulimit -s)
- Extremely fast allocation: just move the stack pointer (SP register) by a few bytes
- Excellent locality, very CPU-cache friendly
- Not suitable for large objects that must outlive the function call

**Characteristics of the heap:**
- Dynamic allocation; the programmer controls the lifetime
- Size is limited almost only by physical memory + swap (about 2-3GB on 32-bit, theoretically enormous on 64-bit)
- Slower allocation: requires searching for free blocks and may involve system calls
- Can suffer from memory fragmentation
- Managed manually and error-prone (memory leaks, dangling pointers, double frees)
- Suitable for large objects or objects shared between functions

A detailed look at the process memory layout:

```cpp
// Example: verify where different variables are stored
#include <iostream>

int global_init = 42;        // Data segment
int global_uninit;           // BSS segment (automatically initialized to 0)
static int static_var = 100; // Data segment (static affects linkage, not storage location)

void test() {
    static int local_static = 999; // Data/BSS segment (lifetime = whole program run)
    int local_auto = 10;           // Stack
    int* heap_var = new int(50);   // Heap (the pointer itself is on the Stack)

    std::cout << "Global initialized: " << &global_init << std::endl;
    std::cout << "Global uninitialized: " << &global_uninit << std::endl;
    std::cout << "Local static: " << &local_static << std::endl;
    std::cout << "Local automatic: " << &local_auto << std::endl;
    std::cout << "Heap var (pointer): " << &heap_var << std::endl;  // the pointer is on the stack
    std::cout << "Heap var (value): " << heap_var << std::endl;      // the memory is on the heap

    delete heap_var;
}

int main() {
    test();
    return 0;
}
```

3.4 How malloc / free Work Internally
-------------------------------------

malloc does not request memory from the operating system every time. It maintains an internal
**free list** to manage memory blocks that have been obtained from the OS but not yet
handed out to the user.

**Basic workflow:**

1. **Initialization:** On the first call to malloc, the allocator obtains a large chunk of memory
   (usually by extending the data segment with the brk/sbrk system calls, or by mapping an
   anonymous memory region with mmap)

2. **Handling an allocation request:** When the user calls malloc(size):
   - Add the metadata header size (usually 8-16 bytes) to the requested size, and align it to
     a suitable boundary (usually 8 or 16 bytes)
   - Walk the free list looking for a large-enough free block
     - First Fit: allocate the first block that is large enough
     - Best Fit: walk all blocks and pick the one closest to the requested size
     - Next Fit: start searching from where the last allocation left off
   - If the block is too large, split it into two (the allocated block + a remaining free block)
   - Return the address of the allocated block (skipping the metadata header) to the user

3. **Freeing:** When the user calls free(ptr):
   - Subtract the metadata header size from ptr to find the real start of the block
   - Mark the block as free
   - Check whether neighboring blocks are also free, and if so merge them (coalescing)
   - If the merged free block is large enough, the heap may be shrunk via brk (returned to the OS)

**malloc's metadata structure (simplified):**

```cpp
// Sketch of malloc's internal data structure (the real implementation is more complex)
struct malloc_chunk {
    size_t prev_size;   // size of the previous chunk (if the previous chunk is free)
    size_t size;        // size of this chunk (low bits used as flags: in use or not)
                        // size & 1 == 0 means the previous chunk is free
                        // size & 2 == 0 means this chunk was allocated by mmap
    struct malloc_chunk* fd;  // forward pointer (in the free list)
    struct malloc_chunk* bk;  // backward pointer (in the free list)
    // ... user data starts here ...
};
```

**The brk/sbrk system calls:** malloc obtains more heap memory by moving the program's
"program break" (the end of the data segment). The program break is the boundary between
the process's data segment and unallocated space.

```
Calling brk(addr) sets the program break to address addr.
Calling sbrk(increment) increases the program break by increment bytes.

When malloc's free list cannot satisfy a request:
1. If the request is below some threshold (e.g. 128KB), extend the heap with brk/sbrk
2. If the request is large, use mmap directly to allocate a separate anonymous memory region
   (advantage: on free it can be returned to the OS directly with munmap)
```

**Memory Fragmentation:**

```
Internal Fragmentation:
  The allocator hands out a block larger than requested (alignment, metadata overhead)
  e.g.: request 7 bytes → allocate 16 bytes (aligned to 8 bytes + 8-byte header)
      9 bytes wasted

External Fragmentation:
  Enough free memory exists but it is scattered, so a large contiguous request cannot be satisfied

  e.g.: free list: [8B] [16B] [8B] [16B] [8B] (56B free in total)
      Request 32B of contiguous memory → cannot be satisfied! (no contiguous 32B free block)
      Even though total free memory 56B > 32B, it is scattered.
```

```cpp
// Simulating how external fragmentation arises (conceptual code)
#include <iostream>
#include <cstdlib>
#include <cstring>

void demonstrateFragmentation() {
    const int BLOCK_COUNT = 5;
    void* blocks[BLOCK_COUNT];

    std::cout << "=== Memory Fragmentation Demo ===" << std::endl;

    // Allocate five 1KB blocks (they are usually contiguous)
    for (int i = 0; i < BLOCK_COUNT; ++i) {
        blocks[i] = std::malloc(1024);
        std::cout << "Block " << i << ": " << blocks[i] << std::endl;
        std::memset(blocks[i], 0, 1024);  // write data to make sure it is physically allocated
    }

    std::cout << "\nFreeing blocks 1, 3 and 5 (alternating):" << std::endl;
    std::free(blocks[0]);  // free alternating blocks
    std::free(blocks[2]);
    std::free(blocks[4]);

    std::cout << "Free memory is now scattered across 3 places (external fragmentation)" << std::endl;
    std::cout << "What happens if we now request 2KB of contiguous space?" << std::endl;

    // Try to allocate a larger block
    void* bigBlock = std::malloc(2048);
    std::cout << "Big block address: " << bigBlock << std::endl;
    // This big block may be between the fragments, or somewhere else entirely
    std::free(bigBlock);

    // Free the remaining blocks
    std::free(blocks[1]);
    std::free(blocks[3]);

    std::cout << "After freeing everything, if adjacent blocks are merged they become one large contiguous free block again" << std::endl;
}

int main() {
    demonstrateFragmentation();
    return 0;
}
```

3.5 The Low-Level Implementation of new: operator new → malloc → brk/mmap
-------------------------------------------------------------------------

Under the hood, a C++ `new` expression goes through several layers of calls:

```
new T(args)
  │
  ├──► Step 1: call void* operator new(sizeof(T))
  │       │
  │       ├──► call malloc(sizeof(T))
  │       │     │
  │       │     ├──► search the internal free list
  │       │     ├──► not found → call brk() / mmap() to request memory from the OS
  │       │     └──► return a raw memory pointer
  │       │
  │       ├──► if malloc returns NULL
  │       │     │
  │       │     ├──► call the new_handler function (if one is set)
  │       │     ├──► retry the allocation
  │       │     └──► cannot allocate → throw std::bad_alloc
  │       │
  │       └──► return a raw memory pointer
  │
  └──► Step 2: call T's constructor on the returned memory
       │     (placement new: new (ptr) T(args))
       │
       └──► return a pointer of type T*
```

```cpp
// Verifying new's low-level call chain (by overloading operator new)
#include <iostream>
#include <cstdlib>

class Tracker {
public:
    int id;

    Tracker(int i) : id(i) {
        std::cout << "  → Tracker::constructor(id=" << id << ")" << std::endl;
    }

    ~Tracker() {
        std::cout << "  → Tracker::destructor(id=" << id << ")" << std::endl;
    }

    // Overload the class's operator new
    static void* operator new(std::size_t size) {
        std::cout << "[operator new] requesting " << size << " bytes" << std::endl;
        void* ptr = std::malloc(size);
        if (!ptr) throw std::bad_alloc();
        std::cout << "  got address: " << ptr << std::endl;
        return ptr;
    }

    // Overload the class's operator delete
    static void operator delete(void* ptr) noexcept {
        std::cout << "[operator delete] freeing address: " << ptr << std::endl;
        std::free(ptr);
    }
};

int main() {
    std::cout << "Executing: auto t = new Tracker(42);" << std::endl;
    auto t = new Tracker(42);
    // Output order:
    // [operator new] requesting 4 bytes
    //   got address: 0x...
    //   → Tracker::constructor(id=42)
    // returned to main: t = 0x...

    std::cout << "\nExecuting: delete t;" << std::endl;
    delete t;
    // Output order:
    //   → Tracker::destructor(id=42)
    // [operator delete] freeing address: 0x...

    return 0;
}
```

**operator new's failure-handling mechanism:**

When malloc returns nullptr, operator new does not throw immediately; instead it calls the
user-installed new_handler function (registered via std::set_new_handler). The new_handler can:
1. Free some memory and return (operator new will retry malloc)
2. Throw an exception
3. Call abort() / exit() to terminate the program
4. Simply return (operator new will keep retrying)

```cpp
#include <iostream>
#include <new>  // std::set_new_handler, std::bad_alloc

// Custom new_handler
void myNewHandler() {
    std::cerr << "Out of memory! Trying to clean up..." << std::endl;
    // In a real project you would free caches, write logs, etc. here
    // If no more memory can be freed, throw bad_alloc
    throw std::bad_alloc();
}

int main() {
    // Install a new new_handler and save the old one
    std::new_handler oldHandler = std::set_new_handler(myNewHandler);

    try {
        // Try to allocate a huge amount of memory (will fail)
        auto huge = new char[30ULL * 1024 * 1024 * 1024]; // 30 GB
        delete[] huge;
    } catch (const std::bad_alloc& e) {
        std::cerr << "Caught bad_alloc: " << e.what() << std::endl;
    }

    // Restore the original new_handler
    std::set_new_handler(oldHandler);

    return 0;
}
```

3.6 Pointer Arithmetic and Visualizing Memory Addresses
-------------------------------------------------------

Understanding what a pointer really is means understanding memory addresses. A pointer's value is simply a memory address.

```cpp
#include <iostream>
#include <iomanip>

int main() {
    // Array on the stack (contiguous memory)
    int arr[5] = {10, 20, 30, 40, 50};

    std::cout << "=== Stack Array Memory Layout ===" << std::endl;
    for (int i = 0; i < 5; ++i) {
        std::cout << "arr[" << i << "] = " << arr[i]
                  << "  address: " << &arr[i]
                  << " (offset: +" << i * sizeof(int) << " bytes)"
                  << std::endl;
    }

    // Pointer arithmetic
    int* p = arr;  // p points to arr[0]
    std::cout << "\n*p = " << *p << std::endl;        // 10
    std::cout << "*(p+1) = " << *(p + 1) << std::endl; // 20
    std::cout << "*(p+2) = " << *(p + 2) << std::endl; // 30
    // p + n is equivalent to (char*)p + n * sizeof(int)

    // Array on the heap
    int* heapArr = new int[5]{100, 200, 300, 400, 500};

    std::cout << "\n=== Heap Array Memory Layout ===" << std::endl;
    for (int i = 0; i < 5; ++i) {
        std::cout << "heapArr[" << i << "] = " << heapArr[i]
                  << "  address: " << &heapArr[i]
                  << std::endl;
    }

    delete[] heapArr;

    // Subtracting pointers gives the difference in element count
    int* p1 = &arr[1];
    int* p2 = &arr[4];
    std::cout << "\np2 - p1 = " << (p2 - p1) << " elements" << std::endl;

    // Illustrating memory bounds
    std::cout << "\n=== Memory Span ===" << std::endl;
    std::cout << "Total bytes occupied by the array: "
              << (char*)(&arr[4] + 1) - (char*)(&arr[0])
              << " bytes" << std::endl;

    return 0;
}
```

4.1 The new Operator (Allocating a Single Object)

```cpp
// Basic usage
int* p1 = new int;           // uninitialized (indeterminate value)
```

4.2 The new[] Operator (Allocating Arrays)
------------------------------------------

```cpp
// Allocating arrays of fundamental types
int* arr1 = new int[10];           // uninitialized
int* arr2 = new int[10]();         // value-initialized to 0
int* arr3 = new int[10]{};         // value-initialized to 0
int* arr4 = new int[10]{1,2,3};    // first 3 are 1,2,3, the rest are 0

// Allocating arrays of objects (requires a default constructor)
class Foo {
public:
    Foo() { std::cout << "Foo()" << std::endl; }
    Foo(int x) { std::cout << "Foo(" << x << ")" << std::endl; }
};

Foo* foos1 = new Foo[5];                  // 5 default constructions
Foo* foos2 = new Foo[3]{Foo(1), Foo(2)};  // first 2 with arguments, the 3rd default

// Multidimensional arrays (C++11 lets you use auto)
int (*matrix)[5] = new int[3][5];  // 3 rows, 5 columns
// Free it
delete[] matrix;

// Use auto to simplify multidimensional arrays
auto matrix2 = new int[3][5];      // C++11
delete[] matrix2;
```

**The "hidden counter" when new[] allocates an array:**

When you use new T[n] to allocate an array of objects that have a destructor, the compiler usually
stores the element count **before** the returned pointer, so that delete[] knows how many times to call the destructor:

```
Actual memory layout (when the objects have a destructor):
┌──────────────┬──────────┬──────────┬─────┬──────────┐
│ element cnt n│ object[0]│ object[1]│ ... │object[n-1]│
│  (size_t)    │          │          │     │          │
└──────────────┴──────────┴──────────┴─────┴──────────┘
       ↑              ↑
       │              └── pointer returned by new[]
       └── allocator's internal pointer

If T has no destructor (trivially destructible), the compiler may
not store this counter, to save space.
```

4.4 placement new
------------------------------

Constructs an object on already-allocated raw memory, without allocating new memory.

```cpp
#include <iostream>
#include <new>  // placement new

class Object {
public:
    int x, y;
    Object(int a, int b) : x(a), y(b) {
        std::cout << "constructed(" << a << "," << b << ")" << std::endl;
    }
    ~Object() {
        std::cout << "destroyed(" << x << "," << y << ")" << std::endl;
    }
};

int main() {
    // Allocate raw memory (no constructor is called)
    void* buffer = operator new(sizeof(Object) * 3);
    // or
    // char buffer[sizeof(Object) * 3]; // a buffer on the stack works too

    // Construct objects one slot at a time in the buffer
    Object* obj1 = new (buffer) Object(1, 2);
    Object* obj2 = new (static_cast<char*>(buffer) + sizeof(Object)) Object(3, 4);
    Object* obj3 = new (static_cast<char*>(buffer) + 2 * sizeof(Object)) Object(5, 6);

    // ⚠ Objects constructed with placement new must have their destructors called manually
    obj1->~Object();
    obj2->~Object();
    obj3->~Object();

    // Free the raw memory
    operator delete(buffer);

    return 0;
}
```

Typical use cases for placement new:
- Memory pools: pre-allocate a large block and construct objects in it with placement new when needed
- Custom containers: std::vector internally uses placement new to construct elements in pre-allocated memory
- Shared memory: constructing C++ objects in a shared memory region
- Embedded development: constructing objects at fixed physical addresses

4.5 std::set_new_handler
---------------------------

Installs a global "out-of-memory handler" that is called when new fails to allocate.

```cpp
#include <iostream>
#include <new>
#include <cstdlib>

void noMemoryHandler() {
    std::cerr << "Fatal: memory exhausted!" << std::endl;
    std::abort();
}

int main() {
    // Save the old handler
    std::new_handler old = std::set_new_handler(noMemoryHandler);

    // Try to allocate a huge amount of memory to trigger the handler
    try {
        auto big = new char[100ULL * 1024 * 1024 * 1024]; // 100 GB
        delete[] big;
    } catch (const std::bad_alloc&) {
        std::cerr << "bad_alloc" << std::endl;
    }

    // Restore the old handler
    std::set_new_handler(old);

    return 0;
}
```

4.6 malloc / calloc / realloc / free (The C Way)
-----------------------------------------------

```cpp
#include <cstdlib>
#include <cstring>
#include <iostream>

int main() {
    // malloc: allocate uninitialized memory
    int* m1 = (int*)std::malloc(10 * sizeof(int));
    std::memset(m1, 0, 10 * sizeof(int));

    // calloc: allocate and zero-initialize (args: n elements, size of each element)
    int* m2 = (int*)std::calloc(10, sizeof(int));
    // every byte of m2 is already 0

    // realloc: resize previously allocated memory
    // When growing: may extend in place or copy to a new location
    int* m3 = (int*)std::realloc(m1, 20 * sizeof(int));
    // m3 may be m1 (extended in place) or a new address (if in-place extension failed)
    // If m3 != m1, then m1 has already been freed
    if (m3) m1 = m3;  // update the pointer

    // When shrinking
    int* m4 = (int*)std::realloc(m1, 5 * sizeof(int));
    if (m4) m1 = m4;

    // realloc(NULL, size) is equivalent to malloc(size)
    // realloc(ptr, 0) is equivalent to free(ptr)

    std::free(m1);
    std::free(m2);
    // m1 and m3/m4 may point to the same memory; do not free it twice

    return 0;
}
```

4.7 unique_ptr (Exclusive-Ownership Smart Pointer, C++11)
---------------------------------------------------------

A smart pointer that does not share ownership; it manages its object exclusively. Supports move semantics, copying is disabled.

```cpp
#include <iostream>
#include <memory>
#include <utility>

class Resource {
public:
    Resource(const char* name) : name_(name) {
        std::cout << "Acquiring resource: " << name_ << std::endl;
    }
    ~Resource() {
        std::cout << "Releasing resource: " << name_ << std::endl;
    }
    void use() {
        std::cout << "Using resource: " << name_ << std::endl;
    }
private:
    const char* name_;
};

int main() {
    // 1. Create a unique_ptr
    std::unique_ptr<int> up1(new int(42));
    std::cout << "*up1 = " << *up1 << std::endl;

    // 2. C++14 recommends make_unique
    auto up2 = std::make_unique<int>(100);
    std::cout << "*up2 = " << *up2 << std::endl;

    // 3. Managing an array
    auto upArr = std::make_unique<int[]>(5);  // int[5]
    for (int i = 0; i < 5; ++i) upArr[i] = i * 10;

    // 4. Transferring ownership
    auto up3 = std::move(up2);  // up2 is now empty
    if (!up2) std::cout << "up2 is empty" << std::endl;

    // 5. Releasing ownership (does not call delete)
    int* raw = up1.release();
    std::cout << "Raw pointer: " << *raw << std::endl;
    delete raw;  // free it manually

    // 6. Resetting a unique_ptr
    auto up4 = std::make_unique<Resource>("Resource-A");
    up4->use();
    up4.reset(new Resource("Resource-B")); // release the old resource, take over the new one
    up4->use();
    // Resource-B is released automatically when up4 goes out of scope

    // 7. Custom deleter
    FILE* file = nullptr;
    {
        auto fileDeleter = [](FILE* f) {
            if (f) {
                std::cout << "Closing file" << std::endl;
                fclose(f);
            }
        };
        std::unique_ptr<FILE, decltype(fileDeleter)>
            fp(fopen("/etc/hostname", "r"), fileDeleter);
        // fileDeleter is called automatically to close the file when leaving scope
    }

    return 0;
}
```

4.8 shared_ptr (Shared-Ownership Smart Pointer, C++11)
------------------------------------------------------

A smart pointer with shared ownership that maintains an internal reference count. The resource is released when the count drops to zero.

```cpp
#include <iostream>
#include <memory>
#include <vector>
#include <string>

class SharedObj {
public:
    SharedObj(int id) : id_(id) {
        std::cout << "SharedObj constructed: #" << id_ << std::endl;
    }
    ~SharedObj() {
        std::cout << "SharedObj destroyed: #" << id_ << std::endl;
    }
    void greet() const {
        std::cout << "SharedObj#" << id_ << " says hello" << std::endl;
    }
    int getId() const { return id_; }
private:
    int id_;
};

int main() {
    // 1. Create a shared_ptr
    std::shared_ptr<SharedObj> sp1(new SharedObj(1));
    // Reference count: 1

    {
        // 2. Sharing ownership
        std::shared_ptr<SharedObj> sp2 = sp1;    // copy construction, reference count +1
        std::shared_ptr<SharedObj> sp3(sp1);     // same
        // Reference count: 3

        std::cout << "Reference count: " << sp1.use_count() << std::endl; // 3

        sp2->greet();
    }
    // sp2, sp3 go out of scope, reference count -1 each (only sp1 remains)
    std::cout << "Reference count: " << sp1.use_count() << std::endl; // 1

    // 3. Using make_shared (a single memory allocation, more efficient)
    auto sp2 = std::make_shared<SharedObj>(2);

    // 4. Checking for empty
    std::shared_ptr<SharedObj> nullPtr;
    if (!nullPtr) std::cout << "nullPtr is empty" << std::endl;

    // 5. Resetting
    sp1.reset();  // drop the reference, count -1 (SharedObj#1 is destroyed here)
    sp1.reset(new SharedObj(3));  // take over a new object

    // 6. Getting the raw pointer (do NOT delete the returned value!)
    SharedObj* raw = sp1.get();
    raw->greet();

    // 7. shared_ptr with arrays (needs a custom deleter before C++17)
    {
        std::shared_ptr<int> spArr(
            new int[10],
            [](int* p) { std::cout << "Deleting int array" << std::endl; delete[] p; }
        );
    }
    // Since C++17 you can use it directly
    // std::shared_ptr<int[]> spArr2(new int[10]);
    // C++20 has std::make_shared<int[]>(10)

    return 0;
}
```

**The shared_ptr control block structure:**

```
┌─────────────────────────────────────────────────────┐
│              shared_ptr control block               │
│  ┌──────────────────────────────┐                    │
│  │ Reference count (use_count)  │  ← # of shared_ptr│
│  ├──────────────────────────────┤                    │
│  │ Weak count (weak_count)      │  ← # of weak_ptr  │
│  ├──────────────────────────────┤                    │
│  │ Deleter                      │  ← how to free obj│
│  ├──────────────────────────────┤                    │
│  │ Allocator                    │  ← optional       │
│  └──────────────────────────────┘                    │
└─────────────────────────────────────────────────────┘
         │
         │ points to
         ▼
┌─────────────────┐
│ Managed object  │
│ (instance of T) │
└─────────────────┘

make_shared allocates the control block and the managed object together (single allocation):
┌─────────────────┬──────────────────────────────────┐
│ Managed object  │  Control block                   │
│ (instance of T) │  (ref counts + deleter + alloc.) │
└─────────────────┴──────────────────────────────────┘
```

4.9 weak_ptr (Weak Reference Pointer, C++11)
--------------------------------------------

An "observer" pointer that does not participate in reference counting; used to break shared_ptr reference cycles.

```cpp
#include <iostream>
#include <memory>

// Forward declaration
struct Node;

struct Node {
    std::string name;
    std::shared_ptr<Node> next;   // strong reference: next node
    std::weak_ptr<Node> prev;     // weak reference: previous node (avoids a reference cycle)

    Node(const std::string& n) : name(n) {
        std::cout << "Node " << name << " constructed" << std::endl;
    }
    ~Node() {
        std::cout << "Node " << name << " destroyed" << std::endl;
    }
};

int main() {
    // 1. Basic usage
    auto sp = std::make_shared<int>(42);
    std::weak_ptr<int> wp = sp;  // does not increase the reference count

    std::cout << "shared_ptr reference count: " << sp.use_count() << std::endl; // 1

    // 2. Before using a weak_ptr you must check whether it has expired
    if (auto locked = wp.lock()) {  // promote to a shared_ptr
        std::cout << "Value: " << *locked << std::endl;
    }

    // 3. Release the original shared_ptr; the weak_ptr becomes expired
    sp.reset();
    if (wp.expired()) {
        std::cout << "weak_ptr has expired" << std::endl;
    }

    // 4. Breaking reference cycles — the key use case
    auto node1 = std::make_shared<Node>("first");
    auto node2 = std::make_shared<Node>("second");

    node1->next = node2;   // node1 → node2 (shared_ptr)
    node2->prev = node1;   // node1 ← node2 (weak_ptr, does not increase the count)

    std::cout << "node1 reference count: " << node1.use_count() << std::endl; // 1
    std::cout << "node2 reference count: " << node2.use_count() << std::endl; // 2

    // When leaving scope:
    // node1's reference count drops to 0 → Node "first" is destroyed
    // node2's reference count drops to 0 → Node "second" is destroyed
    // (if prev were also a shared_ptr, they would hold each other and never be freed)

    return 0;
}
```

**The scenario without weak_ptr (bad example):**

```cpp
struct BadNode {
    std::string name;
    std::shared_ptr<BadNode> next;
    std::shared_ptr<BadNode> prev;  // Wrong! Should be weak_ptr

    BadNode(const std::string& n) : name(n) {}
    ~BadNode() { std::cout << "BadNode " << name << " destroyed" << std::endl; }
};

// When node1->next = node2; node2->prev = node1;:
// node1 holds a shared_ptr to node2 → node2 reference count = 2
// node2 holds a shared_ptr to node1 → node1 reference count = 2
// After leaving scope: the local variables node1 and node2 are destroyed
// node1 reference count: 2-1 = 1 (node2->prev still holds it)
// node2 reference count: 2-1 = 1 (node1->next still holds it)
// Can never reach 0 → memory leak!
```

4.10 Smart Pointer Deleters

```cpp
#include <iostream>
#include <memory>
#include <fstream>

// Custom deleter example 1: closing a file
void closeFile(std::ofstream* fp) {
    std::cout << "Custom deleter: closing file" << std::endl;

// Custom deleter example 2: deleting an array
template<typename T>
struct ArrayDeleter {
    void operator()(T* p) const {
        std::cout << "Deleter: freeing array" << std::endl;
        delete[] p;
    }
};

// Custom deleter example 3: deletion with logging
auto loggingDeleter = [](int* p) {
    std::cout << "Deleter: freeing int* (value=" << *p << ")" << std::endl;

int main() {

    {
        std::unique_ptr<std::ofstream, void(*)(std::ofstream*)>
            filePtr(new std::ofstream("test.log"), closeFile);

        std::unique_ptr<int, ArrayDeleter<int>>
            arr(new int[100], ArrayDeleter<int>());

    // 2. shared_ptr with a deleter (the deleter is not part of the type)
```

4.11 The std::allocator Class
------------------------------

An allocator separates memory allocation from object construction, allowing objects to be constructed on demand in pre-allocated memory.

```cpp
#include <iostream>
#include <memory>
#include <string>

int main() {
    std::allocator<std::string> alloc;

    // 1. Allocate raw memory (no objects constructed)
    const int n = 3;
    std::string* p = alloc.allocate(n);

    // 2. Construct objects one by one in the raw memory
    alloc.construct(p, "Hello");
    alloc.construct(p + 1, "World");
    alloc.construct(p + 2, "!");

    // 3. Use the objects
    for (int i = 0; i < n; ++i) {
        std::cout << p[i] << " ";
    }
    std::cout << std::endl;

    // 4. Destroy the objects (memory is not freed)
    for (int i = 0; i < n; ++i) {
        alloc.destroy(p + i);
    }

    // 5. Free the memory
    alloc.deallocate(p, n);

    // Since C++17 allocator has a more streamlined interface
    // but the principle is the same: allocate/deallocate + construct/destroy

    return 0;
}
```

4.13 Custom Global operator new / delete
----------------------------------------

```cpp
#include <iostream>
#include <cstdlib>
#include <new>

// Allocation counters for the global new
namespace {
    std::size_t totalAllocated = 0;
    std::size_t totalFreed = 0;
    std::size_t allocationCount = 0;
}

// Overload the global operator new
void* operator new(std::size_t size) {
    totalAllocated += size;
    ++allocationCount;
    void* p = std::malloc(size);
    if (!p) throw std::bad_alloc();
    std::cout << "[global new] allocated " << size << " bytes → " << p << std::endl;
    return p;
}

// Overload the global operator new[] (arrays)
void* operator new[](std::size_t size) {
    return operator new(size);  // reuse the implementation above
}

// Overload the global operator delete
void operator delete(void* p) noexcept {
    std::cout << "[global delete] freed " << p << std::endl;
    std::free(p);
}

// Overload the global operator delete[] (arrays)
void operator delete[](void* p) noexcept {
    operator delete(p);
}

// Sized operator delete (C++14)
void operator delete(void* p, std::size_t size) noexcept {
    totalFreed += size;
    std::cout << "[global delete sized] freed " << p
              << " (size: " << size << " bytes)" << std::endl;
    std::free(p);
}

int main() {
    std::cout << "=== Custom Global new/delete ===" << std::endl;

    int* a = new int(42);
    delete a;

    double* b = new double(3.14);
    delete b;

    int* arr = new int[5];
    delete[] arr;

    std::cout << "Total allocations: " << allocationCount << std::endl;
    std::cout << "Total bytes allocated: " << totalAllocated << std::endl;

    return 0;
}
```

Simulating what these tools do in your own code:

```cpp
#include <iostream>
#include <set>
#include <cstdlib>
#include <new>

// A simple memory leak detector
namespace MemTracker {
    std::set<void*> allocations;

    void* trackedAlloc(std::size_t size, const char* file, int line) {
        void* p = std::malloc(size);
        allocations.insert(p);
        std::cout << "[ALLOC] " << file << ":" << line
                  << " allocated " << size << " bytes → " << p
                  << " (live allocations: " << allocations.size() << ")"
                  << std::endl;
        return p;
    }

    void trackedFree(void* p, const char* file, int line) {
        if (allocations.erase(p)) {
            std::cout << "[FREE]  " << file << ":" << line
                      << " freed " << p
                      << " (live allocations: " << allocations.size() << ")"
                      << std::endl;
        }
        std::free(p);
    }

    void reportLeaks() {
        if (!allocations.empty()) {
            std::cerr << "\n!!! Memory leak detected !!!" << std::endl;
            std::cerr << "Unfreed allocations: " << allocations.size() << std::endl;
            for (auto p : allocations) {
                std::cerr << "  Leaked: " << p << std::endl;
            }
        } else {
            std::cout << "\nNo memory leaks detected" << std::endl;
        }
    }
}
```

Example 1: A Variable-Length Grade Management System
----------------------------------------------------------------

Real-life scenario: At the end of the semester, a teacher needs to enter the grades of every student
in the class. Since class size varies, a dynamically growing array is needed to store the grades.
The array must grow automatically as grades are entered, and at the end the average and rankings are computed.

This example covers: new[] dynamic allocation, realloc-style logic, pointer arithmetic, basic memory management.

```cpp
#include <iostream>
#include <iomanip>
#include <cstring>
#include <algorithm>

// ============================================================
// Grade management system namespace
// ============================================================
namespace GradeManager {

    struct Student {
        char name[32];
        double score;
    };

    // Dynamic array class (simplified, shows new[] and how growth works)
    class DynamicStudentArray {
    public:
        DynamicStudentArray()
            : data_(nullptr), size_(0), capacity_(0) {}

        ~DynamicStudentArray() {
            delete[] data_;
        }

        // Disable copying (for simplicity)
        DynamicStudentArray(const DynamicStudentArray&) = delete;
        DynamicStudentArray& operator=(const DynamicStudentArray&) = delete;

        // Add a student (grows automatically)
        void add(const char* name, double score) {
            if (size_ >= capacity_) {
                // Growth strategy: double the capacity
                std::size_t newCapacity = (capacity_ == 0)
                                          ? 4
                                          : capacity_ * 2;
                resize(newCapacity);
            }

            std::strncpy(data_[size_].name, name, 31);
            data_[size_].name[31] = '\0';
            data_[size_].score = score;
            ++size_;
        }

        // Get a student's information
        const Student& at(std::size_t index) const {
            return data_[index];
        }

        std::size_t size() const { return size_; }
        std::size_t capacity() const { return capacity_; }

        // Sort by score in descending order
        void sortByScore() {
            // Simple selection sort (this example demonstrates pointer arithmetic)
            for (std::size_t i = 0; i < size_; ++i) {
                std::size_t maxIdx = i;
                for (std::size_t j = i + 1; j < size_; ++j) {
                    if (data_[j].score > data_[maxIdx].score) {
                        maxIdx = j;
                    }
                }
                if (maxIdx != i) {
                    Student temp = data_[i];
                    data_[i] = data_[maxIdx];
                    data_[maxIdx] = temp;
                }
            }
        }

        // Compute the average score
        double average() const {
            if (size_ == 0) return 0.0;
            double sum = 0.0;
            for (std::size_t i = 0; i < size_; ++i) {
                sum += data_[i].score;
            }
            return sum / size_;
        }

        // Find the highest score
        double maxScore() const {
            if (size_ == 0) return 0.0;
            double maxVal = data_[0].score;
            for (std::size_t i = 1; i < size_; ++i) {
                if (data_[i].score > maxVal) {
                    maxVal = data_[i].score;
                }
            }
            return maxVal;
        }

        // Find the lowest score
        double minScore() const {
            if (size_ == 0) return 0.0;
            double minVal = data_[0].score;
            for (std::size_t i = 1; i < size_; ++i) {
                if (data_[i].score < minVal) {
                    minVal = data_[i].score;
                }
            }
            return minVal;
        }

        // Print the report card
        void printReport() const {
            std::cout << "\n┌─────────────────────────────────────┐" << std::endl;
            std::cout << "│         Report Card                 │" << std::endl;
            std::cout << "├──────┬──────────────────┬───────────┤" << std::endl;
            std::cout << "│ Rank │ Name             │ Score     │" << std::endl;
            std::cout << "├──────┼──────────────────┼───────────┤" << std::endl;

            for (std::size_t i = 0; i < size_; ++i) {
                std::cout << "│ "
                          << std::setw(4) << (i + 1) << " │ "
                          << std::setw(16) << std::left << data_[i].name << " │ "
                          << std::setw(9) << std::right << std::fixed
                          << std::setprecision(2) << data_[i].score << " │"
                          << std::endl;
            }

            std::cout << "└──────┴──────────────────┴───────────┘" << std::endl;
        }

    private:
        Student* data_;
        std::size_t size_;
        std::size_t capacity_;

        void resize(std::size_t newCapacity) {
            std::cout << "  [grow] " << capacity_ << " → "
                      << newCapacity << " (current students: " << size_ << ")"
                      << std::endl;

            // Allocate new memory
            Student* newData = new Student[newCapacity];

            // Copy the old data
            for (std::size_t i = 0; i < size_; ++i) {
                newData[i] = data_[i];
            }

            // Free the old memory
            delete[] data_;

            // Update the pointer and capacity
            data_ = newData;
            capacity_ = newCapacity;
        }
    };

}  // namespace GradeManager

int main() {
    std::cout << "╔══════════════════════════════╗" << std::endl;
    std::cout << "║ Variable-Length Grade Manager║" << std::endl;
    std::cout << "╚══════════════════════════════╝\n" << std::endl;

    GradeManager::DynamicStudentArray arr;

    // Simulate entering grades
    std::cout << "=== Entering Student Grades ===" << std::endl;
    arr.add("Li Ming", 95.5);
    arr.add("Wang Xiaohong", 88.0);
    arr.add("Zhang Wei", 76.5);
    arr.add("Liu Fang", 92.0);
    arr.add("Chen Qiang", 85.0);
    arr.add("Zhao Min", 78.5);
    arr.add("Zhou Jie", 91.0);
    arr.add("Wu Xin", 69.0);
    arr.add("Zheng Shuang", 83.5);
    arr.add("Qian Biao", 97.0);
    arr.add("Sun Li", 81.0);
    arr.add("Ma Chao", 74.0);

    std::cout << "\nEntry complete, " << arr.size() << " students in total" << std::endl;
    std::cout << "Array capacity: " << arr.capacity() << std::endl;

    // Sort
    arr.sortByScore();

    // Statistics
    std::cout << "\n=== Grade Statistics ===" << std::endl;
    std::cout << "Average: " << std::fixed << std::setprecision(2)
              << arr.average() << std::endl;
    std::cout << "Highest: " << arr.maxScore() << std::endl;
    std::cout << "Lowest: " << arr.minScore() << std::endl;

    // Print the report card
    arr.printReport();

    return 0;
}
```


Example 2: Restaurant Order Queue (Dynamic Linked List)
----------------------------------------------------------------

Real-life scenario: A popular restaurant needs a ticket-calling system. Customers take a number on
arrival and wait in line, and the host calls numbers in FIFO order. The queue is managed with
linked-list nodes we create ourselves with new, supporting enqueue, dequeue and querying the number of waiting parties.

This example covers: building a dynamic linked list with new/delete, organizing code with namespaces, raw pointer manipulation.

```cpp
#include <iostream>
#include <string>
#include <iomanip>

// ============================================================
// Restaurant queuing system namespace
// ============================================================
namespace Restaurant {

    // Queue node (guest information)
    struct GuestNode {
        int ticketNumber;          // ticket number taken
        std::string name;          // guest name
        int partySize;             // number of people in the party
        GuestNode* next;           // points to the next node

        GuestNode(int ticket, const std::string& n, int size)
            : ticketNumber(ticket), name(n), partySize(size), next(nullptr) {
            std::cout << "  [new] New guest " << name << " ticket: "
                      << ticket << " (" << partySize << " people)" << std::endl;
        }

        ~GuestNode() {
            std::cout << "  [delete] Guest " << name << " (ticket: "
                      << ticketNumber << ") served" << std::endl;
        }
    };

    // Waiting queue
    class GuestQueue {
    public:
        GuestQueue() : head_(nullptr), tail_(nullptr), count_(0), nextTicket_(1) {}

        ~GuestQueue() {
            // Free all nodes
            while (head_) {
                GuestNode* temp = head_;
                head_ = head_->next;
                delete temp;
            }
        }

        // Disable copying
        GuestQueue(const GuestQueue&) = delete;
        GuestQueue& operator=(const GuestQueue&) = delete;

        // Enqueue: the guest takes a number
        int enqueue(const std::string& name, int partySize) {
            GuestNode* newNode = new GuestNode(nextTicket_, name, partySize);
            ++nextTicket_;

            if (!tail_) {
                // The queue is empty
                head_ = tail_ = newNode;
            } else {
                tail_->next = newNode;
                tail_ = newNode;
            }

            ++count_;
            return newNode->ticketNumber;
        }

        // Call a number: dequeue
        bool dequeue() {
            if (!head_) {
                std::cout << "The queue is empty, no guests waiting" << std::endl;
                return false;
            }

            GuestNode* served = head_;
            head_ = head_->next;
            if (!head_) tail_ = nullptr;  // the queue is now empty

            std::cout << "\n>>> Ticket " << served->ticketNumber << ", "
                      << served->name << " "
                      << "(" << served->partySize << " people), please be seated!"
                      << std::endl;

            delete served;
            --count_;
            return true;
        }

        // Show the queue status
        void displayQueue() const {
            std::cout << "\n┌─────────────────────────────┐" << std::endl;
            std::cout << "│    Current Waiting Queue    │" << std::endl;
            std::cout << "├──────┬──────────┬───────────┤" << std::endl;
            std::cout << "│ No.  │ Name     │ Party     │" << std::endl;
            std::cout << "├──────┼──────────┼───────────┤" << std::endl;

            GuestNode* current = head_;
            while (current) {
                std::cout << "│ "
                          << std::setw(4) << current->ticketNumber << " │ "
                          << std::setw(8) << std::left << current->name << " │ "
                          << std::setw(9) << std::right << current->partySize << " │"
                          << std::endl;
                current = current->next;
            }

            if (!head_) {
                std::cout << "│    (no guests waiting)      │" << std::endl;
            }

            std::cout << "└──────┴──────────┴───────────┘" << std::endl;
            std::cout << "Currently waiting: " << count_ << " parties"
                      << " | Next ticket: " << nextTicket_ << std::endl;
        }

        // Look up the guest with a given ticket number
        GuestNode* findGuest(int ticket) const {
            GuestNode* current = head_;
            while (current) {
                if (current->ticketNumber == ticket) {
                    return current;
                }
                current = current->next;
            }
            return nullptr;
        }

        // Query the number of waiting parties
        int waitingCount() const { return count_; }

    private:
        GuestNode* head_;
        GuestNode* tail_;
        int count_;
        int nextTicket_;
    };

    // Restaurant operation interface
    namespace Host {
        void showMenu() {
            std::cout << "\nMenu:" << std::endl;
            std::cout << "  1. Take a number" << std::endl;
            std::cout << "  2. Call a number to be seated" << std::endl;

            std::cout << "  0. Close for the day" << std::endl;
            std::cout << "Please choose: ";
        }
    }

}  // namespace Restaurant

        queue.dequeue();
    }

    queue.displayQueue();

    return 0;
```

Example 3: A Simple Memory Pool
----------------------------------------------------------------

Real-life scenario: In a game, bullet objects are created and destroyed constantly (possibly hundreds or
thousands per frame). Using new/delete every time is not only slow (requesting/returning memory from the
system each time) but also causes memory fragmentation. A memory pool pre-allocates one large block, so
"creating" and "destroying" an object merely marks a slot as used/free, which greatly
improves performance.

This example covers: overloading operator new/delete, placement new, pre-allocated memory blocks, free lists.

```cpp
#include <iostream>
#include <cstddef>
#include <cstdint>

// Debug macro from Chapter 2 (bringing in earlier material)
#ifdef ENABLE_POOL_DEBUG
    #define POOL_LOG(msg) \
        std::cout << "[MemoryPool][" << __FILE__ << ":" << __LINE__ \
                  << "] " << msg << std::endl
#else
    #define POOL_LOG(msg) ((void)0)
#endif

// Enable debugging
#define ENABLE_POOL_DEBUG

// ============================================================
// Memory pool namespace
// ============================================================
namespace MemPool {

    // Bullet class (simulates a small object that is frequently created/destroyed)
    class Bullet {
    public:
        float x, y;
        float vx, vy;
        bool active;
        int damage;

        Bullet() : x(0), y(0), vx(0), vy(0), active(false), damage(10) {}

        Bullet(float px, float py, float vx_, float vy_, int dmg)
            : x(px), y(py), vx(vx_), vy(vy_), active(true), damage(dmg) {
            POOL_LOG("Bullet constructed at (" << x << "," << y << ")"
                      << " velocity(" << vx << "," << vy << ")"
                      << " damage=" << damage);
        }

        ~Bullet() {
            POOL_LOG("Bullet destroyed");
        }

        void update() {
            if (!active) return;
            x += vx;
            y += vy;
        }

        void print() const {
            std::cout << "  Bullet[position(" << x << "," << y << ")"
                      << " velocity(" << vx << "," << vy << ")"
                      << " damage=" << damage
                      << " " << (active ? "active" : "dormant") << "]"
                      << std::endl;
        }
    };

    // ============================================================
    // Memory pool implementation
    // ============================================================
    class BulletPool {
    public:
        static const std::size_t POOL_SIZE = 16;   // maximum number of bullets in the pool
        static const std::size_t BULLET_SIZE = sizeof(Bullet);

        BulletPool() : rawMemory_(nullptr), freeList_(nullptr), usedCount_(0) {
            // 1. Pre-allocate one large block of raw memory
            rawMemory_ = static_cast<char*>(
                ::operator new(POOL_SIZE * BULLET_SIZE)
            );
            POOL_LOG("Pre-allocated " << (POOL_SIZE * BULLET_SIZE)
                      << " bytes of raw memory → " << (void*)rawMemory_);

            // 2. Initialize the free list: cut the large block into small slots and chain them together
            char* current = rawMemory_;
            for (std::size_t i = 0; i < POOL_SIZE - 1; ++i) {
                // The first sizeof(void*) bytes of each free slot store the address of the next free slot
                *reinterpret_cast<char**>(current) = current + BULLET_SIZE;
                current += BULLET_SIZE;
            }
            *reinterpret_cast<char**>(current) = nullptr;  // the last one points to null
            freeList_ = rawMemory_;  // head of the free list

            POOL_LOG("Free list initialized, " << POOL_SIZE << " slots in total");
        }

        ~BulletPool() {
            POOL_LOG("Releasing the memory pool");
            ::operator delete(rawMemory_);
        }

        // Disable copying
        BulletPool(const BulletPool&) = delete;
        BulletPool& operator=(const BulletPool&) = delete;

        // "Allocate" a bullet (take one from the pool)
        Bullet* allocate() {
            if (!freeList_) {
                POOL_LOG("Memory pool is full! Cannot allocate more bullets");
                return nullptr;
            }

            // Take a slot from the head of the free list
            char* slot = static_cast<char*>(freeList_);
            // The address of the next free slot is stored in the first bytes of the current slot
            freeList_ = *reinterpret_cast<void**>(slot);

            ++usedCount_;
            POOL_LOG("Allocated a bullet slot from the pool (" << usedCount_
                      << "/" << POOL_SIZE << " used)"
                      << " address: " << (void*)slot);

            return reinterpret_cast<Bullet*>(slot);
        }

        // "Free" a bullet (return it to the pool)
        void deallocate(Bullet* bullet) {
            if (!bullet) return;

            // Destroy it first (in case the user didn't call it manually)
            bullet->~Bullet();

            // Insert the current slot at the head of the free list
            char* slot = reinterpret_cast<char*>(bullet);
            *reinterpret_cast<void**>(slot) = freeList_;
            freeList_ = slot;

            --usedCount_;
            POOL_LOG("Returned a bullet slot to the pool (" << usedCount_
                      << "/" << POOL_SIZE << " used)"
                      << " address: " << (void*)slot);
        }

        // Construct a bullet in the pool
        Bullet* createBullet(float x, float y, float vx, float vy, int damage) {
            Bullet* bullet = allocate();
            if (bullet) {
                // placement new: construct the object in already-allocated memory
                new (bullet) Bullet(x, y, vx, vy, damage);
            }
            return bullet;
        }

        // Destroy a bullet and return its memory
        void destroyBullet(Bullet* bullet) {
            if (bullet) {
                bullet->~Bullet();  // call the destructor manually
                deallocate(bullet);
            }
        }

        // Pool status
        void printStats() const {
            std::cout << "Memory pool status: "
                      << usedCount_ << "/" << POOL_SIZE << " in use"
                      << " (" << (usedCount_ * 100 / POOL_SIZE) << "%)"
                      << std::endl;
        }

        std::size_t usedCount() const { return usedCount_; }
        std::size_t totalSlots() const { return POOL_SIZE; }

    private:
        char* rawMemory_;   // the whole pre-allocated block
        void* freeList_;    // head of the free list
        std::size_t usedCount_;
    };

}  // namespace MemPool

// Overload operator new/delete for Bullet so it uses the memory pool automatically
namespace MemPool {
    // Get the global memory pool instance
    BulletPool& getGlobalBulletPool() {
        static BulletPool pool;  // singleton (globally unique)
        return pool;
    }

    // For testing: create bullets in bulk
    void fireBulletStorm(BulletPool& pool, int count) {
        std::cout << "\n--- Firing " << count << " bullets ---" << std::endl;

        Bullet* bullets[32] = {nullptr};  // temporary storage
        int created = 0;

        for (int i = 0; i < count; ++i) {
            float angle = i * 0.2f;
            Bullet* b = pool.createBullet(
                0.0f, 0.0f,           // position: origin
                std::cos(angle), std::sin(angle),  // velocity direction
                10 + i % 20           // damage
            );
            if (b) {
                bullets[created++] = b;
            } else {
                std::cout << "  Cannot create more bullets! The pool is full" << std::endl;
                break;
            }
        }

        pool.printStats();

        // Simulate a few frames of updates
        for (int frame = 1; frame <= 3; ++frame) {
            std::cout << "\nFrame " << frame << ":" << std::endl;
            for (int i = 0; i < created; ++i) {
                bullets[i]->update();
            }
            // Print the first bullet's position each frame
            if (created > 0) {
                bullets[0]->print();
            }
        }

        // Destroy all bullets
        std::cout << "\n--- Clearing bullets ---" << std::endl;
        for (int i = 0; i < created; ++i) {
            pool.destroyBullet(bullets[i]);
        }
        pool.printStats();
    }
}

int main() {
    std::cout << "╔══════════════════════════════╗" << std::endl;
    std::cout << "║     Game Memory Pool         ║" << std::endl;
    std::cout << "╚══════════════════════════════╝\n" << std::endl;

    MemPool::BulletPool& pool = MemPool::getGlobalBulletPool();
    pool.printStats();

    // Scenario 1: fire a few bullets (within the pool capacity)
    MemPool::fireBulletStorm(pool, 5);

    // Scenario 2: fire a large batch (will hit the pool-full case)
    MemPool::fireBulletStorm(pool, 20);

    return 0;
}
```

Code walkthrough:
- At construction time the memory pool allocates `POOL_SIZE * sizeof(Bullet)` bytes of raw memory in one go
- The free list chains all free slots together: the first 8 bytes (sizeof(void*)) of each slot
  store the address of the next free slot
- `allocate()` takes a slot from the head of the list (O(1) time complexity)
- `deallocate()` puts a slot back at the head of the list (O(1) time complexity)
- Unlike new/delete, it does not go through malloc/free → brk/mmap system calls every time
- The POOL_LOG macro (from Chapter 2) controls the output of debug logs


Example 4: A Library Book Management System (shared_ptr + weak_ptr)
----------------------------------------------------------------

Real-life scenario: A university library's lending system. A book can be reserved by several readers
at once (shared ownership). Readers and books reference each other: a reader knows which books they
have reserved, and a book records which readers have reserved it. If both directions used shared_ptr
we would get a reference cycle (never freed), so weak_ptr must be used to break the cycle.

This example covers: shared_ptr, weak_ptr, monitoring reference counts, the reference cycle problem and its solution.

```cpp
#include <iostream>
#include <memory>
#include <string>
#include <vector>
#include <iomanip>
#include <algorithm>

// Forward declaration
struct Book;

// ============================================================
// Library system namespace
// ============================================================
namespace Library {

    // Preprocessor constants (bringing in Chapter 2 material)
    #define MAX_BORROW_COUNT 5        // maximum books per reader
    #define LOAN_PERIOD_DAYS 30       // loan period (days)
    #define STRINGIFY_HELPER(x) #x
    #define STRINGIFY(x) STRINGIFY_HELPER(x)

    // Reader
    struct Reader {
        std::string name;
        std::string id;                    // library card number
        // Books held by the reader (shared_ptr means the reader holds borrowing rights to the book)
        std::vector<std::shared_ptr<Book>> borrowedBooks;

        Reader(const std::string& n, const std::string& studentId)
            : name(n), id(studentId) {
            std::cout << "  [construct] Reader " << name << " (" << id << ")" << std::endl;
        }

        ~Reader() {
            std::cout << "  [destruct] Reader " << name << " (" << id << ")" << std::endl;
        }

        void showBorrowed() const {
            std::cout << "\nBorrowed list of reader " << name << ":" << std::endl;
            if (borrowedBooks.empty()) {
                std::cout << "  (no borrowing records)" << std::endl;
                return;
            }
            for (const auto& book : borrowedBooks) {
                std::cout << "  - '" << book->title << "' (ISBN: "
                          << book->isbn << ")" << std::endl;
            }
        }
    };

    // Book
    struct Book {
        std::string title;
        std::string isbn;
        std::string author;
        // List of readers who reserved this book (weak_ptr avoids a reference cycle)
        std::vector<std::weak_ptr<Reader>> reservationList;

        Book(const std::string& t, const std::string& i, const std::string& a)
            : title(t), isbn(i), author(a) {
            std::cout << "  [construct] Book '" << title << "' (ISBN: " << isbn << ")" << std::endl;
        }

        ~Book() {
            std::cout << "  [destruct] Book '" << title << "' (ISBN: " << isbn << ")" << std::endl;
        }

        // Show reservation information
        void showReservations() const {
            std::cout << "\nReaders who reserved '" << title << "':" << std::endl;
            int validCount = 0;
            for (const auto& weakReader : reservationList) {
                if (auto reader = weakReader.lock()) {
                    std::cout << "  - " << reader->name
                              << " (" << reader->id << ")" << std::endl;
                    ++validCount;
                }
            }
            std::cout << "  Valid reservations: " << validCount
                      << " / Total: " << reservationList.size() << std::endl;
        }

        void printInfo() const {
            std::cout << "'" << title << "' "
                      << "ISBN:" << isbn << " "
                      << "Author:" << author;
        }
    };

    // Library management class
    class LibrarySystem {
    public:
        // Add a book to the collection
        void addBook(const std::string& title,
                     const std::string& isbn,
                     const std::string& author) {
            books_.push_back(std::make_shared<Book>(title, isbn, author));
        }

        // Register a reader
        void registerReader(const std::string& name,
                            const std::string& studentId) {
            readers_.push_back(std::make_shared<Reader>(name, studentId));
        }

        // Borrow: a reader borrows a book
        bool borrowBook(const std::string& studentId, const std::string& isbn) {
            // Find the reader
            std::shared_ptr<Reader> reader = findReaderById(studentId);
            if (!reader) {
                std::cout << "Error: reader not found " << studentId << std::endl;
                return false;
            }

            // Check the borrowing limit
            if (reader->borrowedBooks.size() >= MAX_BORROW_COUNT) {
                std::cout << "Error: " << reader->name
                          << " has reached the borrowing limit (" << MAX_BORROW_COUNT << " books)"
                          << std::endl;
                return false;
            }

            // Find the book
            std::shared_ptr<Book> book = findBookByIsbn(isbn);
            if (!book) {
                std::cout << "Error: book not found " << isbn << std::endl;
                return false;
            }

            // Check whether it is already borrowed
            for (const auto& b : reader->borrowedBooks) {
                if (b->isbn == isbn) {
                    std::cout << "Error: " << reader->name
                              << " has already borrowed '" << book->title << "'"
                              << std::endl;
                    return false;
                }
            }

            // Perform the loan
            reader->borrowedBooks.push_back(book);
            // The book also records the borrower (weak_ptr avoids a reference cycle)
            book->reservationList.push_back(reader);

            std::cout << "√ " << reader->name << " successfully borrowed '"
                      << book->title << "'" << std::endl;

            // Inspect reference counts
            std::cout << "  Book shared_ptr reference count: "
                      << book.use_count() << std::endl;
            std::cout << "  Reader shared_ptr reference count: "
                      << reader.use_count() << std::endl;

            return true;
        }

        // Return a book
        bool returnBook(const std::string& studentId, const std::string& isbn) {
            std::shared_ptr<Reader> reader = findReaderById(studentId);
            if (!reader) return false;

            std::shared_ptr<Book> book = findBookByIsbn(isbn);
            if (!book) return false;

            // Remove it from the reader's borrowed list
            auto& borrowed = reader->borrowedBooks;
            auto it = std::find_if(borrowed.begin(), borrowed.end(),
                [&isbn](const std::shared_ptr<Book>& b) {
                    return b->isbn == isbn;
                });
            if (it != borrowed.end()) {
                borrowed.erase(it);
            }

            // Remove the reader from the book's reservation list
            auto& reservations = book->reservationList;
            reservations.erase(
                std::remove_if(reservations.begin(), reservations.end(),
                    [&reader](const std::weak_ptr<Reader>& wr) {
                        auto sp = wr.lock();
                        return sp && sp->id == reader->id;
                    }),
                reservations.end()
            );

            std::cout << "√ " << reader->name << " returned '"
                      << book->title << "'" << std::endl;

            std::cout << "  Book shared_ptr reference count: "
                      << book.use_count() << std::endl;

            return true;
        }

        // Show the whole collection
        void showAllBooks() const {
            std::cout << "\n=== Library Collection ===" << std::endl;
            for (const auto& book : books_) {
                std::cout << "  ";
                book->printInfo();
                std::cout << " (reference count: " << book.use_count() << ")"
                          << std::endl;
            }
        }

        // Show all readers
        void showAllReaders() const {
            std::cout << "\n=== Registered Readers ===" << std::endl;
            for (const auto& reader : readers_) {
                std::cout << "  " << reader->name
                          << " (" << reader->id << ")"
                          << " (reference count: " << reader.use_count() << ")"
                          << std::endl;
            }
        }

        // Show a system overview
        void showSystemStatus() const {
            std::cout << "\n╔══════════════════════════════╗" << std::endl;
            std::cout << "║     Library System Status    ║" << std::endl;
            std::cout << "╠══════════════════════════════╣" << std::endl;
            std::cout << "║ Books held: " << std::setw(3) << books_.size()
                      << " volumes       ║" << std::endl;
            std::cout << "║ Registered readers: " << std::setw(3) << readers_.size()
                      << "      ║" << std::endl;
            std::cout << "║ Limit per reader: " << MAX_BORROW_COUNT << " books"
                      << "     ║" << std::endl;
            std::cout << "║ Loan period: " << LOAN_PERIOD_DAYS << " days"
                      << "         ║" << std::endl;
            std::cout << "╚══════════════════════════════╝" << std::endl;
        }

    private:
        std::vector<std::shared_ptr<Book>> books_;
        std::vector<std::shared_ptr<Reader>> readers_;

        std::shared_ptr<Reader> findReaderById(const std::string& id) {
            for (auto& r : readers_) {
                if (r->id == id) return r;
            }
            return nullptr;
        }

        std::shared_ptr<Book> findBookByIsbn(const std::string& isbn) {
            for (auto& b : books_) {
                if (b->isbn == isbn) return b;
            }
            return nullptr;
        }
    };

}  // namespace Library

int main() {
    std::cout << "╔══════════════════════════════╗" << std::endl;
    std::cout << "║  University Library System   ║" << std::endl;

    Library::LibrarySystem lib;

    lib.borrowBook("S2024003", "978-0321563842");  // Wang Wu borrows TCPL
```

Code walkthrough:
- `Book` and `Reader` reference each other through `shared_ptr` and `weak_ptr`
- `shared_ptr<Book>` is stored in `books_` and in each reader's `borrowedBooks` → shared ownership
- `weak_ptr<Reader>` is stored in the book's `reservationList` → does not increase the reference count
- If `reservationList` also used `shared_ptr<Reader>`, a cycle would form: Reader holds
  Book, Book holds Reader → neither reference count would ever reach zero → memory leak
- The code shows `use_count()` for monitoring reference counts and `lock()` for promoting a weak_ptr


Example 5: A 2D Image Matrix Processor (RAII + Move Semantics)
----------------------------------------------------------------

Real-life scenario: An image-processing program needs to work with pixel matrices (e.g. a 1920×1080 RGB image).
The matrix data is large (about 6MB) and needs to be passed between functions, but frequent deep copies are
too expensive. We implement a complete RAII matrix class that supports move semantics to avoid unnecessary copies.

This example covers: the Rule of 3/5, move semantics, RAII, element access via operator(),
and combined use of the first three chapters.

```cpp
#include <iostream>
#include <iomanip>
#include <cstring>
#include <stdexcept>

// ============================================================
// Preprocessor definitions (bringing in Chapter 2
#define MATRIX_ASSERT(cond, msg) \
    do { \
        if (!(cond)) { \
            std::cerr << "[ASSERT][" << __FILE__ << ":" << __LINE__ \
                      << "] " << msg << std::endl; \
        } \
    } while(0)

// Namespace (bringing in Chapter 1)
namespace ImageProcessing {

    // ============================================================
    // Matrix<T>: a 2D dynamic matrix (similar to an image pixel buffer)
    // ============================================================
    template<typename T>
    class Matrix {
    public:
        // Default constructor
        Matrix()
            : rows_(0), cols_(0), data_(nullptr) {}

        // Constructor with parameters (RAII part 1: Resource Acquisition Is Initialization)
        Matrix(std::size_t rows, std::size_t cols)
            : rows_(rows), cols_(cols), data_(nullptr) {
            if (rows > 0 && cols > 0) {
                data_ = new T[rows * cols];
                std::memset(data_, 0, rows * cols * sizeof(T));
            }
        }

        // Constructor with a fill value
        Matrix(std::size_t rows, std::size_t cols, T fillValue)
            : rows_(rows), cols_(cols), data_(nullptr) {
            if (rows > 0 && cols > 0) {
                data_ = new T[rows * cols];
                for (std::size_t i = 0; i < rows * cols; ++i) {
                    data_[i] = fillValue;
                }
            }
        }

        // Destructor (RAII part 2)
        ~Matrix() {
            delete[] data_;
            // #ifdef ENABLE_MATRIX_DEBUG (using the Chapter 2 debug macro idea)
            // std::cout << "[~Matrix] freeing " << rows_ << "x" << cols_
            //           << " matrix" << std::endl;
            // #endif
        }

        // ============================================================
        // Copy constructor (Rule of 5 — deep copy)
        // ============================================================
        Matrix(const Matrix& other)
            : rows_(other.rows_), cols_(other.cols_), data_(nullptr) {
            if (other.data_ && rows_ > 0 && cols_ > 0) {
                std::size_t total = rows_ * cols_;
                data_ = new T[total];
                for (std::size_t i = 0; i < total; ++i) {
                    data_[i] = other.data_[i];
                }
            }
        }

        // Copy assignment
        Matrix& operator=(const Matrix& other) {
            if (this != &other) {
                // Free the old resource
                delete[] data_;
                data_ = nullptr;

                rows_ = other.rows_;
                cols_ = other.cols_;

                if (other.data_ && rows_ > 0 && cols_ > 0) {
                    std::size_t total = rows_ * cols_;
                    data_ = new T[total];
                    for (std::size_t i = 0; i < total; ++i) {
                        data_[i] = other.data_[i];
                    }
                }
            }
            return *this;
        }

        // ============================================================
        // Move constructor (Rule of 5 — transfer ownership)
        // ============================================================
        Matrix(Matrix&& other) noexcept
            : rows_(other.rows_), cols_(other.cols_), data_(other.data_) {
            // Put the source object into an empty state
            other.rows_ = 0;
            other.cols_ = 0;
            other.data_ = nullptr;
        }

        // Move assignment
        Matrix& operator=(Matrix&& other) noexcept {
            if (this != &other) {
                // Free the current resource
                delete[] data_;

                // "Steal" other's resource
                rows_ = other.rows_;
                cols_ = other.cols_;
                data_ = other.data_;

                // Put other into an empty state
                other.rows_ = 0;
                other.cols_ = 0;
                other.data_ = nullptr;
            }
            return *this;
        }

        // ============================================================
        // Element access
        // ============================================================
        T& operator()(std::size_t row, std::size_t col) {
            MATRIX_ASSERT(row < rows_ && col < cols_,
                          "Index out of range: (" + std::to_string(row) + ","
                          + std::to_string(col) + ") exceeds ("
                          + std::to_string(rows_) + "," + std::to_string(cols_) + ")");
            return data_[row * cols_ + col];
        }

        const T& operator()(std::size_t row, std::size_t col) const {
            MATRIX_ASSERT(row < rows_ && col < cols_, "Index out of range (const)");
            return data_[row * cols_ + col];
        }

        // ============================================================
        // Properties
        // ============================================================
        std::size_t rows() const { return rows_; }
        std::size_t cols() const { return cols_; }
        std::size_t totalElements() const { return rows_ * cols_; }
        std::size_t totalBytes() const { return rows_ * cols_ * sizeof(T); }
        bool empty() const { return data_ == nullptr; }

        // ============================================================
        // Raw data access
        // ============================================================
        T* data() { return data_; }
        const T* data() const { return data_; }

        // ============================================================
        // Matrix operations
        // ============================================================
        void fill(T value) {
            for (std::size_t i = 0; i < rows_ * cols_; ++i) {
                data_[i] = value;
            }
        }

        // Transpose (returns a new matrix)
        Matrix transposed() const {
            Matrix result(cols_, rows_);
            for (std::size_t r = 0; r < rows_; ++r) {
                for (std::size_t c = 0; c < cols_; ++c) {
                    result(c, r) = (*this)(r, c);
                }
            }
            return result;
        }

        // Print the matrix (visualization for small matrices)
        void print(const char* name = nullptr, int width = 6) const {
            if (name) std::cout << name << " (" << rows_ << "x" << cols_ << "):" << std::endl;
            else std::cout << "Matrix (" << rows_ << "x" << cols_ << "):" << std::endl;

            for (std::size_t r = 0; r < rows_; ++r) {
                std::cout << "  [";
                for (std::size_t c = 0; c < cols_; ++c) {
                    std::cout << std::setw(width) << (*this)(r, c);
                }
                std::cout << "  ]" << std::endl;
            }
            std::cout << std::endl;
        }

    private:
        std::size_t rows_;
        std::size_t cols_;
        T* data_;
    };

    // ============================================================
    // Image-processing utilities namespace
    // ============================================================
    namespace Filters {

        // Simulated grayscale conversion (process an RGB region into grayscale)
        void adjustBrightness(Matrix<double>& image, double factor) {
            std::size_t total = image.totalElements();
            for (std::size_t i = 0; i < total; ++i) {
                image.data()[i] *= factor;
            }
        }

        // Generate a Gaussian kernel (a common convolution kernel in image processing)
        Matrix<double> createGaussianKernel(int size, double sigma) {
            Matrix<double> kernel(size, size);
            int center = size / 2;
            double sum = 0.0;

            for (int r = 0; r < size; ++r) {
                for (int c = 0; c < size; ++c) {
                    double dx = static_cast<double>(c - center);
                    double dy = static_cast<double>(r - center);
                    double val = std::exp(-(dx * dx + dy * dy) / (2.0 * sigma * sigma));
                    kernel(r, c) = val;
                    sum += val;
                }
            }

            // Normalize
            for (int r = 0; r < size; ++r) {
                for (int c = 0; c < size; ++c) {
                    kernel(r, c) /= sum;
                }
            }

            return kernel;
        }

        // Simulated edge detection (the vertical part of the Sobel operator)
        Matrix<double> createSobelVertical() {
            Matrix<double> sobel(3, 3);
            sobel(0, 0) = -1; sobel(0, 1) = 0; sobel(0, 2) = 1;
            sobel(1, 0) = -2; sobel(1, 1) = 0; sobel(1, 2) = 2;
            sobel(2, 0) = -1; sobel(2, 1) = 0; sobel(2, 2) = 1;
            return sobel;
        }

    }  // namespace Filters

    // ============================================================
    // Simulated image-processing pipeline
    // ============================================================
    namespace Pipeline {

        // Simulate loading an image (create a pixel matrix)
        Matrix<double> loadImage(int width, int height) {
            std::cout << "Loading image " << width << "x" << height << std::endl;
            Matrix<double> img(height, width);

            // Simulated pixel data
            for (int r = 0; r < height; ++r) {
                for (int c = 0; c < width; ++c) {
                    // Simple gradient + simulated random noise
                    img(r, c) = static_cast<double>(r + c) * 0.5;
                }
            }

            std::cout << "  Allocated memory: " << img.totalBytes() << " bytes" << std::endl;
            return img;  // move semantics! not a deep copy
        }

        // Simulate saving an image
        void saveImage(const Matrix<double>& img, const char* filename) {
            std::cout << "Saving image to: " << filename << std::endl;
            std::cout << "  Dimensions: " << img.cols() << "x" << img.rows()
                      << " (" << img.totalBytes() << " bytes)" << std::endl;
        }

    }  // namespace Pipeline

}  // namespace ImageProcessing

    std::cout << "║     Image Processor          ║" << std::endl;
    std::cout << "╚══════════════════════════════╝\n" << std::endl;

    // ============================================================
    // 1. Basic operations: create a matrix, access elements
    // ============================================================
    std::cout << "=== 1. Creating a Simple Matrix ===" << std::endl;

    for (int r = 0; r < 3; ++r) {
        for (int c = 0; c < 4; ++c) {
            smallMat(r, c) = (r + 1) * 10 + c;
        }
    }
    smallMat.print("Small matrix (3x4)", 4);

    // ============================================================
    // 2. Copy construction (deep copy)
    // ============================================================
    std::cout << "=== 2. Copy Construction Demo (Deep Copy) ===" << std::endl;
    Img::Matrix<int> matCopy(smallMat);  // deep copy
    matCopy(0, 0) = 999;                 // modifying the copy does not affect the original
    std::cout << "Original (0,0) = " << smallMat(0, 0) << std::endl;  // 10
    std::cout << "Copy (0,0) = " << matCopy(0, 0) << std::endl;  // 999

    // ============================================================
    // 3. Move construction (transfer ownership, avoid a deep copy)
    // ============================================================
    std::cout << "\n=== 3. Move Construction Demo (Zero-Copy) ===" << std::endl;
    Img::Matrix<int> matSource(3, 3, 42);   // filled with 42
    std::cout << "Before move: matSource.empty() = "
              << matSource.empty() << std::endl;  // false

    Img::Matrix<int> matDest(std::move(matSource));  // move construction
    std::cout << "After move: matSource.empty() = "
              << matSource.empty() << std::endl;  // true (resource transferred)
    std::cout << "After move: matDest.empty() = "
              << matDest.empty() << std::endl;    // false
    matDest.print("Destination matrix (moved in)", 4);

    // ============================================================
    // 4. Image-processing pipeline (real scenario)
    // ============================================================
    std::cout << "\n=== 4. Image-Processing Pipeline ===" << std::endl;

    // Load an "image"
    Img::Matrix<double> photo = ImgPipeline::loadImage(1920, 1080);
    // The return value uses move semantics, no deep copy

    // Apply a Gaussian blur kernel
    Img::Matrix<double> gaussian = ImgFilters::createGaussianKernel(5, 1.4);
    gaussian.print("Gaussian kernel 5x5 (sigma=1.4)", 10);

    // Apply Sobel edge detection
    Img::Matrix<double> sobel = ImgFilters::createSobelVertical();
    sobel.print("Sobel vertical operator 3x3", 4);

    std::cout << "Adjusting brightness..." << std::endl;
    ImgFilters::adjustBrightness(photo, 1.2);  // brighten by 20%

    // Save the processed image
    ImgPipeline::saveImage(photo, "output_processed.raw");

    // ============================================================
    // 5. Matrix transpose (returns a new matrix, uses move semantics)
    // ============================================================
    std::cout << "\n=== 5. Matrix Transpose ===" << std::endl;
    Img::Matrix<int> matA(2, 3);
    matA(0, 0) = 1; matA(0, 1) = 2; matA(0, 2) = 3;
    matA(1, 0) = 4; matA(1, 1) = 5; matA(1, 2) = 6;
    matA.print("Original matrix (2x3)", 4);

    Img::Matrix<int> matAT = matA.transposed();
    matAT.print("Transposed matrix (3x2)", 4);
    // transposed() returns a temporary; move semantics avoid a copy

    // ============================================================
    // 6. Move assignment demo
    // ============================================================
    std::cout << "\n=== 6. Move Assignment ===" << std::endl;
    Img::Matrix<int> matB(2, 2, 1);
    Img::Matrix<int> matC(3, 3, 9);
    std::cout << "matB size: " << matB.rows() << "x" << matB.cols() << std::endl;
    std::cout << "matC size: " << matC.rows() << "x" << matC.cols() << std::endl;

    matB = std::move(matC);  // move assignment: matB frees its old resource and takes over matC's
    std::cout << "After move assignment:" << std::endl;
    std::cout << "matB size: " << matB.rows() << "x" << matB.cols()
              << " (took over matC's 3x3 data)" << std::endl;
    std::cout << "matC size: " << matC.rows() << "x" << matC.cols()
              << " (now an empty matrix)" << std::endl;

    std::cout << "\n=== Image Processing Complete ===" << std::endl;
    // All Matrix objects go out of scope here; destructors free the memory automatically (RAII)
    return 0;
}
```

Code walkthrough:
- **Rule of 5** fully implemented: copy constructor, copy assignment, move constructor, move assignment, destructor
- **RAII**: `new T[rows*cols]` on construction, `delete[] data_` on destruction, never leaks
- **Move semantics**: move construction/assignment avoids deep-copying large data when returning
  from functions and passing arguments (copying a 6MB+ pixel matrix even once can hurt performance)
- **operator()** provides 2D-array-like syntax for element access
- **Namespaces** organize the code: `ImageProcessing::Matrix`, `ImageProcessing::Filters`,
  `ImageProcessing::Pipeline`
- **Macro** (`MATRIX_ASSERT`) provides debug assertions with file name + line number
- Simulates a complete image-processing workflow: load → process → save

Exercise: A Variable-Length String Class, FlexString
----------------------------------------------------

**Scenario**:
C++'s std::string is powerful, but understanding its underlying implementation is essential for mastering
dynamic memory management. This exercise asks you to implement a variable-length string class, FlexString,
from scratch, to deepen your understanding of dynamic memory, RAII, the Rule of 5 and copy control.

**Requirements**:

1. **Internal storage**:
   - Use `char* data_` with dynamically allocated memory to store the string contents
   - Provide `size_` (current string length, excluding '\0') and `capacity_` (allocated capacity)
   - Always keep a '\0' at the end of the string (C-string compatible)

2. **Fully implement the Rule of 5**:
   - Constructors: `FlexString()` (empty string), `FlexString(const char*)` (from a C string),
     `FlexString(const char* s, std::size_t n)` (take the first n characters)
   - Copy constructor: deep copy
   - Copy assignment: free the old resource → deep-copy the new data
   - Move constructor: transfer ownership (the source becomes empty)
   - Move assignment: free the old resource → transfer ownership
   - Destructor: free `data_`

3. **Member functions**:
   - `size()` — returns the string length
   - `capacity()` — returns the capacity
   - `c_str()` — returns a const char*
   - `append(const char* s)` — appends a string, growing automatically when needed
   - `insert(std::size_t pos, const char* s)` — inserts at the given position
   - `erase(std::size_t pos, std::size_t count)` — removes a substring
   - `find(const char* s)` — finds a substring and returns its position (npos if not found)
   - `substr(std::size_t pos, std::size_t count)` — extracts a substring, returning a new FlexString

4. **Operator overloading** (laying the groundwork for Chapter 7):
   - `operator+` for string concatenation (returns a new FlexString)
   - `operator==` for string comparison
   - `operator<<` for stream output (defined outside the class as a friend or free function)

5. **Debug macros** (combining Chapter 2 material):
   - Define a `FLEXSTRING_DEBUG` macro switch
   - In DEBUG mode, print debug information with file name + line number on construction/destruction/growth

6. **Demo program**:
   - Create several FlexString objects in main and test every method
   - Demonstrate the difference between copy construction and move construction (via counters or output)
   - Demonstrate the automatic growth mechanism

**Reference solution skeleton**:

```cpp
#include <iostream>
#include <cstring>
#include <algorithm>
#include <utility>

// ============================================================
// Debug switch (Chapter 2: preprocessor macros)
// ============================================================
#define FLEXSTRING_DEBUG

#ifdef FLEXSTRING_DEBUG
    #define FS_LOG(msg) \
        std::cout << "[FlexString][" << __FILE__ << ":" << __LINE__ \
                  << "] " << msg << std::endl
#else
    #define FS_LOG(msg) ((void)0)
#endif

// Minimum capacity (avoid frequent tiny allocations)
#define MIN_CAPACITY 16

// ============================================================
// FlexString class definition
// ============================================================
class FlexString {
public:
    static const std::size_t npos = static_cast<std::size_t>(-1);

    // Default constructor
    FlexString() : data_(nullptr), size_(0), capacity_(0) {
        FS_LOG("Default constructor: empty string");
        ensureCapacity(MIN_CAPACITY);
        data_[0] = '\0';
    }

    // Construct from a C string
    FlexString(const char* s) : data_(nullptr), size_(0), capacity_(0) {
        FS_LOG("Constructed from C string: \"" << (s ? s : "null") << "\"");
        if (s) {
            size_ = std::strlen(s);
            ensureCapacity(size_ + 1);
            std::strcpy(data_, s);
        } else {
            ensureCapacity(MIN_CAPACITY);
            data_[0] = '\0';
        }
    }

    // Construct from the first n characters
    FlexString(const char* s, std::size_t n) : data_(nullptr), size_(0), capacity_(0) {
        FS_LOG("Partial construction: taking the first " << n << " characters");
        if (s) {
            size_ = std::min(n, std::strlen(s));
            ensureCapacity(size_ + 1);
            std::strncpy(data_, s, size_);
            data_[size_] = '\0';
        } else {
            ensureCapacity(MIN_CAPACITY);
            data_[0] = '\0';
        }
    }

    // Copy constructor (deep copy)
    FlexString(const FlexString& other)
        : data_(nullptr), size_(other.size_), capacity_(0) {
        FS_LOG("Copy constructor: copying \"" << other.c_str() << "\"");
        ensureCapacity(size_ + 1);
        std::strcpy(data_, other.data_);
    }

    // Move constructor
    FlexString(FlexString&& other) noexcept
        : data_(other.data_), size_(other.size_), capacity_(other.capacity_) {
        FS_LOG("Move constructor: transferring \"" << (data_ ? data_ : "") << "\"");
        other.data_ = nullptr;
        other.size_ = 0;
        other.capacity_ = 0;
    }

    // Destructor
    ~FlexString() {
        FS_LOG("Destructor: \"" << (data_ ? data_ : "(empty)") << "\""
                << " (capacity=" << capacity_ << ")");
        delete[] data_;
    }

    // Copy assignment
    FlexString& operator=(const FlexString& other) {
        FS_LOG("Copy assignment: \"" << other.c_str() << "\"");
        if (this != &other) {
            FlexString temp(other);      // copy-construct a temporary
            swap(temp);                  // swap resources
        }
        return *this;
    }

    // Move assignment
    FlexString& operator=(FlexString&& other) noexcept {
        FS_LOG("Move assignment: \"" << (other.data_ ? other.data_ : "") << "\"");
        if (this != &other) {
            delete[] data_;
            data_ = other.data_;
            size_ = other.size_;
            capacity_ = other.capacity_;
            other.data_ = nullptr;
            other.size_ = 0;
            other.capacity_ = 0;
        }
        return *this;
    }

    // ============================================================
    // Element access
    // ============================================================
    char& operator[](std::size_t index) { return data_[index]; }
    const char& operator[](std::size_t index) const { return data_[index]; }

    const char* c_str() const { return data_ ? data_ : ""; }
    std::size_t size() const { return size_; }
    std::size_t capacity() const { return capacity_; }
    bool empty() const { return size_ == 0; }

    // ============================================================
    // Operations
    // ============================================================
    void append(const char* s) {
        if (!s) return;
        std::size_t slen = std::strlen(s);
        if (slen == 0) return;

        FS_LOG("append: \"" << s << "\" (length " << slen << ")");
        ensureCapacity(size_ + slen + 1);
        std::strcpy(data_ + size_, s);
        size_ += slen;
    }

    void insert(std::size_t pos, const char* s) {
        if (!s) return;
        if (pos > size_) pos = size_;

        std::size_t slen = std::strlen(s);
        FS_LOG("insert at position " << pos << ": \"" << s << "\"");
        ensureCapacity(size_ + slen + 1);

        // Shift the characters after pos
        std::memmove(data_ + pos + slen, data_ + pos, size_ - pos + 1);
        // Insert the new characters
        std::memcpy(data_ + pos, s, slen);
        size_ += slen;
    }

    void erase(std::size_t pos, std::size_t count) {
        if (pos >= size_) return;
        std::size_t actualCount = std::min(count, size_ - pos);
        FS_LOG("erase: removing " << actualCount << " characters starting at " << pos);
        std::memmove(data_ + pos, data_ + pos + actualCount,
                     size_ - pos - actualCount + 1);
        size_ -= actualCount;
    }

    std::size_t find(const char* s) const {
        if (!s || !data_) return npos;
        const char* pos = std::strstr(data_, s);
        return pos ? static_cast<std::size_t>(pos - data_) : npos;
    }

    FlexString substr(std::size_t pos, std::size_t count) const {
        if (pos >= size_) return FlexString();
        std::size_t actualCount = std::min(count, size_ - pos);
        return FlexString(data_ + pos, actualCount);
    }

    // ============================================================
    // Operators
    // ============================================================
    FlexString operator+(const FlexString& other) const {
        FlexString result(data_, size_);
        result.append(other.data_);
        return result;
    }

    FlexString operator+(const char* s) const {
        FlexString result(*this);
        result.append(s);
        return result;
    }

    bool operator==(const FlexString& other) const {
        if (size_ != other.size_) return false;
        return std::strcmp(data_, other.data_) == 0;
    }

    bool operator!=(const FlexString& other) const {
        return !(*this == other);
    }

    // ============================================================
    // Utilities
    // ============================================================
    void clear() {
        data_[0] = '\0';
        size_ = 0;
    }

    void swap(FlexString& other) noexcept {
        std::swap(data_, other.data_);
        std::swap(size_, other.size_);
        std::swap(capacity_, other.capacity_);
    }

    void printDebugInfo() const {
        std::cout << "  data_ = " << (void*)data_ << std::endl;
        std::cout << "  size_ = " << size_ << std::endl;
        std::cout << "  capacity_ = " << capacity_ << std::endl;
        std::cout << "  content = \"" << c_str() << "\"" << std::endl;
    }

private:
    char* data_;
    std::size_t size_;
    std::size_t capacity_;

    // Ensure there is enough capacity (grow if not)
    void ensureCapacity(std::size_t required) {
        if (capacity_ >= required) return;

        std::size_t newCapacity = std::max(capacity_ * 2,
                                           std::max(required,
                                                    (std::size_t)MIN_CAPACITY));
        FS_LOG("Growing: " << capacity_ << " → " << newCapacity
                << " (need " << required << " bytes)");

        char* newData = new char[newCapacity];
        if (data_) {
            std::strcpy(newData, data_);
            delete[] data_;
        } else {
            newData[0] = '\0';
        }

        data_ = newData;
        capacity_ = newCapacity;
    }
};

// Stream output operator (global function)
std::ostream& operator<<(std::ostream& os, const FlexString& str) {
    os << str.c_str();
    return os;
}

    std::cout << "\n=== 3. Append and Growth ===" << std::endl;
    FlexString s6("C++");
    s6.append(" is");
    s6.append(" a");
    s6.append(" powerful");
    s6.append(" programming");
    s6.append(" language");
    std::cout << "s6 = \"" << s6 << "\""
              << " (size=" << s6.size()
              << ", capacity=" << s6.capacity() << ")" << std::endl;

    // 4. insert and erase
    std::cout << "\n=== 4. Insert and Erase ===" << std::endl;
    FlexString s7("Hello World");
    std::cout << "Original: \"" << s7 << "\"" << std::endl;

    s7.insert(6, "Beautiful ");
    std::cout << "insert(6, \"Beautiful \"): \"" << s7 << "\"" << std::endl;

    s7.erase(6, 10);
    std::cout << "erase(6, 10): \"" << s7 << "\"" << std::endl;

    // 5. find and substr
    std::cout << "\n=== 5. Find and Substr ===" << std::endl;
    FlexString s8("The quick brown fox jumps over the lazy dog");
    std::size_t pos = s8.find("fox");
    std::cout << "find(\"fox\") = " << pos << std::endl;

    FlexString sub = s8.substr(pos, 3);
    std::cout << "substr(" << pos << ", 3) = \"" << sub << "\"" << std::endl;

    pos = s8.find("elephant");
    std::cout << "find(\"elephant\") = "
              << (pos == FlexString::npos ? "npos (not found)" : std::to_string(pos))
              << std::endl;

    // 6. operator+
    std::cout << "\n=== 6. operator+ ===" << std::endl;
    FlexString firstName("John");
    FlexString lastName(" Doe");
    FlexString fullName = firstName + lastName;
    std::cout << firstName << " + " << lastName << " = \""
              << fullName << "\"" << std::endl;

    FlexString greeting = FlexString("Hello, ") + fullName + "!";
    std::cout << "Concatenated: \"" << greeting << "\"" << std::endl;

    // 7. Copy assignment vs move assignment
    std::cout << "\n=== 7. Copy Assignment vs Move Assignment ===" << std::endl;
    FlexString sa("Original");
    FlexString sb("Temporary");
    std::cout << "Before assignment: sa = \"" << sa << "\", sb = \"" << sb << "\"" << std::endl;

    sa = sb;  // copy assignment
    std::cout << "After sa=sb (copy assignment): sa = \"" << sa << "\"" << std::endl;

    FlexString sc("ToBeMoved");
    sb = std::move(sc);  // move assignment
    std::cout << "After sb=move(sc) (move assignment): sb = \"" << sb
              << "\", sc = \"" << sc << "\" (empty)" << std::endl;

    // 8. Comparison
    std::cout << "\n=== 8. Comparison ===" << std::endl;
    FlexString a("abc"), b("abc"), c("xyz");
    std::cout << "\"abc\"==\"abc\" → " << (a == b ? "true" : "false") << std::endl;
    std::cout << "\"abc\"==\"xyz\" → " << (a == c ? "true" : "false") << std::endl;
    std::cout << "\"abc\"!=\"xyz\" → " << (a != c ? "true" : "false") << std::endl;

    // 9. Debug information
    std::cout << "\n=== 9. Debug Information ===" << std::endl;
    s6.printDebugInfo();

    std::cout << "\n=== Tests Complete ===" << std::endl;
    return 0;
}
```

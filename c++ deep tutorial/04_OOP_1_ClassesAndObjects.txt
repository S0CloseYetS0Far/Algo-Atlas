1. Class Definition and Access Control: Basic Examples
------------------------------------------------------

In C++, the class is the core of object-oriented programming. A class encapsulates data (member variables) and the functions that operate on that data (member functions) together.

[Example 1-1] A simple BankAccount class:

```cpp
#include <iostream>
#include <string>

class BankAccount {
public:    // public members: accessible directly from outside
    // Constructor
    BankAccount(const std::string& owner, double initialBalance)
        : ownerName(owner), balance(initialBalance) {
        std::cout << "Account created for " << ownerName << std::endl;
    }

    // Public member functions: provide the external interface
    void deposit(double amount) {
        if (amount > 0) {
            balance += amount;
            std::cout << "Deposited: " << amount << std::endl;
        }
    }

    bool withdraw(double amount) {
        if (amount > 0 && amount <= balance) {
            balance -= amount;
            std::cout << "Withdrawn: " << amount << std::endl;
            return true;
        }
        return false;
    }

    double getBalance() const {   // const member function: does not modify member variables
        return balance;
    }

private:   // private members: not directly accessible from outside
    std::string ownerName;
    double balance;
    int internalID;   // internal ID that outside code doesn't need to know about
};

int main() {
    BankAccount acc("Alice", 1000.0);
    acc.deposit(500.0);
    acc.withdraw(200.0);
    std::cout << "Balance: " << acc.getBalance() << std::endl;
    // acc.balance = 10000;  // Compile error! balance is private
    return 0;
}
```

Access control explained:
  public    — accessible to users of the class (outside code)
  private   — accessible only to the class's own member functions (the default access level with the class keyword)
  protected — accessible to the class itself and its derived classes (covered in detail in Chapter 5, Inheritance)

[Example 1-2] Constructors and destructors:

```cpp
#include <iostream>
#include <cstring>

class Message {
private:
    char* content;     // dynamically allocated character array
    size_t length;
    static int msgCount;  // static member variable

public:
    // Default constructor
    Message() : content(nullptr), length(0) {
        msgCount++;
        std::cout << "Default constructor: empty message created" << std::endl;
    }

    // Parameterized constructor
    Message(const char* msg) : length(std::strlen(msg)) {
        content = new char[length + 1];
        std::strcpy(content, msg);
        msgCount++;
        std::cout << "Parameterized constructor: \"" << content << "\"" << std::endl;
    }

    // Copy constructor — deep copy
    Message(const Message& other) : length(other.length) {
        content = new char[length + 1];
        std::strcpy(content, other.content);
        msgCount++;
        std::cout << "Copy constructor" << std::endl;
    }

    // Destructor
    ~Message() {
        delete[] content;
        msgCount--;
        std::cout << "Destructor: message destroyed" << std::endl;
    }

    void print() const {
        if (content)
            std::cout << "Message: " << content << std::endl;
        else
            std::cout << "Message: (empty)" << std::endl;
    }

    static int getCount() { return msgCount; }
};

int Message::msgCount = 0;  // static member variable defined outside the class

int main() {
    Message m1("Hello, World!");  // parameterized construction
    Message m2(m1);               // copy construction
    Message m3;                   // default construction
    m1.print();
    m2.print();
    m3.print();
    std::cout << "Live messages: " << Message::getCount() << std::endl;
    return 0;
}
// The destructors of the three objects are called automatically here (in reverse order of construction)
```

2. Low-Level Computer Principles: Object Memory Layout
------------------------------------------------------

[Principle 2-1] Object memory layout — how member variables are arranged in memory

Consider the following class definition:

```cpp
class Demo {
public:
    int a;      // 4 bytes (assuming a 32-bit system)
    char b;     // 1 byte
    double c;   // 8 bytes
    short d;    // 2 bytes
    void func(); // member functions take no space in the object!
};
```

The object's layout in memory is as follows (assuming a 64-bit system with default 8-byte alignment):

  Offset    Content
  ────────────────────────────────────
  0x00     a (int, 4 bytes)
  0x04     b (char, 1 byte)
  0x05     [padding: 3 bytes]      ← alignment padding
  0x08     c (double, 8 bytes)
  0x10     d (short, 2 bytes)
  0x12     [padding: 6 bytes]      ← aligned to a multiple of 8
  ────────────────────────────────────
  Total size: 24 bytes (not 4+1+8+2=15!)

Memory alignment (padding/alignment) rules:
  - Each member variable's address must be a multiple of its type's size
    (e.g. int is aligned to a multiple of 4, double to a multiple of 8)
  - The size of the whole object must be a multiple of its largest alignment requirement
  - Why the compiler does this: the CPU reads aligned memory addresses more efficiently;
    unaligned access may require two memory reads or even cause a hardware exception

[Principle 2-2] Verifying object size with the sizeof operator

```cpp
#include <iostream>

class Demo {
public:
    int a;      // 4
    char b;     // 1
    double c;   // 8
    short d;    // 2
    // Member functions do not increase the object's size!
    void func() { a = 10; }
    void func2() { b = 'x'; }
};

class Empty {};  // empty class

int main() {
    std::cout << "sizeof(Demo): " << sizeof(Demo) << std::endl;   // prints 24
    std::cout << "sizeof(Empty): " << sizeof(Empty) << std::endl; // prints 1
    // An empty class has size 1 byte because C++ guarantees every object has a unique address
    // This 1 byte stores no data; it exists only to distinguish addresses
    return 0;
}
```

Key points for computing object size:
  1. Only non-static member variables occupy space in the object
  2. Member functions do not occupy object space (the code lives in the text segment, shared by all objects)
  3. Static member variables do not occupy object space (they live in the global data segment)
  4. Virtual functions add a vptr (virtual table pointer), usually 8 bytes (on 64-bit systems)
     — covered in detail in Chapter 6

[Principle 2-3] The this pointer — the implicit parameter of member functions

Every non-static member function implicitly receives a pointer to the current object, named this.

```cpp
class Point {
private:
    int x, y;
public:
    Point(int x, int y) {
        // this->x refers to the member variable, x refers to the parameter
        this->x = x;   // equivalent to Point::x = x
        this->y = y;
    }

    Point& setX(int x) {
        this->x = x;          // distinguish the member variable from the parameter
        return *this;         // return the object itself to support method chaining
    }

    Point& setY(int y) {
        this->y = y;
        return *this;
    }
};

int main() {
    Point p(3, 4);
    p.setX(10).setY(20);  // method chaining: p.setX(10) returns p itself
    return 0;
}
```

How the this pointer works (under the hood):

  When you call p.setX(10), the compiler transforms it into:
      setX(&p, 10);    // this = &p

  Inside the member function:
      this->x = x;     // member variables are accessed through the this pointer

  Compiled assembly pseudocode:
      mov rax, rdi          ; rdi = the this pointer (first argument)
      mov [rax], esi        ; write the argument value into this->x (at offset 0)
      ret

  Notes on calling conventions:
  - In the x86-64 System V ABI (Linux), the this pointer is passed in the rdi register
  - In the x86-64 Microsoft ABI (Windows), the this pointer is passed in the rcx register
  - The this pointer is essentially the first implicit parameter of a member function

[Principle 2-4] Constructor initialization order

```cpp
#include <iostream>

class Member {
public:
    Member(const char* name) : name_(name) {
        std::cout << "Member " << name_ << " constructed" << std::endl;
    }
private:
    const char* name_;
};

class Container {
private:
    Member m1;    // first declared member
    Member m2;    // second declared member
    const int id;
public:
    // The order in the initializer list does not matter! Actual initialization order = member declaration order!
    Container() : m2("second"), m1("first"), id(42) {
        std::cout << "Container constructed" << std::endl;
    }
};

int main() {
    Container c;
    // Output:
    // Member first constructed    ← m1 is initialized first (even though m2 comes first in the initializer list)
    // Member second constructed   ← m2 is initialized afterwards
    // Container constructed
    return 0;
}
```

Key rules:
  1. Member variables are initialized in the order they are declared in the class, regardless of the initializer list order
  2. Base class subobjects are initialized before member variables (covered in Chapter 5)
  3. const members and reference members must be initialized in the initializer list
  4. The initializer list runs before the constructor body

Why must the declaration order be followed?
  Because objects are destroyed in the reverse order of initialization, the compiler must guarantee a deterministic construction/destruction order.
  If construction followed the initializer list order, the correct reverse order could not be guaranteed during destruction.

[Principle 2-5] A deeper look at member function calling conventions

Consider the following code:

```cpp
class Calculator {
    int value;
public:
    Calculator(int v) : value(v) {}
    int add(int x) { return value + x; }      // non-const member function
    int get() const { return value; }          // const member function
    static int version() { return 1; }         // static member function
};

// The low-level correspondence at call time:
int main() {
    Calculator calc(10);

    int r1 = calc.add(5);
    // The compiler transforms this into: int r1 = Calculator::add(&calc, 5);
    // The real function signature is: int add(Calculator* this, int x)

    int r2 = calc.get();
    // The compiler transforms this into: int r2 = Calculator::get(&calc);
    // For a const member function, this is: const Calculator* this

    int v = Calculator::version();
    // Static functions have no this pointer; called directly: int v = Calculator::version();

    return 0;
}
```

How type qualifiers relate to the this pointer:
  - Non-const member function: this has type T* const (the pointer itself cannot change, the pointee can)
  - const member function:     this has type const T* const (neither the pointer nor the pointee can change)
  - This is the fundamental reason const member functions cannot modify member variables

[Principle 2-6] A note on the space reserved in objects for the virtual pointer (vptr)

If a class contains virtual functions, the compiler inserts a vptr at the very beginning of the object's memory layout:

```cpp
class Base {
    int data;
public:
    virtual void func() {}   // has a virtual function → contains a vptr
};

class NoVirtual {
    int data;
public:
    void func() {}           // no virtual functions → no vptr
};

// sizeof(Base) == 16 (vptr=8 bytes + int=4 bytes + padding=4 bytes)
// sizeof(NoVirtual) == 4  (only the int member)

// The vptr points to the virtual function table (vtable), which stores the addresses of all virtual functions
// The vtable lives in the read-only data segment (.rodata); all objects of the same class share one vtable
// This is studied in depth in Chapter 6, "Polymorphism and Virtual Functions"
```

2.1 class vs struct
------------------------------------

```cpp
// class: default access level is private
class C {
    int a;          // private (default)
public:
    int b;          // public
};

// struct: default access level is public
struct S {
    int a;          // public (default)
private:
    int b;          // private
};

// Apart from this, class and struct are almost identical in C++
// Both can have member functions, constructors, destructors, inheritance, etc.

// By convention:
// struct is used for simple data aggregates (POD types)
// class  is used for complex types with encapsulated logic
```

2.2 Constructors: A Complete Guide
------------------------------------

[Default constructor]
A constructor with no parameters (or where every parameter has a default value).

```cpp
class Widget {
    int id;
public:
    Widget() : id(0) { }              // default constructor
    Widget(int i = 0) : id(i) { }     // also a default constructor (the parameter has a default value)
};
// Note: if a class has no constructors at all, the compiler generates a default constructor automatically
// Once you define any constructor, the compiler no longer generates it automatically
```

[Parameterized constructor]

```cpp
class Point {
    int x, y;
public:
    Point(int xVal, int yVal) : x(xVal), y(yVal) { }
    // You can also assign in the constructor body, but it is less efficient:
    // Point(int xVal, int yVal) { x = xVal; y = yVal; }
};
```

[Copy constructor]
Called when a new object is initialized from an object of the same type.

```cpp
class Buffer {
    int* data;
    size_t size;
public:
    Buffer(size_t s) : size(s), data(new int[s]) { }

    // Copy constructor — deep copy
    Buffer(const Buffer& other) : size(other.size), data(new int[other.size]) {
        for (size_t i = 0; i < size; ++i)
            data[i] = other.data[i];
    }

    ~Buffer() { delete[] data; }
};

// When it is called:
// Buffer b2(b1);        // direct initialization
// Buffer b3 = b1;       // copy initialization
// void func(Buffer b);  // pass-by-value parameter
// Buffer func() { return b; } // return value (may be optimized away by RVO)
```

[Delegating constructor (C++11)]
One constructor calls another constructor of the same class.

```cpp
class Employee {
    std::string name;
    int id;
    double salary;
public:
    // Primary constructor
    Employee(const std::string& n, int i, double s)
        : name(n), id(i), salary(s) { }

    // Delegates to the primary constructor
    Employee(const std::string& n, int i)
        : Employee(n, i, 0.0) { }         // only name and employee ID given, salary defaults to 0

    Employee(const std::string& n)
        : Employee(n, 0, 0.0) { }         // only the name given

    Employee()
        : Employee("Unknown", 0, 0.0) { } // no arguments, everything defaulted

    void print() const {
        std::cout << name << " (ID:" << id << ") $" << salary << std::endl;
    }
};

// Usage:
// Employee e1("Alice", 1001, 50000.0);  // primary constructor
// Employee e2("Bob", 1002);             // delegating constructor
// Employee e3("Charlie");              // delegating constructor
// Employee e4;                          // delegating constructor
```

Note: when using a delegating constructor, the initializer list may not contain any other member initializers.
That is, `Employee(const std::string& n) : name(n), Employee(n, 0, 0.0) {}` is an error!

2.3 Destructors
------------------------------------

```cpp
class FileHandler {
    FILE* file;
public:
    FileHandler(const char* filename) {
        file = fopen(filename, "r");
    }

    // Destructor — cleans up resources automatically
    ~FileHandler() {
        if (file) {
            fclose(file);
            std::cout << "File closed" << std::endl;
        }
    }
    // Characteristics of a destructor:
    // 1. Takes no parameters and has no return value
    // 2. Each class can have only one destructor
    // 3. Called automatically when the object goes out of scope
    // 4. Destruction order = reverse of construction order
};

// When a destructor is called:
// 1. A stack object goes out of scope
// 2. delete frees a heap object
// 3. A temporary object's lifetime ends
// 4. Global/static objects are destroyed when the program ends
```

2.4 Member Initializer List vs Assignment in the Constructor Body
-----------------------------------------------------------------

```cpp
#include <iostream>
#include <string>
#include <chrono>

class Inefficient {
    std::string name;
    int value;
public:
    // Assignment in the constructor body: members are default-initialized first, then assigned (two steps)
    Inefficient(const std::string& n, int v) {
        name = n;     // 1. name is first default-constructed (empty string)
                      // 2. then the assignment runs (copying n's contents)
        value = v;    // for fundamental types, assignment and initialization are equally efficient
    }
};

class Efficient {
    std::string name;
    int value;
public:
    // Initializer list: members are initialized directly (in one step)
    Efficient(const std::string& n, int v)
        : name(n), value(v) { }  // name directly calls the copy constructor, no default + assignment needed
};

// Cases where the initializer list is mandatory:
class MustUseInitList {
    const int MAX_SIZE;       // const members must be initialized
    int& ref;                 // reference members must be initialized
    std::string name;
public:
    MustUseInitList(int max, int& r, const std::string& n)
        : MAX_SIZE(max), ref(r), name(n) { }
    // The following is wrong:
    // MustUseInitList(int max) {
    //     MAX_SIZE = max;    // Error: a const member cannot be assigned
    // }
};
```

Efficiency comparison summary:
  Initializer list:     member → constructed directly (e.g. by calling the copy constructor)
  Body assignment:      member → default-constructed → assignment (one extra step)
  For fundamental types (int, double, etc.): equally efficient
  For class types (string, vector, etc.): the initializer list is clearly better

2.5 More Uses of the this Pointer
------------------------------------

```cpp
class Chain {
    int val;
public:
    Chain(int v) : val(v) { }

    // 1. Return *this to enable method chaining
    Chain& increment() { ++val; return *this; }
    Chain& multiply(int factor) { val *= factor; return *this; }

    // 2. Use this when comparing
    bool isEqual(const Chain& other) const {
        return this == &other;  // check whether it is the same object
    }

    // 3. Using this in a const member function
    const Chain* getPointer() const {
        return this;  // this has type const Chain*
    }

    // 4. delete this (rarely used, but appears in some design patterns)
    void destroySelf() {
        // Only safe to call if the object was allocated with new
        delete this;
    }

    int getVal() const { return val; }
};

int main() {
    Chain c(1);
    c.increment().multiply(5).increment();  // ((1+1)*5)+1 = 11
    std::cout << c.getVal() << std::endl;    // prints 11
    return 0;
}
```

Summary of when to use the this pointer:
  1. To distinguish a member variable from a parameter with the same name
  2. To return *this to support method chaining
  3. To return a pointer/reference to the object itself
  4. To check whether a parameter is the current object itself
  5. To get the derived class's type in templates (the CRTP pattern, Chapter 8)

2.6 static Member Variables and Static Member Functions
-------------------------------------------------------

```cpp
#include <iostream>

class Product {
private:
    std::string name;
    double price;

    static int totalProducts;     // static member variable declaration
    static double totalRevenue;   // static member variable declaration

public:
    Product(const std::string& n, double p) : name(n), price(p) {
        totalProducts++;
        totalRevenue += p;
    }

    ~Product() {
        totalProducts--;
    }

    // Static member functions — can only access static members
    static int getTotalProducts() { return totalProducts; }
    static double getTotalRevenue() { return totalRevenue; }
    static double getAveragePrice() {
        if (totalProducts == 0) return 0.0;
        return totalRevenue / totalProducts;
    }

    // There is no this pointer in a static member function!
    // So it cannot access non-static members
    // static void printName() { std::cout << name; }  // Error!
};

// Static member variables must be defined outside the class (to allocate storage)
int Product::totalProducts = 0;
double Product::totalRevenue = 0.0;

int main() {
    Product p1("Laptop", 999.99);
    Product p2("Phone", 699.99);
    Product p3("Tablet", 399.99);

    // Access static members through the class name (recommended)
    std::cout << "Total products: " << Product::getTotalProducts() << std::endl;
    std::cout << "Total revenue: $" << Product::getTotalRevenue() << std::endl;
    std::cout << "Average price: $" << Product::getAveragePrice() << std::endl;

    // You can also access them through an object (not recommended)
    // std::cout << p1.getTotalProducts() << std::endl;  // works but is bad style

    return 0;
}
```

How static members work under the hood:
  - Static member variables are stored in the global data segment (.data or .bss) and belong to no object
  - The lifetime of a static member variable is the entire run of the program
  - Static member functions have no this pointer, so they are true "class-level functions"
  - Since C++17, static member variables can be defined inside the class using inline:
    `static inline int count = 0;  // can be initialized in-class since C++17`

2.7 const Member Functions and the mutable Keyword
--------------------------------------------------

```cpp
#include <iostream>
#include <string>

class Sensor {
private:
    std::string id;
    double temperature;
    mutable int readCount;  // mutable: can be modified even in const functions

public:
    Sensor(const std::string& sensorId)
        : id(sensorId), temperature(0.0), readCount(0) { }

    void setTemperature(double t) {
        temperature = t;  // non-const functions can modify any member
    }

    // A const member function promises not to modify the object's state
    double getTemperature() const {
        readCount++;  // mutable members can be modified (e.g. counting reads)
        return temperature;
    }

    // const overloading — chosen automatically based on the constness of the calling object
    std::string& getID() {               // non-const version
        std::cout << "Non-const getID called" << std::endl;
        return id;
    }

    const std::string& getID() const {   // const version
        std::cout << "Const getID called" << std::endl;
        return id;
    }

    int getReadCount() const { return readCount; }
};

int main() {
    Sensor s("TEMP001");
    s.setTemperature(25.5);

    std::cout << "Temp: " << s.getTemperature() << std::endl;
    std::cout << "ReadCount: " << s.getReadCount() << std::endl;  // 1
    std::cout << "Temp: " << s.getTemperature() << std::endl;
    std::cout << "ReadCount: " << s.getReadCount() << std::endl;  // 2

    // A const object can only call const member functions
    const Sensor cs("TEMP002");
    std::cout << "Temp: " << cs.getTemperature() << std::endl;  // calls the const version
    // cs.setTemperature(30.0);  // Error! A const object cannot call a non-const function

    // Testing const overloading
    s.getID();   // calls the non-const version
    cs.getID();  // calls the const version

    return 0;
}
```

When to use mutable:
  1. Caching computed results (e.g. an expensive computation cached in a mutable member)
  2. Members that don't affect the object's logical state, such as access counters or debug logs
  3. Synchronization locks (mutex members are usually declared mutable, since locking doesn't affect logical constness)

2.8 The explicit Keyword (Preventing Implicit Conversions)
----------------------------------------------------------

```cpp
#include <iostream>

class Dollar {
private:
    double amount;
public:
    // No explicit — implicit conversions are allowed
    Dollar(double amt) : amount(amt) {
        std::cout << "Dollar constructed from double: " << amt << std::endl;
    }

    double getAmount() const { return amount; }
};

class ExplicitDollar {
private:
    double amount;
public:
    // With explicit — implicit conversions are forbidden
    explicit ExplicitDollar(double amt) : amount(amt) {
        std::cout << "ExplicitDollar constructed from double: " << amt << std::endl;
    }

    double getAmount() const { return amount; }
};

void processDollar(const Dollar& d) {
    std::cout << "Processing: $" << d.getAmount() << std::endl;
}

void processExplicitDollar(const ExplicitDollar& d) {
    std::cout << "Processing: $" << d.getAmount() << std::endl;
}

int main() {
    Dollar d1(99.99);     // direct construction, OK
    Dollar d2 = 199.99;   // implicit conversion, OK (because there is no explicit)

    processDollar(299.99);  // implicit conversion: double → Dollar, OK
    // This line silently creates a temporary Dollar object, which may not be what the programmer intended

    ExplicitDollar ed1(99.99);     // direct construction, OK
    // ExplicitDollar ed2 = 199.99;   // Error! explicit forbids implicit conversion
    // processExplicitDollar(299.99); // Error! explicit forbids implicit conversion

    ExplicitDollar ed3 = ExplicitDollar(199.99);  // explicit conversion, OK
    processExplicitDollar(ExplicitDollar(299.99)); // explicit conversion, OK

    return 0;
}
```

Advice on explicit:
  Most single-argument constructors should be marked explicit, unless you specifically want to support implicit conversion.
  This prevents bugs caused by accidental type conversions.

explicit can also be used on conversion operators (since C++11):
```cpp
class Wrapper {
    int value;
public:
    Wrapper(int v) : value(v) {}
    explicit operator int() const { return value; }  // requires an explicit conversion
    operator bool() const { return value != 0; }     // allows implicit conversion to bool
};

// Wrapper w(42);
// int x = w;         // Error! explicit operator int()
// int x = int(w);    // OK, explicit conversion
// int x = static_cast<int>(w); // OK
// if (w) { ... }     // OK, operator bool() is not explicit
```

2.9 =default and =delete (C++11)
------------------------------------

```cpp
#include <iostream>

// =default: explicitly ask the compiler to generate the default version
class DefaultDemo {
public:
    DefaultDemo() = default;                        // default constructor
    DefaultDemo(const DefaultDemo&) = default;      // copy constructor
    DefaultDemo& operator=(const DefaultDemo&) = default;  // copy assignment
    ~DefaultDemo() = default;                       // destructor
};

// =delete: explicitly disable a function
class NonCopyable {
public:
    NonCopyable() = default;

    // Disable copy construction and copy assignment
    NonCopyable(const NonCopyable&) = delete;
    NonCopyable& operator=(const NonCopyable&) = delete;

    // Allow moving
    NonCopyable(NonCopyable&&) = default;
    NonCopyable& operator=(NonCopyable&&) = default;
};

// =delete can also be used to disable specific implicit conversions
class OnlyInt {
public:
    OnlyInt(int value) : val(value) {}
    OnlyInt(double) = delete;          // forbid construction from double
    OnlyInt(char) = delete;            // forbid construction from char
    // OnlyInt(long) = delete;         // long can be disabled too if needed

    int getVal() const { return val; }
private:
    int val;
};

int main() {
    NonCopyable obj1;
    // NonCopyable obj2 = obj1;  // Error: copy constructor is deleted
    // NonCopyable obj3(obj1);   // Error: copy constructor is deleted

    NonCopyable obj2 = std::move(obj1);  // OK, move construction

    OnlyInt oi1(42);     // OK
    // OnlyInt oi2(3.14);   // Error: construction from double is deleted
    // OnlyInt oi3('A');    // Error: construction from char is deleted

    return 0;
}
```

When to use =default:
  1. When you have defined other constructors but still need the compiler-generated default constructor
  2. To declare intent explicitly and make the code more readable
  3. =default can be used on an out-of-class definition (putting the implementation in a .cpp file)

When to use =delete:
  1. Forbidding copies (singleton pattern, exclusive-resource classes)
  2. Forbidding certain unsafe implicit conversions
  3. Disabling certain template specializations (Chapter 8)
  4. Forbidding allocation on the heap/stack (combined with the new/delete operators)

Example 1: Temperature Converter (the Temperature Class)
--------------------------------------------------------

[Real-life scenario] A weather app needs to display and convert between three temperature units: Celsius, Fahrenheit and Kelvin.
const member functions guarantee that reading the temperature does not modify state, and static is used to count conversions.

```cpp
#include <iostream>
#include <string>
#include <iomanip>

// ====== Debug macro from Chapter 2 (bringing in earlier material) ======
#ifdef DEBUG_MODE
    #define DEBUG_LOG(msg) std::cout << "[DEBUG] " << msg << std::endl
#else
    #define DEBUG_LOG(msg)
#endif

class Temperature {
private:
    double celsius;                    // stored internally in Celsius
    static size_t conversionCount;     // global conversion counter

public:
    // Constructor — defaults to 0 degrees
    Temperature() : celsius(0.0) {
        DEBUG_LOG("Temperature default constructed: 0°C");
    }

    explicit Temperature(double c) : celsius(c) {
        DEBUG_LOG(std::string("Temperature constructed: ") +
                  std::to_string(c) + "°C");
    }

    // Copy constructor
    Temperature(const Temperature& other) : celsius(other.celsius) {
        DEBUG_LOG("Temperature copy constructed");
    }

    // ========== Getting the temperature (const member functions) ==========
    double getCelsius() const {
        conversionCount++;
        return celsius;
    }

    double getFahrenheit() const {
        conversionCount++;
        return celsius * 9.0 / 5.0 + 32.0;
    }

    double getKelvin() const {
        conversionCount++;
        return celsius + 273.15;
    }

    // ========== Setting the temperature ==========
    void setCelsius(double c) {
        celsius = c;
        DEBUG_LOG(std::string("Set to ") + std::to_string(c) + "°C");
    }

    void setFahrenheit(double f) {
        celsius = (f - 32.0) * 5.0 / 9.0;
        DEBUG_LOG(std::string("Set from Fahrenheit: ") + std::to_string(f) + "°F");
    }

    void setKelvin(double k) {
        celsius = k - 273.15;
        DEBUG_LOG(std::string("Set from Kelvin: ") + std::to_string(k) + "K");
    }

    // ========== Static members ==========
    static size_t getConversionCount() { return conversionCount; }
    static void resetConversionCount() { conversionCount = 0; }

    // ========== Temperature comparisons ==========
    bool isFreezing() const { return celsius <= 0.0; }
    bool isBoiling() const { return celsius >= 100.0; }

    // ========== Weather description ==========
    std::string weatherDescription() const {
        if (celsius < 0)       return "Freezing";
        else if (celsius < 10) return "Cold";
        else if (celsius < 20) return "Cool";
        else if (celsius < 30) return "Warm";
        else if (celsius < 38) return "Hot";
        else                   return "Scorching";
    }
};

// Static member variable defined outside the class
size_t Temperature::conversionCount = 0;

// ========== Demo code ==========
int main() {
    // Simulate a weather app's temperature display
    Temperature today(28.5);  // a day at 28.5°C

    std::cout << "===== Weather App Temperature Display =====\n";
    std::cout << "Celsius: " << std::fixed << std::setprecision(1)
              << today.getCelsius() << "°C" << std::endl;
    std::cout << "Fahrenheit: " << today.getFahrenheit() << "°F" << std::endl;
    std::cout << "Kelvin: " << today.getKelvin() << "K" << std::endl;
    std::cout << "Weather: " << today.weatherDescription() << std::endl;
    std::cout << "Freezing: " << (today.isFreezing() ? "Yes" : "No") << std::endl;

    std::cout << "\n===== International City Temperatures =====\n";

    Temperature tokyo;
    tokyo.setCelsius(22.0);
    std::cout << "Tokyo: " << tokyo.getCelsius() << "°C / "
              << tokyo.getFahrenheit() << "°F" << std::endl;

    Temperature newYork;
    newYork.setFahrenheit(77.0);  // the US customarily uses Fahrenheit
    std::cout << "New York: " << newYork.getCelsius() << "°C / "
              << newYork.getFahrenheit() << "°F" << std::endl;

    Temperature northPole;
    northPole.setKelvin(243.15);  // scientific data uses Kelvin
    std::cout << "North Pole: " << northPole.getCelsius() << "°C - "
              << northPole.weatherDescription() << std::endl;

    std::cout << "\nTotal temperature reads: " << Temperature::getConversionCount() << std::endl;

    return 0;
}
```

  g++ -DDEBUG_MODE -std=c++11 program.cpp -o program

  - Class encapsulation (private celsius + public interface)
  - const member functions (the get functions don't modify state)
  - static member variables and functions (conversion counter)
  - explicit constructor (avoids implicit conversions)
  - Copy constructor
  - Preprocessor macros from Chapter 2 (DEBUG_LOG)
  - Member initializer lists

Example 2: Smart Alarm Clock (the AlarmClock Class)
---------------------------------------------------

[Real-life scenario] The underlying implementation of a phone alarm-clock app. It supports several ways of setting the time,
validates that the time is legal, and can simulate the passage of time (tick).

```cpp
#include <iostream>
#include <iomanip>
#include <stdexcept>

// ====== Organizing code with namespaces (bringing in Chapter 3 material) ======
namespace chrono {

class AlarmClock {
private:
    int hour;
    int minute;
    int second;
    bool isAM;          // true=AM, false=PM (ignored in 24-hour format)
    bool use24Hour;     // format flag

    static int totalAlarms;       // total number of alarm clocks created
    static const int MAX_HOUR_24 = 23;
    static const int MAX_HOUR_12 = 12;
    static const int MAX_MINUTE = 59;
    static const int MAX_SECOND = 59;

    // Private helper function for validating the time
    void validateTime(int h, int m, int s, bool is24) {
        if (is24) {
            if (h < 0 || h > MAX_HOUR_24)
                throw std::invalid_argument("Invalid hour for 24-hour format");
        } else {
            if (h < 1 || h > MAX_HOUR_12)
                throw std::invalid_argument("Invalid hour for 12-hour format");
        }
        if (m < 0 || m > MAX_MINUTE)
            throw std::invalid_argument("Invalid minute");
        if (s < 0 || s > MAX_SECOND)
            throw std::invalid_argument("Invalid second");
    }

public:
    // ====== Constructor overloads ======

    // Default constructor — set to 00:00:00, 24-hour format
    AlarmClock() : hour(0), minute(0), second(0), isAM(true), use24Hour(true) {
        totalAlarms++;
        std::cout << "[construct] Default alarm created: 00:00:00 (24-hour format)" << std::endl;
    }

    // Parameterized constructor — 24-hour format
    AlarmClock(int h, int m, int s)
        : hour(h), minute(m), second(s), isAM(true), use24Hour(true) {
        validateTime(h, m, s, true);
        totalAlarms++;
        std::cout << "[construct] Alarm created: " << toString() << std::endl;
    }

    // Parameterized constructor — 12-hour format
    AlarmClock(int h, int m, int s, bool am)
        : hour(h), minute(m), second(s), isAM(am), use24Hour(false) {
        validateTime(h, m, s, false);
        totalAlarms++;
        std::cout << "[construct] Alarm created: " << toString() << std::endl;
    }

    // Copy constructor
    AlarmClock(const AlarmClock& other)
        : hour(other.hour), minute(other.minute), second(other.second),
          isAM(other.isAM), use24Hour(other.use24Hour) {
        totalAlarms++;
        std::cout << "[construct] Alarm copy created: " << toString() << std::endl;
    }

    // Destructor
    ~AlarmClock() {
        totalAlarms--;
        std::cout << "[destruct] Alarm destroyed: " << toString() << std::endl;
    }

    // ====== Simulating the passage of time ======
    void tick() {
        second++;
        if (second > MAX_SECOND) {
            second = 0;
            minute++;
            if (minute > MAX_MINUTE) {
                minute = 0;
                if (use24Hour) {
                    hour = (hour + 1) % 24;
                } else {
                    hour++;
                    if (hour > MAX_HOUR_12) {
                        hour = 1;
                    }
                    if (hour == 12 && minute == 0 && second == 0) {
                        isAM = !isAM;  // switch AM/PM when passing 12 o'clock
                    }
                }
            }
        }
    }

    // Advance n seconds
    void tick(int n) {
        for (int i = 0; i < n; ++i) {
            tick();
        }
    }

    // ====== Time display (const member functions) ======
    std::string toString() const {
        std::ostringstream oss;
        oss << std::setfill('0') << std::setw(2) << hour << ":"
            << std::setw(2) << minute << ":"
            << std::setw(2) << second;
        if (!use24Hour) {
            oss << " " << (isAM ? "AM" : "PM");
        }
        return oss.str();
    }

    void display() const {
        std::cout << "Current time: " << toString() << std::endl;
    }

    // ====== Getter/Setter ======
    int getHour() const   { return hour; }
    int getMinute() const { return minute; }
    int getSecond() const { return second; }
    bool isAMTime() const { return isAM; }
    bool is24HourFormat() const { return use24Hour; }

    void setTime(int h, int m, int s) {
        validateTime(h, m, s, use24Hour);
        hour = h; minute = m; second = s;
    }

    // Convert to total seconds (for time comparisons)
    int totalSeconds() const {
        return hour * 3600 + minute * 60 + second;
    }

    // ====== Static members ======
    static int getTotalAlarms() { return totalAlarms; }

    // ====== Operator overloading (laying the groundwork for Chapter 7) ======
    bool operator==(const AlarmClock& other) const {
        return totalSeconds() == other.totalSeconds();
    }

    bool operator<(const AlarmClock& other) const {
        return totalSeconds() < other.totalSeconds();
    }
};

int AlarmClock::totalAlarms = 0;

}  // namespace chrono

// ========== Demo code ==========
int main() {
    using namespace chrono;

    std::cout << "===== Alarm Setup Demo =====\n";

    // Several ways to construct
    AlarmClock defaultClock;                          // default construction
    AlarmClock morning(7, 0, 0);                     // 24-hour format: 07:00:00
    AlarmClock afternoon(3, 30, 0, true);            // 12-hour format: 03:30:00 AM
    AlarmClock evening(10, 15, 0, false);            // 12-hour format: 10:15:00 PM
    AlarmClock copied(morning);                       // copy construction

    std::cout << "\nAll alarm times:\n";
    defaultClock.display();
    morning.display();
    afternoon.display();
    evening.display();
    copied.display();

    std::cout << "\nCurrently active alarms: " << AlarmClock::getTotalAlarms() << std::endl;

    // Simulating the passage of time
    std::cout << "\n===== 7:00 alarm started, simulating the passage of time =====\n";

    AlarmClock stopwatch(6, 59, 50);  // start from 6:59:50
    std::cout << "Start time: " << stopwatch.toString() << std::endl;

    for (int i = 0; i < 15; i++) {
        stopwatch.tick();
        std::cout << "Tick " << (i+1) << ": " << stopwatch.toString() << std::endl;
    }

    // Test a 12-hour-format time crossing 12 o'clock
    std::cout << "\n===== 12-Hour Format Crossing-12 Test =====\n";
    AlarmClock amClock(11, 59, 55, true);  // 11:59:55 AM
    for (int i = 0; i < 10; i++) {
        amClock.tick();
        std::cout << "  " << amClock.toString() << std::endl;
    }

    // Comparing times
    std::cout << "\n===== Time Comparison =====\n";
    AlarmClock t1(8, 30, 0);
    AlarmClock t2(9, 0, 0);
    std::cout << "8:30 < 9:00 ? " << (t1 < t2 ? "Yes" : "No") << std::endl;
    std::cout << "8:30 == 9:00 ? " << (t1 == t2 ? "Yes" : "No") << std::endl;

    return 0;
}
// All local objects have their destructors called automatically when they go out of scope
```

Concepts incorporated:
  - The chrono namespace organizes the code (Chapter 3)
  - Constructor overloading (default, parameterized, copy)
  - Destructor
  - const member functions
  - static member variables and functions
  - Time validation logic
  - The concept of operator overloading (== and <) — laying the groundwork for Chapter 7

Example 3: Bank Card Account System (the BankAccount Class)
-----------------------------------------------------------

[Real-life scenario] The back-end system behind ATM operations. It encapsulates the card number and balance, stores transaction records in a dynamic array,
manages memory with unique_ptr, and implements deposit/withdrawal/inquiry functions.

```cpp
#include <iostream>
#include <string>
#include <memory>    // unique_ptr
#include <iomanip>
#include <vector>
#include <sstream>

// ====== Debug macro (Chapter 2 material) ======
#ifdef ENABLE_LOGGING
    #define LOG(msg) std::cout << "[LOG] " << msg << std::endl
#else
    #define LOG(msg)
#endif

namespace bank {

// Structure for a single transaction record
struct Transaction {
    std::string timestamp;
    std::string type;   // "DEPOSIT", "WITHDRAW", "TRANSFER_IN", "TRANSFER_OUT"
    double amount;
    double balanceAfter;

    Transaction(const std::string& ts, const std::string& tp,
                double amt, double bal)
        : timestamp(ts), type(tp), amount(amt), balanceAfter(bal) {
        LOG("Transaction recorded: " + type + " $" +
            std::to_string(amount));
    }
};

class BankAccount {
private:
    std::string accountNumber;      // card number
    std::string ownerName;          // account holder's name
    double balance;                 // balance
    // Manage the dynamic array with unique_ptr — memory is freed automatically
    std::unique_ptr<Transaction[]> transactions;
    size_t transactionCount;        // current number of transaction records
    size_t transactionCapacity;     // current capacity
    static size_t totalAccounts;    // total accounts in the system
    static double totalBalance;     // total funds in the system

    // Expand the capacity of the transaction array
    void expandCapacity() {
        size_t newCapacity = transactionCapacity * 2;
        std::unique_ptr<Transaction[]> newArray(
            new Transaction[newCapacity]);
        // Move the old data into the new array
        for (size_t i = 0; i < transactionCount; ++i) {
            newArray[i] = transactions[i];
        }
        transactions = std::move(newArray);
        transactionCapacity = newCapacity;
        LOG("Transaction capacity expanded to " +
            std::to_string(newCapacity));
    }

    // Add a transaction record
    void addTransaction(const std::string& timestamp,
                       const std::string& type, double amount) {
        if (transactionCount >= transactionCapacity) {
            expandCapacity();
        }
        transactions[transactionCount++] =
            Transaction(timestamp, type, amount, balance);
    }

public:
    // ====== Constructor ======
    BankAccount(const std::string& accNum, const std::string& owner,
                double initialDeposit)
        : accountNumber(accNum), ownerName(owner),
          balance(initialDeposit),
          transactions(new Transaction[8]),  // initial capacity 8
          transactionCount(0),
          transactionCapacity(8) {
        totalAccounts++;
        totalBalance += initialDeposit;
        addTransaction("Opening", "DEPOSIT", initialDeposit);
        LOG("Account created: " + accNum + " (" + owner + ")");
    }

    // Copy constructor (duplicates the account)
    BankAccount(const BankAccount& other)
        : accountNumber(other.accountNumber + "_COPY"),
          ownerName(other.ownerName),
          balance(other.balance),
          transactions(new Transaction[other.transactionCapacity]),
          transactionCount(other.transactionCount),
          transactionCapacity(other.transactionCapacity) {
        for (size_t i = 0; i < other.transactionCount; ++i) {
            transactions[i] = other.transactions[i];
        }
        totalAccounts++;
        totalBalance += balance;
        LOG("Account copied: " + accountNumber);
    }

    // Destructor
    ~BankAccount() {
        totalAccounts--;
        totalBalance -= balance;
        LOG("Account closed: " + accountNumber);
        // unique_ptr frees the transaction array memory automatically
    }

    // ====== Deposit ======
    bool deposit(double amount) {
        if (amount <= 0) {
            std::cerr << "Error: deposit amount must be positive" << std::endl;
            return false;
        }
        if (amount > 1000000) {  // per-deposit limit
            std::cerr << "Error: a single deposit cannot exceed 1,000,000" << std::endl;
            return false;
        }
        balance += amount;
        totalBalance += amount;
        addTransaction("Now", "DEPOSIT", amount);
        std::cout << "Deposit successful! $" << amount
                  << " Current balance: $" << balance << std::endl;
        return true;
    }

    // ====== Withdrawal ======
    bool withdraw(double amount) {
        if (amount <= 0) {
            std::cerr << "Error: withdrawal amount must be positive" << std::endl;
            return false;
        }
        // Validate the balance — groundwork for exceptions (Chapter 9 covers full exception handling)
        if (amount > balance) {
            std::cerr << "Error: insufficient funds! Current balance: $" << balance
                      << " Withdrawal amount: $" << amount << std::endl;
            return false;
        }
        if (amount > 50000) {  // per-withdrawal limit
            std::cerr << "Error: a single withdrawal cannot exceed 50,000" << std::endl;
            return false;
        }
        balance -= amount;
        totalBalance -= amount;
        addTransaction("Now", "WITHDRAW", -amount);
        std::cout << "Withdrawal successful! $" << amount
                  << " Current balance: $" << balance << std::endl;
        return true;
    }

    // ====== Transfer ======
    bool transfer(BankAccount& target, double amount) {
        if (&target == this) {
            std::cerr << "Error: cannot transfer to yourself" << std::endl;
            return false;
        }
        if (!withdraw(amount))
            return false;
        target.deposit(amount);
        // Override the type of the withdrawal record
        addTransaction("Now", "TRANSFER_OUT to " + target.accountNumber, -amount);
        target.addTransaction("Now", "TRANSFER_IN from " + accountNumber, amount);
        std::cout << "Transfer successful! $" << amount
                  << " from " << accountNumber << " to " << target.accountNumber
                  << std::endl;
        return true;
    }

    // ====== Queries (const member functions) ======
    double getBalance() const { return balance; }
    const std::string& getAccountNumber() const { return accountNumber; }
    const std::string& getOwnerName() const { return ownerName; }

    // ====== Print the transaction statement ======
    void printStatement() const {
        std::cout << "\n========== Transaction Statement ==========" << std::endl;
        std::cout << "Account: " << accountNumber
                  << " Holder: " << ownerName << std::endl;
        std::cout << "Current balance: $" << std::fixed << std::setprecision(2)
                  << balance << std::endl;
        std::cout << "Number of transactions: " << transactionCount << std::endl;
        std::cout << "-------------------------------" << std::endl;

        for (size_t i = 0; i < transactionCount; ++i) {
            std::cout << std::left
                      << "#" << std::setw(3) << (i + 1)
                      << std::setw(18) << transactions[i].type
                      << " $" << std::setw(10) << transactions[i].amount
                      << " Balance: $" << transactions[i].balanceAfter
                      << std::endl;
        }
        std::cout << "===============================" << std::endl;
    }

    // ====== Account summary ======
    void printSummary() const {
        std::cout << "[" << accountNumber << "] "
                  << ownerName << " - Balance: $"
                  << balance << " - Transactions: " << transactionCount
                  << std::endl;
    }

    // ====== Static members ======
    static size_t getTotalAccounts() { return totalAccounts; }
    static double getTotalBalance()  { return totalBalance; }
    static double getAverageBalance() {
        return totalAccounts == 0 ? 0.0 : totalBalance / totalAccounts;
    }
};

// Static member definitions
size_t BankAccount::totalAccounts = 0;
double BankAccount::totalBalance = 0.0;

}  // namespace bank

// ========== Demo code: simulating ATM operations ==========
int main() {
    using namespace bank;

    std::cout << "===== Bank Account System =====" << std::endl;

    // Create accounts
    BankAccount alice("6222021001000001", "Alice Wang", 5000.0);
    BankAccount bob("6222021001000002", "Bob Li", 3000.0);
    BankAccount charlie("6222021001000003", "Charlie Zhang", 10000.0);

    std::cout << "\n--- Initial Account Overview ---" << std::endl;
    alice.printSummary();
    bob.printSummary();
    charlie.printSummary();
    std::cout << "Total accounts in system: " << BankAccount::getTotalAccounts()
              << " | Total funds: $" << BankAccount::getTotalBalance() << std::endl;

    // Alice deposits
    std::cout << "\n--- Alice Deposits ---" << std::endl;
    alice.deposit(2000.0);
    alice.deposit(500.0);

    // Alice withdraws
    std::cout << "\n--- Alice Withdraws ---" << std::endl;
    alice.withdraw(1500.0);
    alice.withdraw(10000.0);  // insufficient funds
    alice.withdraw(60000.0);  // exceeds the per-withdrawal limit

    // Alice transfers to Bob
    std::cout << "\n--- Alice Transfers to Bob ---" << std::endl;
    alice.transfer(bob, 1000.0);

    // Charlie withdraws
    std::cout << "\n--- Charlie Withdraws ---" << std::endl;
    charlie.withdraw(3000.0);

    // Print statements
    std::cout << "\n--- Alice's Transaction Statement ---" << std::endl;
    alice.printStatement();

    std::cout << "\n--- Bob's Transaction Statement ---" << std::endl;
    bob.printStatement();

    std::cout << "\n--- Charlie's Transaction Statement ---" << std::endl;
    charlie.printStatement();

    // System statistics
    std::cout << "\n===== System Statistics =====" << std::endl;
    std::cout << "Total accounts: " << BankAccount::getTotalAccounts() << std::endl;
    std::cout << "Total funds: $" << BankAccount::getTotalBalance() << std::endl;
    std::cout << "Average balance: $" << BankAccount::getAverageBalance() << std::endl;

    return 0;
}
// When the program ends, all BankAccount objects are destroyed and unique_ptr frees the memory automatically
```

Concepts incorporated:
  - Thorough class encapsulation (private + public interface)
  - unique_ptr managing a dynamic array (Chapter 3, Dynamic Memory)
  - Constructors (parameterized, copy) and destructor
  - const member functions
  - static member variables and functions
  - The this pointer (detecting a transfer to oneself in transfer)
  - Debug macros (Chapter 2)
  - Namespaces (Chapter 3)

Example 4: Student Grade Records System (Combining the Student/Course Classes)
-----------------------------------------------------------------------------

[Real-life scenario] A school's academic affairs office needs to manage student information and course grades.
Two classes work together, sharing course data through shared_ptr.

```cpp
#include <iostream>
#include <string>
#include <memory>   // shared_ptr, make_shared
#include <vector>
#include <iomanip>
#include <algorithm>
#include <map>

// ====== Debug macro (Chapter 2) ======
#define GRADE_DEBUG 1
#if GRADE_DEBUG
    #define G_LOG(msg) std::cout << "[Registrar] " << msg << std::endl
#else
    #define G_LOG(msg)
#endif

namespace school {

// ====== Course class ======
class Course {
private:
    std::string courseID;       // course code, e.g. "MATH101"
    std::string courseName;     // course name, e.g. "Advanced Mathematics"
    int credits;                // credits
    double maxScore;            // full marks (usually 100)
    static int totalCourses;    // total number of courses in the school

public:
    Course() : courseID("N/A"), courseName("Unknown"), credits(0), maxScore(100.0) {
        totalCourses++;
        G_LOG("Default course created");
    }

    Course(const std::string& id, const std::string& name,
           int cr, double max = 100.0)
        : courseID(id), courseName(name), credits(cr), maxScore(max) {
        totalCourses++;
        G_LOG("Course created: " + id + " " + name);
    }

    Course(const Course& other)
        : courseID(other.courseID + "(copy)"),
          courseName(other.courseName),
          credits(other.credits),
          maxScore(other.maxScore) {
        totalCourses++;
        G_LOG("Course copied: " + courseID);
    }

    ~Course() {
        totalCourses--;
        G_LOG("Course destroyed: " + courseID);
    }

    // const member functions
    const std::string& getID()   const { return courseID; }
    const std::string& getName() const { return courseName; }
    int getCredits()             const { return credits; }
    double getMaxScore()         const { return maxScore; }

    void display() const {
        std::cout << "[" << courseID << "] " << courseName
                  << " (" << credits << " credits, max score " << maxScore << ")"
                  << std::endl;
    }

    static int getTotalCourses() { return totalCourses; }
};

int Course::totalCourses = 0;

// ====== Student class ======
class Student {
private:
    std::string studentID;      // student ID
    std::string name;           // name
    int grade;                  // year (1-4)
    std::string major;          // major

    // Transcript: course ID → score
    std::map<std::string, double> scores;

    // Every student holds a shared reference (shared_ptr) to the course catalog;
    // all students share the same course data
    std::shared_ptr<std::vector<Course>> courseCatalog;

    static int totalStudents;

    // Compute the GPA (4.0 scale)
    double calculateGPA() const {
        if (scores.empty()) return 0.0;
        double totalGradePoints = 0.0;
        int totalCredits = 0;

        for (const auto& [courseID, score] : scores) {
            // Look up the course in the catalog to get its credits
            bool found = false;
            int credits = 0;
            if (courseCatalog) {
                for (const auto& course : *courseCatalog) {
                    if (course.getID() == courseID) {
                        credits = course.getCredits();
                        found = true;
                        break;
                    }
                }
            }
            if (!found) continue;  // the course is not in the catalog

            // Convert a percentage score to 4.0-scale grade points
            double gradePoint;
            if (score >= 90)      gradePoint = 4.0;
            else if (score >= 85) gradePoint = 3.7;
            else if (score >= 80) gradePoint = 3.3;
            else if (score >= 75) gradePoint = 3.0;
            else if (score >= 70) gradePoint = 2.7;
            else if (score >= 65) gradePoint = 2.3;
            else if (score >= 60) gradePoint = 2.0;
            else                  gradePoint = 0.0;  // failed

            totalGradePoints += gradePoint * credits;
            totalCredits += credits;
        }

        return totalCredits == 0 ? 0.0 : totalGradePoints / totalCredits;
    }

public:
    Student(const std::string& id, const std::string& n,
            int gr, const std::string& maj,
            std::shared_ptr<std::vector<Course>> catalog)
        : studentID(id), name(n), grade(gr), major(maj),
          courseCatalog(catalog) {
        totalStudents++;
        G_LOG("Student enrolled: " + id + " " + n + " (" + maj + ")");
    }

    ~Student() {
        totalStudents--;
        G_LOG("Student graduated/withdrew: " + studentID + " " + name);
    }

    // ====== Recording scores ======
    void recordScore(const std::string& courseID, double score) {
        // Verify that the course exists
        if (courseCatalog) {
            bool courseExists = false;
            double maxScore = 100.0;
            for (const auto& course : *courseCatalog) {
                if (course.getID() == courseID) {
                    courseExists = true;
                    maxScore = course.getMaxScore();
                    break;
                }
            }
            if (!courseExists) {
                std::cerr << "Error: course " << courseID << " does not exist in the course catalog"
                          << std::endl;
                return;
            }
            if (score < 0 || score > maxScore) {
                std::cerr << "Error: score " << score << " is outside the valid range [0, "
                          << maxScore << "]" << std::endl;
                return;
            }
        }

        scores[courseID] = score;
        G_LOG(name + " (" + studentID + ") " + courseID + ": " +
              std::to_string(score));
    }

    // ====== Querying scores ======
    double getScore(const std::string& courseID) const {
        auto it = scores.find(courseID);
        if (it != scores.end()) {
            return it->second;
        }
        return -1.0;  // not yet recorded
    }

    bool hasScore(const std::string& courseID) const {
        return scores.find(courseID) != scores.end();
    }

    // ====== Ranking ======
    int getRank() const {
        // Simplified: rank by average score (if multiple student objects can be compared)
        return 0;  // real ranking requires all students to be managed externally
    }

    // ====== Getting information (const member functions) ======
    const std::string& getID()   const { return studentID; }
    const std::string& getName() const { return name; }
    int getGrade()               const { return grade; }
    const std::string& getMajor() const { return major; }

    double getAverageScore() const {
        if (scores.empty()) return 0.0;
        double total = 0.0;
        for (const auto& [id, score] : scores) {
            total += score;
        }
        return total / scores.size();
    }

    double getGPA() const { return calculateGPA(); }

    // ====== Grade levels ======
    std::string getGradeLevel(double score) const {
        if (score >= 90) return "Excellent (A)";
        if (score >= 80) return "Good (B)";
        if (score >= 70) return "Average (C)";
        if (score >= 60) return "Pass (D)";
        return "Fail (F)";
    }

    // ====== Print the transcript ======
    void printTranscript() const {
        std::cout << "\n╔═══════════════════════════════════╗" << std::endl;
        std::cout << "║       TRANSCRIPT                  ║" << std::endl;
        std::cout << "╠═══════════════════════════════════╣" << std::endl;
        std::cout << "║ ID:   " << std::left << std::setw(24) << studentID << "║" << std::endl;
        std::cout << "║ Name: " << std::setw(24) << name << "║" << std::endl;
        std::cout << "║ Year: " << grade << " Major: " << std::setw(16)
                  << major << "║" << std::endl;
        std::cout << "╠═══════════════════════════════════╣" << std::endl;

        if (scores.empty()) {
            std::cout << "║   No grade records yet            ║" << std::endl;
        } else {
            for (const auto& [courseID, score] : scores) {
                std::string courseName = courseID;
                if (courseCatalog) {
                    for (const auto& course : *courseCatalog) {
                        if (course.getID() == courseID) {
                            courseName = course.getName();
                            break;
                        }
                    }
                }
                std::cout << "║ " << std::left << std::setw(10) << courseID
                          << std::setw(12) << courseName
                          << std::right << std::setw(7) << score
                          << " " << getGradeLevel(score) << " ║" << std::endl;
            }
        }

        std::cout << "╠═══════════════════════════════════╣" << std::endl;
        std::cout << "║ Average: " << std::fixed << std::setprecision(1)
                  << std::setw(24) << getAverageScore() << "║" << std::endl;
        std::cout << "║ GPA: " << std::setw(27)
                  << getGPA() << "║" << std::endl;
        std::cout << "╚═══════════════════════════════════╝" << std::endl;
    }

    static int getTotalStudents() { return totalStudents; }
};

int Student::totalStudents = 0;

}  // namespace school
```

Example 5: Implementing a Custom String Class from Scratch (MyString)
---------------------------------------------------------------------

[Real-life scenario] The core of a text editor needs efficient string storage.
We implement a string class from scratch, fully demonstrating the Rule of Five.

```cpp
#include <iostream>
#include <cstring>
#include <utility>   // std::move, std::swap
#include <cassert>

// ====== Debug macro ======
#define MYSTRING_DEBUG 1
#if MYSTRING_DEBUG
    #define MSG_LOG(msg) std::cout << "[MyString] " << msg << std::endl
#else
    #define MSG_LOG(msg)
#endif

class MyString {
private:
    char* data;          // dynamically allocated character array
    size_t length;       // string length (excluding '\0')
    size_t capacity;     // currently allocated memory capacity

    static size_t totalChars;   // total characters across all strings
    static int stringCount;     // number of string objects currently alive

    // Reallocate memory
    void reallocate(size_t newCapacity) {
        char* newData = new char[newCapacity + 1];  // +1 for '\0'
        if (data) {
            std::strcpy(newData, data);
            newData[length] = '\0';
        } else {
            newData[0] = '\0';
        }
        delete[] data;
        data = newData;
        capacity = newCapacity;
        MSG_LOG("Reallocated to capacity " + std::to_string(newCapacity));
    }

public:
    // ====== 1. Default constructor ======
    MyString() : data(nullptr), length(0), capacity(0) {
        stringCount++;
        MSG_LOG("Default constructed");
    }

    // ====== 2. Parameterized constructor (from a C string) ======
    MyString(const char* str) {
        length = std::strlen(str);
        capacity = length;
        data = new char[capacity + 1];
        std::strcpy(data, str);
        totalChars += length;
        stringCount++;
        MSG_LOG(std::string("Constructed from C-string: \"") + str + "\"");
    }

    // ====== 3. Copy constructor (Rule of Five - 1) ======
    MyString(const MyString& other) {
        length = other.length;
        capacity = other.capacity;
        if (other.data) {
            data = new char[capacity + 1];
            std::strcpy(data, other.data);
        } else {
            data = nullptr;
        }
        totalChars += length;
        stringCount++;
        MSG_LOG("Copy constructed");
    }

    // ====== 4. Move constructor (Rule of Five - 2) ======
    MyString(MyString&& other) noexcept
        : data(other.data), length(other.length), capacity(other.capacity) {
        // Leave the source object in a valid but unspecified state
        other.data = nullptr;
        other.length = 0;
        other.capacity = 0;
        stringCount++;
        MSG_LOG("Move constructed");
    }

    // ====== 5. Copy assignment operator (Rule of Five - 3) ======
    MyString& operator=(const MyString& other) {
        if (this != &other) {
            // Allocate the new memory first, then free the old (exception safety)
            char* newData = nullptr;
            if (other.data) {
                newData = new char[other.capacity + 1];
                std::strcpy(newData, other.data);
            }
            delete[] data;

            totalChars -= length;
            data = newData;
            length = other.length;
            capacity = other.capacity;
            totalChars += length;
        }
        MSG_LOG("Copy assigned");
        return *this;
    }

    // ====== 6. Move assignment operator (Rule of Five - 4) ======
    MyString& operator=(MyString&& other) noexcept {
        if (this != &other) {
            delete[] data;
            totalChars -= length;

            data = other.data;
            length = other.length;
            capacity = other.capacity;

            other.data = nullptr;
            other.length = 0;
            other.capacity = 0;
        }
        MSG_LOG("Move assigned");
        return *this;
    }

    // ====== 7. Destructor (Rule of Five - 5) ======
    ~MyString() {
        delete[] data;
        totalChars -= length;
        stringCount--;
        MSG_LOG("Destructed (data@" +
                std::to_string(reinterpret_cast<uintptr_t>(data)) + ")");
    }

    // ====== Basic operations ======
    // Get the length
    size_t size() const { return length; }
    size_t getCapacity() const { return capacity; }
    bool empty() const { return length == 0; }

    // Get the C string
    const char* c_str() const { return data ? data : ""; }

    // Append a string
    MyString& append(const MyString& str) {
        if (str.empty()) return *this;
        size_t newLength = length + str.length;
        if (newLength > capacity) {
            reallocate(newLength * 2);  // allocate double the space to reduce future reallocations
        }
        std::strcpy(data + length, str.data);
        totalChars += str.length;
        length = newLength;
        return *this;
    }

    MyString& append(const char* str) {
        return append(MyString(str));  // delegate to the overload above
    }

    // Clear
    void clear() {
        if (data) {
            data[0] = '\0';
        }
        totalChars -= length;
        length = 0;
    }

    // ====== Operator overloading (studied in depth in Chapter 7) ======
    // Subscript operator — non-const version
    char& operator[](size_t index) {
        assert(index < length && "Index out of bounds");
        return data[index];
    }

    // Subscript operator — const version
    const char& operator[](size_t index) const {
        assert(index < length && "Index out of bounds");
        return data[index];
    }

    // Comparison operators
    bool operator==(const MyString& other) const {
        if (length != other.length) return false;
        if (!data && !other.data) return true;
        if (!data || !other.data) return false;
        return std::strcmp(data, other.data) == 0;
    }

    bool operator!=(const MyString& other) const {
        return !(*this == other);
    }

    // Stream output operator (friend function, groundwork for Chapter 7)
    friend std::ostream& operator<<(std::ostream& os, const MyString& str) {
        if (str.data) {
            os << str.data;
        }
        return os;
    }

    // ====== Static members ======
    static size_t getTotalChars() { return totalChars; }
    static int getStringCount() { return stringCount; }

    // ====== Utilities ======
    // Swap two strings
    friend void swap(MyString& a, MyString& b) noexcept {
        using std::swap;
        swap(a.data, b.data);
        swap(a.length, b.length);
        swap(a.capacity, b.capacity);
    }

    // Insert a string at the given position
    MyString& insert(size_t pos, const MyString& str) {
        if (pos > length) return *this;
        size_t newLength = length + str.length;
        if (newLength > capacity) {
            char* newData = new char[newLength * 2 + 1];
            std::strncpy(newData, data, pos);
            std::strcpy(newData + pos, str.data);
            std::strcpy(newData + pos + str.length, data + pos);
            delete[] data;
            data = newData;
            capacity = newLength * 2;
        } else {
            // Shift the following characters
            for (size_t i = length; i >= pos; --i) {
                data[i + str.length] = data[i];
            }
            std::strncpy(data + pos, str.data, str.length);
        }
        totalChars += str.length;
        length = newLength;
        return *this;
    }

    // Get a substring
    MyString substr(size_t pos, size_t count) const {
        if (pos >= length) return MyString();
        if (count > length - pos) count = length - pos;
        char* temp = new char[count + 1];
        std::strncpy(temp, data + pos, count);
        temp[count] = '\0';
        MyString result(temp);
        delete[] temp;
        return result;
    }
};

// Static member variable initialization
size_t MyString::totalChars = 0;
int MyString::stringCount = 0;

// ========== Demo code: simulating a text editor ==========
int main() {
    std::cout << "===== Full Custom String Class Demo =====\n" << std::endl;

    // 1. Construction
    std::cout << "--- 1. Construction ---" << std::endl;
    MyString s1("Hello");
    MyString s2(" World");
    MyString s3;  // empty string

    std::cout << "s1: " << s1 << " (size=" << s1.size() << ")" << std::endl;
    std::cout << "s2: " << s2 << " (size=" << s2.size() << ")" << std::endl;
    std::cout << "s3: \"" << s3 << "\" (empty=" << s3.empty() << ")" << std::endl;

    // 2. Copy construction
    std::cout << "\n--- 2. Copy Construction ---" << std::endl;
    MyString s4(s1);
    std::cout << "s4 (copy of s1): " << s4 << std::endl;
    // Modifying s1 does not affect s4 (deep copy)
    s1[0] = 'h';
    std::cout << "After s1[0]='h': s1=" << s1 << " s4=" << s4 << std::endl;

    // 3. Move construction
    std::cout << "\n--- 3. Move Construction ---" << std::endl;
    MyString s5(std::move(s2));
    std::cout << "s5 (moved from s2): " << s5 << std::endl;
    std::cout << "s2 after move: \"" << s2 << "\" (empty=" << s2.empty() << ")"
              << std::endl;

    // 4. Copy assignment
    std::cout << "\n--- 4. Copy Assignment ---" << std::endl;
    s3 = s1;  // s3 was an empty string before
    std::cout << "s3 after copy assignment from s1: " << s3 << std::endl;

    // 5. Move assignment
    std::cout << "\n--- 5. Move Assignment ---" << std::endl;
    MyString s6("Temporary String");
    s6 = std::move(s5);
    std::cout << "s6 after move assignment from s5: " << s6 << std::endl;

    // 6. append operation
    std::cout << "\n--- 6. Append ---" << std::endl;
    MyString s7("C++");
    s7.append(" is ").append("awesome!");
    std::cout << "s7: " << s7 << " (size=" << s7.size()
              << " cap=" << s7.getCapacity() << ")" << std::endl;

    // 7. insert operation
    std::cout << "\n--- 7. Insert ---" << std::endl;
    MyString s8("Hello World!");
    std::cout << "Before insert: " << s8 << std::endl;
    s8.insert(6, MyString("Beautiful "));
    std::cout << "After insert: " << s8 << std::endl;

    // 8. substr operation
    std::cout << "\n--- 8. Substring ---" << std::endl;
    MyString s9("The quick brown fox");
    MyString sub = s9.substr(4, 5);  // "quick"
    std::cout << "s9: " << s9 << std::endl;
    std::cout << "substr(4, 5): " << sub << std::endl;

    // 9. Subscript access
    std::cout << "\n--- 9. Subscript Access ---" << std::endl;
    MyString s10("Indexable");
    std::cout << "s10: " << s10 << std::endl;
    for (size_t i = 0; i < s10.size(); ++i) {
        std::cout << "  s10[" << i << "] = '" << s10[i] << "'" << std::endl;
    }

    // 10. Statistics
    std::cout << "\n--- 10. Statistics ---" << std::endl;
    std::cout << "Live string objects: " << MyString::getStringCount() << std::endl;
    std::cout << "Total characters: " << MyString::getTotalChars() << std::endl;

    // 11. Text editor simulation
    std::cout << "\n--- 11. Text Editor Simulation ---" << std::endl;
    // The editor's line buffer
    MyString line("Welcome to the Text Editor!");
    std::cout << "Current line: " << line << std::endl;

    // Type new characters
    line.clear();
    line.append("Editing ").append("mode: ").append("Insert");
    std::cout << "After editing: " << line << std::endl;

    // Delete and replace
    line.clear();
    line.append("Final document content...");
    std::cout << "Final content: " << line << std::endl;

    return 0;
}
```

1. Best Practices for Object Lifetime Management
------------------------------------------------

[The RAII principle (Resource Acquisition Is Initialization)]
One of the most important resource-management principles in C++. It ties a resource's lifetime to an object's lifetime.

```cpp
// Bad practice — managing resources manually
void badPractice() {
    int* data = new int[100];
    FILE* file = fopen("data.txt", "r");

    if (someError) {
        delete[] data;          // easy to forget the cleanup!
        fclose(file);
        return;
    }

    // More code... might return midway and forget to clean up

    delete[] data;
    fclose(file);
}

// Good practice — RAII
class FileGuard {
    FILE* file;
public:
    explicit FileGuard(const char* name) : file(fopen(name, "r")) {}
    ~FileGuard() { if(file) fclose(file); }
    FILE* get() const { return file; }
    FileGuard(const FileGuard&) = delete;
    FileGuard& operator=(const FileGuard&) = delete;
};

class ArrayGuard {
    int* data;
public:
    explicit ArrayGuard(size_t size) : data(new int[size]) {}
    ~ArrayGuard() { delete[] data; }
    int* get() const { return data; }
};

void goodPractice() {
    ArrayGuard arr(100);
    FileGuard f("data.txt");

    if (someError) {
        return;  // ~ArrayGuard and ~FileGuard are called automatically to clean up
    }
    // Automatic cleanup, no memory leaks!
}
```

2. Exception Safety in Constructors and Destructors
---------------------------------------------------

When a constructor throws an exception, the members and base class subobjects that have already been fully constructed are destroyed automatically.
The constructor body itself, however, does not run to completion.

```cpp
#include <iostream>

class Resource {
public:
    Resource(int id) : id_(id) {
        std::cout << "Resource(" << id_ << ") acquired" << std::endl;
        if (id_ < 0) {
            throw std::runtime_error("Invalid resource ID");
        }
    }
    ~Resource() {
        std::cout << "Resource(" << id_ << ") released" << std::endl;
    }
private:
    int id_;
};

class Manager {
    Resource r1;
    Resource r2;
public:
    Manager() : r1(1), r2(2) {  // r1 and r2 are constructed via the initializer list
        std::cout << "Manager constructed" << std::endl;
    }
    // If r1 is constructed successfully but r2 throws, r1 is destroyed automatically
    // This guarantees resources do not leak
};

// Advice for exception safety in constructors:
// 1. Initialize all members in the initializer list
// 2. Use RAII resource-management classes (such as unique_ptr) instead of raw pointers
// 3. Do not manually release resources in this class's constructor
```

3. Quick Reference: Class Features in C++11/14/17/20
----------------------------------------------------

```cpp
#include <iostream>
#include <string>
#include <memory>

// C++11: delegating constructors, =default/=delete, move semantics, override/final, explicit conversions
// C++14: no significant class-related changes (mainly improved lambdas and constexpr)
// C++17: inline static member variables, structured bindings, class template argument deduction (CTAD)
// C++20: defaulted comparison operators (<=>), consteval

class ModernFeatures {
    static inline int s_globalCount = 0;  // C++17: inline static initialization
    std::string name;

public:
    ModernFeatures() = default;                           // C++11: =default
    ModernFeatures(const ModernFeatures&) = delete;       // C++11: =delete
    ModernFeatures(ModernFeatures&&) noexcept = default;  // C++11: move constructor
    explicit ModernFeatures(const std::string& n)         // C++11: explicit
        : name(n) { s_globalCount++; }

    explicit operator bool() const noexcept {             // C++11: explicit conversion
        return !name.empty();                             // + noexcept
    }

    // C++20: generate comparison operators automatically with <=>
    // auto operator<=>(const ModernFeatures&) const = default;

    static int count() { return s_globalCount; }
};
```

4. Common Interview Questions Explained
---------------------------------------

[Question 1] Why is the size of an empty class 1 rather than 0?
Answer: The C++ standard requires every object to have a unique address. If an empty class had size 0,
   two empty-class objects could occupy the same address, which would violate the memory model.

[Question 2] Why don't member functions take up space in the object?
Answer: Member function code is stored in the text segment (.text), and all objects share the same copy of the code.
   Only per-object data (non-static member variables) needs storage allocated for each object.

[Question 3] Why is the initializer list faster than assignment in the constructor body?
Answer:
  For fundamental types (int, double, etc.): equally efficient.
  For class types (string, vector, etc.): initializer list → calls the copy/move constructor directly;
  body assignment → first calls the default constructor (creating an empty object), then the assignment operator.
  That is one extra default construction + assignment.

Verify it with the following code:
```cpp
#include <iostream>
class Logger {
public:
    Logger()                 { std::cout << "  Default ctor\n"; }
    Logger(const Logger&)    { std::cout << "  Copy ctor\n"; }
    Logger& operator=(const Logger&) {
        std::cout << "  Copy assignment\n"; return *this;
    }
};

class WithInitList {
    Logger log;
public:
    WithInitList(const Logger& l) : log(l) { }
    // Output: "  Copy ctor" (just one copy construction)
};

class WithoutInitList {
    Logger log;
public:
    WithoutInitList(const Logger& l) {
        log = l;
    }
    // Output: "  Default ctor" (default construction first) + "  Copy assignment" (then assignment)
};
```

[Question 4] What data can a const member function modify?
Answer:
  - It cannot modify non-mutable, non-static member variables
  - It can modify mutable member variables (design intent: for caches, logging, etc.)
  - It can modify static member variables (static members don't belong to a specific object)
  - It can modify what a pointer member points to (but not the pointer itself)
  Example: with int* const p, inside a const function p cannot change, but *p can

[Question 5] What is the type of the this pointer?
Answer:
  - In a non-const member function: T* const (a constant pointer; the pointee can be modified)
  - In a const member function: const T* const (a constant pointer to a constant)
  - In a volatile member function: volatile T* const

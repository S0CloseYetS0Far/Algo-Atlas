1. Operator Overloading Basics: It Is Really a Function Call
------------------------------------

Operator overloading is syntactic sugar provided by C++ that lets programmers define the behavior of operators for user-defined types.
In essence, operator overloading is just another way of writing a function call.

[Example 1-1] Basic operator overloading for a complex number class:

```cpp
#include <iostream>

class Complex {
private:
    double real;
    double imag;

public:
    Complex(double r = 0.0, double i = 0.0) : real(r), imag(i) { }

    // ====== Operators overloaded as member functions ======

    // operator+ is actually the function Complex::operator+(const Complex&)
    Complex operator+(const Complex& other) const {
        return Complex(real + other.real, imag + other.imag);
    }

    // operator- : subtraction
    Complex operator-(const Complex& other) const {
        return Complex(real - other.real, imag - other.imag);
    }

    // operator* : multiplication (a+bi)(c+di) = (ac-bd) + (ad+bc)i
    Complex operator*(const Complex& other) const {
        return Complex(
            real * other.real - imag * other.imag,
            real * other.imag + imag * other.real
        );
    }

    // operator== : equality comparison
    bool operator==(const Complex& other) const {
        return real == other.real && imag == other.imag;
    }

    // operator!= : inequality comparison
    bool operator!=(const Complex& other) const {
        return !(*this == other);  // reuse operator==
    }

    // Getters
    double getReal() const { return real; }
    double getImag() const { return imag; }

    void print() const {
        std::cout << real;
        if (imag >= 0) std::cout << " + " << imag << "i";
        else           std::cout << " - " << -imag << "i";
        std::cout << std::endl;
    }
};

int main() {
    Complex c1(3.0, 4.0);
    Complex c2(1.0, -2.0);

    // The following two lines are equivalent!
    Complex c3 = c1 + c2;          // syntactic sugar
    Complex c4 = c1.operator+(c2); // the actual call

    c1.print();  // 3 + 4i
    c2.print();  // 1 - 2i
    c3.print();  // 4 + 2i

    Complex c5 = c1 * c2;  // (3+4i)(1-2i) = 11 - 2i
    c5.print();

    std::cout << "c1 == c2? " << (c1 == c2 ? "yes" : "no") << std::endl;
    std::cout << "c1 != c2? " << (c1 != c2 ? "yes" : "no") << std::endl;

    return 0;
}
```

2. Low-Level Principles: The Nature of Operator Overloading
------------------------------------

[Principle 2-1] How the compiler matches operator overloads

When the compiler encounters the expression `a + b`, it looks up candidate functions as follows:

1. The candidate set includes:
   - Member functions: a.operator+(b)  (if a is of class type)
   - Non-member functions: operator+(a, b) (looked up in the namespaces of a and b)
   - Built-in operators (if the operands are fundamental types)

2. The overload resolution process:
   (a) Name lookup: find all functions named operator+
   (b) Template deduction (if they are function templates)
   (c) Viability check: do the number and types of arguments match?
   (d) Best match: choose the best overload based on the cost of implicit conversions

```cpp
class MyInt {
    int value;
public:
    MyInt(int v) : value(v) {}

    // Member function overload
    MyInt operator+(const MyInt& other) const {
        return MyInt(value + other.value);
    }

    // Non-member function overload (friend)
    friend MyInt operator-(const MyInt& a, const MyInt& b) {
        return MyInt(a.value - b.value);
    }
};

int main() {
    MyInt a(5), b(3);

    // Matching process for the following calls:
    MyInt c = a + b;
    // Compiler looks up: a.operator+(b) -> finds the member function version

    MyInt d = a - b;
    // Compiler looks up: a.operator-(b) -> no member function found
    // Continues looking: operator-(a, b) -> finds the friend function version

    // Mixed-type arithmetic
    MyInt e = a + 10;
    // Compiler: a.operator+(10) -> 10 can be implicitly converted to MyInt(10) -> viable!

    // MyInt f = 10 + a;
    // Compiler: 10.operator+(a) -> int has no member operator+
    //           operator+(10, a) -> no non-member function accepting int+MyInt found
    //           Error!
    // Solution: define a non-member function operator+(int, const MyInt&)

    return 0;
}
```

[Principle 2-2] Decision tree: member function vs friend function

Whether to overload as a member function or as a friend/global function depends on the following principles:

When to use member function overloads:
  - The operator's semantics are closely tied to the class, and the left operand must be a class object
  - Assignment operators (=, +=, -=, ...)
  - Subscript operator ([])
  - Function call operator (())
  - Member access operator (->)
  - Increment/decrement operators (++, --)
  - new/delete operators

When to use friend/global function overloads:
  - Symmetry is needed (e.g. operator+ should support both 5 + obj and obj + 5)
  - The output operator (<<) needs to return ostream&
  - Access to private members is needed but the function is not a member of the class (friend)
  - The left operand is not a class type (as in the 10 + a example above)

Operators that must be overloaded as member functions (required by the C++ standard):
  =   []   ()   ->

```cpp
class Number {
    int value;
public:
    Number(int v) : value(v) { }

    // ====== Operators that must be member functions ======
    Number& operator=(const Number& other) {
        value = other.value;
        return *this;
    }

    // ====== Member function overload (left operand is a class object) ======
    Number operator+(const Number& other) const {
        return Number(value + other.value);
    }

    // ====== Global (friend) function overloads (support symmetry) ======
    friend Number operator*(int scalar, const Number& n) {
        return Number(scalar * n.value);
    }

    friend Number operator*(const Number& n, int scalar) {
        return scalar * n;  // delegate to the overload above
    }

    // ====== Stream operators must be global functions ======
    friend std::ostream& operator<<(std::ostream& os, const Number& n) {
        os << n.value;
        return os;
    }

    int getValue() const { return value; }
};

// Usage demo:
// Number n(5);
// Number m = n + 3;     // OK, member function overload
// Number p = 3 * n;     // OK, friend function overload
// Number q = n * 3;     // OK, friend function overload
// std::cout << n;       // OK, friend function overload
```

[Principle 2-3] Operator overloading does not change precedence or associativity

```cpp
class Vec {
    int x, y;
public:
    Vec(int xv, int yv) : x(xv), y(yv) { }
    Vec operator+(const Vec& other) const {
        return Vec(x + other.x, y + other.y);
    }
    Vec operator*(int scale) const {
        return Vec(x * scale, y * scale);
    }
};

int main() {
    Vec a(1, 2), b(3, 4);

    // The following expression is equivalent to a + (b * 5), not (a + b) * 5
    // because * has higher precedence than +; this is fixed by the language and cannot be changed
    Vec c = a + b * 5;  // * is evaluated first, then +

    // Nor can you change the associativity of an operator
    // a + b + c always associates left to right: (a + b) + c

    return 0;
}
```

[Principle 2-4] How friends bypass access control

Friend functions/classes are granted special permission at the compiler level. In its symbol table the compiler
marks a friend function as having access to the private/protected members of the class that declares it.

```cpp
class BankAccount {
private:
    double balance;
    std::string secretCode;

    // Friend declarations
    friend void auditorAccess(const BankAccount& account);
    friend class GovernmentAuditor;

public:
    BankAccount(double bal, const std::string& code)
        : balance(bal), secretCode(code) { }
};

// A friend function can access private members
void auditorAccess(const BankAccount& account) {
    // Can access private members directly
    std::cout << "Audit: balance=" << account.balance
              << " code=" << account.secretCode << std::endl;
}

// Friend class -- all of its member functions can access private members
class GovernmentAuditor {
public:
    void examine(const BankAccount& account) {
        std::cout << "Gov Audit: " << account.balance
                  << " " << account.secretCode << std::endl;
    }

    void freeze(BankAccount& account) {
        // account.balance = 0;  // can modify it!
        std::cout << "Account frozen" << std::endl;
    }
};

int main() {
    BankAccount acc(9999.99, "SECRET123");
    auditorAccess(acc);

    GovernmentAuditor auditor;
    auditor.examine(acc);

    return 0;
}
```

Underlying implementation:
  The compiler maintains a friend list in the symbol entry for the class definition. When a friend function
  tries to access a private member of the class, the compiler checks whether the caller is in that friend list.
  This is purely a compile-time check and incurs no runtime overhead.

```cpp
class Vector2D {
    double x, y;
public:
    Vector2D(double xv, double yv) : x(xv), y(yv) {}

    Vector2D operator+(const Vector2D& v) const {

    }
    Vector2D operator/(double scalar) const {

    Vector2D operator%(double scalar) const {
        return Vector2D(std::fmod(x, scalar), std::fmod(y, scalar));

    // Symmetric friend version
    friend Vector2D operator*(double scalar, const Vector2D& v) {
```

[Relational operators] ==  !=  <  >  <=  >=

```cpp
class Date {
    int year, month, day;
public:
    Date(int y, int m, int d) : year(y), month(m), day(d) {}

    bool operator==(const Date& other) const {
        return year == other.year &&
               month == other.month && day == other.day;
    }
    bool operator!=(const Date& other) const {
        return !(*this == other);
    }
    bool operator<(const Date& other) const {
        if (year != other.year) return year < other.year;
        if (month != other.month) return month < other.month;
        return day < other.day;
    }
    bool operator>(const Date& other) const {
        return other < *this;  // reuse <
    }
    bool operator<=(const Date& other) const {
        return !(other < *this);
    }
    bool operator>=(const Date& other) const {
        return !(*this < other);
    }
};
```

[Logical operators] !  &&  ||

```cpp
class Flag {
    bool state;
public:
    Flag(bool s = false) : state(s) {}

    bool operator!() const {           // logical NOT
        return !state;
    }
    bool operator&&(const Flag& other) const {  // logical AND (overloading not recommended!)
        return state && other.state;
    }
    bool operator||(const Flag& other) const {  // logical OR (overloading not recommended!)
        return state || other.state;
    }
    // Note: overloading && and || loses short-circuit evaluation! This is a common pitfall.
    // For example: if (f1 && f2) -- even if f1 is false, f2 is still evaluated.
};
```

[Bitwise operators] &  |  ^  ~  <<  >>

```cpp
class BitSet {
    unsigned int bits;
public:
    BitSet(unsigned int b = 0) : bits(b) {}

    BitSet operator&(const BitSet& other) const { return BitSet(bits & other.bits); }
    BitSet operator|(const BitSet& other) const { return BitSet(bits | other.bits); }
    BitSet operator^(const BitSet& other) const { return BitSet(bits ^ other.bits); }
    BitSet operator~() const { return BitSet(~bits); }
    BitSet operator<<(int shift) const { return BitSet(bits << shift); }
    BitSet operator>>(int shift) const { return BitSet(bits >> shift); }
```

[Assignment operators] =  +=  -=  *=  /=  %=  &=  |=  ^=  <<=  >>=

```cpp
class Counter {
    int value;
public:
    Counter(int v = 0) : value(v) {}

    Counter& operator=(const Counter& other) {
        if (this != &other) {
            value = other.value;
        }
        return *this;
    }
    Counter& operator+=(const Counter& other) {
        value += other.value;
        return *this;
    }
    Counter& operator-=(const Counter& other) {
        value -= other.value;
        return *this;
    }
    Counter& operator*=(int factor) {
        value *= factor;
        return *this;
    }
    Counter& operator/=(int divisor) {
        value /= divisor;
        return *this;
    }

    int getValue() const { return value; }
};

// + is usually implemented in terms of += (code reuse)
Counter operator+(const Counter& a, const Counter& b) {
    Counter result(a);
    result += b;
    return result;
}
```

[Increment/decrement operators] ++ (prefix/postfix)  -- (prefix/postfix)

```cpp
class Iterator {
    int index;
public:
    Iterator(int i = 0) : index(i) {}

    // Prefix ++: ++it
    Iterator& operator++() {
        ++index;
        return *this;  // return the modified object itself
    }

    // Postfix ++: it++
    // The int parameter is a dummy (used only to distinguish prefix from postfix)!
    Iterator operator++(int) {
        Iterator temp(*this);  // save the old value
        ++index;
        return temp;   // return the old value (note: returned by value, not by reference!)
    }

    // Prefix --: --it
    Iterator& operator--() {
        --index;
        return *this;
    }

    // Postfix --: it--
    Iterator operator--(int) {
        Iterator temp(*this);
        --index;
        return temp;
    }

    int getValue() const { return index; }
};

int main() {
    Iterator it(5);
    Iterator a = ++it;  // a=6, it=6 (prefix: increment first, then assign)
    Iterator b = it++;  // b=6, it=7 (postfix: assign first, then increment)

    // Note: postfix increment returns a value (a copy), not a reference
    // it++++;  // this is actually (it.operator++(0)).operator++(0)
    // but the second ++ operates on the temporary returned by the first ++, not on it itself!
    // so it++++ is usually not the intended behavior

    // ++++it;  // this is (it.operator++()).operator++()
    // both ++ operate on it itself -- correct!

    return 0;
}
```

[Subscript operator] []

```cpp
class Array {
    int* data;
    size_t size;
public:
    Array(size_t s) : size(s), data(new int[s]()) { }
    ~Array() { delete[] data; }

    // Non-const version -- read/write
    int& operator[](size_t index) {
        if (index >= size) throw std::out_of_range("Index out of bounds");
        return data[index];
    }

    // Const version -- read-only
    const int& operator[](size_t index) const {
        if (index >= size) throw std::out_of_range("Index out of bounds");
        return data[index];
    }

    size_t getSize() const { return size; }
};
```

```cpp
class Multiplier {

    }

    int operator()(int x, int y) const {
```

2.2 Type Conversion Operators
------------------------------------

```cpp
class Meter {
    double length;
public:
    Meter(double l) : length(l) { }

    // Implicit conversion operator (not recommended unless necessary)
    operator double() const {
        return length;  // allows implicit Meter -> double conversion
    }

    // Explicit conversion operator (C++11) -- recommended!
    explicit operator int() const {
        return static_cast<int>(length);
    }

    // bool conversion operator (commonly used in conditions)
    explicit operator bool() const {
        return length > 0.0;
    }
};

int main() {
    Meter m(5.5);

    // Implicit conversion
    double d = m;  // OK, operator double() is implicit

    // Explicit conversion
    int i = static_cast<int>(m);  // OK, operator int() is explicit
    // int j = m;  // Error! operator int() is explicit

    // bool conversion
    if (m) {  // in a boolean context, explicit operator bool() is allowed
        std::cout << "Length is positive" << std::endl;
    }

    return 0;
}
```

```cpp
class Distance {
```

2.5 Friend Functions and Friend Classes
------------------------------------

```cpp
#include <iostream>

// ====== Friend functions ======
class Point {
private:
    int x, y;

public:
    Point(int xv, int yv) : x(xv), y(yv) { }

    // Friend functions -- can access private members
    friend double distance(const Point& p1, const Point& p2);
    friend std::ostream& operator<<(std::ostream& os, const Point& p);
    friend std::istream& operator>>(std::istream& is, Point& p);
    friend void swap(Point& a, Point& b) noexcept;
};

double distance(const Point& p1, const Point& p2) {
    int dx = p1.x - p2.x;   // direct access to private members
    int dy = p1.y - p2.y;
    return std::sqrt(dx * dx + dy * dy);
}

std::ostream& operator<<(std::ostream& os, const Point& p) {
    os << "(" << p.x << ", " << p.y << ")";
    return os;
}

std::istream& operator>>(std::istream& is, Point& p) {
    is >> p.x >> p.y;
    return is;
}

void swap(Point& a, Point& b) noexcept {
    std::swap(a.x, b.x);  // direct access to private members
    std::swap(a.y, b.y);
}

// ====== Friend class ======
class Rectangle {
private:
    int width, height;
    friend class RectanglePainter;  // RectanglePainter can access private members

public:
    Rectangle(int w, int h) : width(w), height(h) { }
};

class RectanglePainter {
public:
    void paint(const Rectangle& rect) {
        std::cout << "Painting rectangle " << rect.width
                  << "x" << rect.height << std::endl;
    }
};

// ====== Friend member function ======
class Engine;  // forward declaration

class Car {
public:
    void startEngine(Engine& engine);  // declared but not yet defined
};

class Engine {
private:
    int rpm;
    friend void Car::startEngine(Engine& engine);
    // Only Car::startEngine is made a friend, not the whole Car class

public:
    Engine() : rpm(0) { }
};

void Car::startEngine(Engine& engine) {
    engine.rpm = 1000;  // access Engine's private member
    std::cout << "Engine started at " << engine.rpm << " RPM" << std::endl;
}
```

Case 1: Complex Number Calculator (Complex class)
------------------------------------

[Real-life scenario] Impedance calculations in circuit design: complex representations of resistors, inductors and capacitors.

```cpp
#include <iostream>
#include <cmath>
#include <iomanip>
#include <string>

// ====== Debug macro ======
#ifdef COMPLEX_DEBUG
    #define CPX_LOG(msg) std::cout << "[Complex] " << msg << std::endl
#else
    #define CPX_LOG(msg)
#endif

namespace math {

class Complex {
private:
    double real;
    double imag;

public:
    Complex(double r = 0.0, double i = 0.0) : real(r), imag(i) {
        CPX_LOG("Complex(" + std::to_string(r) + "," +
                std::to_string(i) + ")");
    }

    // ====== Arithmetic operators (member functions) ======
    Complex operator+(const Complex& other) const {
        return Complex(real + other.real, imag + other.imag);
    }

    Complex operator-(const Complex& other) const {
        return Complex(real - other.real, imag - other.imag);
    }

    Complex operator*(const Complex& other) const {
        // (a+bi)(c+di) = (ac-bd) + (ad+bc)i
        return Complex(
            real * other.real - imag * other.imag,
            real * other.imag + imag * other.real
        );
    }

    Complex operator/(const Complex& other) const {
        // (a+bi)/(c+di) = ((ac+bd)+(bc-ad)i)/(c^2+d^2)
        double denominator = other.real * other.real +
                             other.imag * other.imag;
        if (denominator == 0.0) {
            throw std::runtime_error("Division by zero complex");
        }
        return Complex(
            (real * other.real + imag * other.imag) / denominator,
            (imag * other.real - real * other.imag) / denominator
        );
    }

    // ====== Assignment operators ======
    Complex& operator+=(const Complex& other) {
        real += other.real;
        imag += other.imag;
        return *this;
    }

    Complex& operator-=(const Complex& other) {
        real -= other.real;
        imag -= other.imag;
        return *this;
    }

    Complex& operator*=(const Complex& other) {
        *this = *this * other;  // reuse operator*
        return *this;
    }

    Complex& operator/=(const Complex& other) {
        *this = *this / other;  // reuse operator/
        return *this;
    }

    // ====== Unary operators ======
    Complex operator-() const {        // negation
        return Complex(-real, -imag);
    }

    Complex operator+() const {        // unary plus (usually not needed)
        return *this;
    }

    // ====== Comparison operators ======
    bool operator==(const Complex& other) const {
        return real == other.real && imag == other.imag;
    }

    bool operator!=(const Complex& other) const {
        return !(*this == other);
    }

    // ====== Math operations ======
    double magnitude() const {
        return std::sqrt(real * real + imag * imag);
    }

    double phase() const {
        return std::atan2(imag, real);
    }

    Complex conjugate() const {
        return Complex(real, -imag);
    }

    // ====== Type conversion ======
    explicit operator double() const {
        return magnitude();
    }

    // ====== Accessors ======
    double getReal() const { return real; }
    double getImag() const { return imag; }

    // ====== Friends -- stream output/input ======
    friend std::ostream& operator<<(std::ostream& os,
                                     const Complex& c) {
        os << c.real;
        if (c.imag >= 0) os << " + " << c.imag;

        else os << " - " << -c.imag;
        os << "i";
        return os;
    }

    friend std::istream& operator>>(std::istream& is, Complex& c) {
        std::cout << "Real part: ";
        is >> c.real;
        std::cout << "Imag part: ";
        is >> c.imag;
        return is;
    }

    // ====== Static factory method ======
    static Complex fromPolar(double magnitude, double phase) {
        return Complex(magnitude * std::cos(phase),
                       magnitude * std::sin(phase));
    }
};

// ====== Impedance calculation ======
// Resistor R  -> Z = R (purely real)
// Inductor L  -> Z = j*omega*L (purely imaginary)
// Capacitor C -> Z = 1/(j*omega*C) = -j/(omega*C) (purely imaginary)
Complex resistorImpedance(double r) {
    return Complex(r, 0);  // resistor impedance is purely real
}

Complex inductorImpedance(double L, double freq) {
    double omega = 2 * M_PI * freq;  // angular frequency
    return Complex(0, omega * L);    // inductor impedance is purely imaginary: omega*L
}

Complex capacitorImpedance(double C, double freq) {
    double omega = 2 * M_PI * freq;
    return Complex(0, -1.0 / (omega * C));  // capacitor impedance = -j/(omega*C)
}

}  // namespace math
```

```cpp
#include <iostream>

// ====== Debug macro ======
#define FRAC_DEBUG 0
#if FRAC_DEBUG
    #define FRAC_LOG(msg) std::cout << "[Fraction] " << msg << std::endl
#else
    #define FRAC_LOG(msg)
#endif

// Simple gcd implementation (compatible with C++11/14)
namespace {
    int gcd_custom(int a, int b) {
        a = std::abs(a);
        b = std::abs(b);
        while (b != 0) {
            int t = b;
            b = a % b;
            a = t;
        }
        return a ? a : 1;
    }
}

namespace math {

class Fraction {
private:
    int numerator;   // numerator
    int denominator; // denominator (always positive)

    // Reduce to lowest terms
    void simplify() {
        int g = gcd_custom(std::abs(numerator), denominator);
        numerator /= g;
        denominator /= g;
    }

public:
    // ====== Constructors ======
    Fraction(int num = 0, int den = 1) : numerator(num), denominator(den) {
        if (den == 0) {
            throw std::invalid_argument("Denominator cannot be zero");
        }
        if (den < 0) {  // keep the denominator positive; the sign goes on the numerator
            numerator = -numerator;
            denominator = -denominator;
        }
        simplify();
        FRAC_LOG("Fraction(" + std::to_string(num) + "/" +
                 std::to_string(den) + ")");
    }

    // Copy constructor (the compiler-generated one is fine)
    Fraction(const Fraction&) = default;

    // ====== Arithmetic operators (member functions) ======
    Fraction operator+(const Fraction& other) const {
        // a/b + c/d = (ad + bc) / bd
        return Fraction(
            numerator * other.denominator + other.numerator * denominator,
            denominator * other.denominator
        );
    }

    Fraction operator-(const Fraction& other) const {
        return Fraction(
            numerator * other.denominator - other.numerator * denominator,
            denominator * other.denominator
        );
    }

    Fraction operator*(const Fraction& other) const {
        return Fraction(
            numerator * other.numerator,
            denominator * other.denominator
        );
    }

    Fraction operator/(const Fraction& other) const {
        if (other.numerator == 0) {
            throw std::runtime_error("Division by zero fraction");
        }
        return Fraction(
            numerator * other.denominator,
            denominator * other.numerator
        );
    }

    // ====== Assignment operators ======
    Fraction& operator+=(const Fraction& other) {
        *this = *this + other;
        return *this;
    }

    Fraction& operator-=(const Fraction& other) {
        *this = *this - other;
        return *this;
    }

    Fraction& operator*=(const Fraction& other) {
        *this = *this * other;
        return *this;
    }

    Fraction& operator/=(const Fraction& other) {
        *this = *this / other;
        return *this;
    }

    // ====== Increment/decrement ======
    Fraction& operator++() {         // prefix ++
        numerator += denominator;
        return *this;
    }

    Fraction operator++(int) {       // postfix ++
        Fraction temp(*this);
        numerator += denominator;
        return temp;
    }

    Fraction& operator--() {         // prefix --
        numerator -= denominator;
        return *this;
    }

    Fraction operator--(int) {       // postfix --
        Fraction temp(*this);
        numerator -= denominator;
        return temp;
    }

    // ====== Comparison operators ======
    bool operator==(const Fraction& other) const {
        return numerator == other.numerator &&
               denominator == other.denominator;
    }

    bool operator!=(const Fraction& other) const {
        return !(*this == other);
    }

    bool operator<(const Fraction& other) const {
        // a/b < c/d is equivalent to ad < bc (when both denominators are positive)
        return numerator * other.denominator <
               other.numerator * denominator;
    }

    bool operator>(const Fraction& other) const {
        return other < *this;
    }

    bool operator<=(const Fraction& other) const {
        return !(other < *this);
    }

    bool operator>=(const Fraction& other) const {
        return !(*this < other);
    }

    // ====== Unary operator ======
    Fraction operator-() const {
        return Fraction(-numerator, denominator);
    }

    // ====== Type conversion operator ======
    explicit operator double() const {
        return static_cast<double>(numerator) / denominator;
    }

    // Implicit conversion to double (convenient for mixed arithmetic)
    // Note: it can cause surprising behavior, so use it with care

    // ====== Accessors ======
    int getNumerator()   const { return numerator; }
    int getDenominator() const { return denominator; }

    // ====== Friend functions -- stream output/input ======
    friend std::ostream& operator<<(std::ostream& os,
                                     const Fraction& f) {
        if (f.denominator == 1) {
            os << f.numerator;         // integer
        } else {
            os << f.numerator << "/" << f.denominator;
        }
        return os;
    }

    friend std::istream& operator>>(std::istream& is, Fraction& f) {
        char slash;
        is >> f.numerator >> slash >> f.denominator;
        if (slash != '/') {
            is.setstate(std::ios::failbit);
        } else {
            f.simplify();
        }
        return is;
    }

    // ====== Utility methods ======
    double toDouble() const {
        return static_cast<double>(numerator) / denominator;
    }

    std::string toString() const {
        if (denominator == 1) {
            return std::to_string(numerator);
        }
        return std::to_string(numerator) + "/" +
               std::to_string(denominator);
    }
};
```

Case 3: Set Class (IntSet class)
------------------------------------

[Real-life scenario] A course registration system -- computing the intersection of a student's selected courses and the required courses.
Overload set operators to implement intersection, union, difference and other operations.

```cpp
#include <iostream>
#include <memory>
#include <algorithm>
#include <string>
#include <vector>
#include <iomanip>

// ====== Knowledge from earlier chapters ======
#define SET_DEBUG 0
#if SET_DEBUG
    #define SET_LOG(msg) std::cout << "[Set] " << msg << std::endl
#else
    #define SET_LOG(msg)
#endif

namespace ds {

class IntSet {
private:
    int* elements;          // dynamic array
    size_t count;           // current number of elements
    size_t capacity;        // current capacity
    static int setCount;    // total number of sets

    // Grow the capacity
    void expandCapacity() {
        size_t newCap = (capacity == 0) ? 8 : capacity * 2;
        int* newData = new int[newCap];
        for (size_t i = 0; i < count; ++i) {
            newData[i] = elements[i];
        }
        delete[] elements;
        elements = newData;
        capacity = newCap;
        SET_LOG("Capacity expanded to " + std::to_string(newCap));
    }

    // Check whether an element is in the set
    bool contains(int val) const {
        for (size_t i = 0; i < count; ++i) {
            if (elements[i] == val) return true;
        }
        return false;
    }

    // Find the index of an element
    int findIndex(int val) const {
        for (size_t i = 0; i < count; ++i) {
            if (elements[i] == val) return static_cast<int>(i);
        }
        return -1;
    }

    // Keep the array sorted
    void sortElements() {
        std::sort(elements, elements + count);
    }

public:
    // ====== Constructors ======
    IntSet() : elements(nullptr), count(0), capacity(0) {
        setCount++;
        SET_LOG("Empty set created");
    }

    IntSet(std::initializer_list<int> init)
        : elements(nullptr), count(0), capacity(0) {
        for (int val : init) {
            this->add(val);  // use add() to remove duplicates
        }
        setCount++;
        SET_LOG("Set created with " + std::to_string(count) + " elements");
    }

    // Copy constructor (deep copy)
    IntSet(const IntSet& other)
        : count(other.count), capacity(other.capacity) {
        elements = new int[capacity];
        for (size_t i = 0; i < count; ++i) {
            elements[i] = other.elements[i];
        }
        setCount++;
        SET_LOG("Set copy constructed");
    }

    // Move constructor
    IntSet(IntSet&& other) noexcept
        : elements(other.elements), count(other.count),
          capacity(other.capacity) {
        other.elements = nullptr;
        other.count = 0;
        other.capacity = 0;
        setCount++;
        SET_LOG("Set move constructed");
    }

    // Destructor
    ~IntSet() {
        delete[] elements;
        setCount--;
        SET_LOG("Set destroyed");
    }

    // ====== Basic operations ======
    bool add(int val) {
        if (contains(val)) return false;  // already present, don't add a duplicate
        if (count >= capacity) {
            expandCapacity();
        }
        elements[count++] = val;
        return true;
    }

    bool remove(int val) {
        int idx = findIndex(val);
        if (idx == -1) return false;
        // Move the last element into the removed slot
        elements[idx] = elements[count - 1];
        count--;
        return true;
    }

    bool contains_check(int val) const {  // avoids confusion with the private contains
        return contains(val);
    }

    size_t size() const { return count; }
    bool empty() const { return count == 0; }

    void clear() { count = 0; }

    // ====== Operator overloading: set operations ======

    // | union
    IntSet operator|(const IntSet& other) const {
        IntSet result(*this);  // copy this
        for (size_t i = 0; i < other.count; ++i) {
            result.add(other.elements[i]);  // add removes duplicates automatically
        }
        return result;
    }

    // & intersection
    IntSet operator&(const IntSet& other) const {
        IntSet result;
        for (size_t i = 0; i < count; ++i) {
            if (other.contains(elements[i])) {
                result.add(elements[i]);
            }
        }
        return result;
    }

    // - difference (this - other: elements in this but not in other)
    IntSet operator-(const IntSet& other) const {
        IntSet result;
        for (size_t i = 0; i < count; ++i) {
            if (!other.contains(elements[i])) {
                result.add(elements[i]);
            }
        }
        return result;
    }

    // ====== Assignment operators ======
    IntSet& operator+=(int val) {
        add(val);
        return *this;
    }

    IntSet& operator+=(const IntSet& other) {
        *this = *this | other;  // union assignment
        return *this;
    }

    IntSet& operator-=(int val) {
        remove(val);
        return *this;
    }

    // ====== Comparison operators ======
    bool operator==(const IntSet& other) const {
        if (count != other.count) return false;
        for (size_t i = 0; i < count; ++i) {
            if (!other.contains(elements[i])) return false;
        }
        return true;
    }

    bool operator!=(const IntSet& other) const {
        return !(*this == other);
    }

    // Subset test
    bool operator<=(const IntSet& other) const {
        for (size_t i = 0; i < count; ++i) {
            if (!other.contains(elements[i])) return false;
        }
        return true;
    }

    // ====== Subscript operator ======
    // Access the element at position index (for iteration only; order is not guaranteed)
    int& operator[](size_t index) {
        if (index >= count) throw std::out_of_range("Index out of range");
        return elements[index];
    }

    const int& operator[](size_t index) const {
        if (index >= count) throw std::out_of_range("Index out of range");
        return elements[index];
    }

    // ====== Function call operator ======
    size_t operator()() const {
        return count;  // returns the number of elements, e.g. int n = mySet();
    }

    // ====== Type conversion ======
    explicit operator bool() const {
        return !empty();  // non-empty means true
    }

    // ====== Stream output ======
    friend std::ostream& operator<<(std::ostream& os, const IntSet& s) {
        os << "{";
        for (size_t i = 0; i < s.count; ++i) {
            if (i > 0) os << ", ";
            os << s.elements[i];
        }
        os << "}";
        return os;
    }

    // ====== Static member ======
    static int getSetCount() { return setCount; }

    // ====== Get the element list (for external iteration) ======
    std::vector<int> toVector() const {
        std::vector<int> v(elements, elements + count);
        return v;
    }
};

int IntSet::setCount = 0;

// Global operator: element + set (adds the element)
IntSet operator+(int val, const IntSet& s) {
    IntSet result(s);
    result += val;
    return result;
}

}  // namespace ds

// ========== Demo code: course registration system ==========

    using namespace ds;
```

Case 4: A Simplified Smart Pointer (SimplePtr class)
------------------------------------

[Real-life scenario] Automatic file handle management. Overload the *, -> and bool conversion operators
to implement the complete RAII pattern.

```cpp
#include <iostream>
#include <cstring>
#include <utility>

#define PTR_DEBUG 1
#if PTR_DEBUG
    #define PTR_LOG(msg) std::cout << "[Ptr] " << msg << std::endl
#else
    #define PTR_LOG(msg)
#endif

namespace smart {

// ====== Simplified smart pointer ======
template <typename T>
class SimplePtr {
private:
    T* ptr;  // raw pointer

public:
    // Constructor
    explicit SimplePtr(T* p = nullptr) : ptr(p) {
        PTR_LOG("SimplePtr created @" + std::to_string(
            reinterpret_cast<uintptr_t>(ptr)));
    }

    // Destructor -- releases the resource automatically (the core of RAII)
    ~SimplePtr() {
        if (ptr) {
            PTR_LOG("SimplePtr deleting @" + std::to_string(
                reinterpret_cast<uintptr_t>(ptr)));
            delete ptr;
        }
    }

    // Disallow copying (unique ownership)
    SimplePtr(const SimplePtr&) = delete;
    SimplePtr& operator=(const SimplePtr&) = delete;

    // Move constructor -- transfers ownership
    SimplePtr(SimplePtr&& other) noexcept : ptr(other.ptr) {
        other.ptr = nullptr;
        PTR_LOG("SimplePtr moved");
    }

    // Move assignment
    SimplePtr& operator=(SimplePtr&& other) noexcept {
        if (this != &other) {
            if (ptr) delete ptr;
            ptr = other.ptr;
            other.ptr = nullptr;
            PTR_LOG("SimplePtr move-assigned");
        }
        return *this;
    }

    // ====== Operator overloading ======

    // operator* -- dereference
    T& operator*() {
        if (!ptr) throw std::runtime_error("Dereferencing null pointer");
        return *ptr;
    }

    const T& operator*() const {
        if (!ptr) throw std::runtime_error("Dereferencing null pointer");
        return *ptr;
    }

    // operator-> -- arrow operator
    T* operator->() {
        if (!ptr) throw std::runtime_error("Access via null pointer");
        return ptr;
    }

    const T* operator->() const {
        if (!ptr) throw std::runtime_error("Access via null pointer");
        return ptr;
    }

    // operator bool -- check whether it is null (the safe way)
    explicit operator bool() const {
        return ptr != nullptr;
    }

    // operator! -- negation
    bool operator!() const {
        return ptr == nullptr;
    }

    // ====== Management methods ======
    T* get() const { return ptr; }

    T* release() {
        T* temp = ptr;
        ptr = nullptr;
        PTR_LOG("SimplePtr released ownership");
        return temp;
    }

    void reset(T* p = nullptr) {
        if (ptr) delete ptr;
        ptr = p;
        PTR_LOG("SimplePtr reset");
    }

    // ====== Friends ======
    friend void swap(SimplePtr& a, SimplePtr& b) noexcept {
        std::swap(a.ptr, b.ptr);
    }

    // Friend comparison operators
    friend bool operator==(const SimplePtr& a, std::nullptr_t) {
        return a.ptr == nullptr;
    }

    friend bool operator!=(const SimplePtr& a, std::nullptr_t) {
        return a.ptr != nullptr;
    }

    friend bool operator==(std::nullptr_t, const SimplePtr& a) {
        return a.ptr == nullptr;
    }

    friend bool operator!=(std::nullptr_t, const SimplePtr& a) {
        return a.ptr != nullptr;
    }
};

// ====== Simulated file handle class ======
class FileHandle {
private:
    std::string filename;
    bool isOpen;
    std::string content;

public:
    FileHandle(const std::string& fname)
        : filename(fname), isOpen(true), content("") {
        PTR_LOG("File opened: " + filename);
    }

    ~FileHandle() {
        if (isOpen) {
            close();
        }
        PTR_LOG("File object destroyed: " + filename);
    }

    void write(const std::string& data) {
        if (!isOpen) {
            throw std::runtime_error("File is not open");
        }
        content += data;
        std::cout << "Writing to file " << filename << ": " << data << std::endl;
    }

    std::string read() const {
        return content;
    }

    void close() {
        isOpen = false;
        std::cout << "Closing file " << filename << std::endl;
    }

    bool openCheck() const { return isOpen; }
    const std::string& getFilename() const { return filename; }
    size_t getSize() const { return content.size(); }
};
```

Case 5: A Complete Custom String Class (String class)
------------------------------------

[Real-life scenario] Building the index of a text search engine. A String class with comprehensive operator overloading.

```cpp
#include <iostream>
#include <cstring>
#include <utility>
#include <algorithm>
#include <iomanip>

// ====== Bringing together everything from the first 7 chapters ======
#define STR_DEBUG 0
#if STR_DEBUG
    #define STR_LOG(msg) std::cout << "[String] " << msg << std::endl
#else
    #define STR_LOG(msg)
#endif

namespace text {

// ====== Forward declarations ======
class String;
class StringIterator;

// ====== String class ======
class String {
private:
    char* data;
    size_t length;
    size_t capacity;

    static size_t totalAllocated;

    void ensureCapacity(size_t newCap) {
        if (newCap <= capacity) return;
        size_t newCapacity = (capacity == 0) ? 16 : capacity * 2;
        while (newCapacity < newCap) newCapacity *= 2;

        char* newData = new char[newCapacity + 1];
        if (data) {
            std::memcpy(newData, data, length);
            newData[length] = '\0';
            delete[] data;
        } else {
            newData[0] = '\0';
        }
        totalAllocated -= capacity;
        data = newData;
        capacity = newCapacity;
        totalAllocated += capacity;
        STR_LOG("Capacity expanded to " + std::to_string(capacity));
    }

public:
    // ====== Constructors ======
    String() : data(nullptr), length(0), capacity(0) {
        STR_LOG("Default constructed");
    }

    String(const char* str) {
        length = std::strlen(str);
        capacity = length;
        data = new char[capacity + 1];
        std::strcpy(data, str);
        totalAllocated += capacity;
        STR_LOG("Constructed from C-string");
    }

    // Copy constructor (deep copy)
    String(const String& other) {
        length = other.length;
        capacity = other.capacity;
        if (other.data) {
            data = new char[capacity + 1];
            std::strcpy(data, other.data);
        } else {
            data = nullptr;
        }
        totalAllocated += capacity;
        STR_LOG("Copy constructed");
    }

    // Move constructor
    String(String&& other) noexcept
        : data(other.data), length(other.length), capacity(other.capacity) {
        other.data = nullptr;
        other.length = 0;
        other.capacity = 0;
        STR_LOG("Move constructed");
    }

    // Destructor
    ~String() {
        delete[] data;
        totalAllocated -= capacity;
        STR_LOG("Destructed");
    }

    // ====== Copy assignment ======
    String& operator=(const String& other) {
        if (this != &other) {
            delete[] data;
            totalAllocated -= capacity;

            length = other.length;
            capacity = other.capacity;
            if (other.data) {
                data = new char[capacity + 1];
                std::strcpy(data, other.data);
            } else {
                data = nullptr;
            }
            totalAllocated += capacity;
        }
        return *this;
    }

    // ====== Move assignment ======
    String& operator=(String&& other) noexcept {
        if (this != &other) {
            delete[] data;
            totalAllocated -= capacity;

            data = other.data;
            length = other.length;
            capacity = other.capacity;

            other.data = nullptr;
            other.length = 0;
            other.capacity = 0;
        }
        return *this;
    }

    // ====== Concatenation operators ======

    // operator+ concatenates two strings
    String operator+(const String& other) const {
        String result;
        result.length = length + other.length;
        result.capacity = result.length;
        result.data = new char[result.capacity + 1];

        if (data) std::strcpy(result.data, data);
        else result.data[0] = '\0';

        if (other.data) std::strcat(result.data, other.data);
        totalAllocated += result.capacity;
        return result;
    }

    // operator+ concatenates a C string
    String operator+(const char* str) const {
        return *this + String(str);
    }

    // C string + String (global or friend function)
    friend String operator+(const char* str, const String& s) {
        return String(str) + s;
    }

    // ====== Append-assignment operators ======
    String& operator+=(const String& other) {
        size_t newLength = length + other.length;
        ensureCapacity(newLength);
        if (other.data) {
            std::strcpy(data + length, other.data);
        }
        length = newLength;
        data[length] = '\0';
        return *this;
    }

    String& operator+=(char ch) {
        ensureCapacity(length + 1);
        data[length++] = ch;
        data[length] = '\0';
        return *this;
    }

    String& operator+=(const char* str) {
        return *this += String(str);
    }

    // ====== Subscript operator ======
    char& operator[](size_t index) {
        if (index >= length) throw std::out_of_range("Index out of range");
        return data[index];
    }

    const char& operator[](size_t index) const {
        if (index >= length) throw std::out_of_range("Index out of range");
        return data[index];
    }

    // ====== Comparison operators ======
    bool operator==(const String& other) const {
        if (length != other.length) return false;
        if (!data && !other.data) return true;
        return std::strcmp(data ? data : "",
                           other.data ? other.data : "") == 0;
    }

    bool operator!=(const String& other) const { return !(*this == other); }

    bool operator<(const String& other) const {
        if (!data) return other.data != nullptr;
        if (!other.data) return false;
        return std::strcmp(data, other.data) < 0;
    }

    bool operator>(const String& other)  const { return other < *this; }
    bool operator<=(const String& other) const { return !(other < *this); }
    bool operator>=(const String& other) const { return !(*this < other); }

    // ====== Function call operator: substring ======
    String operator()(size_t pos, size_t count) const {
        if (pos >= length) return String();
        if (count > length - pos) count = length - pos;

        char* temp = new char[count + 1];
        std::strncpy(temp, data + pos, count);
        temp[count] = '\0';
        String result(temp);
        delete[] temp;
        return result;
    }

    // Function call operator: get a single character (different semantics from [] -- safer, with a default value)
    char operator()(size_t index, char defaultVal) const {
        if (index >= length) return defaultVal;
        return data[index];
    }

    // ====== Type conversion operators ======
    operator const char*() const {
        return data ? data : "";
    }

    explicit operator bool() const {
        return length > 0;
    }

    // ====== Accessors ======
    size_t size() const { return length; }
    size_t getCapacity() const { return capacity; }
    bool empty() const { return length == 0; }
    const char* c_str() const { return data ? data : ""; }

    // ====== Stream operators ======
    friend std::ostream& operator<<(std::ostream& os, const String& s) {
        if (s.data) os << s.data;
        return os;
    }

    friend std::istream& operator>>(std::istream& is, String& s) {
        char buffer[1024];
        is >> buffer;
        s = String(buffer);
        return is;
    }

    // ====== Static member ======
    static size_t getTotalAllocated() { return totalAllocated; }

    // ====== Searching ======
    int find(const String& substr) const {
        if (!data || !substr.data || substr.length == 0) return -1;
        const char* pos = std::strstr(data, substr.data);
        return pos ? static_cast<int>(pos - data) : -1;
    }

    bool contains(const String& substr) const {
        return find(substr) != -1;
    }

    // ====== Friend class -- iterator ======
    friend class StringIterator;
};

size_t String::totalAllocated = 0;

class StringIterator {
private:

public:
    explicit StringIterator(const String& s, size_t start = 0)
        : str(s), index(start) { }

};

        searchPos += found + keyword.size();
        occurrence++;
    }
    std::cout << "\"" << keyword << "\" occurrences: " << occurrence << std::endl;
    std::cout << "Searched document length: " << corpus.size() << " characters" << std::endl;

    // 11. Iterator demo (friend class)
    std::cout << "\n--- Iterator Traversal ---" << std::endl;
    StringIterator it(title);
    std::cout << "Character-by-character iteration: ";
    while (it.hasNext()) {
        std::cout << it.next() << " ";
    }
    std::cout << std::endl;

    // 12. Memory statistics
    std::cout << "\n--- Memory Statistics ---" << std::endl;
    std::cout << "Total allocated capacity: " << String::getTotalAllocated() << " bytes"
              << std::endl;
    std::cout << "title capacity: " << title.getCapacity() << std::endl;
    std::cout << "description capacity: " << description.getCapacity() << std::endl;

    return 0;
}
```

Exercise: Design a "time span" class, TimeSpan
======================================================

[Real-life scenario]
A video player needs to handle the durations of video clips. The TimeSpan class represents a length of time
(hours:minutes:seconds) and must support adding and subtracting times, comparisons, stream input/output and more.

[Requirements]

1. Class name: TimeSpan
   Private members: hours, minutes, seconds (all int)
   - Normalized internal storage: seconds in [0,59], minutes in [0,59], hours can be any value
   - The constructor normalizes its input automatically (e.g. 75 seconds -> 1 minute 15 seconds)

2. Overloaded operators (must be implemented):

   (a) Arithmetic operators:
       operator+  (const TimeSpan&) const:    add times
       operator-  (const TimeSpan&) const:    subtract times (the result cannot be negative; clamp to 0)
       operator+= (const TimeSpan&):          accumulate
       operator-= (const TimeSpan&):          decrement by a time span

   (b) Increment/decrement operators:
       operator++():       prefix ++ (add 1 second)
       operator++(int):    postfix ++ (add 1 second, return the old value)
       operator--():       prefix -- (subtract 1 second)
       operator--(int):    postfix -- (subtract 1 second, return the old value)

   (c) Comparison operators:
       operator==, !=, <, >, <=, >=

   (d) Stream operators:
       operator<<  (friend std::ostream&, const TimeSpan&):
           output format "HH:MM:SS" (e.g. "02:15:30")
       operator>>  (friend std::istream&, TimeSpan&):
           input from a stream (format: hours minutes seconds)

   (e) Type conversion:
       explicit operator int() const: converts to the total number of seconds

3. Helper functions:
   - void normalize(): normalizes the internal representation
   - int totalSeconds() const: returns the total number of seconds
   - void display() const: user-friendly display

4. Friend functions:
   - operator<< and operator>> must be friends
   - Also add a friend function operator*(int scalar, const TimeSpan& ts)
     for multiplying a time span by an integer (e.g. 2 * TimeSpan(1,30,0) = 3 hours)

5. In main():
   - Create several TimeSpan objects
   - Demonstrate the use of every overloaded operator
   - Simulate a video player scenario:
     * A video has a total length of 1 hour 30 minutes
     * 45 minutes 20 seconds have already been played
     * Compute the remaining time
     * Fast-forward 30 seconds, rewind 10 seconds

[Hints]
- normalize() should be called after every operation that may change the time
- Time normalization: totalSeconds -> hours = ts/3600, mins = (ts%3600)/60, secs = ts%60
- Prefix increment returns a reference; postfix increment returns a value (not a reference!)
- Pay attention to const correctness in all operator overloads

[Sample expected output]
===== Video Player Time Management =====
Total video length: 01:30:00 (5400 seconds)
Played: 00:45:20 (2720 seconds)
Remaining: 00:44:40 (2680 seconds)

Fast-forward 30 seconds -> Played: 00:45:50
Rewind 10 seconds -> Played: 00:45:40

Less than 30 minutes remaining? yes
Double playback speed -> Estimated remaining: 00:22:20

- Stream operators correctly implemented as friends (+1 point)

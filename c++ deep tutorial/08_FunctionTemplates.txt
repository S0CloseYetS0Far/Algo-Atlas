### Section 1: Basic Example Code + Low-Level Computer Principles

1. Basic Template Syntax

A template is declared with the template keyword, followed by a template parameter list. Type parameters can use
either the typename or the class keyword (the two are completely equivalent in a template parameter declaration).

---------------------------------------------------------------
// ---- Basic example: a generic max function ----
#include <iostream>
#include <string>

// Function template definition
template<typename T>
T maxValue(T a, T b) {
    return (a > b) ? a : b;
}

int main() {
    // Implicit instantiation: the compiler deduces T from the argument types
    std::cout << maxValue(3, 7) << std::endl;          // T = int
    std::cout << maxValue(3.14, 2.71) << std::endl;    // T = double
    std::cout << maxValue(std::string("hello"),
                          std::string("world")) << std::endl;  // T = std::string

    // Explicit instantiation
    std::cout << maxValue<int>(5.5, 3.3) << std::endl;  // T = int, the floating-point values are truncated

    return 0;
}
---------------------------------------------------------------

2. How the Compiler Works Under the Hood

1. Compile-time polymorphism vs runtime polymorphism

   ┌──────────────────────────────────────────────────────────────────────┐
   │        Compile-time polymorphism (templates) vs Runtime (virtual)    │
   ├──────────────────────────────────────────────────────────────────────┤
   │ Binding time:   compile time                  run time               │
   │ Mechanism:      code generation (instantiation)  virtual table       │
   │ Overhead:       none at run time, but code bloat  indirect call cost │
   │ Flexibility:    types fixed at compile time    types extensible      │
   │                                                at run time           │
   │ Typical use:    STL containers/algorithms      plugin systems/       │
   │                                                framework design      │
   └──────────────────────────────────────────────────────────────────────┘

   Templates are called "static polymorphism" or "compile-time polymorphism": the polymorphic behavior is fully determined at compile time
   and does not rely on a virtual table (vtable), so there is no indirect addressing overhead of a virtual function call.

2. A deep dive into the template instantiation mechanism

   Key principle: when the compiler sees a template definition it **generates no code at all**.
   Only when the template is called (instantiated) does the compiler generate a concrete function from the actual template arguments.

   The instantiation process step by step:

   Step 1: The compiler parses the template definition and performs basic syntax checks (phase-one checking).
           For example, it checks matching brackets, correct keywords and other syntax unrelated to the template parameters.
           This phase is also called "definition-time checking".

   Step 2: When the compiler encounters a template call, e.g. maxValue(3, 7),
           it starts phase-two checking -- "instantiation-time checking".
           The compiler generates the complete function definition of int maxValue(int, int).

   Step 3: The compiler compiles the instantiated code into object code (.o file).

   This "two-phase checking" model (Two-Phase Lookup) is the core mechanism of C++ templates:
   - Phase one: check code that does not depend on template parameters (non-dependent names)
   - Phase two: at instantiation, check code that depends on template parameters (dependent names)

   Example:

   template<typename T>
   void foo(T x) {
       x.hello();        // Phase one: not checked (the type of x is unknown; it is a dependent name)
       int y = "abc";    // Phase one: error! (does not depend on T, so it is checked in this phase)
   }

3. Code Bloat

   One potential problem with templates is code bloat:

   template<typename T>
   void process(T value) { /* 100 lines of code */ }

   process<int>(1);      // generates a 100-line int version
   process<double>(1.0); // generates another 100-line double version
   process<float>(1.0f); // generates yet another 100-line float version

   Every distinct combination of template arguments produces its own independent copy of the code.
   If a template function is large and instantiated with many types, the final binary size can grow significantly.

   Mitigation strategies:
   - Move code that does not depend on the template parameters into a non-template base class (the "thin template" technique)
   - Use void* for type erasure so that only one instantiation is needed
   - In C++20, use concepts to constrain the range of types that can be instantiated

4. How templates are handled in object files

   When the same function template is instantiated in multiple translation units (.cpp files),
   each translation unit generates its own object code for that instantiation.
   For example, if both a.cpp and b.cpp call maxValue<int>(1,2),
   then a.o and b.o each contain a copy of the machine code for maxValue<int>.

   The linker is responsible for "deduplication" at final link time (also known as COMDAT folding or ICF),
   keeping only one copy. This means:
   - Compile time increases (every .cpp has to instantiate it once)
   - But the final binary does not grow from the duplicates

5. Templates at the assembly level

   An instantiated function template is no different from an ordinary function at the assembly level.
   Take the following code as an example:

   template<typename T>
   T square(T x) { return x * x; }

   square(5);    // instantiated as int square(int)
   square(3.14); // instantiated as double square(double)

    In the assembly the compiler generates, square(5) and square(3.14) are
    two completely independent functions with different mangled names (name mangling),
    and completely different addresses. Templates carry no special marker at the assembly level.

6. Compile-time branching in templates -- if constexpr (C++17)

   if constexpr, introduced in C++17, allows conditional branching at compile time.
   Unlike an ordinary if, the condition of if constexpr is evaluated at compile time,
   and branches whose condition is not satisfied are not instantiated (they do not even have to be valid for that type).

   This solves the problem of "making one piece of code work for different types" in template code:

   ---------------------------------------------------------------
   #include <iostream>
   #include <type_traits>
   #include <string>

   template<typename T>
   auto getValueDescription(const T& value) {
       if constexpr (std::is_integral_v<T>) {
           return "Integer: " + std::to_string(value);
       }
       else if constexpr (std::is_floating_point_v<T>) {
           return "Floating point: " + std::to_string(value);
       }
       else if constexpr (std::is_same_v<T, std::string>) {
           return "String: " + value;
       }
       else {
           return "Unknown type (size: " + std::to_string(sizeof(T)) + " bytes)";
       }
   }

   int main() {
       std::cout << getValueDescription(42) << std::endl;
       std::cout << getValueDescription(3.14) << std::endl;
       std::cout << getValueDescription(std::string("Hello")) << std::endl;
       std::cout << getValueDescription(nullptr) << std::endl;
       return 0;
   }
   ---------------------------------------------------------------

   Key properties of if constexpr:
   - The condition must be a compile-time constant expression
   - Branches that are not selected are not compiled at all (they cause no errors)
   - Commonly used to replace the clumsy SFINAE syntax

7. Explicit Instantiation

   When a template is defined in a .cpp file, or to control where it is instantiated and reduce compile time,
   you can use explicit instantiation:

   ---------------------------------------------------------------
   // ---- mytemplate.h ----
   template<typename T>
   T max(T a, T b) {
       return (a > b) ? a : b;
   }

   extern template int max<int>(int, int);      // declaration: do not instantiate in this translation unit
   extern template double max<double>(double, double);

   // ---- mytemplate.cpp ----
   template int max<int>(int, int);             // explicit instantiation definition
   template double max<double>(double, double);  // the code is generated here
   ---------------------------------------------------------------

   Use case: when several .cpp files use the same template instantiations,
   suppress automatic instantiation with extern template declarations and perform
   the explicit instantiations centrally in one .cpp to reduce total compile time.

9. Templates and compile-time type computation -- a deeper look at type_traits

   <type_traits> provides a large set of compile-time type query and transformation tools:

   ---------------------------------------------------------------
   #include <iostream>
   #include <type_traits>
   #include <vector>

   template<typename T>
   void analyzeType() {
       std::cout << "Properties of type " << typeid(T).name() << ":" << std::endl;
       std::cout << "  integral:       " << std::is_integral_v<T> << std::endl;
       std::cout << "  floating point: " << std::is_floating_point_v<T> << std::endl;
       std::cout << "  class:          " << std::is_class_v<T> << std::endl;
       std::cout << "  pointer:        " << std::is_pointer_v<T> << std::endl;
       std::cout << "  const:          " << std::is_const_v<T> << std::endl;
       std::cout << "  size:           " << sizeof(T) << " bytes" << std::endl;

       // Type transformation examples
       using RemovedRef = std::remove_reference_t<T>;
       using AddedConst = std::add_const_t<T>;
       using Decayed = std::decay_t<T>;  // removes reference/const/volatile, array decays to pointer

       std::cout << "  decay_t   = " << typeid(Decayed).name() << std::endl;
       std::cout << std::endl;
   }

   int main() {
       analyzeType<int>();
       analyzeType<double>();
       analyzeType<const int&>();
       analyzeType<std::vector<int>>();
       analyzeType<int[10]>();
       return 0;
   }
   ---------------------------------------------------------------

   Common categories of type_traits:
   ┌─────────────────────┬──────────────────────────────────────────┐
   │ Category            │ Example traits                           │
   ├─────────────────────┼──────────────────────────────────────────┤
   │ Type queries        │ is_void, is_integral, is_floating_point  │
   │ Type relationships  │ is_same, is_base_of, is_convertible      │
   │ Type modifications  │ remove_const, add_pointer, decay         │
   │ Type properties     │ is_pod, is_abstract, is_trivially_xxx    │
   │ Compound types      │ is_reference, is_pointer, is_array       │
   │ SFINAE support      │ enable_if, conditional, void_t           │
   └─────────────────────┴──────────────────────────────────────────┘

1. Defining Function Templates

Basic form:

template<typename T>       // typename is recommended (clearer meaning)
T add(T a, T b) { return a + b; }

template<class T>           // class works too; it is equivalent to typename
T subtract(T a, T b) { return a - b; }

// Multiple template parameters
template<typename T1, typename T2>
auto multiply(T1 a, T2 b) -> decltype(a * b) {
    return a * b;
}

// Since C++14, auto can deduce the return type automatically
template<typename T1, typename T2>
auto multiply14(T1 a, T2 b) {
    return a * b;    // the compiler deduces the return type
}

2. Non-type Template Parameters

Besides type parameters, templates can also accept compile-time constant values as parameters:

---------------------------------------------------------------
#include <iostream>
#include <array>

// N is a compile-time constant
template<typename T, int N>
class FixedArray {
private:
    T data[N];          // array size is fixed at compile time; no dynamic memory needed
public:
    int size() const { return N; }
    T& operator[](int index) { return data[index]; }
    const T& operator[](int index) const { return data[index]; }
    void fill(const T& value) {
        for(int i = 0; i < N; ++i) data[i] = value;
    }
};

int main() {
    FixedArray<int, 5> arr;     // 5 is fixed at compile time
    arr.fill(42);
    std::cout << arr[3] << std::endl;  // prints 42
    return 0;
}
---------------------------------------------------------------

Non-type template parameters can be:
- Integral constants (int, long, short, char, bool, etc.)
- Enumeration constants
- Pointers/references (to global objects or functions)
- std::nullptr_t
- Since C++20: floating-point values and class types (literal types)

3. Defining Class Templates

Class templates are the foundation of generic containers (such as std::vector<T>, std::map<K,V>):

---------------------------------------------------------------
#include <iostream>
#include <stdexcept>

template<typename T>
class Stack {
private:
    T* data;
    int capacity;
    int topIndex;
public:
    explicit Stack(int cap = 100)
        : capacity(cap), topIndex(-1) {
        data = new T[capacity];      // dynamic memory allocation
    }

    ~Stack() { delete[] data; }

    Stack(const Stack& other)        // copy constructor
        : capacity(other.capacity), topIndex(other.topIndex) {
        data = new T[capacity];
        for(int i = 0; i <= topIndex; ++i)
            data[i] = other.data[i];
    }

    Stack& operator=(const Stack& other) {
        if(this != &other) {
            delete[] data;
            capacity = other.capacity;
            topIndex = other.topIndex;
            data = new T[capacity];
            for(int i = 0; i <= topIndex; ++i)
                data[i] = other.data[i];
        }
        return *this;
    }

    void push(const T& value) {
        if(topIndex >= capacity - 1)
            throw std::overflow_error("Stack overflow");
        data[++topIndex] = value;
    }

    T pop() {
        if(topIndex < 0)
            throw std::underflow_error("Stack underflow");
        return data[topIndex--];
    }

    T& top() {
        if(topIndex < 0)
            throw std::underflow_error("Stack empty");
        return data[topIndex];
    }

    bool empty() const { return topIndex < 0; }
    int size() const { return topIndex + 1; }
};

int main() {
    Stack<std::string> s(10);
    s.push("Hello");
    s.push("World");
    std::cout << s.pop() << std::endl;  // World
    std::cout << s.pop() << std::endl;  // Hello
    return 0;
}

4. Template Specialization

4.1 Full Specialization

When a particular type needs special handling, you can fully specialize the template:

---------------------------------------------------------------
#include <iostream>

// Primary template
template<typename T>
class TypeInfo {
public:
    static const char* name() { return "Unknown"; }
    static int size() { return sizeof(T); }
};

// Full specialization for int
template<>
class TypeInfo<int> {
public:
    static const char* name() { return "integer"; }
    static int size() { return sizeof(int); }
};

// Full specialization for double
template<>
class TypeInfo<double> {
public:
    static const char* name() { return "double-precision float"; }
    static int size() { return sizeof(double); }
};

// Full specialization for std::string
template<>
class TypeInfo<std::string> {
public:
    static const char* name() { return "string"; }
    static int size() { return sizeof(std::string); }
};

int main() {
    std::cout << TypeInfo<char>::name() << std::endl;      // Unknown
    std::cout << TypeInfo<int>::name() << std::endl;       // integer
    std::cout << TypeInfo<double>::name() << std::endl;    // double-precision float
    return 0;
}
---------------------------------------------------------------

4.2 Partial Specialization

Partial specialization lets you specialize some of the template parameters, or add constraints on them:

---------------------------------------------------------------
#include <iostream>

// Primary template
template<typename T, typename U>
class Pair {
public:
    T first;
    U second;
    Pair(T f, U s) : first(f), second(s) {}
    void describe() { std::cout << "Generic Pair" << std::endl; }
};

// Partial specialization: both types are the same
template<typename T>
class Pair<T, T> {
public:
    T first, second;
    Pair(T f, T s) : first(f), second(s) {}
    void describe() { std::cout << "Homogeneous Pair" << std::endl; }
};

// Partial specialization: the second parameter is fixed to int
template<typename T>
class Pair<T, int> {
public:
    T first;
    int second;
    Pair(T f, int s) : first(f), second(s) {}
    void describe() { std::cout << "Pair with int second" << std::endl; }
};

// Partial specialization: pointer types (strip the pointer, keep the pointee type)
template<typename T>
class Pair<T*, T*> {
public:
    T* first;
    T* second;
    Pair(T* f, T* s) : first(f), second(s) {}
    void describe() { std::cout << "Pointer Pair" << std::endl; }
};

int main() {
    Pair<double, char> p1(3.14, 'A');    // generic version
    p1.describe();                         // "Generic Pair"

    Pair<int, int> p2(1, 2);              // partial specialization: same-type version
    p2.describe();                         // "Homogeneous Pair"

    Pair<double, int> p3(3.14, 42);       // partial specialization: second is int
    p3.describe();                         // "Pair with int second"

    int a = 10, b = 20;
    Pair<int*, int*> p4(&a, &b);          // partial specialization: pointer version
    p4.describe();                         // "Pointer Pair"

    return 0;
}

5. Default Template Arguments

Just as functions can have default arguments, templates can have default template arguments:

---------------------------------------------------------------
#include <iostream>
#include <vector>
#include <functional>

// Default template argument: Container defaults to std::vector
template<typename T, typename Container = std::vector<T>>
class Queue {
private:
    Container data;
public:
    void enqueue(const T& value) { data.push_back(value); }
    T dequeue() {
        T front = data.front();
        data.erase(data.begin());
        return front;
    }
    bool empty() const { return data.empty(); }
    size_t size() const { return data.size(); }
};

// Default comparator argument
template<typename T, typename Comparator = std::less<T>>
T maxOfThree(T a, T b, T c, Comparator cmp = Comparator()) {
    T maxVal = a;
    if(cmp(maxVal, b)) maxVal = b;
    if(cmp(maxVal, c)) maxVal = c;
    return maxVal;
}

int main() {
    // Use the default container std::vector
    Queue<int> q;
    q.enqueue(1);
    q.enqueue(2);
    std::cout << q.dequeue() << std::endl;  // 1

    // Use the default comparator std::less
    std::cout << maxOfThree(3, 7, 1) << std::endl;  // 7

    return 0;
}

6. Variadic Templates (C++11)

Variadic templates let a function or class accept any number of arguments of any types:

---------------------------------------------------------------
#include <iostream>
#include <string>

// Recursion base case: empty parameter pack
void print() {
    std::cout << std::endl;  // newline after the last argument
}

// Recursively expand the parameter pack
template<typename T, typename... Args>
void print(T first, Args... rest) {
    std::cout << first;
    if constexpr(sizeof...(rest) > 0)   // C++17 if constexpr
        std::cout << ", ";
    print(rest...);  // recursive call; the pack shrinks by one
}

// Expansion with an initializer list (another expansion technique)
template<typename... Args>
void printAll(Args... args) {
    // Expand using the comma operator and an initializer list
    int dummy[] = { (std::cout << args << " ", 0)... };
    std::cout << std::endl;
    (void)dummy;  // suppress the unused-variable warning
}

// Another recursive example: sum
template<typename T>
T sum(T value) {
    return value;
}

template<typename T, typename... Args>
T sum(T first, Args... rest) {
    return first + sum(rest...);
}

int main() {
    print("Hello", 42, 3.14, std::string("World"));
    // Output: Hello, 42, 3.14, World

    printAll(1, 2, 3, 4, 5);
    // Output: 1 2 3 4 5

    std::cout << sum(1, 2, 3, 4, 5) << std::endl;         // 15
    std::cout << sum(1.5, 2.5, 3.0) << std::endl;         // 7.0

    return 0;
}
---------------------------------------------------------------

7. Fold Expressions (C++17)

Fold expressions are a concise syntax for working with variadic templates. There are four forms:

---------------------------------------------------------------
#include <iostream>
#include <string>

// Unary left fold: (... op args)
template<typename... Args>
auto sumLeft(Args... args) {
    return (... + args);  // expands to ((arg1 + arg2) + arg3) + ...
}

// Unary right fold: (args op ...)
template<typename... Args>
auto sumRight(Args... args) {
    return (args + ...);  // expands to arg1 + (arg2 + (arg3 + ...))
}

// Binary left fold: (init op ... op args)
template<typename... Args>
auto sumWithInit(Args... args) {
    return (0 + ... + args);  // initial value is 0
}

// Binary right fold: (args op ... op init)
template<typename... Args>
auto prodWithInit(Args... args) {
    return (args * ... * 1);  // initial value is 1
}

// Folding over output: print each argument in turn
template<typename... Args>
void printAllFold(Args... args) {
    (std::cout << ... << args) << std::endl;  // binary left fold
}

// Logical AND fold: all conditions hold
template<typename... Args>
bool allTrue(Args... args) {
    return (... && args);  // returns true only if all arguments are true
}

// Logical OR fold: any condition holds
template<typename... Args>
bool anyTrue(Args... args) {
    return (... || args);
}

int main() {
    std::cout << "Sum: " << sumLeft(1, 2, 3, 4, 5) << std::endl;      // 15
    std::cout << "Sum right: " << sumRight(1, 2, 3) << std::endl;     // 6
    std::cout << "Sum with init: " << sumWithInit(10, 20) << std::endl;// 30
    std::cout << "Product: " << prodWithInit(2, 3, 4) << std::endl;   // 24

    printAllFold("Hello", " ", "World", " ", 2024);
    // Output: Hello World 2024

    std::cout << "All true: " << allTrue(true, 1, 5 > 3) << std::endl;      // 1 (true)
    std::cout << "Any true: " << anyTrue(false, 0, true) << std::endl;      // 1 (true)

    return 0;
}
---------------------------------------------------------------

8. Introduction to Template Metaprogramming

Template metaprogramming (TMP) uses templates to perform computations at compile time. Take factorial as an example:

---------------------------------------------------------------
#include <iostream>

// Template metaprogramming: computing factorial at compile time
template<unsigned int N>
struct Factorial {
    // Recursion: N! = N * (N-1)!
    static constexpr unsigned long long value = N * Factorial<N - 1>::value;
};

// Recursion base case: 0! = 1 (template specialization)
template<>
struct Factorial<0> {
    static constexpr unsigned long long value = 1;
};

// Compile-time Fibonacci sequence
template<unsigned int N>
struct Fibonacci {
    static constexpr unsigned long long value =
        Fibonacci<N - 1>::value + Fibonacci<N - 2>::value;
};

template<>
struct Fibonacci<0> {
    static constexpr unsigned long long value = 0;
};

template<>
struct Fibonacci<1> {
    static constexpr unsigned long long value = 1;
};

int main() {
    // These computations are done at compile time; at run time we just read constants
    std::cout << "5!  = " << Factorial<5>::value << std::endl;     // 120
    std::cout << "10! = " << Factorial<10>::value << std::endl;    // 3628800
    std::cout << "20! = " << Factorial<20>::value << std::endl;    // 2432902008176640000

    std::cout << "Fib(10) = " << Fibonacci<10>::value << std::endl; // 55
    std::cout << "Fib(20) = " << Fibonacci<20>::value << std::endl; // 6765

    // Compile-time results can be used directly for array sizes, template arguments, etc.
    int arr[Factorial<5>::value];  // an array of 120 ints (size fixed at compile time)

    return 0;
}
---------------------------------------------------------------

9. decltype and auto Return Type Deduction

decltype queries the type of an expression (without evaluating it); auto deduces types automatically:

---------------------------------------------------------------
#include <iostream>
#include <vector>
#include <type_traits>

// decltype in trailing return type syntax
template<typename T1, typename T2>
auto add(T1 a, T2 b) -> decltype(a + b) {
    return a + b;
}

// Since C++14, plain auto can be used
template<typename T1, typename T2>
auto multiply(T1 a, T2 b) {
    return a * b;
}

// decltype preserves reference-ness
int globalVar = 100;
decltype(globalVar) ref = globalVar;     // int -- not a reference
decltype((globalVar)) ref2 = globalVar;   // int& -- double parentheses yield a reference

// Practical use: deducing the element type in a template
template<typename Container>
void processContainer(const Container& c) {
    // Deduce the type of the container's elements
    using ElementType = decltype(*c.begin());

    std::cout << "Element type size: " << sizeof(ElementType) << std::endl;

    // If you need the plain value type
    using ConstElementType = typename Container::value_type;
}

int main() {
    auto result1 = add(3, 4.5);      // decltype(3 + 4.5) => double
    auto result2 = multiply(2, 3.5); // double

    std::cout << result1 << " | " << result2 << std::endl;

    std::vector<int> vec = {1, 2, 3, 4, 5};
    processContainer(vec);

    return 0;
}

10. Introduction to SFINAE and enable_if

SFINAE = Substitution Failure Is Not An Error
This is a core principle of C++ templates: if substituting the template arguments into a candidate function
produces invalid code, the compiler does not report an error; it silently drops that candidate.

---------------------------------------------------------------
#include <iostream>
#include <type_traits>
#include <vector>

// Basic use of enable_if: conditional compilation
// std::enable_if exposes a type member when the condition is true, and nothing otherwise

// A function that only works for integral types
template<typename T>
typename std::enable_if<std::is_integral<T>::value, T>::type
safeDivide(T a, T b) {
    if(b == 0) throw std::runtime_error("Division by zero");
    return a / b;
}

// A function that only works for floating-point types
template<typename T>
typename std::enable_if<std::is_floating_point<T>::value, T>::type
safeDivide(T a, T b) {
    if(std::abs(b) < 1e-10)
        throw std::runtime_error("Division by near-zero");
    return a / b;
}

// Since C++14 there is a more concise form
template<typename T>
std::enable_if_t<std::is_integral_v<T>, T>
multiplyByTwo(T x) {
    return x * 2;
}

// Another SFINAE example: detect whether a type has a size() method
template<typename T>
auto hasSize(int) -> decltype(std::declval<T>().size(), std::true_type{});

template<typename T>
std::false_type hasSize(...);

template<typename T>
struct HasSizeMethod : decltype(hasSize<T>(0)) {};

int main() {
    // Integer version
    std::cout << safeDivide(10, 3) << std::endl;      // 3
    // Floating-point version
    std::cout << safeDivide(10.0, 3.0) << std::endl;  // 3.33333

    std::cout << multiplyByTwo(21) << std::endl;       // 42

    std::cout << "vector has size(): "
              << HasSizeMethod<std::vector<int>>::value << std::endl; // 1
    std::cout << "int has size(): "
              << HasSizeMethod<int>::value << std::endl;              // 0

    return 0;
}

11. A Brief Introduction to Concepts (C++20)

Concepts are the template constraint mechanism introduced in C++20. They impose compile-time constraints on template parameters
and make template error messages much clearer (replacing the clumsy SFINAE syntax):

---------------------------------------------------------------
// C++20 Concepts example (requires a C++20 compiler)
#if __cplusplus >= 202002L

#include <iostream>
#include <concepts>
#include <type_traits>

// Define a concept: the type must support the + operator and return the same type
template<typename T>
concept Addable = requires(T a, T b) {
    { a + b } -> std::same_as<T>;
};

// Define a concept: must be a numeric type
template<typename T>
concept Numeric = std::integral<T> || std::floating_point<T>;

// Use a concept to constrain the template parameter
template<Numeric T>
T square(T x) {
    return x * x;
}

// Define a concept requiring begin()/end()
template<typename T>
concept Iterable = requires(T t) {
    t.begin();
    t.end();
    typename T::value_type;
};

// Print types that support iteration
template<Iterable T>
void printElements(const T& container) {
    for(const auto& elem : container)
        std::cout << elem << " ";
    std::cout << std::endl;
}

int main() {
    std::cout << square(5) << std::endl;       // 25
    std::cout << square(2.5) << std::endl;     // 6.25

    std::vector<int> v = {1, 2, 3, 4, 5};
    printElements(v);                           // 1 2 3 4 5

    // printElements(42);  // compile error! int does not satisfy the Iterable concept
    return 0;
}

#endif

Case 1: A Generic Comparator -- Ranking in a Competition Scoring System
---------------------------------------------------------------
Scenario: a judging system for sports competitions needs to compare contestants' scores. Scores can be
int (track timing), double (gymnastics scores) or string (competition grades).

Concepts applied:
- Ch1 Namespaces: namespace ScoreSystem {}
- Ch3 Dynamic memory: dynamically allocated arrays of contestant scores
- Ch7 Operator overloading: > (already supported)

---------------------------------------------------------------
#include <iostream>
#include <string>
#include <cstring>
#include <vector>
#include <algorithm>

namespace ScoreSystem {

    // Generic comparison template: returns the larger value
    template<typename T>
    T maxScore(T a, T b) {
        return (a > b) ? a : b;   // relies on operator>
    }

    // Generic version: returns the smaller value
    template<typename T>
    T minScore(T a, T b) {
        return (a < b) ? a : b;
    }

    // Specialization: comparing const char* strings
    // Comparing const char* directly compares addresses, not contents, so it must be specialized
    template<>
    const char* maxScore<const char*>(const char* a, const char* b) {
        return (std::strcmp(a, b) > 0) ? a : b;
    }

    template<>
    const char* minScore<const char*>(const char* a, const char* b) {
        return (std::strcmp(a, b) < 0) ? a : b;
    }

    // Return the maximum of several scores (variadic template)
    template<typename T>
    T maxOfAll(T first) {
        return first;
    }

    template<typename T, typename... Args>
    T maxOfAll(T first, Args... rest) {
        T maxRest = maxOfAll(rest...);
        return maxScore(first, maxRest);
    }

    // Contestant class (applies Ch4 classes and objects, Ch7 operator overloading)
    class Contestant {
    private:
        std::string name;
        double* scores;       // Ch3 dynamic memory
        int scoreCount;
        int id;
        static int nextId;    // static member

    public:
        Contestant(const std::string& n, int count)
            : name(n), scoreCount(count), id(nextId++) {
            scores = new double[count];  // dynamic allocation
        }

        Contestant(const Contestant& other)   // copy constructor
            : name(other.name), scoreCount(other.scoreCount), id(nextId++) {
            scores = new double[scoreCount];
            for(int i = 0; i < scoreCount; ++i)
                scores[i] = other.scores[i];
        }

        Contestant& operator=(const Contestant& other) {
            if(this != &other) {
                name = other.name;
                scoreCount = other.scoreCount;
                delete[] scores;
                scores = new double[scoreCount];
                for(int i = 0; i < scoreCount; ++i)
                    scores[i] = other.scores[i];
            }
            return *this;
        }

        ~Contestant() { delete[] scores; }

        void setScore(int index, double value) {
            if(index >= 0 && index < scoreCount)
                scores[index] = value;
        }

        double getAverage() const {
            double total = 0;
            for(int i = 0; i < scoreCount; ++i)
                total += scores[i];
            return scoreCount > 0 ? total / scoreCount : 0;
        }

        // Operator overloading: compare by average score (Ch7)
        bool operator<(const Contestant& other) const {
            return getAverage() < other.getAverage();
        }

        bool operator>(const Contestant& other) const {
            return getAverage() > other.getAverage();
        }

        friend std::ostream& operator<<(std::ostream& os,
                                         const Contestant& c) {
            os << "Contestant #" << c.id << " [" << c.name
               << "] average: " << c.getAverage();
            return os;
        }

        const std::string& getName() const { return name; }
        int getId() const { return id; }
    };

    int Contestant::nextId = 1000;

} // namespace ScoreSystem

int main() {
    using namespace ScoreSystem;

    // Test the generic comparator
    std::cout << "===== Competition Scoring System =====" << std::endl;

    // int comparison (100m track times)
    std::cout << "100m sprint, larger value: "
              << maxScore(1030, 987) << " (hundredths of a second)" << std::endl;

    // double comparison (gymnastics scores)
    std::cout << "Highest gymnastics score: "
              << maxScore(9.85, 9.92) << std::endl;

    // string comparison (competition grades)
    const char* grade1 = "Gold";
    const char* grade2 = "Silver";
    std::cout << "Medal grade: "
              << maxScore(grade1, grade2) << std::endl;

    // Variadic comparison
    std::cout << "Highest across all events: "
              << maxOfAll(9.1, 9.5, 9.3, 8.9, 9.6) << std::endl;

    // Contestant management
    Contestant c1("Zhang San", 5);
    Contestant c2("Li Si", 5);

    double scores1[] = {9.2, 9.5, 9.1, 9.8, 9.3};
    double scores2[] = {9.0, 9.4, 9.6, 9.2, 9.5};

    for(int i = 0; i < 5; ++i) {
        c1.setScore(i, scores1[i]);
        c2.setScore(i, scores2[i]);
    }

    std::cout << c1 << std::endl;
    std::cout << c2 << std::endl;

    // Use the template comparator to find the better contestant
    Contestant winner = maxScore(c1, c2);
    std::cout << "Winner: " << winner.getName() << std::endl;

    return 0;
}

Case 2: A Generic Container Printer -- Displaying Database Query Results
---------------------------------------------------------------
Scenario: you are building a database management tool that needs to format and display query results of different types
(lists of integer IDs, lists of string names, lists of floating-point prices, etc.).

Concepts applied:
- Ch1 Namespaces: namespace DBUtils {}
- Ch2 Preprocessor: a DEBUG macro controls debug output
- Ch3 Dynamic memory: traversal with iterators
- Templates + decltype/auto

---------------------------------------------------------------
#include <iostream>
#include <vector>
#include <list>
#include <set>
#include <map>
#include <string>
#include <iomanip>

// Chapter 2: preprocessor macros for the debug level
#define DB_DEBUG_LEVEL 1

#if DB_DEBUG_LEVEL > 0
    #define DB_LOG(msg) std::cout << "[DBG] " << msg << std::endl
#else
    #define DB_LOG(msg)
#endif

namespace DBUtils {

    // Generic container printing function template
    template<typename Container>
    void printContainer(const Container& c, const std::string& title = "") {
        if(!title.empty())
            std::cout << "--- " << title << " ---" << std::endl;

        std::cout << "[";
        size_t count = 0;
        for(auto it = c.begin(); it != c.end(); ++it) {
            if(count++ > 0) std::cout << ", ";
            std::cout << *it;
        }
        std::cout << "]" << std::endl;
    }

    // Overload: handle map containers separately (key-value pairs)
    template<typename K, typename V>
    void printContainer(const std::map<K, V>& m,
                         const std::string& title = "") {
        if(!title.empty())
            std::cout << "--- " << title << " ---" << std::endl;

        for(const auto& pair : m) {
            std::cout << "  " << pair.first << " => "
                      << pair.second << std::endl;
        }
    }

    // Use decltype to deduce the element type and format the output
    template<typename Container>
    void printWithTypeInfo(const Container& c) {
        using ElementType = decltype(*c.begin());
        std::cout << "Container element type size: " << sizeof(ElementType)
                  << " bytes, element count: " << c.size() << std::endl;
        printContainer(c);
    }

    // Print in table form (for database query results)
    template<typename Container>
    void printAsTable(const Container& c,
                      int colWidth = 12,
                      int columnsPerRow = 4) {
        int count = 0;
        for(const auto& elem : c) {
            std::cout << std::setw(colWidth) << std::left << elem;
            if(++count % columnsPerRow == 0)
                std::cout << std::endl;
        }
        if(count % columnsPerRow != 0)
            std::cout << std::endl;
    }

} // namespace DBUtils

int main() {
    using namespace DBUtils;

    DB_LOG("Starting database query demo");

    // Simulate query results of different types
    std::vector<int> userIds = {1001, 1002, 1003, 1004, 1005};
    std::list<std::string> cityNames =
        {"Beijing", "Shanghai", "Guangzhou", "Shenzhen", "Hangzhou", "Chengdu"};
    std::set<double> productPrices = {19.99, 29.50, 99.00, 149.99, 9.90};

    std::map<int, std::string> userMap = {
        {1001, "Zhang San"}, {1002, "Li Si"}, {1003, "Wang Wu"}
    };

    // Print the query results
    printContainer(userIds, "User ID query results");
    printContainer(cityNames, "City query results");
    printContainer(productPrices, "Product price query results (sorted)");
    printContainer(userMap, "User mapping table");

    // Print with type information
    printWithTypeInfo(userIds);

    // Print in table format
    std::cout << "\n=== Table Format Output ===" << std::endl;
    std::vector<std::string> products = {
        "Phone", "Laptop", "Tablet", "Headphones", "Watch", "Speaker",
        "Mouse", "Keyboard", "Monitor", "Charger", "Cable", "Stand"
    };
    printAsTable(products, 15, 4);

    DB_LOG("Query demo finished");

    return 0;
}

Case 3: A Variadic Logging System -- Multi-Level Server Logging
---------------------------------------------------------------
Scenario: a backend server needs a multi-level logging system that supports any number of formatted arguments
and filters output by level, similar to an enterprise logging framework.

Concepts applied:
- Ch1 Namespaces: namespace Logger {}
- Ch2 Preprocessor: a LOG_LEVEL macro controls the compile-time log level
- This chapter: variadic templates + fold expressions

---------------------------------------------------------------
#include <iostream>
#include <string>
#include <sstream>
#include <ctime>
#include <chrono>
#include <iomanip>

// Chapter 2: control the log level with the preprocessor
#ifndef LOG_LEVEL
    #define LOG_LEVEL 0   // 0=ALL, 1=DEBUG, 2=INFO, 3=WARN, 4=ERROR, 5=FATAL
#endif

namespace Logger {

    // Log level enumeration
    enum class Level {
        ALL = 0, DEBUG = 1, INFO = 2,
        WARN = 3, ERROR = 4, FATAL = 5
    };

    // Get the level string
    const char* levelToString(Level lvl) {
        switch(lvl) {
            case Level::DEBUG: return "DEBUG";
            case Level::INFO:  return "INFO ";
            case Level::WARN:  return "WARN ";
            case Level::ERROR: return "ERROR";
            case Level::FATAL: return "FATAL";
            default:           return "ALL  ";
        }
    }

    // Get the current time as a string
    std::string currentTime() {
        auto now = std::chrono::system_clock::now();
        auto timeT = std::chrono::system_clock::to_time_t(now);
        auto ms = std::chrono::duration_cast<std::chrono::milliseconds>(
            now.time_since_epoch()) % 1000;

        std::stringstream ss;
        ss << std::put_time(std::localtime(&timeT), "%Y-%m-%d %H:%M:%S");
        ss << '.' << std::setfill('0') << std::setw(3) << ms.count();
        return ss.str();
    }

    // Core function that converts any argument to a string
    template<typename T>
    std::string toString(const T& value) {
        std::stringstream ss;
        ss << value;
        return ss.str();
    }

    // Logging: a single argument
    template<typename T>
    void log(Level lvl, const T& msg) {
        if(static_cast<int>(lvl) < LOG_LEVEL) return;  // level filtering
        std::cout << "[" << currentTime() << "]"
                  << "[" << levelToString(lvl) << "] "
                  << toString(msg) << std::endl;
    }

    // Logging: variadic arguments -- expanded with a fold expression
    template<typename T, typename... Args>
    void log(Level lvl, const T& first, const Args&... rest) {
        if(static_cast<int>(lvl) < LOG_LEVEL) return;

        std::stringstream ss;
        ss << "[" << currentTime() << "]"
           << "[" << levelToString(lvl) << "] ";

        // Concatenate all arguments with a fold expression
        ss << toString(first);
        ((ss << " " << toString(rest)), ...);

        std::cout << ss.str() << std::endl;
    }

    // Batch logging: output several messages of the same level at once
    template<typename... Args>
    void batchLog(Level lvl, Args... msgs) {
        if(static_cast<int>(lvl) < LOG_LEVEL) return;
        std::cout << "[" << currentTime() << "]"
                  << "[" << levelToString(lvl) << "] === Batch messages ==="
                  << std::endl;
        int count = 0;
        // Output each one in turn using a fold expression
        ((std::cout << "  [" << ++count << "] "
                    << toString(msgs) << std::endl), ...);
    }

    // Summing with a fold expression for log statistics (log volume)
    template<typename... Args>
    size_t totalMessageLength(Args... msgs) {
        // Sum of the lengths of all message strings
        return (0 + ... + toString(msgs).length());
    }

    // Dedicated logging macros (combined with the Chapter 2 preprocessor)
    #define LOG_DEBUG(...) Logger::log(Logger::Level::DEBUG, __VA_ARGS__)
    #define LOG_INFO(...)  Logger::log(Logger::Level::INFO, __VA_ARGS__)
    #define LOG_WARN(...)  Logger::log(Logger::Level::WARN, __VA_ARGS__)
    #define LOG_ERROR(...) Logger::log(Logger::Level::ERROR, __VA_ARGS__)
    #define LOG_FATAL(...) Logger::log(Logger::Level::FATAL, __VA_ARGS__)

} // namespace Logger

int main() {
    using namespace Logger;

    std::cout << "===== Server Logging System Demo =====" << std::endl;

    // Single log entries
    LOG_INFO("Server started");
    LOG_DEBUG("Loading config file", "server.conf");
    LOG_WARN("Disk usage", "85%", "cleanup recommended");
    LOG_ERROR("Database connection failed", "timeout", "30s", "retry", 3, "times");

    // Batch logging
    batchLog(Level::INFO,
             "User 1001 logged in",
             "User 1002 logged in",
             "User 1003 logged in",
             "User 1005 logged in");

    // Count message length
    size_t total = totalMessageLength(
        "Starting...", "Initializing database...", "Loading cache...", "Listening on port 8080");
    LOG_INFO("Total message length:", total, "bytes");

    // Demonstrate summing with a fold expression
    auto intSum = (... + std::vector<int>{1, 2, 3, 4, 5});
    std::cout << "Fold sum (int): " << intSum << std::endl;

    LOG_INFO("Server running normally");

    return 0;
}

Case 4: A Generic Math Library -- A 3D Game Physics Engine
---------------------------------------------------------------
Scenario: 3D game development needs vector operations (position, velocity, acceleration, etc.)
on vectors of different dimensions (N) and different types (float/double).

Concepts applied:
- Ch1 Namespaces: namespace MathLib {}
- Ch3 Dynamic memory: storing vector components
- Ch6 Polymorphism: dispatchable operations
- Ch7 Operator overloading: +, -, *, /, [] and more
- This chapter: class templates / enable_if constraints / specialization

---------------------------------------------------------------
#include <iostream>
#include <cmath>
#include <type_traits>
#include <stdexcept>
#include <initializer_list>

namespace MathLib {

    // Generic vector class template
    // enable_if constraint: only arithmetic types (integers and floating point) are allowed
    template<typename T, int N,
             typename = std::enable_if_t<std::is_arithmetic<T>::value>>
    class Vector {
    private:
        T* components;   // Ch3 dynamic memory allocation

    public:
        // Constructors
        Vector() {
            components = new T[N]{};
        }

        Vector(std::initializer_list<T> list) {
            if(list.size() != static_cast<size_t>(N))
                throw std::invalid_argument("Dimension mismatch");
            components = new T[N];
            int i = 0;
            for(auto& val : list) components[i++] = val;
        }

        // Copy constructor
        Vector(const Vector& other) {
            components = new T[N];
            for(int i = 0; i < N; ++i)
                components[i] = other.components[i];
        }

        // Assignment operator
        Vector& operator=(const Vector& other) {
            if(this != &other) {
                for(int i = 0; i < N; ++i)
                    components[i] = other.components[i];
            }
            return *this;
        }

        // Destructor
        ~Vector() { delete[] components; }

        // Get the dimension
        static constexpr int dimension() { return N; }

        // Subscript operator overloads (Ch7)
        T& operator[](int index) {
            if(index < 0 || index >= N)
                throw std::out_of_range("Index out of range");
            return components[index];
        }

        const T& operator[](int index) const {
            if(index < 0 || index >= N)
                throw std::out_of_range("Index out of range");
            return components[index];
        }

        // Vector addition
        Vector operator+(const Vector& other) const {
            Vector result;
            for(int i = 0; i < N; ++i)
                result.components[i] = components[i] + other.components[i];
            return result;
        }

        // Vector subtraction
        Vector operator-(const Vector& other) const {
            Vector result;
            for(int i = 0; i < N; ++i)
                result.components[i] = components[i] - other.components[i];
            return result;
        }

        // Scalar multiplication
        Vector operator*(T scalar) const {
            Vector result;
            for(int i = 0; i < N; ++i)
                result.components[i] = components[i] * scalar;
            return result;
        }

        // Scalar division
        Vector operator/(T scalar) const {
            if(scalar == 0) throw std::runtime_error("Division by zero");
            Vector result;
            for(int i = 0; i < N; ++i)
                result.components[i] = components[i] / scalar;
            return result;
        }

        // Dot product
        T dot(const Vector& other) const {
            T result = 0;
            for(int i = 0; i < N; ++i)
                result += components[i] * other.components[i];
            return result;
        }

        // Vector length (magnitude)
        double magnitude() const {
            double sum = 0;
            for(int i = 0; i < N; ++i)
                sum += components[i] * components[i];
            return std::sqrt(sum);
        }

        // Normalization
        Vector normalized() const {
            double mag = magnitude();
            if(mag < 1e-10) return *this;
            Vector result;
            for(int i = 0; i < N; ++i)
                result.components[i] =
                    static_cast<T>(components[i] / mag);
            return result;
        }

        // Stream output
        friend std::ostream& operator<<(std::ostream& os,
                                         const Vector& v) {
            os << "Vector" << N << "(";
            for(int i = 0; i < N; ++i) {
                if(i > 0) os << ", ";
                os << v.components[i];
            }
            os << ")";
            return os;
        }
    };

    // Template specialization: Vector<bool, N> uses bit-packed storage
    // Each component is only true/false, so one byte can store 8 dimensions
    template<int N>
    class Vector<bool, N> {
    private:
        static constexpr int bytes_needed = (N + 7) / 8;
        unsigned char data[bytes_needed] = {};

        bool getBit(int index) const {
            int byteIdx = index / 8;
            int bitIdx = index % 8;
            return (data[byteIdx] >> bitIdx) & 1;
        }

        void setBit(int index, bool value) {
            int byteIdx = index / 8;
            int bitIdx = index % 8;
            if(value)
                data[byteIdx] |= (1 << bitIdx);    // set the bit
            else
                data[byteIdx] &= ~(1 << bitIdx);   // clear the bit
        }

    public:
        static constexpr int dimension() { return N; }

        // Proxy class for subscript access
        class BitRef {
        private:
            unsigned char* bytePtr;
            int bitIdx;
        public:
            BitRef(unsigned char* ptr, int idx)
                : bytePtr(ptr), bitIdx(idx) {}

            operator bool() const {
                return (*bytePtr >> bitIdx) & 1;
            }

            BitRef& operator=(bool val) {
                if(val)
                    *bytePtr |= (1 << bitIdx);
                else
                    *bytePtr &= ~(1 << bitIdx);
                return *this;
            }
        };

        BitRef operator[](int index) {
            return BitRef(&data[index / 8], index % 8);
        }

        bool operator[](int index) const {
            return getBit(index);
        }

        friend std::ostream& operator<<(std::ostream& os,
                                         const Vector& v) {
            os << "BoolVector" << N << "(";
            for(int i = 0; i < N; ++i) {
                if(i > 0) os << ", ";
                os << (v.getBit(i) ? "1" : "0");
            }
            os << ")";
            return os;
        }
    };

    // Cross product -- only meaningful in 3D
    template<typename T>
    Vector<T, 3> cross(const Vector<T, 3>& a, const Vector<T, 3>& b) {
        return Vector<T, 3>({
            a[1] * b[2] - a[2] * b[1],
            a[2] * b[0] - a[0] * b[2],
            a[0] * b[1] - a[1] * b[0]
        });
    }

} // namespace MathLib

int main() {
    using namespace MathLib;

    std::cout << "===== 3D Game Physics Engine Vector Demo =====" << std::endl;

    // 3D position vectors
    Vector<double, 3> position({0.0, 0.0, 0.0});
    Vector<double, 3> velocity({10.0, 5.0, 2.5});
    Vector<double, 3> gravity({0.0, -9.8, 0.0});
    Vector<double, 3> force({3.0, 0.0, 1.0});

    std::cout << "Initial position: " << position << std::endl;
    std::cout << "Velocity: " << velocity << std::endl;
    std::cout << "Gravity: " << gravity << std::endl;

    // Physics: new velocity = old velocity + acceleration * time (simplified)
    Vector<double, 3> newVelocity = velocity + gravity * 0.016; // 16ms frame
    Vector<double, 3> newPosition = position + newVelocity * 0.016;

    std::cout << "New velocity: " << newVelocity << std::endl;
    std::cout << "New position: " << newPosition << std::endl;

    // Dot product: the component of the force along the velocity (work calculation)
    double work = force.dot(velocity);
    std::cout << "Work done by the force along the velocity: " << work << std::endl;

    // Normalized direction vector
    auto direction = velocity.normalized();
    std::cout << "Unit vector of velocity direction: " << direction << std::endl;

    // Cross product: a vector perpendicular to two vectors (e.g. a normal vector)
    Vector<double, 3> up({0.0, 1.0, 0.0});
    auto right = cross(up, direction);
    std::cout << "Right vector: " << right << std::endl;

    // 4D color vector (RGBA)
    Vector<float, 4> color({0.2f, 0.5f, 0.8f, 1.0f});
    std::cout << "Color (RGBA): " << color << std::endl;

    // Specialization: bool vector (collision detection results)
    Vector<bool, 8> collisionFlags;
    collisionFlags[0] = true;   // collided with the ground
    collisionFlags[1] = false;  // did not collide with a wall
    collisionFlags[3] = true;   // collided with an enemy
    std::cout << "Collision flags: " << collisionFlags << std::endl;

    return 0;
}

Case 5: A Generic Factory Pattern -- A Plugin-Based Application Framework
---------------------------------------------------------------
Scenario: you are building a plugin-based application framework that needs to create different types of
plugin objects dynamically from a configuration file (e.g. filter plugins, output plugins, input plugins), managed uniformly with the factory pattern.

Concepts applied:
- Ch1 Namespaces: namespace PluginFramework {}
- Ch3 Dynamic memory: management with the unique_ptr smart pointer
- Ch4 Classes and objects: abstract base class + concrete subclasses
- Ch5 Inheritance: FilterPlugin, OutputPlugin and other derived classes
- Ch6 Polymorphism: virtual function interface
- Ch7 Operator overloading: streaming config reads with >>
- This chapter: variadic templates + perfect forwarding + template-metaprogramming type checks

---------------------------------------------------------------
#include <iostream>
#include <memory>
#include <string>
#include <map>
#include <functional>
#include <type_traits>
#include <vector>
#include <sstream>

namespace PluginFramework {

    // ===== Plugin base class hierarchy (Ch4, Ch5, Ch6) =====

    class Plugin {
    protected:
        std::string name;
        std::string version;
    public:
        Plugin(const std::string& n, const std::string& v)
            : name(n), version(v) {}
        virtual ~Plugin() = default;

        virtual void initialize() {
            std::cout << "[Plugin] " << name << " v" << version
                      << " initialized" << std::endl;
        }

        virtual void execute() = 0;  // pure virtual function

        virtual std::string typeName() const = 0;

        const std::string& getName() const { return name; }
        const std::string& getVersion() const { return version; }
    };

    // Filter plugin
    class FilterPlugin : public Plugin {
    private:
        std::string filterType;
    public:
        FilterPlugin(const std::string& n, const std::string& v,
                     const std::string& ftype)
            : Plugin(n, v), filterType(ftype) {}

        void execute() override {
            std::cout << "[Filter] Applying filter: " << filterType << std::endl;
        }

        std::string typeName() const override { return "Filter"; }
    };

    // Output plugin
    class OutputPlugin : public Plugin {
    private:
        std::string format;
    public:
        OutputPlugin(const std::string& n, const std::string& v,
                     const std::string& fmt)
            : Plugin(n, v), format(fmt) {}

        void execute() override {
            std::cout << "[Output] Output format: " << format << std::endl;
        }

        std::string typeName() const override { return "Output"; }
    };

    // Input plugin
    class InputPlugin : public Plugin {
    private:
        std::string sourceType;
    public:
        InputPlugin(const std::string& n, const std::string& v,
                    const std::string& src)
            : Plugin(n, v), sourceType(src) {}

        void execute() override {
            std::cout << "[Input] Data source: " << sourceType << std::endl;
        }

        std::string typeName() const override { return "Input"; }
    };

    // ===== Template metaprogramming: compile-time type checks (core of this chapter) =====

    // Check whether T derives from Plugin
    template<typename T>
    struct IsPlugin {
    private:
        // SFINAE: if T can be converted to Plugin*, this overload is chosen
        template<typename U>
        static auto test(int) -> decltype(
            static_cast<Plugin*>(std::declval<U*>()), std::true_type{}
        );
        // otherwise this one is chosen
        template<typename U>
        static std::false_type test(...);
    public:
        static constexpr bool value = decltype(test<T>(0))::value;
    };

    // In C++17 this can be simplified to:
    // template<typename T>
    // constexpr bool IsPlugin_v = std::is_base_of_v<Plugin, T>;

    // ===== Generic factory function (variadic template + perfect forwarding) =====

    template<typename T, typename... Args,
             typename = std::enable_if_t<IsPlugin<T>::value>>
    std::unique_ptr<T> create(Args&&... args) {
        // Perfectly forward the constructor arguments with std::forward
        auto plugin = std::make_unique<T>(std::forward<Args>(args)...);

        std::cout << "[Factory] Created plugin: " << plugin->getName()
                  << " (type: " << plugin->typeName() << ")"
                  << std::endl;
        return plugin;
    }

    // Overload: create and call initialize
    template<typename T, typename... Args,
             typename = std::enable_if_t<IsPlugin<T>::value>>
    std::unique_ptr<T> createAndInit(Args&&... args) {
        auto plugin = create<T>(std::forward<Args>(args)...);
        plugin->initialize();
        return plugin;
    }

    // ===== Plugin manager (applies Ch1 namespaces, Ch3 smart pointers) =====

    class PluginManager {
    private:
        std::map<std::string, std::unique_ptr<Plugin>> plugins;
        static int pluginCount;

    public:
        template<typename T, typename... Args>
        T* registerPlugin(Args&&... args) {
            auto plugin = createAndInit<T>(std::forward<Args>(args)...);
            std::string key = plugin->getName();
            T* rawPtr = plugin.get();
            plugins[key] = std::move(plugin);
            pluginCount++;
            return rawPtr;
        }

        void executeAll() {
            std::cout << "\n=== Executing all plugins ("
                      << plugins.size() << " total) ===" << std::endl;
            for(auto& pair : plugins) {
                pair.second->execute();
            }
        }

        Plugin* findPlugin(const std::string& name) {
            auto it = plugins.find(name);
            if(it != plugins.end())
                return it->second.get();
            return nullptr;
        }

        static int getCount() { return pluginCount; }
    };

    int PluginManager::pluginCount = 0;

} // namespace PluginFramework

int main() {
    using namespace PluginFramework;

    std::cout << "===== Plugin-Based Application Framework Demo =====" << std::endl;

    PluginManager manager;

    // Create and register plugins of different types
    auto* filter = manager.registerPlugin<FilterPlugin>(
        "Sharpen Filter", "1.0.0", "UnsharpMask"
    );
    auto* output = manager.registerPlugin<OutputPlugin>(
        "PNG Output", "2.1.0", "PNG"
    );
    auto* input = manager.registerPlugin<InputPlugin>(
        "Camera Input", "1.0.0", "USB Camera"
    );

    // Create a standalone plugin (not registered with the manager)
    auto standalone = create<FilterPlugin>("Test Filter", "0.0.1", "Test");
    standalone->initialize();
    standalone->execute();

    // Execute all registered plugins (polymorphic calls)
    manager.executeAll();

    // Find and execute a specific plugin
    Plugin* found = manager.findPlugin("PNG Output");
    if(found) {
        std::cout << "\nFound plugin: " << found->getName() << std::endl;
        found->execute();
    }

    // Template metaprogramming check: compile-time type checking
    static_assert(IsPlugin<FilterPlugin>::value,
                  "FilterPlugin must derive from Plugin");
    static_assert(IsPlugin<OutputPlugin>::value,
                  "OutputPlugin must derive from Plugin");

    // The following code would cause a compile error (blocked by static_assert):
    // static_assert(IsPlugin<std::string>::value,
    //               "std::string does not derive from Plugin");

    std::cout << "\nTotal plugins: " << PluginManager::getCount() << std::endl;

    // Demonstrate perfect forwarding: passing an rvalue
    std::string tempName = "Temporary Plugin";
    auto temp = create<FilterPlugin>(std::move(tempName), "0.0.1", "Temp");

    return 0;
}

[Chapter Overview]
Exception handling is the core mechanism for building robust software in C++. Unlike
other languages, C++ exception handling is tightly bound to RAII (Resource Acquisition
Is Initialization), which guarantees that resources are released correctly when an
exception occurs. This chapter starts from the low-level implementation principles,
covers the syntax and best practices of exception handling comprehensively, and ties
everything together with the knowledge from the previous eight chapters through
five comprehensive case studies.

================================================================================
### Section 1: Basic Example Code + Low-Level Computer Principles
================================================================================

I. Basic Syntax: try / catch / throw

The core flow of exception handling: throw raises an exception, the function call chain
is walked back level by level until a matching catch block is found.

---------------------------------------------------------------
// ---- Basic example: a safe division function ----
#include <iostream>
#include <stdexcept>

double safeDivide(double a, double b) {
    if (b == 0.0) {
        throw std::runtime_error("Divisor cannot be zero!");
    }
    return a / b;
}

// Call chain example
void calculate() {
    try {
        double result = safeDivide(10.0, 0.0);
        std::cout << "Result: " << result << std::endl;
    }
    catch (const std::runtime_error& e) {
        std::cerr << "Runtime error: " << e.what() << std::endl;
    }
    catch (const std::exception& e) {   // catch the base class
        std::cerr << "Standard exception: " << e.what() << std::endl;
    }
    catch (...) {                       // catch everything
        std::cerr << "Unknown exception" << std::endl;
    }
}

int main() {
    std::cout << "Program started" << std::endl;
    calculate();
    std::cout << "Program continues (exception handled properly)" << std::endl;
    return 0;
}

II. Low-Level Implementation of Exception Handling

1. The Stack Unwinding Mechanism in Detail

   When a throw statement executes, the runtime system performs the following steps:

   Step 1: Look for a catch block in the current function's stack frame.
           If a matching type is found, jump there and execute it.
           If not, destroy all local objects in the current stack frame
           (calling their destructors), then return to the caller.

   Step 2: Repeat Step 1 in the caller's stack frame.
           This process walks up the call chain and is called "stack unwinding".

   Step 3: If it reaches main() and still finds no matching catch,
           std::terminate() is called to terminate the program.

   Diagram of the stack unwinding process:

   main()
     └─> functionA()
           └─> functionB()
                 └─> functionC()
                        throw exception! ★
                     (destroy functionC's local objects)
                   ──────── upward ────────>
                 (destroy functionB's local objects)
               ──────── upward ────────>
             (matching catch found in functionA)
             execute the catch block

   Key property: during stack unwinding, the destructors of all successfully
   constructed local objects are called. This is the foundation of how RAII works:
   when an exception occurs, RAII objects such as smart pointers, file streams,
   and mutex locks release their resources automatically.

2. The Exception Table

   At compile time the compiler generates an exception table, stored in the
   read-only data section of the object file (the .eh_frame section in ELF format).

   The exception table contains the following information:
   - The code regions in each function that may throw exceptions
   - The address of the catch block(s) for each try block
   - The addresses of local objects' destructors needed during stack unwinding

   When an exception is thrown, the runtime system consults the exception table to determine:
   - Whether the current execution point is inside a try block
   - Whether there is a matching catch block
   - Which destructors must be called for cleanup

3. The Zero-Cost Exception Model of the Itanium C++ ABI

   Mainstream compilers (GCC, Clang) use the "zero-cost exception model"
   (Zero-Cost Exception Handling) defined by the Itanium C++ ABI:

   Core idea: the normal execution path is completely unaffected by exception handling.

   - Normal path (no exception thrown): code runs with no extra overhead at all.
     No extra runtime records are maintained, and no extra condition checks are performed.

   - Exceptional path (exception thrown): the cost is high.
     The runtime must traverse the exception table (possibly hundreds of KB), do type
     matching, and call many destructors. This is acceptable, because exceptions are
     supposed to be "exceptional situations".

   Implementation details:
   - Uses LSDA (Language-Specific Data Area) tables
   - When an exception is thrown, the stack is walked back using DWARF debug information
   - Two-phase search: first search the current function, then the callers

4. The Deep Relationship Between RAII and Exception Safety

   C++ has no finally clause like Java/C#, because under the RAII model it is not needed.
   Any cleanup that must run when leaving a scope belongs in a destructor.

   Compare the two styles:

   // ---- Java/C# style (using finally) ----
   // C++ has no finally, so this style is not used
   // try { acquire resource } catch { handle exception } finally { release resource }

   // ---- C++ RAII style (recommended) ----
   // {
   //     std::ifstream file("data.txt");   // acquire the resource on construction
   //     // ... use the file ...
   // }  // destroyed automatically on leaving the scope, releasing the resource (even if an exception occurs)

   Benefits of RAII:
   - Cleaner code (no explicit cleanup code needed)
   - Exception safety is guaranteed automatically (destructors are called during stack unwinding)
   - Cleanup is never forgotten (people always forget to write finally)

5. Quantitative Analysis of Exception Handling Performance Overhead

   ┌───────────────────────┬───────────────┬──────────────────┐
   │ Scenario              │ Normal path   │ Exception path   │
   ├───────────────────────┼───────────────┼──────────────────┤
   │ No exception code     │ Baseline 100% │ N/A              │
   │ try without throw     │ ~100%         │ N/A              │
   │ Same-function throw   │ ~100%         │ 10x ~ 100x       │
   │ throw across 5 levels │ ~100%         │ 50x ~ 500x       │
   │ throw across 10 levels│ ~100%         │ 100x ~ 1000x     │
   └───────────────────────┴───────────────┴──────────────────┘

   Note: the overhead comes mainly from calling many destructors during stack
   unwinding and from exception-table lookups, not from the throw/catch statements themselves.

6. Exception Mechanism Compared with Virtual Functions

   ┌─────────────────────┬──────────────────────────────────────────┐
   │ Property            │ Exception handling                       │
   ├─────────────────────┼──────────────────────────────────────────┤
   │ Control flow        │ Non-local jump across many stack frames  │
   │ Type matching       │ Runtime type matching (RTTI), like vfuncs│
   │ Performance impact  │ Zero cost on normal path, cost on throw  │
   │ Code structure      │ Error handling separated from main logic │
   │ Unsuitable for      │ Perf-critical inner loops, hard real-time│
   └─────────────────────┴──────────────────────────────────────────┘

I. The throw Expression

throw can throw an object of any type (throwing classes derived from std::exception is recommended):

---------------------------------------------------------------
#include <iostream>
#include <string>
#include <stdexcept>

// Throwing a fundamental type (not recommended)
void throwInt() {
    throw 42;           // allowed, but not recommended
}

// Throwing a string (not recommended)
void throwCString() {
    throw "Error";      // allowed, but carries limited information
}

// Throwing a standard exception (recommended)
void throwStandard() {
    throw std::runtime_error("Standard runtime error");
}

// Constructing the exception object at the throw site
void throwConstructed() {
    throw std::invalid_argument(std::string("Invalid argument: ") + "value out of bounds");
}

// Rethrowing with throw; (no operand, preserves the original type and context)
void rethrowDemo() {
    try {
        throw std::logic_error("Original error");
    }
    catch (const std::exception& e) {
        std::cout << "Caught: " << e.what() << std::endl;
        std::cout << "Logging, then rethrowing..." << std::endl;
        throw;  // rethrow the original exception (preserves type and stack)
    }
}

int main() {
    try { throwInt(); }
    catch (int e) {
        std::cout << "Caught integer: " << e << std::endl;
    }

    try { throwCString(); }
    catch (const char* msg) {
        std::cout << "Caught string: " << msg << std::endl;
    }

    try { throwStandard(); }
    catch (const std::exception& e) {
        std::cout << "Caught standard exception: " << e.what() << std::endl;
    }

    try { throwConstructed(); }
    catch (const std::exception& e) {
        std::cout << "Caught constructed exception: " << e.what() << std::endl;
    }

    try { rethrowDemo(); }
    catch (const std::logic_error& e) {
        std::cout << "Finally caught (original type preserved): " << e.what() << std::endl;
    }

    return 0;
}

II. try Blocks and catch Blocks

Type matching rules for catch:

---------------------------------------------------------------
#include <iostream>
#include <stdexcept>

class MyException : public std::runtime_error {
public:
    explicit MyException(const std::string& msg)
        : std::runtime_error(msg) {}
};

class SpecialException : public MyException {
public:
    explicit SpecialException(const std::string& msg)
        : MyException(msg) {}
};

void demonstrateCatch() {
    // Rule 1: exact match
    try {
        throw 42;
    }
    catch (int e) {      // exact match on int
        std::cout << "Exact match: " << e << std::endl;
    }

    // Rule 2: a derived class matches its base class
    try {
        throw SpecialException("Special error");
    }
    catch (const MyException& e) {    // catch the derived class through a base-class reference
        std::cout << "Base class caught derived: " << e.what() << std::endl;
    }
    // Note: if catch(MyException) is placed before catch(SpecialException),
    // SpecialException will never be caught by its own handler (the base class catches it first)

    // Rule 3: correct catch order (derived first, then base)
    try {
        throw SpecialException("Special exception");
    }
    catch (const SpecialException& e) {  // match the derived class first
        std::cout << "Caught SpecialException: " << e.what() << std::endl;
    }
    catch (const MyException& e) {       // then the base class
        std::cout << "Caught MyException: " << e.what() << std::endl;
    }
    catch (const std::exception& e) {    // finally the standard base class
        std::cout << "Caught std::exception: " << e.what() << std::endl;
    }

    // Rule 4: catch(...) catches everything
    try {
        throw 3.14159;
    }
    catch (...) {
        std::cout << "catch(...) caught an exception of any type" << std::endl;
        // inside catch(...) you can rethrow with throw; to recover the concrete type
    }
}

int main() {
    demonstrateCatch();
    return 0;
}

III. The Standard Exception Class Hierarchy

The exception hierarchy defined by the C++ standard library is as follows:

std::exception
├─ std::logic_error        (program logic errors)
│   ├─ std::domain_error       (mathematical domain error)
│   ├─ std::invalid_argument   (invalid argument)
│   ├─ std::length_error       (length error)
│   └─ std::out_of_range       (out-of-range access)
│
├─ std::runtime_error      (runtime errors)
│   ├─ std::range_error        (range error)
│   ├─ std::overflow_error     (overflow error)
│   └─ std::underflow_error    (underflow error)
│
├─ std::bad_alloc          (new failed)
├─ std::bad_cast           (dynamic_cast on a reference failed)
├─ std::bad_typeid         (typeid applied to a null pointer)
├─ std::bad_exception      (exception specification violated)
└─ std::bad_function_call  (calling an empty std::function)

---------------------------------------------------------------
#include <iostream>
#include <stdexcept>
#include <new>
#include <typeinfo>

void demonstrateStandardExceptions() {
    // logic_error family
    try {
        throw std::invalid_argument("Age cannot be negative");
    } catch (const std::logic_error& e) {
        std::cout << "logic_error: " << e.what() << std::endl;
    }

    try {
        throw std::out_of_range("Array index 10 is out of range");
    } catch (const std::out_of_range& e) {
        std::cout << "out_of_range: " << e.what() << std::endl;
    }

    // runtime_error family
    try {
        throw std::overflow_error("Computation result overflowed");
    } catch (const std::runtime_error& e) {
        std::cout << "runtime_error: " << e.what() << std::endl;
    }

    // bad_alloc: dynamic memory allocation failed
    try {
        // deliberately request a huge amount of memory to trigger bad_alloc
        int* huge = new int[10000000000ULL];  // may fail
        delete[] huge;
    } catch (const std::bad_alloc& e) {
        std::cout << "bad_alloc: " << e.what() << std::endl;
    }

    // bad_cast: dynamic_cast failed
    class Base { public: virtual ~Base() {} };
    class Derived : public Base {};
    try {
        Base b;
        // dynamic_cast throws bad_cast when a reference conversion fails
        Derived& d = dynamic_cast<Derived&>(b);
        (void)d;
    } catch (const std::bad_cast& e) {
        std::cout << "bad_cast: " << e.what() << std::endl;
    }
}

int main() {
    demonstrateStandardExceptions();
    return 0;
}

IV. Custom Exception Classes

Inherit from std::exception or one of its subclasses and override what():

---------------------------------------------------------------
#include <iostream>
#include <string>
#include <exception>
#include <stdexcept>
#include <sstream>

// Basic custom exception
class DatabaseException : public std::runtime_error {
private:
    int errorCode;
    std::string sqlStatement;

public:
    DatabaseException(int code, const std::string& msg,
                      const std::string& sql = "")
        : std::runtime_error(msg), errorCode(code), sqlStatement(sql) {}

    // Override what() to provide more detailed information
    const char* what() const noexcept override {
        // Note: the string returned by what() must remain valid for the object's lifetime
        // In the simple case, just return the base class's what()
        return std::runtime_error::what();
    }

    int getErrorCode() const { return errorCode; }
    const std::string& getSQL() const { return sqlStatement; }

    // Provide a complete error description
    std::string fullDescription() const {
        std::ostringstream oss;
        oss << "Database error [" << errorCode << "]: "
            << what();
        if(!sqlStatement.empty())
            oss << " (SQL: " << sqlStatement << ")";
        return oss.str();
    }
};

// More specific exceptions derived from the custom exception
class ConnectionException : public DatabaseException {
public:
    ConnectionException(const std::string& msg)
        : DatabaseException(1001, msg, "") {}
};

class QueryException : public DatabaseException {
public:
    QueryException(const std::string& msg, const std::string& sql)
        : DatabaseException(1002, msg, sql) {}
};

int main() {
    try {
        throw QueryException("Syntax error", "SELECT * FORM users");
    }
    catch (const QueryException& e) {
        std::cout << e.fullDescription() << std::endl;
    }
    catch (const ConnectionException& e) {
        std::cout << e.fullDescription() << std::endl;
    }
    catch (const DatabaseException& e) {
        std::cout << e.fullDescription() << std::endl;
    }
    return 0;
}

V. The noexcept Specifier and Operator (C++11)

noexcept declares that a function does not throw exceptions; the compiler can optimize based on this:

---------------------------------------------------------------
#include <iostream>
#include <vector>
#include <type_traits>

// noexcept specifier: declares that the function does not throw
void noThrowFunc() noexcept {
    std::cout << "This function is guaranteed not to throw" << std::endl;
}

int simpleAdd(int a, int b) noexcept {
    return a + b;
}

// Conditional noexcept: does not throw only if T's move operations do not throw
template<typename T>
void swapIfNoexcept(T& a, T& b) noexcept(
    std::is_nothrow_move_constructible<T>::value &&
    std::is_nothrow_move_assignable<T>::value
) {
    T tmp = std::move(a);
    a = std::move(b);
    b = std::move(tmp);
}

// noexcept operator: checks at compile time whether an expression may throw
void mightThrow() {}                    // may throw
void neverThrow() noexcept {}           // does not throw

int main() {
    std::cout << std::boolalpha;

    // noexcept operator checks
    std::cout << "noThrowFunc noexcept: "
              << noexcept(noThrowFunc()) << std::endl;       // true
    std::cout << "simpleAdd noexcept: "
              << noexcept(simpleAdd(1, 2)) << std::endl;     // true
    std::cout << "mightThrow noexcept: "
              << noexcept(mightThrow()) << std::endl;        // false
    std::cout << "neverThrow noexcept: "
              << noexcept(neverThrow()) << std::endl;        // true
    std::cout << "1+2 noexcept: "
              << noexcept(1 + 2) << std::endl;               // true

    // Move constructors are usually marked noexcept (improves vector reallocation performance)
    std::cout << "vector<int> move noexcept: "
              << std::is_nothrow_move_constructible<
                     std::vector<int>>::value << std::endl;  // true

    return 0;
}

VI. Function try Blocks (Constructor try Blocks)

Use try-catch in a constructor to intercept exceptions from the initializer list:

---------------------------------------------------------------
#include <iostream>
#include <string>
#include <stdexcept>

class Database {
private:
    std::string connectionString;
    int maxConnections;
    int* connectionPool;

    void validateConnectionString(const std::string& s) {
        if(s.empty())
            throw std::invalid_argument("Connection string cannot be empty");
    }

    void allocatePool(int size) {
        if(size <= 0)
            throw std::invalid_argument("Connection pool size must be positive");
        connectionPool = new int[size];
    }

public:
    // Constructor try block: catches exceptions from the initializer list
    Database(const std::string& connStr, int maxConn)
    try :
        connectionString(connStr),
        maxConnections(maxConn),
        connectionPool(nullptr)
    {
        validateConnectionString(connectionString);
        allocatePool(maxConnections);
        std::cout << "Database initialized successfully" << std::endl;
    }
    catch (const std::exception& e) {
        std::cerr << "Database construction failed: " << e.what() << std::endl;
        // Note: in a constructor try block, the exception is automatically rethrown,
        // so even though it is caught, construction of the object still fails
        // No explicit delete of connectionPool is needed (it is still nullptr when initialization fails)
    }

    ~Database() {
        std::cout << "Database destroyed" << std::endl;
        delete[] connectionPool;
    }
};

// try block for an ordinary function
void processFile(const std::string& filename)
try {
    // ... file processing code ...
    if(filename.empty())
        throw std::runtime_error("File name cannot be empty");
    std::cout << "Processing file: " << filename << std::endl;
}
catch (const std::exception& e) {
    std::cerr << "File processing failed: " << e.what() << std::endl;
}

int main() {
    // Test the constructor try block
    try {
        Database db("", -1);  // will trigger an exception
    }
    catch (...) {
        std::cout << "Failed to construct Database object" << std::endl;
    }

    // Successful construction
    try {
        Database db("mysql://localhost", 10);
    }
    catch (...) {
        std::cout << "Should not get here" << std::endl;
    }

    // Ordinary function try block
    processFile("");

    return 0;
}

VII. Exception Safety Guarantee Levels

The three levels of exception safety guarantee:

---------------------------------------------------------------
#include <iostream>
#include <vector>
#include <string>
#include <memory>
#include <stdexcept>

// ========== 1. Basic Guarantee ==========
// After an exception, the object is still in a valid (destructible) state, but its contents may have changed

class BasicGuaranteeStack {
private:
    std::vector<int> data;
public:
    void push(int val) {
        data.push_back(val);  // if push_back throws, data is unchanged
    }

    int pop() {
        if(data.empty()) throw std::runtime_error("Empty stack");
        int val = data.back();
        data.pop_back();  // pop_back does not throw
        return val;
    }
};

// ========== 2. Strong Guarantee ==========
// After an exception, the object's state rolls back to its pre-operation state (either full success or no change at all)

class StrongGuaranteeAccount {
private:
    double balance;
    std::string name;

public:
    StrongGuaranteeAccount(const std::string& n, double b)
        : name(n), balance(b) {}

    // transfer function with the strong exception safety guarantee
    void transfer(StrongGuaranteeAccount& to, double amount) {
        // First check all preconditions (without modifying any state)
        if(amount <= 0)
            throw std::invalid_argument("Transfer amount must be positive");
        if(this == &to)
            throw std::invalid_argument("Cannot transfer to yourself");
        if(balance < amount)
            throw std::runtime_error("Insufficient balance");

        // copy-and-swap idiom: copy first, modify the copy, swap in on success
        StrongGuaranteeAccount temp(*this);  // copy
        temp.balance -= amount;

        try {
            to.balance += amount;  // might throw (though it won't here)
        }
        catch(...) {
            // to's balance has changed and would need restoring (but there's no simple way here)
            // a better approach is to use a temporary object
            throw;
        }

        // If everything above succeeded, update the state
        balance = temp.balance;
    }

    double getBalance() const { return balance; }
};

// ========== 3. No-throw Guarantee ==========
// The function promises never to throw an exception

class NoThrowStack {
private:
    int* data;
    int capacity;
    int top;

public:
    NoThrowStack(int cap = 100) : capacity(cap), top(-1) {
        data = new int[capacity];
    }

    ~NoThrowStack() noexcept { delete[] data; }  // destructors are noexcept by default

    void push(int val) noexcept {
        if(top < capacity - 1)
            data[++top] = val;
        // when the stack is full, don't throw, just ignore (not a good design, demo only)
    }

    int pop() noexcept {
        if(top >= 0) return data[top--];
        return -1;  // return -1 on empty stack instead of throwing
    }

    int size() const noexcept { return top + 1; }

    // Declaring noexcept allows the compiler to optimize better
};

int main() {
    std::cout << "===== Exception Safety Guarantee Levels Demo =====" << std::endl;

    // Basic guarantee
    BasicGuaranteeStack basicStack;
    try {
        basicStack.push(42);
        basicStack.push(100);
        std::cout << "Basic-guarantee stack operations completed" << std::endl;
    } catch(...) {
        std::cout << "Basic guarantee: stack is still destructible" << std::endl;
    }

    // Strong guarantee
    StrongGuaranteeAccount alice("Alice", 1000);
    StrongGuaranteeAccount bob("Bob", 500);

    try {
        alice.transfer(bob, 200);
        std::cout << "Transfer succeeded Alice: " << alice.getBalance()
                  << " Bob: " << bob.getBalance() << std::endl;
    } catch(const std::exception& e) {
        std::cout << "Transfer rolled back: " << e.what() << std::endl;
    }

    // No-throw guarantee
    NoThrowStack noThrowStack(10);
    noThrowStack.push(1);
    noThrowStack.push(2);
    noThrowStack.push(3);
    std::cout << "No-throw stack size: " << noThrowStack.size() << std::endl;

    return 0;
}

VIII. Summary of Exception Handling Best Practices

┌──────────────────────────────────────────────────────────────┐
│ 1. Catch by reference: catch(const std::exception& e) {...}  │
│ 2. Order catch blocks from most derived to base class        │
│ 3. Throw exceptions rather than returning error codes (C++)  │
│ 4. Manage resources with RAII, don't rely on manual cleanup  │
│ 5. Destructors should not throw (noexcept by default)        │
│ 6. Mark functions that don't throw as noexcept               │
│ 7. Derive custom exceptions from std::exception              │
│ 8. Don't throw a new exception in catch and lose the original│
│ 9. Rethrow with throw; (no operand) to keep original info    │
│ 10. Avoid exceptions on performance-critical paths (the      │
│     normal path is free, but code bloat may hurt I-cache)    │
└──────────────────────────────────────────────────────────────┘

Case 1: Exception-Safe Bank Deposit System -- ATM Withdrawal Error Messages
---------------------------------------------------------------
Scenario: a bank ATM withdrawal system that must handle exceptions such as
insufficient funds, invalid amounts, and frozen accounts.

Knowledge integrated:
- Ch4 Classes and Objects: the BankAccount class
- Ch6 Polymorphism: SavingAccount / CheckingAccount
- Ch7 Operator Overloading: << for printing account info

---------------------------------------------------------------
#include <iostream>
#include <string>
#include <stdexcept>
#include <vector>
#include <memory>

// ===== Custom exception hierarchy =====

class BankingException : public std::runtime_error {
protected:
    std::string accountNumber;
public:
    BankingException(const std::string& acct, const std::string& msg)
        : std::runtime_error(msg), accountNumber(acct) {}
    const std::string& getAccount() const { return accountNumber; }
};

class InsufficientFundsException : public BankingException {
private:
    double requested;
    double available;
public:
    InsufficientFundsException(const std::string& acct,
                                double req, double avail)
        : BankingException(acct, "Insufficient funds"), requested(req), available(avail) {}

    double getRequested() const { return requested; }
    double getAvailable() const { return available; }

    std::string detail() const {
        return std::string("Account ") + getAccount()
               + " has insufficient funds: requested $" + std::to_string(requested)
               + " > available $" + std::to_string(available);
    }
};

class AccountFrozenException : public BankingException {
public:
    AccountFrozenException(const std::string& acct)
        : BankingException(acct, "Account is frozen") {}
};

class InvalidAmountException : public BankingException {
public:
    InvalidAmountException(const std::string& acct)
        : BankingException(acct, "Invalid amount") {}
};

// ===== Bank account class hierarchy =====

class BankAccount {
protected:
    std::string accountNumber;
    std::string ownerName;
    double balance;
    bool frozen;

public:
    BankAccount(const std::string& num, const std::string& owner,
                double initial = 0.0)
        : accountNumber(num), ownerName(owner), balance(initial),
          frozen(false) {}

    virtual ~BankAccount() = default;

    virtual void deposit(double amount) {
        if(frozen) throw AccountFrozenException(accountNumber);
        if(amount <= 0) throw InvalidAmountException(accountNumber);
        balance += amount;
        std::cout << "[" << accountNumber << "] Deposit $" << amount
                  << " | Balance: $" << balance << std::endl;
    }

    virtual void withdraw(double amount) {
        if(frozen) throw AccountFrozenException(accountNumber);
        if(amount <= 0) throw InvalidAmountException(accountNumber);
        if(amount > balance)
            throw InsufficientFundsException(accountNumber, amount, balance);
        balance -= amount;
        std::cout << "[" << accountNumber << "] Withdraw $" << amount
                  << " | Balance: $" << balance << std::endl;
    }

    // Transfer with the strong exception safety guarantee
    virtual void transfer(BankAccount& target, double amount) {
        // First check all preconditions (without modifying state)
        if(this == &target)
            throw BankingException(accountNumber, "Cannot transfer to the same account");
        if(frozen) throw AccountFrozenException(accountNumber);
        if(target.isFrozen())
            throw AccountFrozenException(target.getAccountNumber());
        if(amount <= 0) throw InvalidAmountException(accountNumber);

        // Two operations: if the second fails, the debit cannot be undone on its own,
        // so we use a "debit first, then credit; roll back if the credit fails" strategy
        double originalBalance = balance;

        try {
            withdraw(amount);  // debit first
        } catch(...) {
            throw;  // debit failed, no rollback needed
        }

        try {
            target.deposit(amount);  // then credit
        } catch(...) {
            // credit failed, roll back the debit
            balance = originalBalance;
            throw;  // still notify the caller that the transfer failed
        }
    }

    virtual std::string getType() const { return "Regular account"; }
    double getBalance() const { return balance; }
    const std::string& getAccountNumber() const { return accountNumber; }
    bool isFrozen() const { return frozen; }
    void freeze() { frozen = true; }
    void unfreeze() { frozen = false; }

    friend std::ostream& operator<<(std::ostream& os,
                                     const BankAccount& acct) {
        os << acct.getType() << " " << acct.accountNumber
           << " [" << acct.ownerName << "] $"
           << acct.balance << (acct.frozen ? " (frozen)" : "");
        return os;
    }
};

private:

public:
    SavingAccount(const std::string& num, const std::string& owner,
                  double initial = 0.0, double rate = 0.02)
        : BankAccount(num, owner, initial), interestRate(rate) {}

        double interest = balance * interestRate;
        std::cout << "[" << accountNumber << "] Interest: $"
                  << interest << std::endl;
        balance += interest;
    }

                    double initial = 0.0, double overdraft = 500.0)

        if(amount <= 0) throw InvalidAmountException(accountNumber);
        if(amount > balance + overdraftLimit)
            throw InsufficientFundsException(accountNumber,
                                              amount, balance + overdraftLimit);

        std::cout << "[" << accountNumber << "] Withdraw $" << amount

---------------------------------------------------------------
#include <iostream>
#include <string>
#include <vector>
#include <fstream>
#include <sstream>
#include <stdexcept>
#include <memory>
#include <regex>

// ===== Custom parse exception =====

class ParseException : public std::runtime_error {
private:
    int lineNumber;
    std::string rawLine;
public:
    ParseException(int line, const std::string& raw,
                   const std::string& msg)
        : std::runtime_error(msg), lineNumber(line), rawLine(raw) {}

    int getLineNumber() const { return lineNumber; }
    const std::string& getRawLine() const { return rawLine; }

    std::string fullReport() const {
        std::ostringstream oss;
        oss << "Failed to parse line " << lineNumber << ": "
            << what() << "\nRaw content: " << rawLine;
        return oss.str();
    }
};

// ===== User data =====

struct UserData {
    int id;
    std::string name;
    std::string email;
    int age;

    friend std::ostream& operator<<(std::ostream& os,
                                     const UserData& u) {
        os << "User{" << u.id << ", " << u.name
           << ", " << u.email << ", " << u.age << "}";
        return os;
    }
};

// ===== CSV parser =====

class CSVParser {
public:
    // Parse (trim) a single field
    static std::string trim(const std::string& s) {
        size_t start = s.find_first_not_of(" \t\r\n");
        if(start == std::string::npos) return "";
        size_t end = s.find_last_not_of(" \t\r\n");
        return s.substr(start, end - start + 1);
    }

    // Split one CSV line
    static std::vector<std::string> splitCSV(const std::string& line) {
        std::vector<std::string> result;
        std::stringstream ss(line);
        std::string field;

        while(std::getline(ss, field, ',')) {
            result.push_back(trim(field));
        }
        return result;
    }

    // Parse a single user record (with line number information)
    static UserData parseLine(const std::string& line, int lineNum) {
        auto fields = splitCSV(line);

        if(fields.size() < 4) {
            throw ParseException(lineNum, line,
                "Not enough fields (need 4: ID,name,email,age), only got "
                + std::to_string(fields.size()));
        }

        UserData user;

        try {
            user.id = std::stoi(fields[0]);
        } catch(const std::exception&) {
            throw ParseException(lineNum, line,
                "Invalid ID: '" + fields[0] + "'");
        }

        user.name = fields[1];
        if(user.name.empty()) {
            throw ParseException(lineNum, line, "Name cannot be empty");
        }

        user.email = fields[2];
        if(user.email.find('@') == std::string::npos) {
            throw ParseException(lineNum, line,
                "Invalid email format: '" + user.email + "'");
        }

        try {
            user.age = std::stoi(fields[3]);
        } catch(const std::exception&) {
            throw ParseException(lineNum, line,
                "Invalid age: '" + fields[3] + "'");
        }

        if(user.age < 0 || user.age > 150) {
            throw ParseException(lineNum, line,
                "Age out of reasonable range (0-150): " + std::to_string(user.age));
        }

        return user;
    }

    // Parse the whole file and return the user list (managed by a smart pointer)
    static std::unique_ptr<std::vector<UserData>> parseFile(
        const std::string& filename)
    {
        std::ifstream file(filename);
        if(!file.is_open()) {
            throw std::runtime_error("Cannot open file: " + filename);
        }

        auto users = std::make_unique<std::vector<UserData>>();

        std::string line;
        int lineNum = 0;
        int errorCount = 0;

        // Skip the header line
        if(std::getline(file, line)) {
            lineNum++;
            // Optional: validate the header line
        }

        while(std::getline(file, line)) {
            lineNum++;
            if(line.empty()) continue;  // skip empty lines

            try {
                auto user = parseLine(line, lineNum);
                users->push_back(user);
            }
            catch(const ParseException& e) {
                std::cerr << e.fullReport() << std::endl;
                errorCount++;
                // keep parsing the next line instead of aborting the whole import
            }
        }

        file.close();

        if(errorCount > 0) {
            std::cerr << "Warning: skipped " << errorCount
                      << " invalid record(s) in total" << std::endl;
        }

        return users;
    }
};

// Helper function: create a test CSV file

    file << "1,Zhang San,zhang@example.com,25\n";

Case 3: Network Request Framework -- Calling a Weather API
---------------------------------------------------------------
Scenario: developing a weather lookup service that calls a third-party API.
Network requests may fail because of timeouts, connection failures, malformed responses, and so on.

Knowledge integrated:
- Ch1 Namespaces: namespace NetworkLib {}
- Ch8 Templates: a template function that wraps requests

---------------------------------------------------------------
#include <iostream>
#include <string>
#include <stdexcept>
#include <sstream>
#include <map>
#include <chrono>
#include <thread>

namespace NetworkLib {

    // ===== Exception inheritance hierarchy =====

    class NetworkException : public std::runtime_error {
    private:
        int httpStatusCode;
    public:
        NetworkException(const std::string& msg, int code = 0)
            : std::runtime_error(msg), httpStatusCode(code) {}

        int getStatusCode() const { return httpStatusCode; }
    };

    class TimeoutException : public NetworkException {
    private:
        int timeoutMs;
    public:
        TimeoutException(int ms, const std::string& url)
            : NetworkException("Request timed out after " + std::to_string(ms) + "ms: " + url),
              timeoutMs(ms) {}

        int getTimeoutMs() const { return timeoutMs; }
    };

    class ConnectionException : public NetworkException {
    public:
        ConnectionException(const std::string& host, int port)
            : NetworkException("Cannot connect to " + host + ":"
                                + std::to_string(port)) {}
    };

    class FormatException : public NetworkException {
    public:
        explicit FormatException(const std::string& detail)
            : NetworkException("Malformed response: " + detail) {}
    };

    // ===== Simulated HTTP response =====

    struct HttpResponse {
        int statusCode;
        std::map<std::string, std::string> headers;
        std::string body;
    };

    // ===== Weather data =====

    struct WeatherData {
        std::string city;
        double temperature;
        double humidity;
        std::string condition;

        friend std::ostream& operator<<(std::ostream& os,
                                         const WeatherData& w) {
            os << "City: " << w.city << "\n"
               << "  Temperature: " << w.temperature << "°C\n"
               << "  Humidity: " << w.humidity << "%\n"
               << "  Condition: " << w.condition;
            return os;
        }
    };

    // ===== HTTP client (simulated) =====

    class HttpClient {
    public:
        // Simulated GET request (in practice use curl or sockets)
        HttpResponse get(const std::string& url,
                         int timeoutMs = 5000) {
            std::cout << "[HTTP] GET " << url << " (timeout: "
                      << timeoutMs << "ms)" << std::endl;

            // Simulation: check whether the URL is empty
            if(url.empty()) {
                throw ConnectionException("localhost", 80);
            }

            // Simulate a timeout
            if(url.find("timeout") != std::string::npos) {
                throw TimeoutException(timeoutMs, url);
            }

            // Simulate a connection failure
            if(url.find("badhost") != std::string::npos) {
                throw ConnectionException("badhost", 8080);
            }

            // Simulate a normal response
            HttpResponse resp;
            resp.statusCode = 200;
            resp.headers["Content-Type"] = "application/json";
            resp.body = R"({"city":"Beijing","temperature":22.5,"humidity":65,"condition":"Sunny"})";
            return resp;
        }

        void close() noexcept {
            std::cout << "[HTTP] Connection closed" << std::endl;
        }
    };

    // ===== Weather API client =====

    class WeatherAPIClient {
    private:
        HttpClient httpClient;
        std::string apiKey;
        std::string baseUrl;

        // Parse the JSON response (simplified)
        WeatherData parseWeatherResponse(const std::string& json,
                                          const std::string& city)
        {
            WeatherData data;
            data.city = city;

            // Simple string parsing (in practice use a JSON library)
            auto findValue = [&json](const std::string& key) -> std::string {
                auto keyPos = json.find("\"" + key + "\"");
                if(keyPos == std::string::npos)
                    throw FormatException("Missing field: " + key);

                auto colonPos = json.find(':', keyPos);
                auto startPos = json.find_first_not_of(" \t:", colonPos);
                auto endPos = json.find_first_of(",}", startPos);
                return json.substr(startPos, endPos - startPos);
            };

            try {
                std::string tempStr = findValue("temperature");
                data.temperature = std::stod(tempStr);

                std::string humStr = findValue("humidity");
                data.humidity = std::stod(humStr);

                std::string cond = findValue("condition");
                // Strip quotes
                cond.erase(std::remove(cond.begin(), cond.end(), '"'),
                          cond.end());
                data.condition = cond;
            }
            catch(const std::invalid_argument& e) {
                throw FormatException(std::string("Numeric parsing failed: ")
                                       + e.what());
            }

            return data;
        }

    public:
        WeatherAPIClient(const std::string& key,
                         const std::string& url = "https://weather.api")
            : apiKey(key), baseUrl(url) {}

        // Get the weather (no-throw version -- an empty optional would indicate failure)
        WeatherData getWeather(const std::string& city,
                               int timeoutMs = 5000)
        {
            std::string url = baseUrl + "/weather?city="
                              + city + "&key=" + apiKey;

            HttpResponse response = httpClient.get(url, timeoutMs);

            if(response.statusCode != 200) {
                throw NetworkException(
                    "HTTP error code: " + std::to_string(response.statusCode),
                    response.statusCode
                );
            }

            return parseWeatherResponse(response.body, city);
        }

        void disconnect() noexcept {
            try {
                httpClient.close();
            } catch(...) {
                // ignore exceptions on close (the work is already done)
            }
        }
    };

    // ===== Request template function with retries (Ch8 Templates) =====

    template<typename Func, typename... Args>
    auto retryRequest(int maxRetries, Func&& func, Args&&... args)
        -> decltype(func(args...))
    {
        NetworkException lastException("No request made");

        for(int attempt = 1; attempt <= maxRetries; ++attempt) {
            try {
                return func(std::forward<Args>(args)...);
            }
            catch(const TimeoutException& e) {
                lastException = NetworkException(e.what());
                std::cerr << "Attempt " << attempt << " timed out, "
                          << (attempt < maxRetries ? "retrying..." : "all attempts failed")
                          << std::endl;
                std::this_thread::sleep_for(
                    std::chrono::milliseconds(100 * attempt));
            }
            catch(const ConnectionException& e) {
                lastException = NetworkException(e.what());
                std::cerr << "Attempt " << attempt << " failed to connect, "
                          << (attempt < maxRetries ? "retrying..." : "all attempts failed")
                          << std::endl;
                std::this_thread::sleep_for(
                    std::chrono::milliseconds(500 * attempt));
            }
        }

        throw lastException;
    }

} // namespace NetworkLib

int main() {
    using namespace NetworkLib;

    std::cout << "===== Weather API Call =====" << std::endl;

    WeatherAPIClient client("api_key_12345");

    // Normal request
    try {
        WeatherData weather = client.getWeather("Beijing");
        std::cout << weather << std::endl;
    }
    catch(const NetworkException& e) {
        std::cerr << "API error: " << e.what() << std::endl;
    }

    // Request with retries
    std::cout << "\n--- Retry mechanism test ---" << std::endl;
    try {
        auto weather = retryRequest(3, [&](const std::string& city) {
            return client.getWeather(city, 3000);
        }, std::string("Shanghai"));

        std::cout << weather << std::endl;
    }
    catch(const NetworkException& e) {
        std::cerr << "Ultimately failed: " << e.what() << std::endl;
    }

    // Exception-safe cleanup
    client.disconnect();

    return 0;
}

Case 4: Bank Transfer System -- Comprehensive Case
---------------------------------------------------------------
Scenario: a bank's core transfer system that requires the strong exception safety guarantee.
A transfer either succeeds completely (both balances updated correctly) or fails completely (both balances unchanged).

Knowledge integrated:
- Ch1 Namespaces: namespace BankCore {}
- Ch3 Dynamic Memory / Smart Pointers: unique_ptr
- Ch4 Classes and Objects
- Ch5 Inheritance: SavingAccount / CheckingAccount
- Ch6 Polymorphism: virtual function dispatch
- Ch7 Operator Overloading
- Ch8 Templates: a template function for batch transfers

---------------------------------------------------------------
#include <iostream>
#include <string>
#include <vector>
#include <memory>
#include <stdexcept>
#include <chrono>
#include <sstream>

namespace BankCore {

    // ===== Exception hierarchy =====

    class TransferException : public std::runtime_error {
    public:
        TransferException(const std::string& msg)
            : std::runtime_error(msg) {}
    };

    class InsufficientBalanceException : public TransferException {
    private:
        std::string accountId;
        double required;
        double available;
    public:
        InsufficientBalanceException(const std::string& id,
                                      double req, double avail)
            : TransferException("Account " + id + " has insufficient balance: required $"
                                 + std::to_string(req) + " available $"
                                 + std::to_string(avail)),
              accountId(id), required(req), available(avail) {}
        const std::string& getAccountId() const { return accountId; }
    };

    class FrozenAccountException : public TransferException {
    public:
        explicit FrozenAccountException(const std::string& id)
            : TransferException("Account " + id + " is frozen") {}
    };

    // ===== Transaction record (RAII transaction log) =====

    class TransactionLog {
    private:
        std::ostringstream log;
        bool committed;
    public:
        TransactionLog() : committed(false) {
            log << "[Transaction begin "
                << std::chrono::system_clock::to_time_t(
                       std::chrono::system_clock::now())
                << "]\n";
        }

        void record(const std::string& entry) {
            log << entry << "\n";
        }

        void commit() {
            committed = true;
            log << "[Transaction committed]\n";
            std::cout << log.str();
        }

        ~TransactionLog() noexcept {
            if(!committed) {
                log << "[Transaction rolled back]\n";
                std::cerr << log.str();
            }
        }
    };

    // ===== Account base class =====

    class Account {
    protected:
        std::string id;
        std::string owner;
        double balance;
        bool frozen;

    public:
        Account(const std::string& i, const std::string& o, double b)
            : id(i), owner(o), balance(b), frozen(false) {}

        virtual ~Account() = default;

        virtual std::string getType() const = 0;

        // Withdraw (may throw)
        void debit(double amount) {
            if(frozen)
                throw FrozenAccountException(id);
            if(amount <= 0)
                throw TransferException("Invalid withdrawal amount: "
                                         + std::to_string(amount));
            if(amount > balance)
                throw InsufficientBalanceException(id, amount, balance);
            balance -= amount;
        }

        // Deposit (does not throw, assumed to always succeed)
        void credit(double amount) noexcept {
            balance += amount;
        }

        // Freeze / unfreeze
        void freeze() noexcept { frozen = true; }
        void unfreeze() noexcept { frozen = false; }
        bool isFrozen() const noexcept { return frozen; }

        double getBalance() const noexcept { return balance; }
        const std::string& getId() const noexcept { return id; }
        const std::string& getOwner() const noexcept { return owner; }

        friend std::ostream& operator<<(std::ostream& os,
                                         const Account& acc) {
            os << acc.getType() << "[" << acc.id << "] "
               << acc.owner << " $" << acc.balance;
            return os;
        }
    };

    // Savings account
    class SavingsAccount : public Account {
    private:
        double rate;
    public:
        SavingsAccount(const std::string& i, const std::string& o,
                       double b, double r = 0.02)
            : Account(i, o, b), rate(r) {}

        std::string getType() const override { return "Savings"; }

        void applyInterest() noexcept {
            balance += balance * rate;
        }
    };

    // Checking account
    class CheckingAccount : public Account {
    private:
        double overdraft;
    public:
        CheckingAccount(const std::string& i, const std::string& o,
                        double b, double od = 500)
            : Account(i, o, b), overdraft(od) {}

        std::string getType() const override { return "Checking"; }

        void debit(double amount) {
            if(frozen) throw FrozenAccountException(id);
            if(amount <= 0)
                throw TransferException("Invalid withdrawal amount");
            if(amount > balance + overdraft)
                throw InsufficientBalanceException(id, amount,
                                                   balance + overdraft);
            balance -= amount;
        }
    };

    // ===== Transfer service (strong exception safety guarantee) =====

    class TransferService {
    public:
        // Single transfer: strongly exception-safe
        static bool transfer(Account& from, Account& to,
                              double amount)
        {
            TransactionLog tlog;

            tlog.record("Transfer from " + from.getId() + " $" +
                        std::to_string(amount) +
                        " to " + to.getId());

            // 1. Perform the withdrawal (may throw)
            from.debit(amount);

            // 2. Perform the deposit
            try {
                to.credit(amount);
            } catch(...) {
                // 3. Deposit failed, roll back the withdrawal
                from.credit(amount);
                tlog.record("Deposit failed, withdrawal rolled back");
                throw;
            }

            tlog.commit();
            return true;
        }

        // Batch transfer (template function, Ch8)
        // Transfer must have fromId, toId, amount fields
        template<typename Transfer>
        static void batchTransfer(
            std::vector<std::unique_ptr<Account>>& accounts,
            const std::vector<Transfer>& transfers)
        {
            TransactionLog tlog;

            // First validate all transfers (without modifying balances)
            for(const auto& tr : transfers) {
                auto* from = findAccount(accounts, tr.fromId);
                auto* to = findAccount(accounts, tr.toId);

                if(!from || !to)
                    throw TransferException("Account does not exist");

                if(from->isFrozen())
                    throw FrozenAccountException(tr.fromId);
                if(to->isFrozen())
                    throw FrozenAccountException(tr.toId);
                if(from->getBalance() < tr.amount)
                    throw InsufficientBalanceException(
                        tr.fromId, tr.amount, from->getBalance());
            }

            // All checks passed, execute each transfer
            for(const auto& tr : transfers) {
                auto* from = findAccount(accounts, tr.fromId);
                auto* to = findAccount(accounts, tr.toId);
                from->debit(tr.amount);
                to->credit(tr.amount);
                tlog.record("Transfer $" + std::to_string(tr.amount)
                            + " " + tr.fromId + " -> " + tr.toId);
            }

            tlog.commit();
        }

    private:
        static Account* findAccount(
            std::vector<std::unique_ptr<Account>>& accounts,
            const std::string& id)
        {
            for(auto& acc : accounts) {
                if(acc->getId() == id) return acc.get();
            }
            return nullptr;
        }
    };

    // Transfer request struct
    struct TransferRequest {
        std::string fromId;
        std::string toId;
        double amount;
    };

} // namespace BankCore

int main() {
    using namespace BankCore;

    std::cout << "===== Bank Core Transfer System =====" << std::endl;

    // Account management
    std::vector<std::unique_ptr<Account>> accounts;
    accounts.push_back(std::make_unique<SavingsAccount>(
        "A001", "Alice", 10000.0));
    accounts.push_back(std::make_unique<CheckingAccount>(
        "B001", "Bob", 5000.0));
    accounts.push_back(std::make_unique<SavingsAccount>(
        "C001", "Charlie", 3000.0));

    // Print the initial state
    for(const auto& acc : accounts)
        std::cout << *acc << std::endl;

    // Normal transfer
    std::cout << "\n--- Normal transfer ---" << std::endl;
    try {
        TransferService::transfer(*accounts[0], *accounts[1], 2000.0);
    } catch(const TransferException& e) {
        std::cerr << "Transfer failed: " << e.what() << std::endl;
    }

    // Failing transfer (insufficient balance)
    std::cout << "\n--- Transfer with insufficient balance ---" << std::endl;
    try {
        TransferService::transfer(*accounts[2], *accounts[0], 50000.0);
    } catch(const TransferException& e) {
        std::cerr << "Transfer failed: " << e.what() << std::endl;
    }

    // Batch transfer
    std::cout << "\n--- Batch transfer ---" << std::endl;
    std::vector<TransferRequest> batch = {
        {"A001", "B001", 1000.0},
        {"B001", "C001", 500.0},
        {"A001", "C001", 1500.0}
    };

    try {
        TransferService::batchTransfer(accounts, batch);
    } catch(const TransferException& e) {
        std::cerr << "Batch transfer failed: " << e.what() << std::endl;
    }

    // Final state
    std::cout << "\n--- Final account state ---" << std::endl;
    for(const auto& acc : accounts)
        std::cout << *acc << std::endl;

    return 0;
}

#include <iostream>
#include <string>
#include <vector>
#include <memory>
#include <map>
#include <stdexcept>
#include <sstream>
#include <type_traits>

namespace GameEngine {

    // ===== Exception hierarchy =====

    class ResourceException : public std::runtime_error {
    private:
        std::string resourcePath;
    public:
        ResourceException(const std::string& path, const std::string& msg)
            : std::runtime_error(msg), resourcePath(path) {}
        const std::string& getPath() const { return resourcePath; }
    };

    class LoadException : public ResourceException {
    public:
        LoadException(const std::string& path, const std::string& reason)
            : ResourceException(path, "Load failed: " + reason) {}
    };

    class FormatException : public ResourceException {
    public:
        FormatException(const std::string& path, const std::string& fmt)
            : ResourceException(path, "Unsupported format: " + fmt) {}
    };

    class OutOfMemoryException : public ResourceException {
    public:
        OutOfMemoryException(const std::string& path, size_t required)
            : ResourceException(path,
                "Out of memory: need " + std::to_string(required) + " bytes") {}
    };

    // ===== Resource base class (Ch4 + Ch5 + Ch6) =====

    class Resource {
    protected:
        std::string name;
        std::string filePath;
        size_t memorySize;
        bool loaded;

        virtual void loadFromFile(const std::string& path) = 0;

    public:
        Resource(const std::string& n, const std::string& path)
            : name(n), filePath(path), memorySize(0), loaded(false) {}

        virtual ~Resource() = default;

        void load() {
            if(loaded) return;

            std::cout << "[Loading] " << getTypeName() << ": "
                      << name << " (" << filePath << ")" << std::endl;

            // Simulate possible load failures
            if(filePath.find(".bad") != std::string::npos) {
                throw FormatException(filePath, "bad");
            }
            if(filePath.find(".huge") != std::string::npos) {
                throw OutOfMemoryException(filePath, 4ULL * 1024 * 1024 * 1024);
            }

            try {
                loadFromFile(filePath);
                loaded = true;
                std::cout << "[Done] " << name
                          << " (" << memorySize << " bytes)" << std::endl;
            }
            catch(const std::exception& e) {
                throw LoadException(filePath, e.what());
            }
        }

        void unload() noexcept {
            loaded = false;
            memorySize = 0;
            std::cout << "[Unloaded] " << name << std::endl;
        }

        virtual std::string getTypeName() const = 0;
        bool isLoaded() const noexcept { return loaded; }
        size_t getMemorySize() const noexcept { return memorySize; }
        const std::string& getName() const noexcept { return name; }
    };

    // Texture resource
    class Texture : public Resource {
    private:
        int width, height;
    protected:
        void loadFromFile(const std::string& path) override {
            // Simulate texture loading
            if(path.find("texture") != std::string::npos) {
                width = 1024;
                height = 1024;
                memorySize = width * height * 4;  // RGBA
            } else {
                throw LoadException(path, "Texture data corrupted");
            }
        }
    public:
        Texture(const std::string& n, const std::string& p)
            : Resource(n, p), width(0), height(0) {}

        std::string getTypeName() const override { return "Texture"; }
        int getWidth() const { return width; }
        int getHeight() const { return height; }
    };

    // Model resource
    class Model : public Resource {
    private:
        int vertexCount;
    protected:
        void loadFromFile(const std::string& path) override {
            if(path.find("model") != std::string::npos) {
                vertexCount = 15000;
                memorySize = vertexCount * 32;  // 32 bytes per vertex
            } else {
                throw LoadException(path, "Model data incomplete");
            }
        }
    public:
        Model(const std::string& n, const std::string& p)
            : Resource(n, p), vertexCount(0) {}

        std::string getTypeName() const override { return "Model"; }
        int getVertexCount() const { return vertexCount; }
    };

    // Sound effect resource
    class Audio : public Resource {
    private:
        double duration;
    protected:
        void loadFromFile(const std::string& path) override {
            if(path.find("audio") != std::string::npos ||
               path.find("sound") != std::string::npos) {
                duration = 3.5;
                memorySize = static_cast<size_t>(duration * 44100 * 2);
            } else {
                throw LoadException(path, "Audio encoding not supported");
            }
        }
    public:
        Audio(const std::string& n, const std::string& p)
            : Resource(n, p), duration(0.0) {}

        std::string getTypeName() const override { return "Audio"; }
        double getDuration() const { return duration; }
    };

    // ===== Resource factory (template pattern, Ch8) =====

    template<typename T>
    std::unique_ptr<T> createResource(const std::string& name,
                                       const std::string& path)
    {
        static_assert(std::is_base_of<Resource, T>::value,
                      "T must derive from Resource");
        return std::make_unique<T>(name, path);
    }

    // ===== Resource manager (templates, Ch8) =====

    class ResourceManager {
    private:
        std::map<std::string, std::unique_ptr<Resource>> resources;
        size_t totalMemory;
        std::vector<std::string> failedResources;

    public:
        ResourceManager() : totalMemory(0) {}

        // Register and load a resource
        template<typename T>
        T* loadResource(const std::string& name,
                        const std::string& path)
        {
            static_assert(std::is_base_of<Resource, T>::value,
                          "T must derive from Resource");

            auto res = createResource<T>(name, path);

            try {
                res->load();
                totalMemory += res->getMemorySize();
                T* ptr = res.get();
                resources[name] = std::move(res);
                return ptr;
            }
            catch(const ResourceException& e) {
                failedResources.push_back(name + ": " + e.what());
                std::cerr << "  [Failed] " << name << ": "
                          << e.what() << std::endl;
                return nullptr;  // return a null pointer on load failure
            }
        }

        // Get a resource (polymorphic)
        Resource* get(const std::string& name) {
            auto it = resources.find(name);
            return (it != resources.end()) ? it->second.get() : nullptr;
        }

        // Unload everything
        void unloadAll() noexcept {
            for(auto& pair : resources) {
                pair.second->unload();
            }
            resources.clear();
            totalMemory = 0;
            std::cout << "[Resource Manager] All resources unloaded" << std::endl;
        }

        // Status report
        void report() const {
            std::cout << "\n===== Resource Loading Report =====" << std::endl;
            std::cout << "Loaded successfully: " << resources.size() << " item(s)" << std::endl;
            std::cout << "Total memory: " << totalMemory / 1024
                      << " KB" << std::endl;

            for(const auto& pair : resources) {
                auto& res = pair.second;
                std::cout << "  [" << res->getTypeName() << "] "
                          << res->getName()
                          << " (" << res->getMemorySize() << " bytes)"
                          << std::endl;
            }

            if(!failedResources.empty()) {
                std::cout << "\nFailed to load: " << failedResources.size()
                          << " item(s)" << std::endl;
                for(const auto& fail : failedResources) {
                    std::cout << "  " << fail << std::endl;
                }
            }
        }

        ~ResourceManager() noexcept {
            unloadAll();
        }
    };

} // namespace GameEngine

int main() {
    using namespace GameEngine;

    std::cout << "===== 3D Game Resource Loading =====" << std::endl;

    ResourceManager manager;

    // Normal loading
    manager.loadResource<Texture>("Hero texture", "assets/texture_hero.png");
    manager.loadResource<Texture>("Grass texture", "assets/texture_grass.png");
    manager.loadResource<Model>("Hero model", "assets/model_hero.fbx");
    manager.loadResource<Model>("Enemy model", "assets/model_enemy.fbx");
    manager.loadResource<Audio>("Background music", "assets/audio_bgm.mp3");
    manager.loadResource<Audio>("Gunshot sound", "assets/audio_shoot.wav");

    // Expected failures
    manager.loadResource<Texture>("Broken texture", "assets/texture_broken.bad");
    manager.loadResource<Model>("Huge model", "assets/model_world.huge");
    manager.loadResource<Audio>("Unknown format", "assets/audio_unknown.xyz");

    // Look up and use a resource (polymorphism)
    Resource* heroTexture = manager.get("Hero texture");
    if(heroTexture) {
        std::cout << "\nUsing resource: " << heroTexture->getName()
                  << " Type: " << heroTexture->getTypeName() << std::endl;

        // Polymorphic dynamic_cast check
        auto* tex = dynamic_cast<Texture*>(heroTexture);
        if(tex) {
            std::cout << "  Resolution: " << tex->getWidth()
                      << "x" << tex->getHeight() << std::endl;
        }
    }

    // Report
    manager.report();

    // RAII ensures all resources are unloaded automatically on exit
    std::cout << "\nExiting game..." << std::endl;
    return 0;
}

[Chapter Overview]
The C++ I/O Streams library provides a powerful abstraction for reading and writing data.
Through its buffering mechanism it connects user-space programs to the underlying
operating system's file operations, offering high-level formatted input/output while
also supporting low-level binary operations.
Starting from the underlying principles, this chapter comprehensively covers I/O streams,
file streams, string streams, and the C++17 filesystem library.

I. Basic File Stream Operations

---------------------------------------------------------------
// ---- Basic example: writing and reading a file ----
#include <iostream>
#include <fstream>
#include <string>

int main() {
    // Write to a file
    std::ofstream outFile("hello.txt");
    if (!outFile.is_open()) {
        std::cerr << "Cannot create file!" << std::endl;
        return 1;
    }
    outFile << "Hello, C++ World!" << std::endl;
    outFile << "This is the second line." << std::endl;
    outFile << "Number: " << 42 << " Float: " << 3.14159 << std::endl;
    outFile.close();

    // Read the file
    std::ifstream inFile("hello.txt");
    if (!inFile.is_open()) {
        std::cerr << "Cannot open file!" << std::endl;
        return 1;
    }

    std::string line;
    std::cout << "===== File contents =====" << std::endl;
    while (std::getline(inFile, line)) {
        std::cout << line << std::endl;
    }
    inFile.close();

    return 0;
}

II. The Stream Buffering Mechanism -- Low-Level Principles

1. Buffer Architecture

   C++ I/O streams use a three-layer architecture:

   ┌─────────────────────────────────────────────────────┐
   │  User program  ofstream / ifstream / cout / cin     │
   │  (high-level)  formatted >> / << , getline, read    │
   ├─────────────────────────────────────────────────────┤
   │  Buffer layer  std::streambuf / std::filebuf        │
   │  (buffering)   internal character buffer (array)    │
   ├─────────────────────────────────────────────────────┤
   │  Syscall layer read() / write() (POSIX)             │
   │  (kernel)      syscall → kernel file system         │
   └─────────────────────────────────────────────────────┘

   Responsibilities of each layer:
   - User program layer: provides the high-level abstraction for formatted input/output
   - Buffer layer: caches data in user space to reduce the number of system calls
   - System call layer: interacts with the disk through the kernel

2. How the Buffer Works

   streambuf maintains an internal character array (the buffer). Its workflow is:

   Output flow (e.g. ofstream << "hello"):
   Step 1: Data is first written into streambuf's internal buffer
   Step 2: When the buffer is full (or on explicit flush, a newline, or normal program exit)
   Step 3: The buffered data is written to the kernel in one write() system call
   Step 4: The kernel writes the data to disk (possibly delayed further by the kernel page cache)

   Input flow (e.g. ifstream >> value):
   Step 1: The kernel reads a large chunk of data from disk via the read() system call
   Step 2: It is placed into streambuf's buffer
   Step 3: The user program takes data from the buffer byte by byte / line by line
   Step 4: When the buffer is exhausted, another read() system call is triggered

3. Three Buffering Strategies

   setbuf() / pubsetbuf() can be used to set the buffering strategy:

   ┌──────────────┬──────────────────────────────────────────────┐
   │ Strategy     │ Behavior                                     │
   ├──────────────┼──────────────────────────────────────────────┤
   │ Full buffer  │ Syscall only when buffer is full (default    │
   │              │ for file streams)                            │
   │ Line buffer  │ Syscall on newline \\n (terminal output)     │
   │ Unbuffered   │ Syscall on every write (stderr/cerr)         │
   └──────────────┴──────────────────────────────────────────────┘

   Practical implications:
   - std::cout is usually line-buffered: flushed on \n when attached to a terminal
   - std::ofstream is usually fully buffered: writes to disk only when the buffer (e.g. 4KB) fills
   - std::cerr is usually unbuffered: guarantees error messages appear immediately
   - endl vs \n: endl explicitly flushes the buffer, \n does not

4. The Low-Level Flow Through System Calls and File Descriptors

   The full path data takes from a C++ stream down to the hardware:

   Application (ofstream::write)
     │
     ▼
   C++ streambuf (user-space buffer)
     │
     ▼ flush
   POSIX write(fd, buf, size) -- system call (syscall)
     │
     ▼ user mode → kernel mode switch
   Kernel VFS (Virtual File System layer)
     │
     ▼
   Kernel Page Cache
     │
     ▼ periodic kernel writeback (dirty_expire_centisecs)
   Concrete file system (ext4/xfs/btrfs)
     │
     ▼
   Block device driver (Block Layer)
     │
     ▼
   Disk controller → physical disk

   Every C++ fstream object is internally associated with a file descriptor (fd).
   The file descriptor refers to an entry in the kernel's file table, which in turn
   points to a specific inode (index node), which finally locates the data blocks on disk.

5. Synchronizing C++ Streams with the C Standard Library (sync_with_stdio)

   By default, C++ streams and the C standard library (stdin/stdout/stderr) are synchronized:

   // Default: C++ cout and C printf can be mixed without out-of-order output
   std::cout << "Hello ";
   printf("World\n");

   This is implemented via ios_base::sync_with_stdio(true) (true by default).
   The cost of synchronization is that every I/O operation must flush both the C and C++ buffers.

   If a program uses only C++ streams or only the C standard library, you can gain performance with:

   std::ios_base::sync_with_stdio(false);
   std::cin.tie(nullptr);  // untie cin from cout

   This makes the C++ stream buffers fully independent of the C standard library, avoiding frequent flushes.

6. Kernel File Descriptors and the File Table

   Each process has a file descriptor table (the first three are fixed: 0=stdin, 1=stdout, 2=stderr).
   When a file is opened, the kernel allocates a new fd and associates it with an entry in the
   kernel-level "open file table". That entry records:
   - The current file offset (read/write pointer position)
   - The open mode (O_RDONLY / O_WRONLY / O_RDWR)
   - A pointer to the inode

   Multiple fds can refer to the same file (e.g. via dup or parent/child process inheritance),
   sharing the same file offset. This is a core design of the UNIX file system.

I. Input Streams (istream)

---------------------------------------------------------------
#include <iostream>
#include <sstream>
#include <string>

int main() {
    // ===== Standard input cin =====
    int age;
    std::string name;

    std::cout << "Enter name and age: ";
    // std::cin >> name >> age;

    // ===== getline: read a whole line (including spaces) =====
    std::string input = "Hello C++ World";
    std::istringstream iss(input);
    std::string word;

    std::cout << "Split by whitespace:" << std::endl;
    while (iss >> word) {         // >> operator: splits on whitespace
        std::cout << "  [" << word << "]" << std::endl;
    }

    // Reset the stream to the beginning
    iss.clear();                  // clear the eof state
    iss.seekg(0);                // move the read pointer to the beginning

    std::string fullLine;
    std::getline(iss, fullLine);  // read the whole line
    std::cout << "Full line: " << fullLine << std::endl;

    // ===== read: read a given number of bytes =====
    const char* data = "ABCDEFGHIJKLMNOP";
    std::istringstream iss2(data);

    char buffer[6] = {};
    iss2.read(buffer, 5);         // read 5 bytes
    std::cout << "First 5 bytes read: " << buffer << std::endl;

    // ===== get: read character by character =====
    iss2.seekg(0);
    char ch;
    std::cout << "First 3 characters read one by one: ";
    for (int i = 0; i < 3; ++i) {
        iss2.get(ch);
        std::cout << ch << " ";
    }
    std::cout << std::endl;

    // ===== peek: look at the next character without consuming it =====
    iss2.seekg(0);
    std::cout << "Next character (not consumed): " << (char)iss2.peek() << std::endl;
    iss2.get(ch);
    std::cout << "Character after consuming: " << ch << std::endl;

    // ===== ignore: skip characters =====
    std::istringstream iss3("123,456,789");
    int a, b;
    iss3 >> a;
    iss3.ignore(10, ',');        // ignore up to 10 characters or until ',' is found
    iss3 >> b;
    std::cout << "a=" << a << " b=" << b << std::endl;  // a=123 b=456

    // ===== tellg / seekg: get/set the read pointer =====
    std::istringstream iss4("Hello World");
    std::cout << "Initial position: " << iss4.tellg() << std::endl;  // 0

    iss4.seekg(6);               // move to byte 6
    std::cout << "Position after move: " << iss4.tellg() << std::endl;

    std::string rest;
    iss4 >> rest;
    std::cout << "Read from position 6: " << rest << std::endl;  // World

    return 0;
}

II. Output Streams (ostream)

---------------------------------------------------------------
#include <iostream>
#include <fstream>
#include <sstream>
#include <iomanip>

int main() {
    // ===== Standard output cout, cerr, clog =====
    std::cout << "cout: standard output (line-buffered)" << std::endl;
    std::cerr << "cerr: standard error (unbuffered)" << std::endl;
    std::clog << "clog: standard log (fully buffered)" << std::endl;

    // ===== write: write a given number of bytes =====
    const char* msg = "Hello";
    std::cout.write(msg, 5);     // write 5 bytes (not including \0)
    std::cout << std::endl;

    // ===== put: write a single character =====
    std::cout.put('A');
    std::cout.put('\n');

    // ===== flush: flush the buffer manually =====
    std::cout << "This line appears immediately" << std::flush;
    // flush forces the buffer contents out (without adding a newline)

    // Comparing endl vs \n:
    // std::endl = \n + flush    (newline and flush)
    // \n = newline only         (no flush)

    // ===== String output stream (ostringstream) =====
    std::ostringstream oss;
    oss << "Name: " << "Zhang San" << ", Age: " << 25
        << ", Score: " << 95.5;
    std::string result = oss.str();
    std::cout << "Formatted string: " << result << std::endl;

    // Build JSON dynamically
    std::ostringstream json;
    json << "{\n";
    json << "  \"name\": \"" << "Xiao Ming" << "\",\n";
    json << "  \"age\": " << 20 << ",\n";
    json << "  \"score\": " << 88.5 << "\n";
    json << "}";
    std::cout << json.str() << std::endl;

    return 0;
}

III. File Streams (fstream) -- Open Modes

---------------------------------------------------------------
#include <iostream>
#include <fstream>
#include <string>

void displayModes() {
    // Overview of open modes:
    // ios::in      - open for reading (ifstream default)
    // ios::out     - open for writing (ofstream default)
    // ios::binary  - binary mode (no text translation)
    // ios::app     - append mode (every write goes to the end of the file)
    // ios::ate     - seek to the end of the file on open
    // ios::trunc   - truncate the file contents on open (ofstream default)
    // ios::nocreate - do not create a new file (only open an existing one)
    // ios::noreplace - do not overwrite an existing file
}

int main() {
    const std::string filename = "test_modes.txt";

    // ===== Mode 1: out (default), trunc (default) -- overwrite =====
    {
        std::ofstream f(filename);           // equivalent to out | trunc
        f << "First line written in overwrite mode" << std::endl;
        f.close();
    }

    // ===== Mode 2: out | app -- append =====
    {
        std::ofstream f(filename, std::ios::out | std::ios::app);
        f << "Appended: will not be overwritten" << std::endl;
        f.close();
    }

    // ===== Mode 3: in -- read only =====
    {
        std::ifstream f(filename);           // equivalent to in
        std::string line;
        while (std::getline(f, line)) {
            std::cout << "Read: " << line << std::endl;
        }
        f.close();
    }

    // ===== Mode 4: in | out -- read and write =====
    {
        std::fstream f(filename, std::ios::in | std::ios::out | std::ios::ate);
        // Append content at the end
        f << "Appended in read/write mode" << std::endl;

        // Move the pointer to the beginning to read
        f.seekg(0);
        std::string line;
        std::getline(f, line);
        std::cout << "First line in read/write mode: " << line << std::endl;
        f.close();
    }

    // ===== Mode 5: in | out | trunc -- read/write but truncate first =====
    {
        std::fstream f(filename, std::ios::in | std::ios::out | std::ios::trunc);
        f << "Brand new content" << std::endl;
        f.seekg(0);
        std::string line;
        std::getline(f, line);
        std::cout << "Content after truncation: " << line << std::endl;
        f.close();
    }

    // ===== Checking file state =====
    {
        std::fstream f("nonexistent_file.txt", std::ios::in);
        if (!f.is_open()) {
            std::cout << "File does not exist (is_open=false)" << std::endl;
        }

        f.open(filename, std::ios::out | std::ios::app);
        if (f.is_open()) {
            std::cout << "File is open" << std::endl;
        }
        f.close();
        std::cout << "Closed: " << (!f.is_open() ? "yes" : "no") << std::endl;
    }

    // Clean up
    std::remove(filename.c_str());

    return 0;
}

IV. Stream State Management

---------------------------------------------------------------
#include <iostream>
#include <sstream>
#include <limits>

int main() {
    std::cout << "===== Stream state bits =====" << std::endl;
    std::cout << "goodbit  = " << std::ios::goodbit  << " (OK)" << std::endl;
    std::cout << "badbit   = " << std::ios::badbit   << " (unrecoverable error)" << std::endl;
    std::cout << "failbit  = " << std::ios::failbit  << " (operation failed)" << std::endl;
    std::cout << "eofbit   = " << std::ios::eofbit   << " (end of file reached)" << std::endl;

    // ===== State checks =====
    std::istringstream iss("123 abc");

    int num;
    iss >> num;                          // successfully reads 123
    std::cout << "\nAfter reading 123:" << std::endl;
    std::cout << "  good(): " << iss.good() << std::endl;   // 1
    std::cout << "  eof():  " << iss.eof()  << std::endl;   // 0
    std::cout << "  fail(): " << iss.fail() << std::endl;   // 0
    std::cout << "  bad():  " << iss.bad()  << std::endl;   // 0

    std::string str;
    iss >> str;                          // reads abc

    std::cout << "\nAfter reading abc:" << std::endl;
    std::cout << "  eof(): " << iss.eof() << std::endl;    // 1 (end reached)

    // ===== Simulating a failure =====
    std::istringstream iss2("hello world");
    int x;
    iss2 >> x;  // fails! "hello" cannot be converted to int

    std::cout << "\nAfter trying to read a string into an int:" << std::endl;
    std::cout << "  fail(): " << iss2.fail() << std::endl;  // 1
    std::cout << "  bad():  " << iss2.bad()  << std::endl;  // 0

    // ===== clear() resets the state =====
    iss2.clear();                        // reset all state bits
    std::cout << "\nfail() after clear(): " << iss2.fail() << std::endl;  // 0

    // ===== rdstate() gets the raw state bits =====
    std::ios::iostate state = iss2.rdstate();
    std::cout << "rdstate(): " << state << std::endl;

    // ===== Safe reading pattern =====
    std::istringstream iss3("42");
    int value;
    if (iss3 >> value) {                 // a stream converts implicitly to bool
        std::cout << "\nRead successfully: " << value << std::endl;
    } else {
        std::cerr << "Read failed" << std::endl;
        iss3.clear();
        iss3.ignore(std::numeric_limits<std::streamsize>::max(), '\n');
    }

    return 0;
}

#include <iostream>
#include <iomanip>
#include <cmath>

int main() {
    double pi = 3.141592653589793;

    // ===== setprecision: precision =====
    std::cout << "Default precision: " << pi << std::endl;
    std::cout << "Precision 2: " << std::setprecision(2) << pi << std::endl;
    std::cout << "Precision 6: " << std::setprecision(6) << pi << std::endl;
    std::cout << "Precision 10: " << std::setprecision(10) << pi << std::endl;

    // ===== fixed / scientific =====
    double val = 1234567.89;

    std::cout << "\nDefault:   " << val << std::endl;
    std::cout << "fixed:     " << std::fixed << val << std::endl;
    std::cout << "scientific:" << std::scientific << val << std::endl;

    // Restore the default
    std::cout << std::defaultfloat;

    // ===== setw: field width =====
    std::cout << "\n===== Table output =====" << std::endl;
    std::cout << std::left;  // left-align
    std::cout << std::setw(15) << "Item" << std::setw(10)
              << "Price" << std::setw(10) << "Qty" << std::endl;
    std::cout << std::setfill('-');  // set the fill character
    std::cout << std::setw(35) << "" << std::endl;
    std::cout << std::setfill(' ');  // restore space fill

    std::cout << std::setw(15) << "Apple" << std::setw(10)
              << 5.99 << std::setw(10) << 100 << std::endl;
    std::cout << std::setw(15) << "Banana" << std::setw(10)
              << 3.49 << std::setw(10) << 200 << std::endl;
    std::cout << std::setw(15) << "Orange" << std::setw(10)
              << 4.29 << std::setw(10) << 150 << std::endl;

    // ===== boolalpha: displaying booleans =====
    std::cout << "\nBoolean: " << true << std::endl;
    std::cout << "boolalpha: " << std::boolalpha << true << std::endl;
    std::cout << "noboolalpha: " << std::noboolalpha << false << std::endl;

    // ===== Number bases =====
    int num = 255;
    std::cout << "\nDecimal:     " << std::dec << num << std::endl;
    std::cout << "Hexadecimal: " << std::hex << num << std::endl;
    std::cout << "Octal:       " << std::oct << num << std::endl;
    std::cout << "showbase:    " << std::showbase << std::hex
              << num << std::endl;  // 0xff

    // ===== hexfloat (C++17) =====
    std::cout << "\nHexadecimal float: " << std::hexfloat << 3.14 << std::endl;

    return 0;
}

VI. Reading and Writing Binary Files

---------------------------------------------------------------
#include <iostream>
#include <fstream>
#include <cstring>

struct Employee {
    int id;
    char name[50];
    double salary;

    void display() const {
        std::cout << "ID: " << id << ", Name: " << name
                  << ", Salary: $" << salary << std::endl;
    }
};

int main() {
    const std::string filename = "employees.bin";

    // ===== Binary write =====
    {
        std::ofstream file(filename, std::ios::binary);
        if (!file) {
            std::cerr << "Cannot create file" << std::endl;
            return 1;
        }

        Employee emp1 = {1001, "Zhang San", 15000.0};
        Employee emp2 = {1002, "Li Si", 18000.0};
        Employee emp3 = {1003, "Wang Wu", 20000.0};

        // Write the structs (POD types can be written directly)
        file.write(reinterpret_cast<const char*>(&emp1), sizeof(Employee));
        file.write(reinterpret_cast<const char*>(&emp2), sizeof(Employee));
        file.write(reinterpret_cast<const char*>(&emp3), sizeof(Employee));

        // Write an int array
        int numbers[] = {1, 2, 3, 4, 5, 100, 200};
        file.write(reinterpret_cast<const char*>(numbers), sizeof(numbers));

        file.close();
        std::cout << "Binary file written" << std::endl;
    }

    // ===== Binary read =====
    {
        std::ifstream file(filename, std::ios::binary);
        if (!file) {
            std::cerr << "Cannot open file" << std::endl;
            return 1;
        }

        // Get the file size
        file.seekg(0, std::ios::end);
        std::streamsize fileSize = file.tellg();
        file.seekg(0, std::ios::beg);
        std::cout << "File size: " << fileSize << " bytes" << std::endl;

        // Read the employee records
        std::cout << "\n===== Employee records =====" << std::endl;
        Employee emp;
        int recordCount = 0;

        while (file.read(reinterpret_cast<char*>(&emp), sizeof(Employee))) {
            emp.display();
            recordCount++;
            if (recordCount >= 3) break;  // read only the first 3 Employee records
        }

        // Read the int array that follows
        if (file) {
            int numbers[7];
            file.read(reinterpret_cast<char*>(numbers), sizeof(numbers));
            std::cout << "\nInteger array: ";
            for (int n : numbers) {
                std::cout << n << " ";
            }
            std::cout << std::endl;
        }

        // ===== Random access (seek to the 2nd record) =====
        file.clear();  // clear a possible eof state
        file.seekg(sizeof(Employee), std::ios::beg);  // skip the 1st record
        Employee secondEmp;
        file.read(reinterpret_cast<char*>(&secondEmp), sizeof(Employee));
        std::cout << "\n2nd record (random access): ";
        secondEmp.display();

        file.close();
    }

    // Clean up
    std::remove(filename.c_str());

    return 0;
}

VII. The C++17 Filesystem Library <filesystem>

---------------------------------------------------------------
#include <iostream>
#include <filesystem>
#include <fstream>
#include <chrono>
#include <iomanip>

namespace fs = std::filesystem;

int main() {
    std::cout << "===== C++17 Filesystem Library =====" << std::endl;

    // ===== Path operations =====
    fs::path p1 = "/home/user/documents/report.pdf";
    std::cout << "Full path: " << p1 << std::endl;
    std::cout << "  Root path: " << p1.root_path() << std::endl;
    std::cout << "  Root name: " << p1.root_name() << std::endl;
    std::cout << "  Root directory: " << p1.root_directory() << std::endl;
    std::cout << "  Relative path: " << p1.relative_path() << std::endl;
    std::cout << "  Parent path: " << p1.parent_path() << std::endl;
    std::cout << "  File name: " << p1.filename() << std::endl;
    std::cout << "  Stem: " << p1.stem() << std::endl;
    std::cout << "  Extension: " << p1.extension() << std::endl;

    // Path concatenation
    fs::path p2 = fs::path("/home/user") / "downloads" / "file.txt";
    std::cout << "\nConcatenated path: " << p2 << std::endl;

    // ===== Directory operations =====
    const fs::path testDir = "./test_filesystem_demo";

    // Create a directory
    if (!fs::exists(testDir)) {
        fs::create_directory(testDir);
        std::cout << "\nCreated directory: " << testDir << std::endl;
    }

    // Create nested directories
    fs::path subDir = testDir / "sub1" / "sub2";
    fs::create_directories(subDir);
    std::cout << "Created nested directories: " << subDir << std::endl;

    // Create test files in the directory
    {
        std::ofstream(testDir / "file1.txt") << "Content 1" << std::endl;
        std::ofstream(testDir / "file2.txt") << "Content 2" << std::endl;
        std::ofstream(subDir / "deep.txt") << "Deeply nested file" << std::endl;
    }

    // ===== Iterate a directory =====
    std::cout << "\n===== Iterating directory =====" << std::endl;
    for (const auto& entry : fs::directory_iterator(testDir)) {
        const auto& path = entry.path();
        std::cout << "  "
                  << (entry.is_directory() ? "[DIR]  " : "[FILE] ")
                  << path.filename();

        if (entry.is_regular_file()) {
            std::cout << "  (" << entry.file_size() << " bytes)";
        }
        std::cout << std::endl;
    }

    // ===== Recursive iteration =====
    std::cout << "\n===== Recursive iteration =====" << std::endl;
    for (const auto& entry : fs::recursive_directory_iterator(testDir)) {
        std::cout << "  " << entry.path() << std::endl;
    }

    // ===== File information =====
    if (fs::exists(testDir / "file1.txt")) {
        auto ftime = fs::last_write_time(testDir / "file1.txt");
        auto size = fs::file_size(testDir / "file1.txt");
        std::cout << "\nFile information:" << std::endl;
        std::cout << "  Size: " << size << " bytes" << std::endl;
    }

    // ===== Disk space =====
    auto spaceInfo = fs::space(testDir);
    std::cout << "\nDisk space:" << std::endl;
    std::cout << "  Capacity:  "
              << spaceInfo.capacity / (1024*1024) << " MB" << std::endl;
    std::cout << "  Available: "
              << spaceInfo.available / (1024*1024) << " MB" << std::endl;

    // ===== Permission operations =====
    // fs::permissions(testDir / "file1.txt",
    //                  fs::perms::owner_read | fs::perms::owner_write,
    //                  fs::perm_options::replace);

Case 1: Diary Application -- Personal Diary Software
---------------------------------------------------------------
Scenario: a simple diary that supports writing new entries (append mode) and viewing entries by date.

Knowledge integrated:
- Ch9 Exception Handling: handling file-open failures
- This chapter: file append mode, getline, date formatting

---------------------------------------------------------------
#include <iostream>
#include <fstream>
#include <string>
#include <sstream>
#include <ctime>
#include <iomanip>
#include <vector>
#include <stdexcept>

namespace Diary {

    class DiaryManager {
    private:
        std::string diaryFile;

        // Get the current date as a string
        std::string getToday() const {
            time_t now = time(nullptr);
            struct tm* t = localtime(&now);
            std::ostringstream oss;
            oss << std::setfill('0')
                << (t->tm_year + 1900) << "-"
                << std::setw(2) << (t->tm_mon + 1) << "-"
                << std::setw(2) << t->tm_mday;
            return oss.str();
        }

    public:
        DiaryManager(const std::string& filename = "diary.txt")
            : diaryFile(filename) {}

        // Write a new diary entry
        void writeEntry(const std::string& content) {
            std::ofstream file(diaryFile, std::ios::app);  // append mode
            if (!file.is_open()) {
                throw std::runtime_error("Cannot open diary file: " + diaryFile);
            }

            std::string today = getToday();
            file << "=== " << today << " ===" << std::endl;
            file << content << std::endl;
            file << std::endl;  // blank line as separator
            file.close();

            std::cout << "[Diary] " << today << " saved successfully" << std::endl;
        }

        // Read all diary entries
        void readAll() const {
            std::ifstream file(diaryFile);
            if (!file.is_open()) {
                std::cout << "Diary file does not exist or is empty" << std::endl;
                return;
            }

            std::string line;
            int entryCount = 0;

            std::cout << "===== All diary entries =====" << std::endl;
            while (std::getline(file, line)) {
                if (line.find("===") != std::string::npos) {
                    entryCount++;
                }
                std::cout << line << std::endl;
            }
            file.close();

            std::cout << "Total: " << entryCount << " entries" << std::endl;
        }

        // Search by keyword
        std::vector<std::string> search(const std::string& keyword) const {
            std::vector<std::string> results;
            std::ifstream file(diaryFile);

            if (!file.is_open()) return results;

            std::string line;
            std::string currentEntry;
            bool inEntry = false;

            while (std::getline(file, line)) {
                if (line.find("===") == 0 && line.find("===", 4) != std::string::npos) {
                    // Found a date separator line
                    if (!currentEntry.empty() &&
                        currentEntry.find(keyword) != std::string::npos) {
                        results.push_back(currentEntry);
                    }
                    currentEntry = line + "\n";
                    inEntry = true;
                } else if (inEntry) {
                    currentEntry += line + "\n";
                }
            }

            // Check the last entry
            if (!currentEntry.empty() &&
                currentEntry.find(keyword) != std::string::npos) {
                results.push_back(currentEntry);
            }

            return results;
        }

        // Read the diary entry for a specific date
        void readByDate(const std::string& date) const {
            std::ifstream file(diaryFile);
            if (!file.is_open()) {
                std::cout << "Diary file does not exist" << std::endl;
                return;
            }

            std::string line;
            bool found = false;
            bool inTargetEntry = false;

            while (std::getline(file, line)) {
                if (line.find("=== " + date + " ===") != std::string::npos) {
                    found = true;
                    inTargetEntry = true;
                    std::cout << line << std::endl;
                    continue;
                }

                if (inTargetEntry) {
                    if (line.find("===") != std::string::npos && !line.empty()) {
                        break;  // the next entry has started
                    }
                    std::cout << line << std::endl;
                }
            }

            if (!found) {
                std::cout << "No diary entry found for " << date << std::endl;
            }
        }
    };

} // namespace Diary

int main() {

    std::cout << "===== Personal Diary =====" << std::endl;

        diary.writeEntry("Implemented a generic comparator with templates; the code is much cleaner now.");
        diary.writeEntry("Today I studied exception handling and understood the deep relationship between stack unwinding and RAII.");

        diary.readAll();

        std::cerr << "Error: " << e.what() << std::endl;

class ScoreProcessor {
private:
    std::vector<Student> students;

    // Parse a CSV line
    static Student parseLine(const std::string& line) {
        std::istringstream iss(line);
        std::string token;
        Student s;

        try {
            std::getline(iss, s.id, ',');
            std::getline(iss, s.name, ',');

            std::getline(iss, token, ',');
            s.math = std::stod(token);

            std::getline(iss, token, ',');
            s.english = std::stod(token);

            std::getline(iss, token, ',');
            s.programming = std::stod(token);
        }
        catch (const std::exception& e) {
            throw std::runtime_error("Failed to parse line: " + line
                                     + " (" + e.what() + ")");
        }

        return s;
    }

    // Find the maximum
    Student findMax(const std::string& subject) const {
        if (students.empty())
            throw std::runtime_error("No student data");

        return *std::max_element(students.begin(), students.end(),
            [&subject](const Student& a, const Student& b) {
                if (subject == "math") return a.math < b.math;
                if (subject == "english") return a.english < b.english;
                return a.programming < b.programming;
            });
    }

public:

        std::ifstream file(filename);
        if (!file.is_open()) {
            throw std::runtime_error("Cannot open file: " + filename);
        }

        students.clear();
        std::string line;

        // Skip the header line
        if (std::getline(file, line)) {
            // the header line format could be validated here
        }

        int lineNum = 1;
        while (std::getline(file, line)) {
            lineNum++;
            if (line.empty()) continue;
            try {
                students.push_back(parseLine(line));
            }
            catch (const std::exception& e) {
                std::cerr << "Warning: skipping line " << lineNum
                          << ": " << e.what() << std::endl;
            }
        }

        file.close();
        std::cout << "Successfully loaded " << students.size()
                  << " student record(s)" << std::endl;
    }

    void printReport() const {
        std::cout << "\n===== Student Report Card =====" << std::endl;
        std::cout << std::string(64, '=') << std::endl;
        std::cout << std::left
                  << std::setw(10) << "ID"
                  << std::setw(12) << "Name"
                  << std::setw(10) << "Math"
                  << std::setw(10) << "English"
                  << std::setw(12) << "Programming"
                  << std::setw(10) << "Average"
                  << std::endl;
        std::cout << std::string(64, '-') << std::endl;

        for (const auto& s : students) {
            std::cout << s << std::endl;
        }
        std::cout << std::string(64, '=') << std::endl;

        // Statistics
        double totalMath = 0, totalEng = 0, totalProg = 0;
        for (const auto& s : students) {
            totalMath += s.math;
            totalEng += s.english;
            totalProg += s.programming;
        }
        int n = students.size();
        std::cout << "\n===== Statistics =====" << std::endl;
        std::cout << "Total students: " << n << std::endl;
        std::cout << "Math average: " << std::fixed << std::setprecision(2)
                  << totalMath / n << std::endl;
        std::cout << "English average: " << totalEng / n << std::endl;
        std::cout << "Programming average: " << totalProg / n << std::endl;

        auto bestMath = findMax("math");

        auto bestProg = findMax("programming");

        std::cout << "\nHighest in math: " << bestMath.name

Case 3: Configuration File Parser -- Managing Software Settings
---------------------------------------------------------------
Scenario: software needs to read/modify/save INI-format configuration files (similar to Windows .ini files).

Knowledge integrated:
- Ch1 Namespaces: namespace config {}
- Ch8 Templates: templates for storing values of any type
- Ch9 Exception Handling: format errors
- This chapter: fstream, stringstream

---------------------------------------------------------------
#include <iostream>
#include <fstream>
#include <sstream>
#include <string>
#include <map>
#include <vector>
#include <algorithm>
#include <stdexcept>
#include <iomanip>
#include <type_traits>

namespace config {

    // Exception classes
    class ConfigException : public std::runtime_error {
    public:
        ConfigException(const std::string& msg)
            : std::runtime_error(msg) {}
    };

    class ParseException : public ConfigException {
    private:
        int lineNumber;
    public:
        ParseException(int line, const std::string& msg)
            : ConfigException("Line " + std::to_string(line) + ": " + msg),
              lineNumber(line) {}
        int getLine() const { return lineNumber; }
    };

    // Value type (supports int, double, string, bool)
    class ConfigValue {
    private:
        std::string raw;

    public:
        ConfigValue(const std::string& v = "") : raw(v) {}
        ConfigValue(int v) : raw(std::to_string(v)) {}
        ConfigValue(double v) : raw(std::to_string(v)) {}
        ConfigValue(bool v) : raw(v ? "true" : "false") {}

        std::string toString() const { return raw; }

        int toInt() const {
            try { return std::stoi(raw); }
            catch(...) { throw ConfigException("Cannot convert to int: " + raw); }
        }

        double toDouble() const {
            try { return std::stod(raw); }
            catch(...) { throw ConfigException("Cannot convert to double: " + raw); }
        }

        bool toBool() const {
            std::string lower = raw;
            std::transform(lower.begin(), lower.end(),
                          lower.begin(), ::tolower);
            if (lower == "true" || lower == "1" || lower == "yes") return true;
            if (lower == "false" || lower == "0" || lower == "no") return false;
            throw ConfigException("Cannot convert to bool: " + raw);
        }

        friend std::ostream& operator<<(std::ostream& os,
                                        const ConfigValue& v) {
            os << v.raw;
            return os;
        }
    };

    // A Section contains key-value pairs
    class Section {
    private:
        std::map<std::string, ConfigValue> entries;

    public:
        void set(const std::string& key, const ConfigValue& value) {
            entries[key] = value;
        }

        template<typename T>
        void set(const std::string& key, T value) {
            entries[key] = ConfigValue(value);
        }

        ConfigValue get(const std::string& key,
                       const ConfigValue& defaultVal = ConfigValue()) const {
            auto it = entries.find(key);
            return (it != entries.end()) ? it->second : defaultVal;
        }

        bool has(const std::string& key) const {
            return entries.find(key) != entries.end();
        }

        const auto& getAll() const { return entries; }
    };

    // Configuration file manager
    class ConfigFile {
    private:
        std::string filename;
        std::map<std::string, Section> sections;
        Section globalSection;  // default section when there is no section name

        // Trim leading and trailing whitespace
        static std::string trim(const std::string& s) {
            size_t start = s.find_first_not_of(" \t\r\n");
            if (start == std::string::npos) return "";
            size_t end = s.find_last_not_of(" \t\r\n");
            return s.substr(start, end - start + 1);
        }

    public:
        ConfigFile(const std::string& fn = "") : filename(fn) {}

        // Load the file
        void load() {
            if (filename.empty())
                throw ConfigException("No configuration file name specified");

            std::ifstream file(filename);
            if (!file.is_open()) {
                std::cerr << "Configuration file not found, using default settings" << std::endl;
                return;
            }

            sections.clear();
            std::string currentSection = "";
            std::string line;
            int lineNum = 0;

            while (std::getline(file, line)) {
                lineNum++;
                line = trim(line);

                // Skip blank lines and comments
                if (line.empty() || line[0] == '#' || line[0] == ';')
                    continue;

                // Section name [SectionName]
                if (line[0] == '[' && line.back() == ']') {
                    currentSection = line.substr(1, line.length() - 2);
                    sections[currentSection] = Section();
                    continue;
                }

                // Key-value pair key = value
                size_t eqPos = line.find('=');
                if (eqPos == std::string::npos) {
                    throw ParseException(lineNum,
                        "Invalid line: " + line + " (missing '=')");
                }

                std::string key = trim(line.substr(0, eqPos));
                std::string value = trim(line.substr(eqPos + 1));

                if (key.empty()) {
                    throw ParseException(lineNum, "Key name is empty");
                }

                if (currentSection.empty()) {
                    globalSection.set(key, value);
                } else {
                    sections[currentSection].set(key, value);
                }
            }

            file.close();
            std::cout << "Configuration file loaded: " << filename
                      << " (" << lineNum << " lines)" << std::endl;
        }

        // Save the file
        void save() {
            if (filename.empty())
                throw ConfigException("No configuration file name specified");

            std::ofstream file(filename);
            if (!file.is_open())
                throw ConfigException("Cannot create file: " + filename);

            file << "# Auto-generated configuration file\n";
            file << "# Reload after making changes\n\n";

            // Global section
            for (const auto& entry : globalSection.getAll()) {
                file << entry.first << " = " << entry.second << "\n";
            }
            file << "\n";

            // Each section
            for (const auto& sec : sections) {
                file << "[" << sec.first << "]\n";
                for (const auto& entry : sec.second.getAll()) {
                    file << entry.first << " = " << entry.second << "\n";
                }
                file << "\n";
            }

            file.close();
            std::cout << "Configuration file saved: " << filename << std::endl;
        }

        // Access a section
        Section& operator[](const std::string& sectionName) {
            return sections[sectionName];
        }

        Section& global() { return globalSection; }

        void setFilename(const std::string& fn) { filename = fn; }

        // Print the configuration
        void print() const {
            std::cout << "\n===== Configuration contents " << filename
                      << " =====" << std::endl;

            std::cout << "[Global settings]" << std::endl;
            for (const auto& e : globalSection.getAll()) {
                std::cout << "  " << e.first << " = " << e.second << std::endl;
            }

            for (const auto& sec : sections) {
                std::cout << "[" << sec.first << "]" << std::endl;
                for (const auto& e : sec.second.getAll()) {
                    std::cout << "  " << e.first << " = " << e.second << std::endl;
                }
            }
        }
    };

} // namespace config

int main() {
    using namespace config;

    std::cout << "===== Configuration File Parser =====" << std::endl;

    // Create a sample configuration file
    {
        std::ofstream f("app.ini");
        f << "# Application configuration\n";
        f << "version = 1.0.0\n";
        f << "debug_mode = false\n\n";
        f << "[Database]\n";
        f << "host = localhost\n";
        f << "port = 3306\n";
        f << "username = admin\n";
        f << "max_connections = 100\n\n";
        f << "[UI]\n";
        f << "theme = dark\n";
        f << "language = zh_CN\n";
        f << "font_size = 14\n";

    }

    try {

Case 4: Simple Database Engine -- Embedded Key-Value Store
---------------------------------------------------------------
Scenario: implement a lightweight file-based Key-Value database that supports create, read,
update, and delete, using a binary index to speed up lookups.

Knowledge integrated:
- Ch3 Dynamic Memory: managing data buffers
- Ch4 Classes and Objects
- Ch8 Templates: a class template supporting any value type
- Ch9 Exception Handling: file operation exceptions
- This chapter: binary reading and writing

---------------------------------------------------------------
#include <iostream>
#include <fstream>
#include <string>
#include <vector>
#include <map>
#include <cstring>
#include <stdexcept>
#include <iomanip>

// A simple key-value storage engine
template<typename ValueType>
class KVStore {
private:
    struct IndexEntry {
        char key[64];        // key (fixed length)
        std::streampos offset;  // offset of the data in the file
        std::streamsize size;   // data size

        IndexEntry() : offset(0), size(0) {
            std::memset(key, 0, sizeof(key));
        }

        IndexEntry(const std::string& k, std::streampos off,
                   std::streamsize sz)
            : offset(off), size(sz) {
            std::strncpy(key, k.c_str(), sizeof(key) - 1);
        }
    };

    std::string dataFile;
    std::string indexFile;
    std::vector<IndexEntry> index;

    // Rebuild the index (by reading the data file)
    void rebuildIndex() {
        index.clear();
        std::ifstream data(dataFile, std::ios::binary);
        if (!data.is_open()) return;

        while (data.peek() != EOF) {
            IndexEntry entry;
            std::streampos pos = data.tellg();

            // Read the key length and the key
            int32_t keyLen = 0;
            data.read(reinterpret_cast<char*>(&keyLen), sizeof(keyLen));
            if (data.eof()) break;

            data.read(entry.key, keyLen);
            entry.key[keyLen] = '\0';

            entry.offset = pos;

            // Read the value length (skipping the value data itself)
            int32_t valLen = 0;
            data.read(reinterpret_cast<char*>(&valLen), sizeof(valLen));
            entry.size = sizeof(int32_t) + keyLen + sizeof(int32_t) + valLen;

            data.seekg(valLen, std::ios::cur);

            index.push_back(entry);
        }

        data.close();
        std::cout << "Index rebuilt: " << index.size() << " record(s)" << std::endl;
    }

    // Serialize a value
    std::string serialize(const ValueType& value) {
        return std::string(reinterpret_cast<const char*>(&value),
                          sizeof(ValueType));
    }

    // Deserialize a value
    ValueType deserialize(const char* data, std::streamsize size) {
        if (size != sizeof(ValueType))
            throw std::runtime_error("Data size mismatch");
        ValueType result;
        std::memcpy(&result, data, sizeof(ValueType));
        return result;
    }

    // Look up a key in the index
    int findIndex(const std::string& key) const {
        for (size_t i = 0; i < index.size(); ++i) {
            if (std::strcmp(index[i].key, key.c_str()) == 0)
                return static_cast<int>(i);
        }
        return -1;
    }

public:
    KVStore(const std::string& name)
        : dataFile(name + ".dat"), indexFile(name + ".idx") {
        // Rebuild the index on startup
        std::ifstream test(dataFile, std::ios::binary);
        if (test.is_open()) {
            test.close();
            rebuildIndex();
        } else {
            // New database, create an empty file
            std::ofstream create(dataFile, std::ios::binary);
            create.close();
        }
    }

    // Insert
    void insert(const std::string& key, const ValueType& value) {
        if (key.length() >= 64) {
            throw std::runtime_error("Key length cannot exceed 63 characters");
        }

        int existing = findIndex(key);
        if (existing >= 0) {
            throw std::runtime_error("Key already exists: " + key);
        }

        std::ofstream data(dataFile, std::ios::binary | std::ios::app);
        if (!data.is_open())
            throw std::runtime_error("Cannot open data file");

        std::streampos offset = data.tellp();

        // Write key length + key + value length + value
        int32_t keyLen = static_cast<int32_t>(key.length());
        data.write(reinterpret_cast<const char*>(&keyLen), sizeof(keyLen));
        data.write(key.c_str(), keyLen);

        int32_t valLen = static_cast<int32_t>(sizeof(ValueType));
        data.write(reinterpret_cast<const char*>(&valLen), sizeof(valLen));
        data.write(reinterpret_cast<const char*>(&value), sizeof(ValueType));

        std::streamsize totalSize = sizeof(int32_t) + keyLen
                                    + sizeof(int32_t) + valLen;

        index.push_back(IndexEntry(key, offset, totalSize));
        data.close();

        std::cout << "[Insert] " << key
                  << " (offset: " << offset << ")" << std::endl;
    }

    // Find
    bool find(const std::string& key, ValueType& outValue) const {
        int idx = findIndex(key);
        if (idx < 0) return false;

        std::ifstream data(dataFile, std::ios::binary);
        if (!data.is_open()) return false;

        // Seek to the record position
        data.seekg(index[idx].offset);

        // Skip the key
        int32_t keyLen;
        data.read(reinterpret_cast<char*>(&keyLen), sizeof(keyLen));
        data.seekg(keyLen, std::ios::cur);

        // Read the value
        int32_t valLen;
        data.read(reinterpret_cast<char*>(&valLen), sizeof(valLen));

        std::vector<char> buffer(valLen);
        data.read(buffer.data(), valLen);

        outValue = deserialize(buffer.data(), valLen);
        data.close();
        return true;
    }

    // Delete (mark as deleted)
    void remove(const std::string& key) {
        int idx = findIndex(key);
        if (idx < 0) {
            throw std::runtime_error("Key does not exist: " + key);
        }
        // Simplified: remove from the index (the data in the file is not actually deleted)
        index.erase(index.begin() + idx);
        std::cout << "[Delete] " << key << std::endl;
    }

    // Update
    void update(const std::string& key, const ValueType& newValue) {
        int idx = findIndex(key);
        if (idx < 0) {
            throw std::runtime_error("Key does not exist: " + key);
        }
        // Simplified: just append a new record and update the index
        remove(key);
        insert(key, newValue);
    }

    // List all keys
    std::vector<std::string> listKeys() const {
        std::vector<std::string> keys;
        for (const auto& entry : index) {
            keys.push_back(std::string(entry.key));
        }
        return keys;
    }

    // Statistics
    void stats() const {
        std::cout << "\n===== KVStore Statistics =====" << std::endl;
        std::cout << "Data file: " << dataFile << std::endl;
        std::cout << "Index file: " << indexFile << std::endl;
        std::cout << "Record count: " << index.size() << std::endl;

        std::streamsize totalSize = 0;
        for (const auto& entry : index) {
            totalSize += entry.size;
        }
        std::cout << "Total data size: " << totalSize << " bytes" << std::endl;
    }
};

int main() {
    std::cout << "===== Simple KV Database Engine =====" << std::endl;

    try {
        // Store temperature data of type double
        KVStore<double> tempDB("temperature");

        // Insert data
        tempDB.insert("Beijing", 22.5);
        tempDB.insert("Shanghai", 28.3);

namespace LogAnalyzer {

    // Log entry
    struct LogEntry {
        std::string timestamp;
        std::string level;     // INFO, WARN, ERROR, DEBUG
        std::string module;
        std::string message;
        int lineNumber;

        friend std::ostream& operator<<(std::ostream& os,
                                         const LogEntry& entry) {
            os << "[" << entry.timestamp << "]"
               << "[" << entry.level << "]"
               << "[" << entry.module << "] "
               << entry.message;
            return os;
        }
    };

    // Analysis statistics result
    struct AnalysisResult {
        int totalLines;
        int errorCount;
        int warningCount;
        int infoCount;
        std::map<std::string, int> moduleStats;
        std::map<std::string, int> errorTypes;
        std::vector<LogEntry> criticalErrors;
    };

    // Log parser
    class LogParser {
    public:
        // Parse a log line
        static bool parseLine(const std::string& line,
                              int lineNum, LogEntry& entry) {
            // Expected format: [2024-01-15 14:30:22][ERROR][Database] Connection timed out
            std::regex logPattern(
                R"(\[(\d{4}-\d{2}-\d{2}\s\d{2}:\d{2}:\d{2})\]\[(\w+)\]\[(\w+)\]\s+(.*))"
            );

            std::smatch match;
            if (std::regex_match(line, match, logPattern)) {
                entry.timestamp = match[1];
                entry.level = match[2];
                entry.module = match[3];
                entry.message = match[4];
                entry.lineNumber = lineNum;
                return true;
            }
            return false;
        }

        // Parse a whole log file
        static std::vector<LogEntry> parseFile(const std::string& filepath) {
            std::vector<LogEntry> entries;
            std::ifstream file(filepath);

            if (!file.is_open()) {
                throw std::runtime_error("Cannot open log file: " + filepath);
            }

            std::string line;
            int lineNum = 0;
            int skipped = 0;

            while (std::getline(file, line)) {
                lineNum++;
                LogEntry entry;
                if (parseLine(line, lineNum, entry)) {
                    entries.push_back(entry);
                } else {
                    skipped++;
                }
            }

            file.close();

            std::cout << "Parsing complete: " << filepath << " ("
                      << entries.size() << " log entries, "
                      << skipped << " skipped)" << std::endl;

            return entries;
        }
    };

    // Log analyzer
    class Analyzer {
    private:
        AnalysisResult result;

    public:
        void analyze(const std::vector<LogEntry>& entries) {
            result = AnalysisResult{};
            result.totalLines = entries.size();

            for (const auto& entry : entries) {
                // Count by level
                if (entry.level == "ERROR") {
                    result.errorCount++;
                    result.criticalErrors.push_back(entry);

                    // Count error types (use the leading characters as the type)
                    std::string errorType = entry.message.substr(0,
                        std::min(entry.message.length(), size_t(30)));
                    result.errorTypes[errorType]++;
                } else if (entry.level == "WARN") {
                    result.warningCount++;
                } else if (entry.level == "INFO") {
                    result.infoCount++;
                }

                // Count by module
                result.moduleStats[entry.module]++;
            }
        }

        void printReport() const {
            std::cout << "\n╔══════════════════════════════════════╗" << std::endl;
            std::cout << "║         Log Analysis Report          ║" << std::endl;
            std::cout << "╚══════════════════════════════════════╝" << std::endl;

            // Overview
            std::cout << "\n--- Overview ---" << std::endl;
            std::cout << "  Total lines: " << result.totalLines << std::endl;
            std::cout << "  ERROR:     " << result.errorCount << std::endl;
            std::cout << "  WARN:      " << result.warningCount << std::endl;
            std::cout << "  INFO:      " << result.infoCount << std::endl;

            // Module statistics
            std::cout << "\n--- Module statistics ---" << std::endl;
            for (const auto& ms : result.moduleStats) {
                std::cout << "  " << std::left << std::setw(20)
                          << ms.first << std::setw(6) << ms.second;
                // Bar chart
                int barLen = ms.second / (result.totalLines / 50 + 1);
                std::cout << std::string(barLen, '#') << std::endl;
            }

            // Error type statistics
            if (!result.errorTypes.empty()) {
                std::cout << "\n--- Common errors ---" << std::endl;
                // Sort and take the top 5
                std::vector<std::pair<std::string, int>> sortedErrors(
                    result.errorTypes.begin(), result.errorTypes.end());
                std::sort(sortedErrors.begin(), sortedErrors.end(),
                    [](const auto& a, const auto& b) {
                        return a.second > b.second;
                    });

                int shown = 0;
                for (const auto& err : sortedErrors) {
                    if (shown++ >= 5) break;
                    std::cout << "  [" << err.second << "x] "
                              << err.first << std::endl;
                }
            }

            // Critical error details
            if (!result.criticalErrors.empty()) {
                std::cout << "\n--- Critical error details (first 3) ---" << std::endl;
                int shown = 0;
                for (const auto& err : result.criticalErrors) {
                    if (shown++ >= 3) break;
                    std::cout << "  " << err << std::endl;
                }
            }
        }

        // Save the report to an HTML file
        void saveHTMLReport(const std::string& filename) const {
            std::ofstream file(filename);
            if (!file.is_open())
                throw std::runtime_error("Cannot create report file");

            file << "<html><head><meta charset='utf-8'><title>Log Analysis Report</title>"
                 << "<style>body{font-family:monospace;background:#1e1e1e;color:#d4d4d4;padding:20px;}"
                 << "table{border-collapse:collapse;width:100%;}"
                 << "th,td{border:1px solid #555;padding:8px;text-align:left;}"
                 << "th{background:#333;}.error{color:#f44747;}.warn{color:#cca700;}.info{color:#6a9955;}"
                 << "</style></head><body>"
                 << "<h1>Log Analysis Report</h1>";

            file << "<h2>Overview</h2><table><tr><th>Metric</th><th>Value</th></tr>";
            file << "<tr><td>Total lines</td><td>" << result.totalLines << "</td></tr>";
            file << "<tr><td class='error'>ERROR</td><td>" << result.errorCount << "</td></tr>";
            file << "<tr><td class='warn'>WARN</td><td>" << result.warningCount << "</td></tr>";
            file << "<tr><td class='info'>INFO</td><td>" << result.infoCount << "</td></tr>";
            file << "</table>";

            file << "</body></html>";
            file.close();
            std::cout << "HTML report saved: " << filename << std::endl;
        }
    };

    // Log directory analyzer
    class LogDirectoryAnalyzer {
    private:
        std::vector<std::string> logFiles;

    public:
        void scanDirectory(const std::string& dirPath) {
            if (!fs::exists(dirPath)) {
                throw std::runtime_error("Directory does not exist: " + dirPath);
            }

            for (const auto& entry : fs::directory_iterator(dirPath)) {
                if (entry.is_regular_file() &&
                    entry.path().extension() == ".log") {
                    logFiles.push_back(entry.path().string());
                    std::cout << "Found log: " << entry.path().filename()
                              << std::endl;
                }
            }

            std::cout << "Found " << logFiles.size()
                      << " log file(s) in total" << std::endl;
        }

        void analyzeAll() const {
            std::vector<LogEntry> allEntries;

            for (const auto& filepath : logFiles) {
                try {
                    auto entries = LogParser::parseFile(filepath);
                    allEntries.insert(allEntries.end(),
                                      entries.begin(), entries.end());
                }
                catch (const std::exception& e) {
                    std::cerr << "Parsing failed: " << filepath
                              << " - " << e.what() << std::endl;
                }
            }

            Analyzer analyzer;
            analyzer.analyze(allEntries);
            analyzer.printReport();
            analyzer.saveHTMLReport("log_report.html");
        }
    };

[About This Tutorial]

This tutorial is aimed at readers who already know basic C++ syntax. Its goal is to
take learners from "able to use C++" to "understanding C++". It covers C++'s core
mechanisms, memory model, concurrent programming, network programming, and the
standard library in depth, including modern features from C++11/14/17/20. Every topic
comes with an analysis of the underlying principles and real-life scenario examples,
helping readers build a complete C++ knowledge system.

Recommended order: study chapters 1 -> 14 in sequence, because each chapter's examples
build on knowledge from earlier chapters, forming a spiral learning curve. If you skip
around, you may run into syntax in the examples that you haven't learned yet.


[About the Learning Roadmap]

Why this order?

Ch. 1-3   (Foundations+)        Namespaces -> Preprocessor -> Dynamic Memory
  These three chapters are C++'s basic tools. Namespaces solve symbol conflicts in
  large projects; the preprocessor is the code-processing stage before compilation;
  dynamic memory is the core difference between C++ and Java/C# -- the programmer
  manages heap memory directly. They come first because nearly every later chapter uses them.

Ch. 4-6   (OOP Core)            Classes and Objects -> Inheritance -> Polymorphism
  C++'s core paradigm: object-oriented programming. Going from encapsulation to
  inheritance to polymorphism is the classic progressive route. Polymorphism is the
  pinnacle of OOP and the foundation of design patterns. It also paves the way for
  operator overloading and templates.

Ch. 7-8   (Intro to Generics)   Operator Overloading -> Function Templates
  Operator overloading lets user-defined types feel as natural as built-in types;
  templates open the door to generic programming. These two chapters lay the
  groundwork for understanding how the STL is implemented.

Ch. 9-11  (Practical Skills)    Exception Handling -> Files and Streams -> Signal Handling
  Exception handling makes programs more robust; files and streams are the basis of
  data persistence; signal handling lets programs respond to operating system events.
  Together these chapters build the ability to write production-grade C++ programs.

Ch. 12    (Concurrency)         Multithreading
  Multithreading is a major topic in modern C++. Mastering threads, mutexes, condition
  variables, atomics, and asynchronous programming is an essential skill for
  high-performance servers and systems software.

Ch. 13    (Networking)          Web Programming
  Socket programming is one of the most common uses of C++ in real-world engineering.
  From the TCP/IP stack to the HTTP protocol, from clients to servers, network
  programming is the bridge between C++ and the outside world.

Ch. 14    (Standard Library)    The C++ Standard Library
  The STL is the essence of C++. A thorough command of containers, algorithms,
  iterators, function objects, smart pointers, and the library components added in
  C++14/17/20 is the key to writing efficient, elegant C++ code.

This roadmap follows the logic "language basics -> OOP -> generics -> practice ->
concurrency -> networking -> standard library", moving from simple to deep and from
the inside out (first master the language itself, then interact with the system, and
finally make good use of the standard library).

[Study Tips]

1. Hands-on practice is king
   - Type out every code example yourself; don't copy and paste
   - Modify the example code and observe how the behavior changes
   - Try different compiler optimization levels (-O0/-O2/-O3) and compare the results

2. Understand the underlying principles
   - The "under the hood" part of each "Section 1" is the heart of this tutorial
   - Knowing "how" is only the start; knowing "why" is real progress
   - Use tools such as objdump/gdb/valgrind to observe program behavior

3. Connect everything together
   - Examples in later chapters build on knowledge from earlier chapters
   - When doing the exercises, actively apply what you've already learned
   - Try solving the same problem in different ways to appreciate C++'s flexibility

4. Study systematically
   - Spend about 2-3 days per chapter (1 day understanding + 1 day practicing + 1 day on exercises)
   - After every 3-4 chapters, go back and review the key points of earlier ones
   - Use the C++ reference documentation (cppreference.com) as the authoritative reference

5. Get fluent with the toolchain
   - Compiler: GCC 10+ or Clang 14+ or MSVC 2019+
   - Compiler flags: -std=c++17 -Wall -Wextra -g -O2
   - Debugger: gdb/lldb
   - Memory checking: valgrind --tool=memcheck
   - Thread checking: valgrind --tool=helgrind
   - Profiling: perf/gprof

6. Further reading
   - "Effective Modern C++" by Scott Meyers
   - "C++ Concurrency in Action" by Anthony Williams
   - "The C++ Standard Library" by Nicolai Josuttis
   - https://en.cppreference.com/ Online C++ reference
   - https://isocpp.org/ The C++ Standards Committee

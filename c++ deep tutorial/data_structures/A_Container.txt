## Chapter Overview

Containers are one of the most central components of the C++ Standard Template Library (STL).
A container is an object used to store and organize a collection of data. It encapsulates the
details of managing data storage and access, letting developers focus on business logic.

The C++ standard library provides many containers. Each is based on a particular data structure
and suits different use cases. This chapter starts from the most basic container concepts, digs
into the underlying data structures, covers the usage of every standard container in full, and
finally consolidates what you've learned through examples and exercises.

### Section 1: Basic Syntax + Underlying Computer Principles
================================================================================

1.1 Basic Container Concepts
----------------------------

A container is "an object that holds data". In C++, the core characteristics of a container are:
- It manages the lifetime of a group of elements
- It provides an interface for inserting, removing, and accessing elements
- It provides a uniform way to traverse elements through iterators
- It comes with specific time-complexity guarantees

The most basic container example -- std::vector:

```cpp
#include <iostream>
#include <vector>

int main() {
    // Create a vector container
    std::vector<int> numbers;

    // Add elements
    numbers.push_back(10);
    numbers.push_back(20);
    numbers.push_back(30);

    // Access and traverse elements
    std::cout << "First element: " << numbers[0] << std::endl;
    std::cout << "Number of elements: " << numbers.size() << std::endl;

    // Traverse with a range-based for loop
    for (int num : numbers) {
        std::cout << num << " ";
    }
    std::cout << std::endl;

    // Traverse with iterators
    for (auto it = numbers.begin(); it != numbers.end(); ++it) {
        std::cout << *it << " ";
    }
    std::cout << std::endl;

    return 0;
}
```

1.2 Under the Hood: Contiguous Storage vs Node Storage
-------------------------------------------------------

Containers fall into two broad categories based on how they store data:

(1) Contiguous Containers
- vector, array, deque, string
- Elements are laid out contiguously in memory
- Direct access via pointer offset (O(1) random access)
- Inserting/removing in the middle requires shifting many elements (O(n))

(2) Node-based Containers
- list, forward_list, map, set, unordered_map, etc.
- Each element is allocated separately on the heap; nodes are linked by pointers
- No random access (or only limited random access)
- Inserting/removing in the middle only requires updating pointers (O(1) or O(log n))

Memory layout comparison:

```
Contiguous storage (vector):
+------+------+------+------+------+------+
| 0x00 | 0x04 | 0x08 | 0x0c | 0x10 | 0x14 |  <- contiguous addresses
| elem0| elem1| elem2| elem3|      |      |
+------+------+------+------+------+------+
         ^ arr[1] = *(arr + 1)

Node storage (list):
+------+     +------+     +------+
| prev | <--> | prev | <--> | prev |
| elem0|     | elem1|     | elem2|
| next | --> | next | --> | next |
+------+     +------+     +------+
 0x100        0x200        0x300     <- non-contiguous addresses
```

1.3 How Iterators Work
----------------------

Iterators are the bridge between containers and algorithms. They abstract the concept of
"traversing elements", so algorithms don't need to care about the concrete type of the
underlying container.

An iterator is essentially a "smart pointer" that supports pointer-like operations:
- operator*  : dereference, get the element currently pointed to
- operator++ : advance to the next element
- operator-- : step back to the previous element (bidirectional iterators only)
- operator[] : random access (random-access iterators only)
- operator==/!= : compare whether two iterators are equal

```cpp
#include <iostream>
#include <vector>
#include <list>

int main() {
    // vector provides random-access iterators
    std::vector<int> vec = {10, 20, 30, 40, 50};
    auto vit = vec.begin();
    std::cout << "vec[0] = " << *vit << std::endl;
    std::cout << "vec[2] = " << *(vit + 2) << std::endl;  // random access
    std::cout << "vec[3] = " << vit[3] << std::endl;       // subscript access

    // list provides bidirectional iterators (no random access)
    std::list<int> lst = {10, 20, 30, 40, 50};
    auto lit = lst.begin();
    std::cout << "list first = " << *lit << std::endl;
    // std::cout << *(lit + 2);  // Error! list does not support random access
    std::advance(lit, 2);  // move using the advance function
    std::cout << "list third = " << *lit << std::endl;

    return 0;
}
```

1.4 Container Classification
----------------------------

C++ standard library containers fall into three main categories by organization:

Sequence Containers:
- array       : fixed-size array, contiguous storage
- vector      : dynamic array, grows automatically, contiguous storage
- deque       : double-ended queue, segmented contiguous storage
- forward_list: singly linked list, node storage
- list        : doubly linked list, node storage
- basic_string: character sequence container

Associative Containers (ordered, based on red-black trees):
- set         : set, elements unique and ordered
- multiset    : multiset, elements may repeat, ordered
- map         : map, keys unique and ordered
- multimap    : multimap, keys may repeat, ordered

Unordered Associative Containers (based on hash tables):
- unordered_set       : unordered set, elements unique
- unordered_multiset  : unordered multiset
- unordered_map       : unordered map
- unordered_multimap  : unordered multimap

Container Adapters (wrappers around an underlying container):
- stack       : stack (LIFO), based on deque by default
- queue       : queue (FIFO), based on deque by default
- priority_queue: priority queue, based on vector by default

1.5 Under the Hood: Memory Allocation and Growth Strategy
---------------------------------------------------------

Taking the most commonly used container, vector, as an example, the underlying principles reveal how a "dynamic array" is implemented:

```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> vec;

    std::cout << "Initial: size=" << vec.size()
              << " capacity=" << vec.capacity() << std::endl;

    // Observe vector's capacity growth strategy
    for (int i = 0; i < 20; ++i) {
        vec.push_back(i);
        std::cout << "push_back(" << i << "): size=" << vec.size()
                  << " capacity=" << vec.capacity() << std::endl;
    }

    return 0;
}
```

Internally, vector maintains three pointers:
- _start : points to the start of the allocated memory
- _finish: points to the end of the used elements (i.e. the size position)
- _end_of_storage: points to the end of the allocated memory (i.e. the capacity position)

Growth process:
1. On push_back, check whether _finish == _end_of_storage
2. If capacity is full, allocate new memory (typically 1.5x to 2x the current capacity)
3. Move/copy the old elements into the new memory
4. Free the old memory
5. Update the pointers

GCC's vector grows by a factor of 2, while Visual Studio's vector grows by a factor of 1.5.
Growing is an O(n) operation, but amortized over many calls, push_back has O(1) amortized time complexity.

```cpp
// A hand-written, simplified version of vector's growth logic (conceptual demo)
#include <iostream>
#include <algorithm>  // std::copy

template<typename T>
class SimpleVector {
private:
    T* _start;
    T* _finish;
    T* _end_of_storage;

    void reallocate() {
        size_t old_size = size();
        size_t new_capacity = old_size == 0 ? 1 : old_size * 2;

        T* new_start = new T[new_capacity];

        // Copy old elements into the new memory
        for (size_t i = 0; i < old_size; ++i) {
            new_start[i] = _start[i];
        }

        // Free the old memory
        delete[] _start;

        // Update the pointers
        _start = new_start;
        _finish = _start + old_size;
        _end_of_storage = _start + new_capacity;

        std::cout << "  Grow: " << old_size << " -> " << new_capacity << std::endl;
    }

public:
    SimpleVector() : _start(nullptr), _finish(nullptr), _end_of_storage(nullptr) {}

    ~SimpleVector() { delete[] _start; }

    size_t size() const { return _finish - _start; }
    size_t capacity() const { return _end_of_storage - _start; }

    void push_back(const T& value) {
        if (_finish == _end_of_storage) {
            reallocate();
        }
        *_finish = value;
        ++_finish;
    }

    T& operator[](size_t index) { return _start[index]; }
};

int main() {
    SimpleVector<int> vec;

    for (int i = 0; i < 8; ++i) {
        vec.push_back(i);
        std::cout << "Add " << i << ": size=" << vec.size()
                  << " capacity=" << vec.capacity() << std::endl;
    }

    std::cout << "\nAll elements: ";
    for (size_t i = 0; i < vec.size(); ++i) {
        std::cout << vec[i] << " ";
    }
    std::cout << std::endl;

    return 0;
}
```

2.1 std::vector -- Dynamic Array
--------------------------------

The most general-purpose sequence container. Contiguous memory, O(1) random access, amortized O(1) insertion/removal at the back.

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

int main() {
    // Various ways to construct
    std::vector<int> v1;                       // empty vector
    std::vector<int> v2(5);                    // 5 default values (0)
    std::vector<int> v3(5, 10);                // five 10s
    std::vector<int> v4 = {1, 2, 3, 4, 5};     // initializer list
    std::vector<int> v5(v4);                   // copy construction
    std::vector<int> v6(v4.begin(), v4.end()); // iterator-range construction

    // Element access
    std::cout << "front: " << v4.front() << std::endl;  // first element
    std::cout << "back: " << v4.back() << std::endl;    // last element
    std::cout << "at(2): " << v4.at(2) << std::endl;    // with bounds checking
    std::cout << "[2]: " << v4[2] << std::endl;         // no bounds checking
    std::cout << "data: " << v4.data() << std::endl;    // pointer to underlying array

    // Adding and removing
    v4.push_back(6);           // append at the back
    v4.pop_back();             // remove from the back
    v4.insert(v4.begin() + 2, 99);  // insert in the middle
    v4.erase(v4.begin() + 1);       // erase in the middle
    v4.resize(10);             // change size (extra elements default-constructed)
    v4.reserve(100);           // reserve capacity (does not change size)

    // Capacity-related
    std::cout << "size: " << v4.size() << std::endl;
    std::cout << "capacity: " << v4.capacity() << std::endl;
    std::cout << "empty: " << v4.empty() << std::endl;

    // Traversal
    for (size_t i = 0; i < v4.size(); ++i)  // index traversal
        std::cout << v4[i] << " ";

    for (int x : v4)                         // range-based for
        std::cout << x << " ";

    for (auto it = v4.begin(); it != v4.end(); ++it)  // iterators
        std::cout << *it << " ";

    // Working with algorithms
    std::sort(v4.begin(), v4.end());         // sort
    auto it = std::find(v4.begin(), v4.end(), 99);  // find
    std::reverse(v4.begin(), v4.end());     // reverse

    // New in C++11: emplace_back (constructs in place, avoids copying)
    struct Point { int x, y; Point(int a, int b) : x(a), y(b) {} };
    std::vector<Point> points;
    points.emplace_back(3, 4);  // constructed directly inside the container, no temporary
    points.push_back(Point(1, 2));  // push_back needs a temporary object first

    // shrink_to_fit: release excess capacity
    v4.shrink_to_fit();

    return 0;
}
```

2.2 std::array -- Fixed-Size Array
----------------------------------

Introduced in C++11, it wraps a built-in array, providing the STL container interface but no dynamic growth.

```cpp
#include <iostream>
#include <array>
#include <algorithm>

int main() {
    // Construction
    std::array<int, 5> arr1 = {1, 2, 3, 4, 5};
    std::array<int, 5> arr2{};  // all initialized to 0

    // Access
    std::cout << "arr1[0]: " << arr1[0] << std::endl;
    std::cout << "arr1.at(1): " << arr1.at(1) << std::endl;
    std::cout << "front: " << arr1.front() << std::endl;
    std::cout << "back: " << arr1.back() << std::endl;
    std::cout << "data: " << arr1.data() << std::endl;  // pointer to the underlying C array

    // Size
    std::cout << "size: " << arr1.size() << std::endl;      // 5
    std::cout << "max_size: " << arr1.max_size() << std::endl;

    // Sorting
    std::array<int, 5> arr3 = {5, 3, 1, 4, 2};
    std::sort(arr3.begin(), arr3.end());

    // Filling
    arr2.fill(42);  // set every element to 42

    // Get the underlying C array
    int* raw_ptr = arr1.data();

    // Compile-time size (template parameter)
    std::cout << std::tuple_size<std::array<int, 5>>::value << std::endl;

    return 0;
}
```

2.3 std::deque -- Double-Ended Queue
------------------------------------

Segmented contiguous storage; supports fast O(1) insertion/removal at both ends and O(1) random access.

Internally it consists of multiple fixed-size buffers (blocks), managed by a central controller (the map).

```cpp
#include <iostream>
#include <deque>

int main() {
    std::deque<int> dq = {10, 20, 30};

    // Operations at both ends
    dq.push_front(5);    // insert at the front
    dq.push_back(40);    // insert at the back
    dq.pop_front();      // remove from the front
    dq.pop_back();       // remove from the back

    // Access (random access supported, but one extra level of indirection compared to vector)
    std::cout << "dq[0]: " << dq[0] << std::endl;
    std::cout << "front: " << dq.front() << std::endl;
    std::cout << "back: " << dq.back() << std::endl;

    // Insert/erase in the middle (slightly better than vector, but still shifts some elements)
    dq.insert(dq.begin() + 1, 99);
    dq.erase(dq.begin() + 2);

    // Traversal
    for (int x : dq) std::cout << x << " ";
    std::cout << std::endl;

    return 0;
}
```

2.4 std::list -- Doubly Linked List
-----------------------------------

Implemented as a doubly linked list; each node contains a previous pointer, a next pointer, and the data.
Insertion/removal is O(1), but random access is not supported.

```cpp
#include <iostream>
#include <list>
#include <algorithm>

int main() {
    std::list<int> lst = {3, 1, 4, 1, 5, 9};

    // Adding and removing
    lst.push_front(0);
    lst.push_back(10);
    lst.pop_front();
    lst.pop_back();

    // Insertion (inserts before pos)
    auto it = std::find(lst.begin(), lst.end(), 4);
    if (it != lst.end()) {
        lst.insert(it, 100);  // insert 100 before 4
    }

    // Removal
    lst.remove(1);         // remove all elements equal to 1
    lst.remove_if([](int x) { return x > 5; });  // remove all elements > 5

    // List-specific operations
    lst.sort();                            // sort
    lst.unique();                          // remove consecutive duplicates
    lst.reverse();                         // reverse

    std::list<int> other = {100, 200};
    lst.splice(lst.end(), other);          // splice the other list onto the end of lst
    // other is now empty

    // Merge (both lists must already be sorted)
    std::list<int> a = {1, 3, 5};
    std::list<int> b = {2, 4, 6};
    a.merge(b);                            // a becomes {1,2,3,4,5,6}, b is empty

    // Traversal (sequential access only)
    for (int x : lst) std::cout << x << " ";

    return 0;
}
```

2.5 std::forward_list -- Singly Linked List
-------------------------------------------

Introduced in C++11, it uses less memory than list (only a next pointer, no previous pointer).
It supports only forward traversal and fast insertion/removal only at the head.

```cpp
#include <iostream>
#include <forward_list>

int main() {
    std::forward_list<int> flst = {1, 2, 3, 4, 5};

    // Operations only at the head
    flst.push_front(0);
    flst.pop_front();

    // Insert after a given position (you must find the predecessor first)
    auto it = flst.before_begin();  // position before the first element
    flst.insert_after(it, 99);     // insert after the head position (becomes the first element)

    // Erase the element after a given position
    flst.erase_after(flst.before_begin());  // erase the first element

    // Specific operations
    flst.sort();
    flst.unique();
    flst.reverse();
    flst.merge(std::forward_list<int>{2, 4, 6});

    // Traversal (forward iterators only)
    for (int x : flst) std::cout << x << " ";

    return 0;
}
```

2.6 std::set and std::multiset -- Sets
--------------------------------------

Implemented with red-black trees; elements are sorted automatically, and insert/erase/find are all O(log n).

```cpp
#include <iostream>
#include <set>

int main() {
    // set: elements are unique
    std::set<int> s = {3, 1, 4, 1, 5, 9};  // actually stored: {1, 3, 4, 5, 9}

    // Insertion
    s.insert(2);
    s.insert(2);  // fails, 2 already exists; returns pair{iterator, false}

    // Lookup
    auto it = s.find(4);
    if (it != s.end()) {
        std::cout << "Found: " << *it << std::endl;
    }

    // Counting
    std::cout << "Count of 3 in s: " << s.count(3) << std::endl;  // 0 or 1

    // Removal
    s.erase(1);    // erase the element with the given value
    auto it2 = s.find(5);
    if (it2 != s.end()) s.erase(it2);  // erase via iterator

    // Range operations
    auto lower = s.lower_bound(3);  // first element >= 3
    auto upper = s.upper_bound(6);  // first element > 6
    for (auto it3 = lower; it3 != upper; ++it3) {
        std::cout << *it3 << " ";  // elements in the range [3, 6)
    }

    // multiset: duplicates allowed
    std::multiset<int> ms = {1, 2, 2, 3, 3, 3};
    std::cout << "2 appears " << ms.count(2) << " times" << std::endl;
    ms.erase(2);  // erase all elements equal to 2

    // equal_range: get the range of duplicate elements
    auto [begin, end] = ms.equal_range(3);
    for (auto it4 = begin; it4 != end; ++it4) {
        std::cout << *it4 << " ";
    }

    // Custom ordering
    std::set<int, std::greater<int>> desc_set = {3, 1, 4, 1, 5, 9};
    // Descending set: {9, 5, 4, 3, 1}

    return 0;
}
```

2.7 std::map and std::multimap -- Maps
--------------------------------------

Implemented with red-black trees; stores key-value pairs sorted by key, and insert/erase/find are all O(log n).

```cpp
#include <iostream>
#include <map>
#include <string>

int main() {
    // map: keys are unique
    std::map<std::string, int> ages;

    // Ways to insert
    ages["Alice"] = 25;     // via operator[]
    ages["Bob"] = 30;
    ages.insert({"Charlie", 35});     // via initializer list
    ages.insert(std::make_pair("David", 28));  // via make_pair
    ages.emplace("Eve", 22);          // in-place construction

    // Access
    std::cout << "Alice's age: " << ages["Alice"] << std::endl;
    std::cout << "Bob's age: " << ages.at("Bob") << std::endl;
    // ages.at("Unknown");  // throws std::out_of_range

    // Lookup
    auto it = ages.find("Charlie");
    if (it != ages.end()) {
        std::cout << "Found: " << it->first << " -> " << it->second << std::endl;
    }

    // Check whether a key exists
    if (ages.count("David") > 0) {
        std::cout << "David exists in the map" << std::endl;
    }

    // Removal
    ages.erase("Eve");          // erase by key
    auto it2 = ages.find("David");
    if (it2 != ages.end()) ages.erase(it2);  // erase by iterator

    // Traversal
    for (const auto& [key, value] : ages) {  // C++17 structured bindings
        std::cout << key << " : " << value << std::endl;
    }

    // multimap: keys may repeat
    std::multimap<std::string, std::string> phonebook;
    phonebook.insert({"John", "13800138000"});
    phonebook.insert({"John", "13900139000"});  // same person, multiple numbers
    phonebook.insert({"Mary", "13700137000"});

    // Get all values associated with a key
    auto range = phonebook.equal_range("John");
    for (auto it3 = range.first; it3 != range.second; ++it3) {
        std::cout << it3->first << " : " << it3->second << std::endl;
    }

    return 0;
}
```

2.8 std::unordered_set and std::unordered_map -- Unordered Containers
---------------------------------------------------------------------

Implemented with hash tables; average O(1) insert/erase/find, elements stored in no particular order.

```cpp
#include <iostream>
#include <unordered_set>
#include <unordered_map>
#include <string>

int main() {
    // unordered_set
    std::unordered_set<int> us = {5, 3, 1, 3, 2, 5};
    us.insert(10);
    us.erase(3);

    if (us.find(5) != us.end()) {
        std::cout << "5 exists in the set" << std::endl;
    }

    // Bucket interface
    std::cout << "Bucket count: " << us.bucket_count() << std::endl;
    std::cout << "Load factor: " << us.load_factor() << std::endl;
    us.rehash(50);  // rehash, setting the number of buckets

    // unordered_map
    std::unordered_map<std::string, double> prices;
    prices["apple"] = 5.5;
    prices["banana"] = 3.0;
    prices["cherry"] = 15.0;

    // Custom hash function (for user-defined types)
    struct Person {
        std::string name;
        int age;
        bool operator==(const Person& other) const {
            return name == other.name && age == other.age;
        }
    };

    struct PersonHash {
        size_t operator()(const Person& p) const {
            return std::hash<std::string>()(p.name) ^
                   (std::hash<int>()(p.age) << 1);
        }
    };

    std::unordered_set<Person, PersonHash> people;
    people.insert({"Alice", 25});
    people.insert({"Bob", 30});

    return 0;
}
```

2.9 Container Adapters: stack, queue, priority_queue
----------------------------------------------------

Container adapters wrap the interface of an underlying container, providing a restricted, specific data-access pattern.

```cpp
#include <iostream>
#include <stack>
#include <queue>
#include <vector>

int main() {
    // ========== stack (LIFO) ==========
    std::stack<int> stk;

    stk.push(10);
    stk.push(20);
    stk.push(30);

    std::cout << "Top of stack: " << stk.top() << std::endl;  // 30
    stk.pop();  // pop the top

    while (!stk.empty()) {
        std::cout << stk.top() << " ";
        stk.pop();
    }
    std::cout << std::endl;

    // Specify vector as the underlying container
    std::stack<int, std::vector<int>> vec_stack;

    // ========== queue (FIFO) ==========
    std::queue<int> que;

    que.push(10);
    que.push(20);
    que.push(30);

    std::cout << "Front of queue: " << que.front() << std::endl;  // 10
    std::cout << "Back of queue: " << que.back() << std::endl;   // 30
    que.pop();  // pop the front

    // ========== priority_queue ==========
    // Max-heap by default (largest element on top)
    std::priority_queue<int> pq;

    pq.push(30);
    pq.push(10);
    pq.push(50);
    pq.push(20);

    std::cout << "Highest priority: " << pq.top() << std::endl;  // 50

    // Min-heap: use greater
    std::priority_queue<int, std::vector<int>, std::greater<int>> min_pq;
    min_pq.push(30);
    min_pq.push(10);
    min_pq.push(50);
    std::cout << "Lowest priority: " << min_pq.top() << std::endl;  // 10

    return 0;
}
```

Example 1: Student Grade Management System
------------------------------------------

Scenario: use a map to store student names and grades, and vectors to store each student's list of scores, then compute statistics.

```cpp
#include <iostream>
#include <vector>
#include <map>
#include <string>
#include <numeric>    // std::accumulate
#include <algorithm>  // std::sort, std::max_element
#include <iomanip>    // std::setprecision

class GradeManager {
private:
    std::map<std::string, std::vector<double>> records;

public:
    void addScore(const std::string& name, double score) {
        records[name].push_back(score);
    }

    double getAverage(const std::string& name) const {
        auto it = records.find(name);
        if (it == records.end() || it->second.empty()) return 0.0;

        const auto& scores = it->second;
        double sum = std::accumulate(scores.begin(), scores.end(), 0.0);
        return sum / scores.size();
    }

    double getClassAverage() const {
        double total = 0.0;
        int count = 0;
        for (const auto& [name, scores] : records) {
            for (double s : scores) {
                total += s;
                ++count;
            }
        }
        return count > 0 ? total / count : 0.0;
    }

    std::string getTopStudent() const {
        if (records.empty()) return "";

        std::string top_name;
        double top_avg = 0.0;

        for (const auto& [name, scores] : records) {
            double avg = getAverage(name);
            if (avg > top_avg) {
                top_avg = avg;
                top_name = name;
            }
        }
        return top_name;
    }

    void printReport() const {
        std::cout << "\n========== Grade Report ==========" << std::endl;

        // Use a vector to sort student names
        std::vector<std::string> names;
        for (const auto& [name, _] : records) {
            names.push_back(name);
        }
        std::sort(names.begin(), names.end());

        for (const auto& name : names) {
            const auto& scores = records.at(name);
            double avg = getAverage(name);
            double max_score = *std::max_element(scores.begin(), scores.end());

            std::cout << name << ": ";
            for (double s : scores) std::cout << s << " ";
            std::cout << "| Average: " << std::fixed << std::setprecision(1)
                      << avg << " | Highest: " << max_score << std::endl;
        }

        std::cout << "Class average: " << std::fixed << std::setprecision(1)
                  << getClassAverage() << std::endl;
        std::cout << "Top student: " << getTopStudent() << std::endl;
    }
};

int main() {
    GradeManager gm;

    gm.addScore("John", 85.5);
    gm.addScore("John", 90.0);
    gm.addScore("Mary", 78.0);
    gm.addScore("Mary", 82.5);
    gm.addScore("Peter", 95.0);
    gm.addScore("Peter", 88.0);
    gm.addScore("Peter", 92.5);

    gm.printReport();

    return 0;
}
```

Example 2: LRU Cache (Least Recently Used)
------------------------------------------

Implements an O(1) LRU cache using list + unordered_map, demonstrating how containers can be combined.

```cpp
#include <iostream>
#include <list>
#include <unordered_map>

class LRUCache {
private:
    int capacity;
    std::list<std::pair<int, int>> items;
    std::unordered_map<int, std::list<std::pair<int, int>>::iterator> cache;

public:
    LRUCache(int cap) : capacity(cap) {}

    int get(int key) {
        auto it = cache.find(key);
        if (it == cache.end()) return -1;

        // Move to the head of the list (most recently used)
        items.splice(items.begin(), items, it->second);
        return it->second->second;
    }

    void put(int key, int value) {
        auto it = cache.find(key);
        if (it != cache.end()) {
            // Key already exists: update the value and move it to the head
            it->second->second = value;
            items.splice(items.begin(), items, it->second);
            return;
        }

        // If full, remove the least recently used entry (the tail of the list)
        if (items.size() >= capacity) {
            int old_key = items.back().first;
            cache.erase(old_key);
            items.pop_back();
        }

        // Insert at the head
        items.emplace_front(key, value);
        cache[key] = items.begin();
    }

    void print() const {
        std::cout << "Cache contents (most recent -> least recent): ";
        for (const auto& [k, v] : items) {
            std::cout << "[" << k << ":" << v << "] ";
        }
        std::cout << std::endl;
    }
};

int main() {
    LRUCache cache(3);

    cache.put(1, 100);
    cache.put(2, 200);
    cache.put(3, 300);
    cache.print();

    std::cout << "get(2): " << cache.get(2) << std::endl;
    cache.print();

    cache.put(4, 400);  // evicts key=1
    cache.print();

    std::cout << "get(1): " << cache.get(1) << std::endl;  // -1 (evicted)

    return 0;
}
```

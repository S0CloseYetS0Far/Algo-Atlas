## Chapter Overview

A stack is a restricted linear data structure that follows the "Last In, First Out" (LIFO)
principle. Stacks are used extremely widely in computer science: the function call stack,
expression evaluation, bracket matching, a browser's back button, undo operations, and more.

This chapter starts from the basic concept of a stack, digs into how stacks are implemented
under the hood, covers every way of using a stack, and finally consolidates what you've learned
through examples and exercises.

### Section 1: Basic Syntax + Underlying Computer Principles
================================================================================

1.1 Basic Stack Concepts
------------------------

A stack is a linear list in which insertions and removals can only happen at one end (called the "top").

Core operations:
- push  : push an element onto the top of the stack
- pop   : pop the top element
- top   : get the top element (without popping it)
- empty : check whether the stack is empty
- size  : return the number of elements in the stack

The most basic stack example:

```cpp
#include <iostream>
#include <stack>

int main() {
    std::stack<int> stk;

    // Push
    stk.push(10);
    stk.push(20);
    stk.push(30);

    // Access the top
    std::cout << "Top element: " << stk.top() << std::endl;  // 30

    // Pop
    stk.pop();
    std::cout << "Top after popping one element: " << stk.top() << std::endl;  // 20

    // Size
    std::cout << "Stack size: " << stk.size() << std::endl;  // 2

    // Traverse and empty the stack
    while (!stk.empty()) {
        std::cout << stk.top() << " ";
        stk.pop();
    }
    std::cout << std::endl;

    return 0;
}
```

1.2 Under the Hood: The Function Call Stack
-------------------------------------------

The stack data structure has direct hardware support at the lowest level of the computer -- this is the "call stack".

When a function is called, the system allocates a "stack frame" on the call stack to store:
- The function's local variables
- The function's parameters
- The return address (where to jump once the function finishes)
- Saved register state

When the function call ends, its stack frame is popped and control returns to the caller.

```cpp
#include <iostream>

void funcC() {
    std::cout << "funcC called" << std::endl;
    // funcC's stack frame: local variables + return address
}

void funcB() {
    std::cout << "funcB called" << std::endl;
    funcC();
}

void funcA() {
    std::cout << "funcA called" << std::endl;
    funcB();
}

int main() {
    std::cout << "main starts" << std::endl;
    funcA();
    std::cout << "main ends" << std::endl;
    return 0;
}
```

How the call stack changes while the code above runs:

```
Initial state:
+-------------------+
| main frame        |
+-------------------+

After calling funcA:
+-------------------+
| funcA frame       |
+-------------------+
| main frame        |
+-------------------+

After calling funcB:
+-------------------+
| funcB frame       |
+-------------------+
| funcA frame       |
+-------------------+
| main frame        |
+-------------------+

After calling funcC:
+-------------------+
| funcC frame       |
+-------------------+
| funcB frame       |
+-------------------+
| funcA frame       |
+-------------------+
| main frame        |
+-------------------+

After funcC returns:
+-------------------+
| funcB frame       |
+-------------------+
| funcA frame       |
+-------------------+
| main frame        |
+-------------------+
```

1.3 How Stack Overflow Happens
------------------------------

The stack has a limited size (typically 1MB to 8MB, depending on the operating system and compiler settings).
If recursion goes too deep or local variables are too large, you get a "stack overflow".

```cpp
// Excessively deep recursion causes a stack overflow
#include <iostream>

void deepRecursion(int depth) {
    int local_array[1000];  // each recursion level consumes about 4KB of stack space
    std::cout << "Depth: " << depth << std::endl;
    deepRecursion(depth + 1);  // eventually causes a segmentation fault
}

int main() {
    deepRecursion(1);
    return 0;
}
```

1.4 Implementing a Stack by Hand (Array-Based)
----------------------------------------------

Understanding how a stack is implemented helps us understand in depth how it works:

```cpp
#include <iostream>
#include <stdexcept>

template<typename T, size_t MAX_SIZE = 100>
class ArrayStack {
private:
    T data[MAX_SIZE];
    size_t top_index;  // current top-of-stack position

public:
    ArrayStack() : top_index(0) {}

    void push(const T& value) {
        if (top_index >= MAX_SIZE) {
            throw std::overflow_error("Stack overflow!");
        }
        data[top_index++] = value;
    }

    void pop() {
        if (empty()) {
            throw std::underflow_error("Stack is empty!");
        }
        --top_index;
    }

    T& top() {
        if (empty()) {
            throw std::underflow_error("Stack is empty!");
        }
        return data[top_index - 1];
    }

    bool empty() const { return top_index == 0; }
    size_t size() const { return top_index; }
};

int main() {
    ArrayStack<int, 10> stk;

    for (int i = 1; i <= 5; ++i) {
        stk.push(i * 10);
    }

    std::cout << "Stack size: " << stk.size() << std::endl;

    while (!stk.empty()) {
        std::cout << stk.top() << " ";
        stk.pop();
    }
    std::cout << std::endl;

    return 0;
}
```

1.5 Implementing a Stack by Hand (Linked-List-Based)
----------------------------------------------------

A linked-list-based stack grows dynamically and has no fixed capacity limit:

```cpp
#include <iostream>
#include <stdexcept>

template<typename T>
class LinkedStack {
private:
    struct Node {
        T data;
        Node* next;
        Node(const T& val) : data(val), next(nullptr) {}
    };

    Node* head;  // top-of-stack pointer
    size_t count;

public:
    LinkedStack() : head(nullptr), count(0) {}

    ~LinkedStack() {
        while (head) {
            Node* temp = head;
            head = head->next;
            delete temp;
        }
    }

    void push(const T& value) {
        Node* new_node = new Node(value);
        new_node->next = head;
        head = new_node;
        ++count;
    }

    void pop() {
        if (empty()) {
            throw std::underflow_error("Stack is empty!");
        }
        Node* temp = head;
        head = head->next;
        delete temp;
        --count;
    }

    T& top() {
        if (empty()) {
            throw std::underflow_error("Stack is empty!");
        }
        return head->data;
    }

    bool empty() const { return head == nullptr; }
    size_t size() const { return count; }
};

int main() {
    LinkedStack<int> stk;

    for (int i = 1; i <= 10; ++i) {
        stk.push(i);
    }

    std::cout << "Stack size: " << stk.size() << std::endl;

    while (!stk.empty()) {
        std::cout << stk.top() << " ";
        stk.pop();
    }
    std::cout << std::endl;

    return 0;
}
```

2.1 std::stack -- The Standard Library Stack Container Adapter
--------------------------------------------------------------

std::stack is a container adapter. By default it uses deque as the underlying container, but you can specify another one.

```cpp
#include <iostream>
#include <stack>
#include <vector>
#include <list>
#include <deque>

int main() {
    // Default underlying container: deque
    std::stack<int> stk1;

    // Use vector as the underlying container
    std::stack<int, std::vector<int>> stk2;

    // Use list as the underlying container
    std::stack<int, std::list<int>> stk3;

    // Construct from an existing container
    std::deque<int> deq = {1, 2, 3, 4, 5};
    std::stack<int> stk4(deq);  // bottom of stack is 1, top is 5

    // Core operations
    std::stack<int> stk;
    stk.push(100);
    stk.push(200);
    stk.emplace(300);   // C++11: constructs in place, same effect as push

    std::cout << "size: " << stk.size() << std::endl;
    std::cout << "top: " << stk.top() << std::endl;

    stk.pop();  // pop (does not return the element)
    std::cout << "after pop, top: " << stk.top() << std::endl;

    // Swap the contents of two stacks
    std::stack<int> other;
    other.push(999);
    stk.swap(other);
    std::cout << "after swap, top: " << stk.top() << std::endl;

    // Relational operators
    std::stack<int> a, b;
    a.push(1); a.push(2);
    b.push(1); b.push(2);
    std::cout << "a == b: " << (a == b) << std::endl;
    // Comparison rule: compares the underlying containers element by element, in order

    // Traversal trick (standard stack doesn't allow traversal, but you can reach the underlying container)
    // Approach: inherit from the adapter or use a friend; a hack is shown here
    // The more recommended practice is to use deque/vector instead of stack

    return 0;
}

// Inherit from stack to expose the underlying container (for demonstration only; not recommended in production code)
template<typename T>
class DebugStack : public std::stack<T> {
public:
    void print() {
        // std::stack<T>::c is the protected underlying container member
        for (const auto& x : this->c) {
            std::cout << x << " ";
        }
        std::cout << "(top -> right)" << std::endl;
    }
};
```

2.2 A Custom Stack with Iterator Support
----------------------------------------

The standard library's stack does not provide iterators, but we can implement an iterable stack ourselves:

```cpp
#include <iostream>
#include <deque>
#include <iterator>

template<typename T>
class IterableStack {
private:
    std::deque<T> data;

public:
    void push(const T& val) { data.push_back(val); }
    void pop() { data.pop_back(); }
    T& top() { return data.back(); }
    bool empty() const { return data.empty(); }
    size_t size() const { return data.size(); }

    // Provide iterator support
    using iterator = typename std::deque<T>::reverse_iterator;
    using const_iterator = typename std::deque<T>::const_reverse_iterator;

    iterator begin() { return data.rbegin(); }
    iterator end() { return data.rend(); }
    const_iterator begin() const { return data.rbegin(); }
    const_iterator end() const { return data.rend(); }
};

int main() {
    IterableStack<int> stk;
    stk.push(10);
    stk.push(20);
    stk.push(30);

    std::cout << "Traversing from top to bottom: ";
    for (int x : stk) {
        std::cout << x << " ";
    }
    std::cout << std::endl;

    return 0;
}
```

2.3 Various Stack Use Cases
---------------------------

(1) Bracket matching

```cpp
#include <iostream>
#include <stack>
#include <string>
#include <unordered_map>

bool isBalanced(const std::string& expr) {
    std::stack<char> stk;
    std::unordered_map<char, char> pairs = {
        {')', '('},
        {']', '['},
        {'}', '{'}
    };

    for (char ch : expr) {
        if (ch == '(' || ch == '[' || ch == '{') {
            stk.push(ch);
        } else if (ch == ')' || ch == ']' || ch == '}') {
            if (stk.empty() || stk.top() != pairs[ch]) {
                return false;
            }
            stk.pop();
        }
    }

    return stk.empty();
}

int main() {
    std::string tests[] = {
        "()", "()[]{}", "([{}])", "(]", "([)]", "((((", ""
    };

    for (const auto& s : tests) {
        std::cout << s << " -> " << (isBalanced(s) ? "balanced" : "unbalanced") << std::endl;
    }

    return 0;
}
```

(2) Converting infix expressions to postfix (Reverse Polish Notation)

```cpp
#include <iostream>
#include <stack>
#include <string>
#include <cctype>

int precedence(char op) {
    if (op == '+' || op == '-') return 1;
    if (op == '*' || op == '/') return 2;
    if (op == '^') return 3;
    return 0;
}

std::string infixToPostfix(const std::string& expr) {
    std::stack<char> stk;
    std::string output;

    for (char ch : expr) {
        if (std::isalnum(ch)) {
            output += ch;
        } else if (ch == '(') {
            stk.push(ch);
        } else if (ch == ')') {
            while (!stk.empty() && stk.top() != '(') {
                output += stk.top();
                stk.pop();
            }
            stk.pop();  // pop '('
        } else {  // operator
            while (!stk.empty() && precedence(stk.top()) >= precedence(ch)) {
                output += stk.top();
                stk.pop();
            }
            stk.push(ch);
        }
    }

    while (!stk.empty()) {
        output += stk.top();
        stk.pop();
    }

    return output;
}

int main() {
    std::string expr = "a+b*(c^d-e)^(f+g*h)-i";
    std::cout << "Infix: " << expr << std::endl;
    std::cout << "Postfix: " << infixToPostfix(expr) << std::endl;
    return 0;
}
```

(3) Evaluating postfix expressions

```cpp
#include <iostream>
#include <stack>
#include <string>
#include <sstream>
#include <cctype>

int evaluatePostfix(const std::string& expr) {
    std::stack<int> stk;
    std::istringstream iss(expr);
    std::string token;

    while (iss >> token) {
        if (std::isdigit(token[0]) || (token.size() > 1 && token[0] == '-')) {
            stk.push(std::stoi(token));
        } else {
            int b = stk.top(); stk.pop();
            int a = stk.top(); stk.pop();

            switch (token[0]) {
                case '+': stk.push(a + b); break;
                case '-': stk.push(a - b); break;
                case '*': stk.push(a * b); break;
                case '/': stk.push(a / b); break;
            }
        }
    }

    return stk.top();
}

int main() {
    std::string expr = "3 4 + 5 * 6 -";
    std::cout << "Expression: " << expr << std::endl;
    std::cout << "Result: " << evaluatePostfix(expr) << std::endl;  // (3+4)*5-6 = 29
    return 0;
}
```

Example 1: A Browser's Back and Forward Buttons
-----------------------------------------------

Using two stacks to implement a browser's back and forward navigation:

```cpp
#include <iostream>
#include <stack>
#include <string>

class BrowserHistory {
private:
    std::stack<std::string> back_stack;   // back stack
    std::stack<std::string> forward_stack; // forward stack
    std::string current_url;

public:
    BrowserHistory(const std::string& homepage) : current_url(homepage) {}

    void visit(const std::string& url) {
        back_stack.push(current_url);
        current_url = url;
        // When visiting a new page, clear the forward stack
        while (!forward_stack.empty()) {
            forward_stack.pop();
        }
        std::cout << "Visit: " << current_url << std::endl;
    }

    std::string back() {
        if (back_stack.empty()) {
            std::cout << "Cannot go back" << std::endl;
            return current_url;
        }
        forward_stack.push(current_url);
        current_url = back_stack.top();
        back_stack.pop();
        std::cout << "Back to: " << current_url << std::endl;
        return current_url;
    }

    std::string forward() {
        if (forward_stack.empty()) {
            std::cout << "Cannot go forward" << std::endl;
            return current_url;
        }
        back_stack.push(current_url);
        current_url = forward_stack.top();
        forward_stack.pop();
        std::cout << "Forward to: " << current_url << std::endl;
        return current_url;
    }

    std::string getCurrent() const { return current_url; }
};

int main() {
    BrowserHistory bh("google.com");

    bh.visit("github.com");
    bh.visit("stackoverflow.com");
    bh.visit("cppreference.com");

    bh.back();  // stackoverflow.com
    bh.back();  // github.com
    bh.forward();  // stackoverflow.com
    bh.visit("reddit.com");  // forward stack cleared

    std::cout << "\nCurrent page: " << bh.getCurrent() << std::endl;

    return 0;
}
```


Example 2: Expression Calculator
--------------------------------

A complete calculator for arithmetic expressions with the four basic operations, including parentheses support:

```cpp
#include <iostream>
#include <stack>
#include <string>
#include <cctype>
#include <stdexcept>

class Calculator {
private:
    // Get the operator's precedence
    int precedence(char op) {
        if (op == '+' || op == '-') return 1;
        if (op == '*' || op == '/') return 2;
        return 0;
    }

    // Perform the operation
    int applyOp(int a, int b, char op) {
        switch (op) {
            case '+': return a + b;
            case '-': return a - b;
            case '*': return a * b;
            case '/':
                if (b == 0) throw std::runtime_error("Division by zero");
                return a / b;
        }
        return 0;
    }

public:
    int evaluate(const std::string& expr) {
        std::stack<int> values;   // operand stack
        std::stack<char> ops;     // operator stack

        for (size_t i = 0; i < expr.length(); ++i) {
            char ch = expr[i];

            // Skip spaces
            if (ch == ' ') continue;

            // Handle numbers
            if (std::isdigit(ch)) {
                int val = 0;
                while (i < expr.length() && std::isdigit(expr[i])) {
                    val = val * 10 + (expr[i] - '0');
                    ++i;
                }
                values.push(val);
                --i;  // the for loop will increment, so step back one
            }
            // Handle left parenthesis
            else if (ch == '(') {
                ops.push(ch);
            }
            // Handle right parenthesis
            else if (ch == ')') {
                while (!ops.empty() && ops.top() != '(') {
                    int b = values.top(); values.pop();
                    int a = values.top(); values.pop();
                    values.push(applyOp(a, b, ops.top()));
                    ops.pop();
                }
                if (ops.empty()) throw std::runtime_error("Mismatched parentheses");
                ops.pop();  // pop '('
            }
            // Handle operators
            else if (ch == '+' || ch == '-' || ch == '*' || ch == '/') {
                while (!ops.empty() && precedence(ops.top()) >= precedence(ch)) {
                    int b = values.top(); values.pop();
                    int a = values.top(); values.pop();
                    values.push(applyOp(a, b, ops.top()));
                    ops.pop();
                }
                ops.push(ch);
            }
        }

        // Process the remaining operators
        while (!ops.empty()) {
            int b = values.top(); values.pop();
            int a = values.top(); values.pop();
            values.push(applyOp(a, b, ops.top()));
            ops.pop();
        }

        return values.top();
    }
};

int main() {
    Calculator calc;

    std::string expressions[] = {
        "10 + 20 * 3",
        "(10 + 20) * 3",
        "5 * (4 + 3) / 7",
        "100 - 50 / 5 * 3",
        "((2 + 3) * (4 + 5))"
    };

    for (const auto& expr : expressions) {
        std::cout << expr << " = " << calc.evaluate(expr) << std::endl;
    }

    return 0;
}
```


Example 3: Depth-First Search (DFS)
-----------------------------------

Using a stack to implement depth-first traversal of a graph/tree:

```cpp
#include <iostream>
#include <stack>
#include <vector>
#include <unordered_set>

// Represent the graph with an adjacency list
class Graph {
private:
    int vertices;
    std::vector<std::vector<int>> adj_list;

public:
    Graph(int v) : vertices(v), adj_list(v) {}

    void addEdge(int u, int v) {
        adj_list[u].push_back(v);
        adj_list[v].push_back(u);  // undirected graph
    }

    void dfs(int start) {
        std::stack<int> stk;
        std::unordered_set<int> visited;

        stk.push(start);

        std::cout << "DFS traversal order: ";

        while (!stk.empty()) {
            int current = stk.top();
            stk.pop();

            if (visited.find(current) != visited.end()) continue;

            visited.insert(current);
            std::cout << current << " ";

            // Push neighbors onto the stack (in reverse order, so they are visited in forward order)
            for (auto it = adj_list[current].rbegin();
                 it != adj_list[current].rend(); ++it) {
                if (visited.find(*it) == visited.end()) {
                    stk.push(*it);
                }
            }
        }
        std::cout << std::endl;
    }
};

int main() {
    Graph g(6);
    g.addEdge(0, 1);
    g.addEdge(0, 2);
    g.addEdge(1, 3);
    g.addEdge(1, 4);
    g.addEdge(2, 4);
    g.addEdge(3, 4);
    g.addEdge(3, 5);

    g.dfs(0);

    return 0;
}
```

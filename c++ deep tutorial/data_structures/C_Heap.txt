## Chapter Overview

A heap is a special complete-binary-tree data structure that satisfies the "heap property": in a
max heap, every node's value is greater than or equal to the values of its children; in a min heap,
every node's value is less than or equal to the values of its children.

Heaps are the ideal way to implement a priority queue and are widely used in heap sort, graph algorithms
(Dijkstra's shortest path), task scheduling, the Top-K problem, and more.

Note: the "heap" here and the "heap memory" of an operating system are different concepts; they share a name but are fundamentally different.

1.1 Basic Heap Concepts
-----------------------

The two kinds of heap:

Max Heap: parent's value >= children's values; the root is the maximum
Min Heap: parent's value <= children's values; the root is the minimum

Physical storage of a heap: although a heap is logically a complete binary tree, it is actually stored in an array.
- The root is at position 0
- For the node at position i:
  - Left child position: 2*i + 1
  - Right child position: 2*i + 2
  - Parent position: (i-1) / 2

```cpp
// Illustration of a heap's array representation
// Max heap:     100
//             /    \
//           80      60
//          /  \    /  \
//         40  30  50  20
//        /
//       10
//
// Array storage: [100, 80, 60, 40, 30, 50, 20, 10]
//                  0    1   2   3   4   5   6   7
```

1.2 Heap Operations in the Standard Library
-------------------------------------------

The C++ standard library provides heap-related functions in <algorithm>:

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

int main() {
    std::vector<int> v = {3, 1, 4, 1, 5, 9, 2, 6};

    // 1. make_heap: turn a range into a heap (max heap by default)
    std::make_heap(v.begin(), v.end());
    std::cout << "After heapify: ";
    for (int x : v) std::cout << x << " ";
    std::cout << std::endl;
    // Output: 9 6 4 3 5 1 2 1  (top of heap is 9)

    // 2. push_heap: insert the last element into the heap
    v.push_back(10);
    std::push_heap(v.begin(), v.end());
    std::cout << "After inserting 10: ";
    for (int x : v) std::cout << x << " ";
    std::cout << std::endl;

    // 3. pop_heap: move the top of the heap to the end
    std::pop_heap(v.begin(), v.end());
    std::cout << "After popping the top: ";
    for (int x : v) std::cout << x << " ";
    std::cout << std::endl;
    std::cout << "Popped maximum element: " << v.back() << std::endl;
    v.pop_back();  // actually remove it

    // 4. sort_heap: heap sort
    std::sort_heap(v.begin(), v.end());
    std::cout << "After heap sort: ";
    for (int x : v) std::cout << x << " ";
    std::cout << std::endl;

    // 5. is_heap: check whether the heap property holds
    std::cout << "Is it a heap? " << std::is_heap(v.begin(), v.end()) << std::endl;

    return 0;
}
```

1.3 Under the Hood: Sift-Up and Sift-Down
-----------------------------------------

The core heap operations are "sift-up" (swim) and "sift-down" (sink).

Sift-up (used for insertion):
1. Place the new element at the end of the array
2. Compare it with its parent
3. If the heap property is violated, swap it with the parent
4. Repeat until the heap property holds or the root is reached

Sift-down (used for removal):
1. Swap the root with the last element, then remove the last element
2. Compare the new root with its larger child
3. If the heap property is violated, swap it with that child
4. Repeat until the heap property holds or a leaf is reached

```cpp
#include <iostream>
#include <vector>
#include <stdexcept>

template<typename T, bool IsMaxHeap = true>
class Heap {
private:
    std::vector<T> data;

    // Comparison function (depends on the heap type)
    bool compare(const T& a, const T& b) const {
        if constexpr (IsMaxHeap) {
            return a > b;  // max heap: parent > child
        } else {
            return a < b;  // min heap: parent < child
        }
    }

    // Sift up
    void sift_up(size_t index) {
        while (index > 0) {
            size_t parent = (index - 1) / 2;
            if (compare(data[parent], data[index])) {
                break;  // heap property satisfied
            }
            std::swap(data[index], data[parent]);
            index = parent;
        }
    }

    // Sift down
    void sift_down(size_t index) {
        size_t size = data.size();
        while (true) {
            size_t target = index;
            size_t left = 2 * index + 1;
            size_t right = 2 * index + 2;

            if (left < size && !compare(data[target], data[left])) {
                target = left;
            }
            if (right < size && !compare(data[target], data[right])) {
                target = right;
            }

            if (target == index) break;  // heap property already satisfied

            std::swap(data[index], data[target]);
            index = target;
        }
    }

public:
    Heap() = default;

    void push(const T& value) {
        data.push_back(value);
        sift_up(data.size() - 1);
    }

    void pop() {
        if (empty()) throw std::underflow_error("Heap is empty");
        std::swap(data.front(), data.back());
        data.pop_back();
        if (!empty()) sift_down(0);
    }

    const T& top() const {
        if (empty()) throw std::underflow_error("Heap is empty");
        return data.front();
    }

    bool empty() const { return data.empty(); }
    size_t size() const { return data.size(); }

    void print() const {
        for (const auto& x : data) std::cout << x << " ";
        std::cout << "(top: " << (empty() ? -1 : top()) << ")" << std::endl;
    }
};

int main() {
    // Max heap
    Heap<int, true> max_heap;
    max_heap.push(3);
    max_heap.push(1);
    max_heap.push(4);
    max_heap.push(1);
    max_heap.push(5);
    max_heap.push(9);

    std::cout << "Max heap: ";
    max_heap.print();

    std::cout << "Extracted in order: ";
    while (!max_heap.empty()) {
        std::cout << max_heap.top() << " ";
        max_heap.pop();
    }
    std::cout << std::endl;

    // Min heap
    Heap<int, false> min_heap;
    min_heap.push(3);
    min_heap.push(1);
    min_heap.push(4);
    min_heap.push(1);
    min_heap.push(5);
    min_heap.push(9);

    std::cout << "Min heap: ";
    min_heap.print();

    std::cout << "Extracted in order: ";
    while (!min_heap.empty()) {
        std::cout << min_heap.top() << " ";
        min_heap.pop();
    }
    std::cout << std::endl;

    return 0;
}
```

1.4 Time Complexity of Building a Heap
--------------------------------------

There are two ways to build a heap from an unordered array:
- Top-down construction: insert elements one by one, O(n log n)
- Bottom-up construction (Floyd's algorithm): sift down each node starting from the last non-leaf node, O(n)

```cpp
#include <iostream>
#include <vector>

// Floyd's heap-construction algorithm (bottom-up sift-down)
void floydBuildHeap(std::vector<int>& arr) {
    int n = arr.size();
    // Start from the last non-leaf node
    for (int i = n / 2 - 1; i >= 0; --i) {
        // Sift down
        int current = i;
        while (true) {
            int largest = current;
            int left = 2 * current + 1;
            int right = 2 * current + 2;

            if (left < n && arr[left] > arr[largest]) largest = left;
            if (right < n && arr[right] > arr[largest]) largest = right;

            if (largest == current) break;
            std::swap(arr[current], arr[largest]);
            current = largest;
        }
    }
}

int main() {
    std::vector<int> arr = {3, 1, 4, 1, 5, 9, 2, 6, 5, 3, 5};

    std::cout << "Original array: ";
    for (int x : arr) std::cout << x << " ";

    floydBuildHeap(arr);

    std::cout << "\nAfter building the heap: ";
    for (int x : arr) std::cout << x << " ";
    std::cout << std::endl;

    return 0;
}
```

Complexity analysis:
- make_heap: O(n) -- uses Floyd's algorithm
- push_heap: O(log n)
- pop_heap: O(log n)
- sort_heap: O(n log n)

1.5 Heap Sort
-------------

Heap sort uses the heap structure, repeatedly taking the largest (or smallest) element and placing it at the end of the array:

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

void heapSort(std::vector<int>& arr) {
    // 1. Build the heap
    std::make_heap(arr.begin(), arr.end());

    // 2. Pop the top of the heap one at a time
    for (int i = arr.size() - 1; i > 0; --i) {
        std::pop_heap(arr.begin(), arr.begin() + i + 1);
    }
}

int main() {
    std::vector<int> arr = {38, 27, 43, 3, 9, 82, 10};

    std::cout << "Before sorting: ";
    for (int x : arr) std::cout << x << " ";

    heapSort(arr);

    std::cout << "\nAfter sorting: ";
    for (int x : arr) std::cout << x << " ";
    std::cout << std::endl;

    return 0;
}
```

2.1 std::priority_queue -- Priority Queue
-----------------------------------------

priority_queue is a container adapter. By default it uses vector as the underlying container and internally
maintains the heap structure with make_heap / push_heap / pop_heap.

```cpp
#include <iostream>
#include <queue>
#include <vector>
#include <functional>

int main() {
    // ========== 1. Max heap (default) ==========
    std::priority_queue<int> max_pq;

    max_pq.push(30);
    max_pq.push(10);
    max_pq.push(50);
    max_pq.push(20);
    max_pq.push(40);

    std::cout << "Max heap (default): ";
    while (!max_pq.empty()) {
        std::cout << max_pq.top() << " ";
        max_pq.pop();
    }
    std::cout << std::endl;

    // ========== 2. Min heap ==========
    std::priority_queue<int, std::vector<int>, std::greater<int>> min_pq;

    min_pq.push(30);
    min_pq.push(10);
    min_pq.push(50);
    min_pq.push(20);
    min_pq.push(40);

    std::cout << "Min heap: ";
    while (!min_pq.empty()) {
        std::cout << min_pq.top() << " ";
        min_pq.pop();
    }
    std::cout << std::endl;

    // ========== 3. Custom comparator ==========
    auto cmp = [](int a, int b) { return a % 10 > b % 10; };
    std::priority_queue<int, std::vector<int>, decltype(cmp)> custom_pq(cmp);

    custom_pq.push(33);
    custom_pq.push(12);
    custom_pq.push(45);
    custom_pq.push(28);
    custom_pq.push(51);

    std::cout << "Ordered by last digit: ";
    while (!custom_pq.empty()) {
        std::cout << custom_pq.top() << " ";
        custom_pq.pop();
    }
    std::cout << std::endl;

    // ========== 4. Storing user-defined types ==========
    struct Task {
        int priority;
        std::string name;

        // Max heap: higher-priority tasks run first
        bool operator<(const Task& other) const {
            return priority < other.priority;
        }
    };

    std::priority_queue<Task> task_queue;
    task_queue.push({3, "Low-priority task"});
    task_queue.push({5, "High-priority task"});
    task_queue.push({4, "Medium-priority task"});

    while (!task_queue.empty()) {
        auto task = task_queue.top();
        std::cout << task.name << " (priority: " << task.priority << ")" << std::endl;
        task_queue.pop();
    }

    // ========== 5. Constructing from an existing container ==========
    std::vector<int> v = {3, 1, 4, 1, 5};
    std::priority_queue<int> pq_from_vec(v.begin(), v.end());

    return 0;
}
```

2.2 Other Heap Functions
------------------------

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

int main() {
    std::vector<int> v = {3, 1, 4, 1, 5, 9, 2, 6};

    // Full usage of push_heap
    // Note: before push_heap, you must ensure that [first, last-1) is already a heap
    v.push_back(10);
    std::push_heap(v.begin(), v.end());

    // pop_heap: moves the top to [last-1]; afterwards [first, last-1) is still a heap
    std::pop_heap(v.begin(), v.end());
    int max_val = v.back();
    v.pop_back();

    // Using a custom comparison (min heap)
    std::make_heap(v.begin(), v.end(), std::greater<int>{});

    // is_heap / is_heap_until
    std::cout << "Is it a heap: " << std::is_heap(v.begin(), v.end()) << std::endl;

    // Returns the first position that violates the heap property
    auto it = std::is_heap_until(v.begin(), v.end());

    // partial_sort uses a heap internally
    std::vector<int> unsorted = {9, 3, 7, 1, 8, 2, 6, 4, 5};
    // Find the 3 largest elements
    std::partial_sort(unsorted.begin(), unsorted.begin() + 3, unsorted.end(),
                      std::greater<int>{});
    // The first 3 elements of unsorted are now the 3 largest (in descending order)

    // nth_element also uses a heap-based selection algorithm
    std::vector<int> data = {7, 3, 9, 1, 8, 2, 6, 4, 5};
    std::nth_element(data.begin(), data.begin() + 4, data.end());
    // data[4] is the 5th smallest element; everything to its left is smaller and everything to its right is larger

    return 0;
}
```

Example 1: Task Scheduler
-------------------------

Using a priority queue (max heap) to schedule tasks so that higher-priority tasks run first:

```cpp
#include <iostream>
#include <queue>
#include <string>
#include <vector>
#include <random>
#include <chrono>

struct Task {
    int id;
    int priority;
    std::string description;
    int duration;  // execution time (seconds)

    // Max heap: higher priority goes first
    bool operator<(const Task& other) const {
        return priority < other.priority;
    }
};

class Scheduler {
private:
    std::priority_queue<Task> task_queue;
    int next_id = 1;

public:
    void addTask(int priority, const std::string& desc, int duration = 1) {
        task_queue.push({next_id++, priority, desc, duration});
        std::cout << "Added task: #" << (next_id - 1)
                  << " [priority=" << priority << "] " << desc << std::endl;
    }

    void runAll() {
        std::cout << "\n========== Starting task execution ==========\n" << std::endl;

        while (!task_queue.empty()) {
            Task task = task_queue.top();
            task_queue.pop();

            std::cout << "Running task #" << task.id
                      << " (priority:" << task.priority << ")"
                      << " - " << task.description << std::endl;
            // Simulate execution
            std::cout << "  Time taken: " << task.duration << " s" << std::endl;
        }

        std::cout << "\nAll tasks completed!" << std::endl;
    }

    bool isEmpty() const { return task_queue.empty(); }
    int size() const { return task_queue.size(); }
};

int main() {
    Scheduler scheduler;

    scheduler.addTask(5, "System security check", 3);
    scheduler.addTask(10, "Process user payment request", 2);
    scheduler.addTask(3, "Log cleanup", 1);
    scheduler.addTask(8, "Update inventory data", 2);
    scheduler.addTask(1, "Send marketing emails", 1);
    scheduler.addTask(7, "Generate end-of-day report", 4);

    scheduler.runAll();

    return 0;
}
```


Example 2: The Top-K Problem (the K Largest Elements in a Data Stream)
----------------------------------------------------------------------

Using a min heap to maintain the Top-K:

```cpp
#include <iostream>
#include <queue>
#include <vector>

class TopKTracker {
private:
    int k;
    std::priority_queue<int, std::vector<int>, std::greater<int>> min_heap;

public:
    TopKTracker(int k_val) : k(k_val) {}

    void add(int value) {
        min_heap.push(value);
        if (min_heap.size() > k) {
            min_heap.pop();  // remove the smallest, keeping the K largest in the heap
        }
    }

    std::vector<int> getTopK() const {
        // Return the current Top-K elements
        auto temp = min_heap;
        std::vector<int> result;
        while (!temp.empty()) {
            result.push_back(temp.top());
            temp.pop();
        }
        // Sort from largest to smallest for output
        std::sort(result.begin(), result.end(), std::greater<int>{});
        return result;
    }

    void print() const {
        auto result = getTopK();
        std::cout << "Current Top-" << k << ": ";
        for (int x : result) std::cout << x << " ";
        std::cout << std::endl;
    }
};

int main() {
    TopKTracker tracker(3);

    std::vector<int> stream = {3, 1, 5, 9, 2, 8, 7, 4, 6};

    for (int v : stream) {
        tracker.add(v);
        tracker.print();
    }

    return 0;
}
```


Example 3: Merging K Sorted Linked Lists
----------------------------------------

Using a heap to merge multiple sorted linked lists efficiently:

```cpp
#include <iostream>
#include <queue>
#include <vector>

struct ListNode {
    int val;
    ListNode* next;
    ListNode(int v) : val(v), next(nullptr) {}
};

// Comparator: for a min heap
struct Compare {
    bool operator()(ListNode* a, ListNode* b) {
        return a->val > b->val;  // min heap
    }
};

ListNode* mergeKLists(std::vector<ListNode*>& lists) {
    std::priority_queue<ListNode*, std::vector<ListNode*>, Compare> pq;

    // Push the head node of every list onto the heap
    for (auto& list : lists) {
        if (list) pq.push(list);
    }

    ListNode dummy(0);
    ListNode* tail = &dummy;

    while (!pq.empty()) {
        // Take the smallest node
        ListNode* node = pq.top();
        pq.pop();

        // Push that node's successor onto the heap
        if (node->next) {
            pq.push(node->next);
        }

        // Append the node to the result list
        tail->next = node;
        tail = tail->next;
    }

    return dummy.next;
}

// Helper function: create a linked list from a vector
ListNode* createList(const std::vector<int>& vals) {
    ListNode dummy(0);
    ListNode* tail = &dummy;
    for (int v : vals) {
        tail->next = new ListNode(v);
        tail = tail->next;
    }
    return dummy.next;
}

// Helper function: print a linked list
void printList(ListNode* head) {
    while (head) {
        std::cout << head->val;
        if (head->next) std::cout << " -> ";
        head = head->next;
    }
    std::cout << std::endl;
}

int main() {
    std::vector<ListNode*> lists;

    lists.push_back(createList({1, 4, 7}));
    lists.push_back(createList({2, 5, 8}));
    lists.push_back(createList({3, 6, 9}));

    std::cout << "Input lists:" << std::endl;
    for (auto& list : lists) {
        printList(list);
    }

    ListNode* merged = mergeKLists(lists);

    std::cout << "\nMerged result: ";
    printList(merged);

    return 0;
}
```

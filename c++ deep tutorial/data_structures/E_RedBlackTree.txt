## Chapter Overview

A Red-Black Tree is a self-balancing binary search tree. Each node carries one
extra bit of storage that records its color (red or black). By constraining the
colors of the nodes along any path from the root to a leaf, it guarantees that no
path is more than twice as long as any other, so the tree is approximately balanced.

The red-black tree is the underlying data structure of std::map, std::set,
std::multimap and std::multiset in the C++ standard library, and it is also a core
data structure in the Linux kernel's CFS scheduler, memory management and more.

1.1 Basic Concepts of Red-Black Trees
-----------------------

The five properties of a red-black tree:
1. Every node is either red or black
2. The root is black
3. Every leaf (NIL empty node) is black
4. If a node is red, both of its children are black
   (i.e. there can never be two consecutive red nodes)
5. Every path from any node to each of its descendant leaves contains the same
   number of black nodes (equal black height)

These constraints guarantee that the height of a red-black tree never exceeds
2*log2(n+1), so the worst-case time complexity of search, insertion and deletion is O(log n).

```
Red-black tree example:
        B(50)
       /      \
    R(30)    R(70)
    /    \    /    \
 B(20) B(40)B(60)B(80)
        /
    R(35)  ← a red node cannot have a red child (here 35's parent is black 40, so it's allowed)
```

1.2 Using Red-Black Trees in the Standard Library
---------------------------

In the standard library, red-black trees are used indirectly through associative
containers such as map/set:

```cpp
#include <iostream>
#include <map>
#include <set>
#include <string>

int main() {
    // map is backed by a red-black tree (keys are ordered)
    std::map<std::string, int> scores;
    scores["Alice"] = 95;
    scores["Bob"] = 87;
    scores["Charlie"] = 92;
    scores["David"] = 78;

    // The red-black tree properties guarantee traversal in key order
    std::cout << "Scores sorted by name:" << std::endl;
    for (const auto& [name, score] : scores) {
        std::cout << "  " << name << ": " << score << std::endl;
    }

    // Lookup (O(log n))
    auto it = scores.find("Bob");
    if (it != scores.end()) {
        std::cout << "Bob's score: " << it->second << std::endl;
    }

    // Range query (takes advantage of the tree's ordering)
    auto lower = scores.lower_bound("B");   // first element >= "B"
    auto upper = scores.upper_bound("D");   // first element > "D"
    std::cout << "Students with names between B and D:" << std::endl;
    for (auto it2 = lower; it2 != upper; ++it2) {
        std::cout << "  " << it2->first << ": " << it2->second << std::endl;
    }

    // The same goes for set
    std::set<int> numbers;
    for (int n : {5, 3, 8, 1, 9, 2, 7}) {
        numbers.insert(n);
    }

    std::cout << "Ordered set: ";
    for (int n : numbers) std::cout << n << " ";
    std::cout << std::endl;

    return 0;
}
```

1.3 How Red-Black Trees Work Internally
----------------------------

The core of a red-black tree is the "fixup" process after insertion and deletion.
After an insertion, the properties are restored by recoloring and rotations; after a
deletion, they are restored by resolving the "double black" problem.

Rotations (same as in AVL trees):
- Left rotation: the right child of node x is lifted into x's position, and x becomes its left child
- Right rotation: the left child of node x is lifted into x's position, and x becomes its right child

```cpp
// Left rotation
//      x              y
//     / \            / \
//    a   y    ->    x   c
//       / \        / \
//      b   c      a   b

// Right rotation
//      x              y
//     / \            / \
//    y   c    ->    a   x
//   / \                / \
//  a   b              b   c
```

1.4 Insertion in a Red-Black Tree
-----------------------

Insertion process:
1. Insert the new node using the normal BST rules
2. Color the new node red
3. Check and repair the red-black properties (at most 2 rotations are needed)

The three cases of insertion fixup:
- Case 1: the uncle is red → recolor (parent and uncle become black, grandparent becomes red)
- Case 2: the uncle is black, and the new node is on the same side as its parent → single rotation + recolor
- Case 3: the uncle is black, and the new node is on the opposite side from its parent → double rotation + recolor

```cpp
#include <iostream>
#include <stdexcept>

enum class Color { RED, BLACK };

template<typename T>
class RBTree {
private:
    struct Node {
        T data;
        Color color;
        Node* left;
        Node* right;
        Node* parent;

        Node(const T& val)
            : data(val), color(Color::RED),
              left(nullptr), right(nullptr), parent(nullptr) {}
    };

    Node* root;
    Node* NIL;  // sentinel empty node (black)

    // Left rotation
    void leftRotate(Node* x) {
        Node* y = x->right;
        x->right = y->left;
        if (y->left != NIL) y->left->parent = x;
        y->parent = x->parent;

        if (x->parent == nullptr) {
            root = y;
        } else if (x == x->parent->left) {
            x->parent->left = y;
        } else {
            x->parent->right = y;
        }
        y->left = x;
        x->parent = y;
    }

    // Right rotation
    void rightRotate(Node* x) {
        Node* y = x->left;
        x->left = y->right;
        if (y->right != NIL) y->right->parent = x;
        y->parent = x->parent;

        if (x->parent == nullptr) {
            root = y;
        } else if (x == x->parent->right) {
            x->parent->right = y;
        } else {
            x->parent->left = y;
        }
        y->right = x;
        x->parent = y;
    }

    // Insertion fixup
    void insertFixup(Node* z) {
        while (z->parent && z->parent->color == Color::RED) {
            if (z->parent == z->parent->parent->left) {
                Node* y = z->parent->parent->right;  // uncle
                if (y && y->color == Color::RED) {
                    // Case 1: the uncle is red
                    z->parent->color = Color::BLACK;
                    y->color = Color::BLACK;
                    z->parent->parent->color = Color::RED;
                    z = z->parent->parent;
                } else {
                    if (z == z->parent->right) {
                        // Case 2: z is a right child → left rotate
                        z = z->parent;
                        leftRotate(z);
                    }
                    // Case 3: z is a left child → right rotate + recolor
                    z->parent->color = Color::BLACK;
                    z->parent->parent->color = Color::RED;
                    rightRotate(z->parent->parent);
                }
            } else {
                // Symmetric case
                Node* y = z->parent->parent->left;
                if (y && y->color == Color::RED) {
                    z->parent->color = Color::BLACK;
                    y->color = Color::BLACK;
                    z->parent->parent->color = Color::RED;
                    z = z->parent->parent;
                } else {
                    if (z == z->parent->left) {
                        z = z->parent;
                        rightRotate(z);
                    }
                    z->parent->color = Color::BLACK;
                    z->parent->parent->color = Color::RED;
                    leftRotate(z->parent->parent);
                }
            }
        }
        root->color = Color::BLACK;
    }

    // In-order traversal
    void inorder(Node* node) const {
        if (node == NIL) return;
        inorder(node->left);
        std::cout << node->data
                  << (node->color == Color::RED ? "(R) " : "(B) ");
        inorder(node->right);
    }

    // Compute the black height
    int blackHeight(Node* node) const {
        if (node == NIL) return 0;
        int left = blackHeight(node->left);
        int right = blackHeight(node->right);
        int add = (node->color == Color::BLACK) ? 1 : 0;
        return add + std::max(left, right);
    }

    // Free memory
    void destroy(Node* node) {
        if (node == NIL) return;
        destroy(node->left);
        destroy(node->right);
        delete node;
    }

public:
    RBTree() {
        NIL = new Node(T());
        NIL->color = Color::BLACK;
        NIL->left = NIL->right = NIL->parent = nullptr;
        root = NIL;
    }

    ~RBTree() {
        destroy(root);
        delete NIL;
    }

    void insert(const T& value) {
        Node* z = new Node(value);
        z->left = NIL;
        z->right = NIL;

        Node* y = nullptr;
        Node* x = root;

        // Find the insertion position
        while (x != NIL) {
            y = x;
            if (z->data < x->data) {
                x = x->left;
            } else if (z->data > x->data) {
                x = x->right;
            } else {
                delete z;
                return;  // duplicates are not allowed
            }
        }

        z->parent = y;
        if (y == nullptr) {
            root = z;
        } else if (z->data < y->data) {
            y->left = z;
        } else {
            y->right = z;
        }

        // Insertion fixup
        insertFixup(z);
    }

    Node* search(const T& value) const {
        Node* cur = root;
        while (cur != NIL) {
            if (value == cur->data) return cur;
            cur = (value < cur->data) ? cur->left : cur->right;
        }
        return nullptr;
    }

    void print() const {
        std::cout << "In-order traversal: ";
        inorder(root);
        std::cout << std::endl;
        std::cout << "Root: " << root->data
                  << (root->color == Color::RED ? "(R)" : "(B)")
                  << " | Black height: " << blackHeight(root) << std::endl;
    }
};

int main() {
    RBTree<int> rbt;

    // Insert a series of values
    int values[] = {7, 3, 18, 10, 22, 8, 11, 26, 2, 6, 13};
    for (int v : values) {
        rbt.insert(v);
        std::cout << "After inserting " << v << ": ";
        rbt.print();
    }

    // Search test
    for (int v : {10, 99}) {
        auto node = rbt.search(v);
        std::cout << "Search " << v << ": "
                  << (node ? "found" : "not found") << std::endl;
    }

    return 0;
}
```

1.5 Red-Black Tree vs AVL Tree
-------------------------------

| Property       | Red-Black Tree             | AVL Tree                        |
|----------------|----------------------------|---------------------------------|
| Balance rule   | Approximate (factor of 2)  | Strict (height diff <= 1)       |
| Lookup speed   | Slightly slower (log n)    | Faster (log n)                  |
| Insert/delete  | Faster (1-2 rotations)     | Slower (may need many rotations)|
| Extra storage  | 1 bit for color            | Balance factor (integer)        |
| Best for       | Frequent inserts/deletes   | Frequent lookups                |

2.1 Red-Black Tree Operations in std::map
------------------------------

```cpp
#include <iostream>
#include <map>
#include <string>

int main() {
    std::map<int, std::string> rbt_map;

    // Insertion (each insertion is an O(log n) red-black tree operation)
    rbt_map[5] = "five";
    rbt_map[3] = "three";
    rbt_map[8] = "eight";
    rbt_map[1] = "one";
    rbt_map[7] = "seven";

    // Range query using the tree's ordering
    auto lb = rbt_map.lower_bound(3);   // >= 3
    auto ub = rbt_map.upper_bound(7);   // > 7

    std::cout << "Elements in range [3, 7]:" << std::endl;
    for (auto it = lb; it != ub; ++it) {
        std::cout << "  " << it->first << " -> " << it->second << std::endl;
    }

    // Reverse traversal (using the tree's bidirectional iterators)
    std::cout << "Reverse traversal:" << std::endl;
    for (auto it = rbt_map.rbegin(); it != rbt_map.rend(); ++it) {
        std::cout << "  " << it->first << " -> " << it->second << std::endl;
    }

    // equal_range
    auto [low, high] = rbt_map.equal_range(5);
    if (low != high) {
        std::cout << "equal_range(5): " << low->first
                  << " -> " << low->second << std::endl;
    }

    return 0;
}
```

2.2 Red-Black Tree Operations in std::set
------------------------------

```cpp
#include <iostream>
#include <set>
#include <algorithm>

int main() {
    std::set<int> s;

    // Insertion
    auto [it, inserted] = s.insert(5);
    std::cout << "Insert 5: " << (inserted ? "succeeded" : "already exists") << std::endl;

    std::tie(it, inserted) = s.insert(5);
    std::cout << "Insert 5 again: " << (inserted ? "succeeded" : "already exists") << std::endl;

    // Bulk insertion
    s.insert({3, 8, 1, 7, 9, 2});

    // Set operations using the tree's ordering
    std::set<int> set_a = {1, 2, 3, 4, 5};
    std::set<int> set_b = {3, 4, 5, 6, 7};
    std::set<int> result;

    // Intersection
    std::set_intersection(set_a.begin(), set_a.end(),
                          set_b.begin(), set_b.end(),
                          std::inserter(result, result.begin()));
    std::cout << "Intersection: ";
    for (int x : result) std::cout << x << " ";
    std::cout << std::endl;

    // Union
    result.clear();
    std::set_union(set_a.begin(), set_a.end(),
                   set_b.begin(), set_b.end(),
                   std::inserter(result, result.begin()));
    std::cout << "Union: ";
    for (int x : result) std::cout << x << " ";
    std::cout << std::endl;

    // Difference
    result.clear();
    std::set_difference(set_a.begin(), set_a.end(),
                        set_b.begin(), set_b.end(),
                        std::inserter(result, result.begin()));
    std::cout << "Difference (A-B): ";
    for (int x : result) std::cout << x << " ";
    std::cout << std::endl;

    return 0;
}
```

2.3 Red-Black Tree Application: Interval Scheduling
-------------------------------

```cpp
#include <iostream>
#include <map>
#include <set>
#include <vector>

// Use a red-black tree (map) to manage meeting room bookings
class MeetingRoom {
private:
    std::map<int, int> bookings;  // start -> end (red-black tree, keys ordered)

public:
    // Book a slot: returns whether it succeeded
    bool book(int start, int end) {
        // Find the first booking with start >= start
        auto next = bookings.lower_bound(start);

        // Check for a conflict with the next booking
        if (next != bookings.end() && next->first < end) {
            return false;
        }

        // Check for a conflict with the previous booking
        if (next != bookings.begin()) {
            auto prev = std::prev(next);
            if (prev->second > start) {
                return false;
            }
        }

        bookings[start] = end;
        return true;
    }

    void printBookings() const {
        std::cout << "Current bookings: ";
        for (const auto& [start, end] : bookings) {
            std::cout << "[" << start << "-" << end << ") ";
        }
        std::cout << std::endl;
    }
};

int main() {
    MeetingRoom room;

    room.book(9, 10);    // 9:00-10:00
    room.book(10, 11);   // 10:00-11:00
    room.book(11, 12);   // 11:00-12:00

    room.printBookings();

    std::cout << "Book 9:30-10:30: "
              << (room.book(9, 10) ? "succeeded" : "failed") << std::endl;
    std::cout << "Book 14:00-15:00: "
              << (room.book(14, 15) ? "succeeded" : "failed") << std::endl;

    room.printBookings();

    return 0;
}
```

Example 1: Dictionary Lookup (Chinese Pinyin Input Method)
----------------------------------------------

Use a map of sets (red-black trees) to map pinyin to candidate characters
(the characters are shown here by their English meanings):

```cpp
#include <iostream>
#include <map>
#include <set>
#include <string>
#include <vector>

class PinyinDictionary {
private:
    // pinyin -> set of candidate characters
    std::map<std::string, std::set<std::string>> dict;

public:
    void addWord(const std::string& pinyin, const std::string& hanzi) {
        dict[pinyin].insert(hanzi);
    }

    // Exact lookup
    std::set<std::string> query(const std::string& pinyin) const {
        auto it = dict.find(pinyin);
        if (it != dict.end()) {
            return it->second;
        }
        return {};
    }

    // Prefix lookup (using the tree's lower_bound/upper_bound)
    std::vector<std::pair<std::string, std::set<std::string>>>
    prefixQuery(const std::string& prefix) const {
        std::vector<std::pair<std::string, std::set<std::string>>> result;

        auto start = dict.lower_bound(prefix);
        // Build the upper bound: increment the last character
        std::string end_prefix = prefix;
        end_prefix.back()++;

        auto end = dict.lower_bound(end_prefix);

        for (auto it = start; it != end; ++it) {
            if (!it->second.empty()) {
                result.push_back({it->first, it->second});
            }
        }

        return result;
    }

    void printAll() const {
        for (const auto& [pinyin, hanzi_set] : dict) {
            std::cout << pinyin << ": ";
            for (const auto& h : hanzi_set) {
                std::cout << h << " ";
            }
            std::cout << std::endl;
        }
    }
};

int main() {
    PinyinDictionary dict;

    dict.addWord("zhong", "middle");
    dict.addWord("zhong", "clock");
    dict.addWord("zhong", "heartfelt");
    dict.addWord("guo", "country");
    dict.addWord("guo", "fruit");
    dict.addWord("guo", "pass");
    dict.addWord("zhongguo", "China");
    dict.addWord("ren", "person");
    dict.addWord("min", "people");
    dict.addWord("renmin", "the people");

    std::cout << "Full dictionary:" << std::endl;
    dict.printAll();

    std::string input = "zhong";
    std::cout << "\nExact lookup \"" << input << "\": ";
    for (const auto& h : dict.query(input)) {
        std::cout << h << " ";
    }
    std::cout << std::endl;

    input = "g";
    std::cout << "\nPrefix lookup \"" << input << "\": " << std::endl;
    for (const auto& [p, hset] : dict.prefixQuery(input)) {
        std::cout << "  " << p << ": ";
        for (const auto& h : hset) std::cout << h << " ";
        std::cout << std::endl;
    }

    return 0;
}
```


Example 2: Stock Exchange Order Book
-----------------------------------

Use red-black trees (map) to manage buy and sell orders for a stock:

```cpp
#include <iostream>
#include <map>
#include <string>
#include <vector>

class OrderBook {
private:
    struct Order {
        int id;
        int quantity;
        double price;
        std::string trader;

        Order(int i, int q, double p, const std::string& t)
            : id(i), quantity(q), price(p), trader(t) {}
    };

    // Sell orders: ascending by price (lowest price fills first)
    std::map<double, std::vector<Order>> sell_orders;

    // Buy orders: descending by price (highest price fills first)
    // Achieve descending order with negative keys, or use greater
    std::map<double, std::vector<Order>, std::greater<double>> buy_orders;

    int next_order_id = 1;

public:
    void placeBuyOrder(int quantity, double price, const std::string& trader) {
        buy_orders[price].emplace_back(next_order_id++, quantity, price, trader);
        std::cout << "Buy order: " << trader << " wants to buy " << quantity
                  << " shares at " << price << std::endl;
        matchOrders();
    }

    void placeSellOrder(int quantity, double price, const std::string& trader) {
        sell_orders[price].emplace_back(next_order_id++, quantity, price, trader);
        std::cout << "Sell order: " << trader << " wants to sell " << quantity
                  << " shares at " << price << std::endl;
        matchOrders();
    }

private:
    void matchOrders() {
        while (!buy_orders.empty() && !sell_orders.empty()) {
            auto highest_buy = buy_orders.begin();
            auto lowest_sell = sell_orders.begin();

            // Highest bid >= lowest ask → trade
            if (highest_buy->first < lowest_sell->first) break;

            auto& buy_orders_at_price = highest_buy->second;
            auto& sell_orders_at_price = lowest_sell->second;

            int trade_qty = std::min(buy_orders_at_price.front().quantity,
                                     sell_orders_at_price.front().quantity);
            double trade_price = lowest_sell->first;

            std::cout << "  [Trade] " << trade_qty << " shares @ "
                      << trade_price << std::endl;

            buy_orders_at_price.front().quantity -= trade_qty;
            sell_orders_at_price.front().quantity -= trade_qty;

            if (buy_orders_at_price.front().quantity == 0) {
                buy_orders_at_price.erase(buy_orders_at_price.begin());
            }
            if (sell_orders_at_price.front().quantity == 0) {
                sell_orders_at_price.erase(sell_orders_at_price.begin());
            }

            if (buy_orders_at_price.empty()) buy_orders.erase(highest_buy);
            if (sell_orders_at_price.empty()) sell_orders.erase(lowest_sell);
        }
    }

public:
    void printBook() const {
        std::cout << "\n========== Order Book ==========" << std::endl;
        std::cout << "--- Sell orders (lowest price first) ---" << std::endl;
        for (auto it = sell_orders.begin(); it != sell_orders.end(); ++it) {
            int total_qty = 0;
            for (const auto& o : it->second) total_qty += o.quantity;
            std::cout << "  $" << it->first << ": " << total_qty << " shares" << std::endl;
        }

        std::cout << "--- Buy orders (highest price first) ---" << std::endl;
        for (auto it = buy_orders.begin(); it != buy_orders.end(); ++it) {
            int total_qty = 0;
            for (const auto& o : it->second) total_qty += o.quantity;
            std::cout << "  $" << it->first << ": " << total_qty << " shares" << std::endl;
        }
        std::cout << "==========================\n" << std::endl;
    }
};

int main() {
    OrderBook ob;

    ob.placeBuyOrder(100, 50.0, "Alice");
    ob.placeSellOrder(50, 49.5, "Bob");
    ob.placeBuyOrder(200, 51.0, "Charlie");
    ob.placeSellOrder(100, 50.5, "David");
    ob.placeSellOrder(150, 49.0, "Eve");

    ob.printBook();

    return 0;
}
```


Example 3: Memory Allocator (Simplified Buddy System)
-------------------------------------------

Use a red-black tree to manage free memory blocks:

```cpp
#include <iostream>
#include <map>
#include <set>

class BuddyAllocator {
private:
    // size -> block addresses (the red-black tree keeps them sorted by size)
    std::map<size_t, std::set<void*>> free_blocks;

public:
    void* allocate(size_t size) {
        // Find the first free block with size >= size
        auto it = free_blocks.lower_bound(size);
        if (it == free_blocks.end()) {
            std::cout << "Allocate " << size << " bytes: failed, not enough memory"
                      << std::endl;
            return nullptr;
        }

        void* addr = *it->second.begin();
        it->second.erase(it->second.begin());

        if (it->second.empty()) {
            free_blocks.erase(it);
        }

        std::cout << "Allocated " << size << " bytes @ " << addr << std::endl;
        return addr;
    }

    void deallocate(void* addr, size_t size) {
        free_blocks[size].insert(addr);
        std::cout << "Freed " << size << " bytes @ " << addr << std::endl;
    }

    void printStats() const {
        std::cout << "\nFree block statistics:" << std::endl;
        for (const auto& [size, addrs] : free_blocks) {
            std::cout << "  " << size << " bytes: " << addrs.size() << " block(s)"
                      << std::endl;
        }
    }
};

int main() {
    BuddyAllocator alloc;

    // Simulate memory management
    void* p1 = alloc.allocate(64);
    void* p2 = alloc.allocate(128);
    void* p3 = alloc.allocate(32);

    alloc.deallocate(p1, 64);
    alloc.deallocate(p3, 32);

    void* p4 = alloc.allocate(48);
    void* p5 = alloc.allocate(256);

    alloc.deallocate(p2, 128);
    alloc.deallocate(p4, 48);
    alloc.deallocate(p5, 256);

    alloc.printStats();

    return 0;
}
```

   - Store timed tasks in a red-black tree keyed by execution time
   - Support adding tasks, cancelling tasks, and fetching the next task to run
   - Simulate the task scheduling process

3. Advanced: Implement interval search on a red-black tree (an interval tree).
   - Add a "maximum endpoint in subtree" field to each red-black tree node
   - Support inserting intervals, deleting intervals, and finding all intervals

   - Support sum(low, high), returning the sum of values whose key is in the range
   - Time complexity O(log n)

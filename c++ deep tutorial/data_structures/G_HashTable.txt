## Chapter Overview

A Hash Table (also called a hash map) is a data structure that accesses storage
locations directly by key. It uses a hash function to map a key to a position in an
array, giving insertion, deletion and lookup an average time complexity of O(1).

The hash table is the underlying implementation of the C++11 containers unordered_map,
unordered_set, unordered_multimap and unordered_multiset. It is widely used in caching
systems, database indexes, cryptography, compiler design and many other fields.

1.1 Basic Concepts of Hash Tables
-----------------------

Core components of a hash table:
- Hash function: maps keys of any size to integers in a fixed range (array indices)
- Array (buckets): contiguous memory that stores the key-value pairs
- Collision resolution: the strategy for handling different keys that map to the same position

The simplest hash table example (using the standard library):

```cpp
#include <iostream>
#include <unordered_map>
#include <unordered_set>
#include <string>

int main() {
    // unordered_map (hash table)
    std::unordered_map<std::string, int> phone_book;

    phone_book["Alice"] = 123456;
    phone_book["Bob"] = 789012;
    phone_book["Charlie"] = 345678;

    std::cout << "Alice's phone number: " << phone_book["Alice"] << std::endl;

    // Lookup
    auto it = phone_book.find("David");
    if (it == phone_book.end()) {
        std::cout << "David is not in the phone book" << std::endl;
    }

    // unordered_set (hash set)
    std::unordered_set<int> numbers = {3, 1, 4, 1, 5, 9};

    numbers.insert(2);
    numbers.erase(1);

    if (numbers.find(4) != numbers.end()) {
        std::cout << "4 is in the set" << std::endl;
    }

    return 0;
}
```

1.2 How Hash Tables Work Internally
-----------------------

Key design points of a hash table:

(1) Choosing the hash function
A good hash function should be:
- Fast to compute
- Uniformly distributed (spreads keys evenly over the whole table)
- Deterministic (the same key always produces the same hash value)

```cpp
#include <iostream>
#include <functional>

int main() {
    // C++ standard hash functions
    std::hash<int> int_hash;
    std::hash<std::string> str_hash;
    std::hash<double> double_hash;

    std::cout << "hash(42) = " << int_hash(42) << std::endl;
    std::cout << "hash(\"hello\") = " << str_hash("hello") << std::endl;
    std::cout << "hash(3.14) = " << double_hash(3.14) << std::endl;

    // Take the modulus to get an array index
    size_t table_size = 100;
    size_t index = int_hash(42) % table_size;
    std::cout << "Bucket index of 42: " << index << std::endl;

    return 0;
}
```

(2) Collision resolution: Separate Chaining
Each bucket maintains a linked list (or another data structure); colliding key-value
pairs are placed in the same bucket's list.

```
Bucket array:
+------+
| idx0 | --> nullptr
+------+
| idx1 | --> [key1, val1] --> [key4, val4] --> nullptr (collision chain)
+------+
| idx2 | --> [key2, val2] --> nullptr
+------+
| idx3 | --> nullptr
+------+
| idx4 | --> [key3, val3] --> nullptr
+------+
```

(3) Collision resolution: Open Addressing
When a collision occurs, look for the next empty bucket. Common probing methods:
- Linear probing: index = (hash(key) + i) % table_size
- Quadratic probing: index = (hash(key) + i^2) % table_size
- Double hashing: index = (hash1(key) + i * hash2(key)) % table_size

1.3 Implementing a Hash Table by Hand (Separate Chaining)
-----------------------------------

```cpp
#include <iostream>
#include <vector>
#include <list>
#include <functional>

template<typename Key, typename Value>
class HashMap {
private:
    struct Entry {
        Key key;
        Value value;
        Entry(const Key& k, const Value& v) : key(k), value(v) {}
    };

    std::vector<std::list<Entry>> buckets;
    size_t num_elements;
    float max_load_factor;

    std::hash<Key> hasher;

    size_t getBucketIndex(const Key& key) const {
        return hasher(key) % buckets.size();
    }

    void rehash(size_t new_bucket_count) {
        std::vector<std::list<Entry>> old_buckets = std::move(buckets);
        buckets.resize(new_bucket_count);
        num_elements = 0;

        for (auto& bucket : old_buckets) {
            for (auto& entry : bucket) {
                insert(entry.key, entry.value);
            }
        }
    }

public:
    HashMap(size_t initial_size = 16)
        : buckets(initial_size), num_elements(0), max_load_factor(0.75) {}

    void insert(const Key& key, const Value& value) {
        // Check the load factor and grow if needed
        if ((float)(num_elements + 1) / buckets.size() > max_load_factor) {
            rehash(buckets.size() * 2);
        }

        size_t index = getBucketIndex(key);
        auto& bucket = buckets[index];

        // Check whether the key already exists
        for (auto& entry : bucket) {
            if (entry.key == key) {
                entry.value = value;  // update
                return;
            }
        }

        bucket.emplace_back(key, value);
        ++num_elements;
    }

    bool find(const Key& key, Value& out_value) const {
        size_t index = getBucketIndex(key);
        const auto& bucket = buckets[index];

        for (const auto& entry : bucket) {
            if (entry.key == key) {
                out_value = entry.value;
                return true;
            }
        }
        return false;
    }

    Value& operator[](const Key& key) {
        size_t index = getBucketIndex(key);
        auto& bucket = buckets[index];

        for (auto& entry : bucket) {
            if (entry.key == key) {
                return entry.value;
            }
        }

        // The key does not exist: insert a default value
        if ((float)(num_elements + 1) / buckets.size() > max_load_factor) {
            rehash(buckets.size() * 2);
            index = getBucketIndex(key);
        }

        buckets[index].emplace_back(key, Value{});
        ++num_elements;
        return buckets[index].back().value;
    }

    bool erase(const Key& key) {
        size_t index = getBucketIndex(key);
        auto& bucket = buckets[index];

        for (auto it = bucket.begin(); it != bucket.end(); ++it) {
            if (it->key == key) {
                bucket.erase(it);
                --num_elements;
                return true;
            }
        }
        return false;
    }

    size_t size() const { return num_elements; }
    bool empty() const { return num_elements == 0; }

    void print() const {
        std::cout << "Hash table (size=" << num_elements
                  << ", buckets=" << buckets.size() << "):" << std::endl;
        for (size_t i = 0; i < buckets.size(); ++i) {
            if (!buckets[i].empty()) {
                std::cout << "  bucket[" << i << "]: ";
                for (const auto& entry : buckets[i]) {
                    std::cout << "[" << entry.key << ":" << entry.value << "] ";
                }
                std::cout << std::endl;
            }
        }
    }
};

int main() {
    HashMap<std::string, int> scores(8);

    scores["Alice"] = 95;
    scores["Bob"] = 87;
    scores["Charlie"] = 92;
    scores["David"] = 78;
    scores["Eve"] = 90;

    scores.print();

    int score;
    if (scores.find("Bob", score)) {
        std::cout << "Bob's score: " << score << std::endl;
    }

    scores.erase("David");
    std::cout << "After removing David: ";
    scores.print();

    return 0;
}
```

1.4 Time and Space Complexity of Hash Tables
---------------------------------------

| Operation | Average   | Worst     |
|-----------|-----------|-----------|
| Insert    | O(1)      | O(n)      |
| Delete    | O(1)      | O(n)      |
| Lookup    | O(1)      | O(n)      |
| Traverse  | O(n)      | O(n)      |

Space complexity: O(n + bucket_count)

The worst case happens when every key maps to the same bucket (a hash collision attack).
The standard library avoids this with good hash functions and dynamic resizing.

1.5 Designing Hash Functions
---------------------

```cpp
#include <iostream>
#include <string>
#include <functional>

// Custom hash function example
struct Student {
    std::string name;
    int id;
    int grade;

    bool operator==(const Student& other) const {
        return id == other.id;
    }
};

// Approach 1: a custom hash function object
struct StudentHash {
    size_t operator()(const Student& s) const {
        // Combine several std::hash values
        return std::hash<std::string>()(s.name) ^
               (std::hash<int>()(s.id) << 1) ^
               (std::hash<int>()(s.grade) << 2);
    }
};

// Approach 2: specialize std::hash
namespace std {
    template<>
    struct hash<Student> {
        size_t operator()(const Student& s) const {
            return hash<int>()(s.id);
        }
    };
}

// A common string hash function: BKDR Hash
size_t bkdrHash(const std::string& str) {
    size_t hash = 0;
    size_t seed = 131;  // 31, 131, 1313, 13131, 131313
    for (char c : str) {
        hash = hash * seed + c;
    }
    return hash;
}

int main() {
    std::cout << "BKDR hash \"hello\": " << bkdrHash("hello") << std::endl;
    std::cout << "BKDR hash \"world\": " << bkdrHash("world") << std::endl;

    // Use the custom hash function
    std::unordered_set<Student, StudentHash> students;
    students.insert({"Alice", 1001, 3});
    students.insert({"Bob", 1002, 2});

    std::cout << "Number of students: " << students.size() << std::endl;

    return 0;
}
```

2.1 std::unordered_map
--------------------------

```cpp
#include <iostream>
#include <unordered_map>
#include <string>

int main() {
    // Construction
    std::unordered_map<std::string, int> m1;
    std::unordered_map<std::string, int> m2 = {
        {"apple", 5}, {"banana", 3}, {"cherry", 8}
    };

    // Insertion
    m1["date"] = 2;                          // operator[]
    m1.insert({"elderberry", 4});            // insert a pair
    m1.emplace("fig", 6);                    // in-place construction
    m1.insert({{"grape", 7}, {"honeydew", 1}});  // bulk insert

    // Access
    std::cout << "apple: " << m2["apple"] << std::endl;
    std::cout << "banana: " << m2.at("banana") << std::endl;
    // m2.at("unknown");  // throws out_of_range

    // Lookup
    auto it = m2.find("cherry");
    if (it != m2.end()) {
        std::cout << "Found: " << it->first << " -> " << it->second << std::endl;
    }

    // Counting
    std::cout << "Occurrences of apple: " << m2.count("apple") << std::endl;

    // Deletion
    m2.erase("banana");

    // Bucket interface
    std::cout << "Bucket count: " << m2.bucket_count() << std::endl;
    std::cout << "Load factor: " << m2.load_factor() << std::endl;
    std::cout << "Max load factor: " << m2.max_load_factor() << std::endl;

    // Number of elements in each bucket
    for (size_t i = 0; i < m2.bucket_count(); ++i) {
        std::cout << "Bucket " << i << ": " << m2.bucket_size(i) << " element(s)"
                  << std::endl;
    }

    // Rehashing
    m2.rehash(100);      // set the bucket count
    m2.reserve(200);     // reserve space (sets the bucket count so the load factor stays reasonable)

    // Traversal
    for (const auto& [key, value] : m2) {
        std::cout << key << " -> " << value << std::endl;
    }

    return 0;
}
```

2.2 std::unordered_set

```cpp
#include <iostream>
#include <unordered_set>
#include <string>

int main() {
    std::unordered_set<int> s = {5, 3, 1, 3, 2, 5};

    // Insertion
    auto [it, inserted] = s.insert(4);
    std::cout << "Insert 4: " << (inserted ? "succeeded" : "already exists") << std::endl;

    std::tie(it, inserted) = s.insert(3);
    std::cout << "Insert 3: " << (inserted ? "succeeded" : "already exists") << std::endl;

    // Bulk insertion
    s.insert({7, 8, 9});

    // Deletion
    s.erase(1);

    // Lookup
    if (s.find(5) != s.end()) {
        std::cout << "5 is in the set" << std::endl;
    }

    // Bucket interface
    std::cout << "Bucket count: " << s.bucket_count() << std::endl;
    std::cout << "Load factor: " << s.load_factor() << std::endl;

    // See which bucket an element is in
    for (int x : {4, 5, 7}) {
        std::cout << x << " is in bucket " << s.bucket(x) << std::endl;
    }

    // Traversal (unordered)
    for (int x : s) std::cout << x << " ";
    std::cout << std::endl;

    return 0;
}
```

2.3 Custom Hashing and Equality
--------------------------

```cpp
#include <iostream>
#include <unordered_map>
#include <unordered_set>
#include <string>

struct Person {
    std::string first_name;
    std::string last_name;
    int age;

    bool operator==(const Person& other) const {
        return first_name == other.first_name &&
               last_name == other.last_name &&
               age == other.age;
    }
};

// Combined hash function
struct PersonHash {
    size_t operator()(const Person& p) const {
        size_t h1 = std::hash<std::string>()(p.first_name);
        size_t h2 = std::hash<std::string>()(p.last_name);
        size_t h3 = std::hash<int>()(p.age);

        // Follows the idea behind boost's hash_combine
        return h1 ^ (h2 << 7) ^ (h3 << 15) ^ (h2 >> 3) ^ (h3 >> 5);
    }
};

int main() {
    std::unordered_set<Person, PersonHash> people;

    people.insert({"Alice", "Smith", 25});
    people.insert({"Bob", "Jones", 30});
    people.insert({"Alice", "Smith", 25});  // duplicate, will not be inserted

    std::cout << "Number of people: " << people.size() << std::endl;

    // Default values (used by operator[])
    std::unordered_map<std::string, int> word_count;
    word_count["hello"]++;  // if hello doesn't exist, insert {hello, 0} and then ++
    word_count["world"]++;
    word_count["hello"]++;
    // Counting relies on operator[] default-constructing missing values

    for (const auto& [word, count] : word_count) {
        std::cout << word << ": " << count << std::endl;
    }

    return 0;
}
```

```cpp
#include <iostream>
#include <unordered_map>
#include <map>
#include <vector>
#include <string>

// Performance comparison: unordered_map vs map
int main() {
    const int N = 100000;

    std::unordered_map<int, int> umap;
    std::map<int, int> rbtree;

    // Compare insertion performance
    auto start = std::chrono::high_resolution_clock::now();
    for (int i = 0; i < N; ++i) {
        umap[i] = i * 2;
    }
    auto umap_time = std::chrono::high_resolution_clock::now() - start;

    start = std::chrono::high_resolution_clock::now();
    for (int i = 0; i < N; ++i) {
        rbtree[i] = i * 2;
    }
    auto rbtree_time = std::chrono::high_resolution_clock::now() - start;

    std::cout << "unordered_map inserting " << N << " elements: "
              << std::chrono::duration_cast<std::chrono::milliseconds>(
                     umap_time).count() << "ms" << std::endl;
    std::cout << "map inserting " << N << " elements: "
              << std::chrono::duration_cast<std::chrono::milliseconds>(
                     rbtree_time).count() << "ms" << std::endl;

    return 0;
}
```

Example 1: Caching System (Hash Table Implementation of an LRU Cache)
---------------------------------------------------

```cpp
#include <iostream>
#include <unordered_map>
#include <list>
#include <string>

class LRUCache {
private:
    int capacity;
    std::list<std::pair<std::string, std::string>> items;
    std::unordered_map<std::string,
                       std::list<std::pair<std::string, std::string>>::iterator>
        cache;

public:
    LRUCache(int cap) : capacity(cap) {}

    std::string get(const std::string& key) {
        auto it = cache.find(key);
        if (it == cache.end()) return "";

        // Move to the front (most recently used)
        items.splice(items.begin(), items, it->second);
        return it->second->second;
    }

    void put(const std::string& key, const std::string& value) {
        auto it = cache.find(key);
        if (it != cache.end()) {
            it->second->second = value;
            items.splice(items.begin(), items, it->second);
            return;
        }

        if (items.size() >= capacity) {
            // Evict the least recently used entry
            std::string old_key = items.back().first;
            cache.erase(old_key);
            items.pop_back();
        }

        items.emplace_front(key, value);
        cache[key] = items.begin();
    }

    void print() const {
        std::cout << "Cache (most recent -> least recent): ";
        for (const auto& [k, v] : items) {
            std::cout << "[" << k << ":" << v << "] ";
        }
        std::cout << std::endl;
    }
};

int main() {
    LRUCache cache(3);

    cache.put("A", "Apple");
    cache.put("B", "Banana");
    cache.put("C", "Cherry");
    cache.print();

    std::cout << "get(B): " << cache.get("B") << std::endl;
    cache.print();

    cache.put("D", "Date");  // evicts A, the least recently used
    cache.print();

    cache.put("E", "Elderberry");  // evicts C, the least recently used
    cache.print();

    return 0;
}
```


Example 2: Word Frequency Counter
-------------------------

```cpp
#include <iostream>
#include <unordered_map>
#include <string>
#include <sstream>
#include <vector>
#include <algorithm>

class WordCounter {
private:
    std::unordered_map<std::string, int> frequency;

public:
    void processText(const std::string& text) {
        std::istringstream iss(text);
        std::string word;

        while (iss >> word) {
            // Strip punctuation
            word.erase(std::remove_if(word.begin(), word.end(),
                         [](char c) { return std::ispunct(c); }),
                       word.end());

            // Convert to lowercase
            std::transform(word.begin(), word.end(), word.begin(),
                           [](char c) { return std::tolower(c); });

            if (!word.empty()) {
                ++frequency[word];  // automatically initialized to 0, then ++
            }
        }
    }

    int getCount(const std::string& word) const {
        auto it = frequency.find(word);
        return it != frequency.end() ? it->second : 0;
    }

    std::vector<std::pair<std::string, int>> getTopK(int k) const {
        std::vector<std::pair<std::string, int>> sorted(
            frequency.begin(), frequency.end());

        std::partial_sort(sorted.begin(),
                          sorted.begin() + std::min(k, (int)sorted.size()),
                          sorted.end(),
                          [](const auto& a, const auto& b) {
                              return a.second > b.second;
                          });

        if (sorted.size() > (size_t)k) sorted.resize(k);
        return sorted;
    }

    void printAll() const {
        std::vector<std::pair<std::string, int>> items(
            frequency.begin(), frequency.end());
        std::sort(items.begin(), items.end(),
                  [](const auto& a, const auto& b) {
                      return a.second > b.second;
                  });

        for (const auto& [word, count] : items) {
            std::cout << word << ": " << count << std::endl;
        }
    }
};

int main() {
    WordCounter wc;

    std::string text =
        "The quick brown fox jumps over the lazy dog. "
        "The dog barks at the fox. "
        "The quick brown fox is quick and brown.";

    wc.processText(text);

    std::cout << "=== Word Frequencies ===" << std::endl;
    wc.printAll();

    std::cout << "\n=== Top 5 ===" << std::endl;
    for (const auto& [word, count] : wc.getTopK(5)) {
        std::cout << word << ": " << count << std::endl;
    }

    return 0;
}
```


Example 3: Web Crawler with URL Deduplication
-------------------------

```cpp
#include <iostream>
#include <unordered_set>
#include <string>
#include <queue>
#include <vector>

class WebCrawler {
private:
    std::unordered_set<std::string> visited_urls;
    std::queue<std::string> url_queue;

    // Simulate extracting links from a page
    std::vector<std::string> extractLinks(const std::string& url) {
        // A real crawler would parse the HTML
        return {
            url + "/page1",
            url + "/page2",
            url + "/page3"
        };
    }

public:
    void crawl(const std::string& start_url, int max_pages = 10) {
        url_queue.push(start_url);

        while (!url_queue.empty() && visited_urls.size() < (size_t)max_pages) {
            std::string url = url_queue.front();
            url_queue.pop();

            // Check whether it has already been visited (O(1))
            if (visited_urls.find(url) != visited_urls.end()) {
                continue;
            }

            visited_urls.insert(url);
            std::cout << "Crawling: " << url
                      << " (visited: " << visited_urls.size() << ")"
                      << std::endl;

            // Extract links
            for (const auto& link : extractLinks(url)) {
                if (visited_urls.find(link) == visited_urls.end()) {
                    url_queue.push(link);
                }
            }
        }

        std::cout << "\nCrawl complete! Visited " << visited_urls.size() << " pages in total"
                  << std::endl;
    }

    bool hasVisited(const std::string& url) const {
        return visited_urls.find(url) != visited_urls.end();
    }
};

int main() {
    WebCrawler crawler;
    crawler.crawl("https://example.com", 8);

    std::cout << "\nHas example.com/page1 been visited? "
              << (crawler.hasVisited("https://example.com/page1") ? "Yes" : "No")
              << std::endl;

    return 0;
}
```
